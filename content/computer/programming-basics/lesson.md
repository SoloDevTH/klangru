## จากอัลกอริทึมสู่โปรแกรม

อัลกอริทึมที่เขียนด้วยรหัสลำลองยังเป็นภาษาของคน ถ้าจะให้คอมพิวเตอร์ทำงานจริง ต้องเขียนเป็น **โปรแกรม** ด้วยภาษาที่เครื่องอ่านได้ บทนี้ใช้ภาษา **Python** ซึ่งอ่านง่ายและใช้กันแพร่หลาย ทั้งในโรงเรียนและงานจริง

คำสั่งแรกที่ควรรู้คือ `print(...)` ซึ่งแสดงค่าในวงเล็บออกทางหน้าจอ

```python
print("สวัสดี")   # แสดงข้อความ สวัสดี
print(3 + 4)       # แสดง 7
```

ข้อความหลังเครื่องหมาย `#` เป็น **คอมเมนต์** ไว้อธิบายให้คนอ่าน คอมพิวเตอร์ไม่ทำตาม

## ตัวแปร: กล่องที่มีชื่อ

**ตัวแปร** คือชื่อที่ใช้เก็บค่าไว้ใช้ภายหลัง ให้นึกถึงกล่องที่มีป้ายชื่อตามภาพ เราสร้างหรือเปลี่ยนค่าด้วยเครื่องหมาย `=` ซึ่งเรียกว่า **การกำหนดค่า** โดยคำนวณค่าทางขวาก่อน แล้วจึงเก็บลงในชื่อทางซ้าย

```python
coins = 10
coins = coins + 5   # ค่าทางขวาคือ 15 แล้วเก็บกลับลง coins
print(coins)        # 15
```

ตัวแปรเก็บได้ทีละค่า ค่าใหม่จะแทนค่าเดิม ชื่อตัวแปรใช้ตัวอักษรอังกฤษ ตัวเลข และ `_` ได้ แต่ห้ามขึ้นต้นด้วยตัวเลข ห้ามมีช่องว่าง และห้ามซ้ำกับคำสงวนอย่าง `for` หรือ `if` ควรตั้งชื่อให้บอกความหมาย เช่น `total_price` ดีกว่า `x`

### ชนิดข้อมูลที่ใช้บ่อย

- `int` จำนวนเต็ม เช่น `75`
- `float` จำนวนทศนิยม เช่น `12.5`
- `str` ข้อความ เขียนในเครื่องหมายคำพูด เช่น `"Mali"` หรือ `"5"`
- `bool` ค่าความจริง `True` หรือ `False`

ชนิดข้อมูลมีผลต่อผลลัพธ์ `5 + 3` ได้ `8` แต่ `"5" + "3"` คือการต่อข้อความ ได้ `"53"` และคำสั่ง `input()` ที่รับค่าจากแป้นพิมพ์จะคืนค่าเป็นข้อความเสมอ ต้องแปลงด้วย `int(...)` ก่อนนำไปคำนวณ

### ตัวดำเนินการทางคณิตศาสตร์

| เครื่องหมาย | ความหมาย | ตัวอย่าง | ผล |
|---|---|---|---|
| `+ - *` | บวก ลบ คูณ | `4 * 3` | `12` |
| `/` | หาร (ได้ทศนิยม) | `17 / 5` | `3.4` |
| `//` | หารแล้วปัดเศษทิ้ง | `17 // 5` | `3` |
| `%` | เศษจากการหาร | `17 % 5` | `2` |
| `**` | ยกกำลัง | `2 ** 3` | `8` |

`%` มีประโยชน์มาก เช่น `n % 2 == 0` ใช้ตรวจว่า n เป็นจำนวนคู่

## เงื่อนไข: if, elif, else

โปรแกรมเลือกทางได้ด้วยคำสั่ง `if` คำสั่งที่อยู่ภายในต้อง **ย่อหน้า** (นิยมใช้ 4 ช่องว่าง) Python ใช้การย่อหน้าบอกว่าคำสั่งใดอยู่ในเงื่อนไข

ตัวเปรียบเทียบ: `==` เท่ากับ, `!=` ไม่เท่ากับ, `>`, `<`, `>=`, `<=` ระวังอย่าสับสน `==` (เปรียบเทียบ) กับ `=` (กำหนดค่า) และรวมเงื่อนไขได้ด้วย `and` (จริงเมื่อจริงทั้งคู่), `or` (จริงเมื่อจริงอย่างน้อยหนึ่ง), `not` (กลับค่าความจริง)

เมื่อมีหลายทาง ใช้ `elif` ต่อกัน Python ตรวจจากบนลงล่าง และทำ **เฉพาะทางแรกที่เป็นจริง** แล้วข้ามที่เหลือทั้งหมด

## การวนซ้ำ: for และ while

`for` ใช้เมื่อรู้จำนวนรอบ มักใช้คู่กับ `range`

- `range(4)` ให้ 0, 1, 2, 3 (4 รอบ)
- `range(1, 5)` ให้ 1, 2, 3, 4 **ไม่รวม 5**
- `range(10, 0, -3)` ให้ 10, 7, 4, 1 (ตัวที่สามคือระยะก้าว)

`for` ยังไล่สมาชิกของรายการได้ตรง ๆ เช่น `for price in [120, 80]:`

`while` ใช้เมื่อไม่รู้จำนวนรอบล่วงหน้า แต่รู้เงื่อนไขที่ต้องทำต่อ โปรแกรมตรวจเงื่อนไขก่อนทุกรอบ และต้องมีคำสั่งในวงวนที่ทำให้เงื่อนไขกลายเป็นเท็จในที่สุด

**ตัวอย่าง: แบบแผนตัวสะสม** หาผลรวม 1 ถึง 10

```python
total = 0                 # ค่าเริ่มต้นของตัวสะสม
for i in range(1, 11):    # i = 1, 2, ..., 10
    total = total + i
print(total)              # 55
```

ถ้าเลื่อน `print(total)` ไปย่อหน้าอยู่ในวงวน โปรแกรมจะแสดงผลรวมสะสมทุกรอบ 10 บรรทัดแทนที่จะแสดงครั้งเดียว ตำแหน่งการย่อหน้าจึงเปลี่ยนความหมายของโปรแกรม

## ข้อผิดพลาดของโปรแกรม

- **ข้อผิดพลาดทางไวยากรณ์ (syntax error)** เช่น ลืม `:` หลัง `if` หรือย่อหน้าไม่ตรงกัน Python จะแจ้งทันทีและไม่ยอมทำงาน
- **ข้อผิดพลาดทางตรรกะ (logic error)** โปรแกรมทำงานได้แต่ผลผิด เช่น ใช้ `range(1, 10)` ทั้งที่ต้องการถึง 10 วิธีหาคือไล่โปรแกรมกับข้อมูลที่รู้คำตอบ หรือแทรก `print` ดูค่าตัวแปรระหว่างทาง

การ **ทดสอบ** ที่ดีเลือกข้อมูลหลายแบบ: ค่าปกติ ค่าที่อยู่บนขอบของเงื่อนไขพอดี และค่าที่อยู่สองข้างของขอบ เช่น เงื่อนไข `score >= 50` ควรลอง 49, 50 และ 51 เพราะความผิดอย่างใช้ `>` แทน `>=` จะเห็นได้ที่ 50 เท่านั้น

## ข้อผิดพลาดที่พบบ่อย

- **ลืมว่า `range` ไม่รวมตัวสุดท้าย** `range(1, 5)` วนแค่ 4 รอบ
- **คิดว่า elif ทำทุกทางที่จริง** ทำเฉพาะทางแรกที่จริงเท่านั้น
- **ต่อข้อความแทนการบวก** `"5" + "3"` ได้ `"53"` ไม่ใช่ `8`
- **สับสน `/`, `//` และ `%`** `17 / 5 = 3.4`, `17 // 5 = 3`, `17 % 5 = 2`
- **ใช้ `and` แทน `or`** "หาร 3 หรือ 5 ลงตัว" ต้องใช้ `or` ถ้าใช้ `and` จะได้เฉพาะตัวที่หารลงตัวทั้งคู่
