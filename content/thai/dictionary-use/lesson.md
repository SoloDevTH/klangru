## เจอคำที่ไม่รู้ความหมาย ทำอย่างไรดี

น้องอ่านนิทานแล้วเจอคำว่า "ขยัน" ไม่แน่ใจว่าแปลว่าอะไร และอ่านอย่างไร เครื่องมือที่ช่วยได้คือ **พจนานุกรม** ซึ่งรวบรวมคำ บอกวิธีอ่าน ชนิดของคำ และความหมาย พจนานุกรมที่ใช้เป็นหลักในประเทศไทยคือ **พจนานุกรมฉบับราชบัณฑิตยสถาน** ฉบับปี พ.ศ. 2554 ค้นออนไลน์ได้ที่เว็บไซต์ของสำนักงานราชบัณฑิตยสภา

## คำในพจนานุกรมเรียงอย่างไร

คำเรียงตามลำดับที่แน่นอน ถ้ารู้ลำดับ จะเปิดหาได้เร็ว

### 1. ดูพยัญชนะต้นก่อน

เรียงตามพยัญชนะ **ก ข ฃ ค ฅ ฆ ง ... อ ฮ** คำที่ขึ้นต้นด้วย ก อยู่ก่อน ข เสมอ

**สระหน้า** (เ แ โ ใ ไ) ไม่นับเป็นตัวแรก ให้ดูพยัญชนะที่ตามมา เช่น "เงิน" อยู่ในหมวด **ง** ไม่ใช่หมวด เ และ "ไก่" อยู่ในหมวด **ก**

### 2. พยัญชนะต้นเหมือนกัน ดูตัวถัดไป

- คำที่ตัวถัดไปเป็น **พยัญชนะ** (ไม่มีรูปสระ) มา **ก่อน** คำที่มีรูปสระ
- ถ้าเป็นสระ เรียงตามลำดับนี้

> ะ ั า ำ ิ ี ึ ื ุ ู เ แ โ ใ ไ

ตัวอย่างหมวด ก: **กบ → กอด → กะทิ → กา → กิน → เกม**

- กบ มาก่อน กอด เพราะ บ อยู่ก่อน อ ในลำดับพยัญชนะ
- กอด มาก่อน กะทิ เพราะ อ เป็นพยัญชนะ ส่วน ะ เป็นสระ
- เกม อยู่ท้าย เพราะสระ เ อยู่ท้ายลำดับสระ

### 3. ต่างกันแค่วรรณยุกต์

คำที่ไม่มีรูปวรรณยุกต์มาก่อน แล้วจึงเรียง **่ ้ ๊ ๋** เช่น **ขา → ข่า → ข้า** วรรณยุกต์ใช้ตัดสินเฉพาะเมื่อตัวอื่นเหมือนกันหมด เช่น ป้า อยู่ก่อน ปาก เพราะ ป้า สั้นกว่า (ป า) ส่วน ปาก มี ก ต่อท้าย

### 4. ฤ ฤๅ ฦ ฦๅ

**ฤ ฤๅ** เรียงต่อจากหมวด ร และ **ฦ ฦๅ** เรียงต่อจากหมวด ล เช่น "ฤดู" อยู่หลัง "เรือ" แต่ก่อน "ลม"

## อ่านคำอธิบายศัพท์

ดูหน้าพจนานุกรมจำลองในภาพด้านบน แต่ละคำมีส่วนต่าง ๆ

| ส่วน | หน้าที่ | ตัวอย่าง |
|---|---|---|
| **คำนำทาง** | คำแรกและคำสุดท้ายของหน้า พิมพ์ที่หัวกระดาษ | ขนม … ขยัน |
| **คำตั้ง** | คำที่เราค้น พิมพ์ตัวหนา | ขยัน |
| **คำอ่าน** | บอกวิธีอ่านในวงเล็บเหลี่ยม | [ขะ-หยัน] |
| **ชนิดของคำ** | อักษรย่อ | ว. |
| **ความหมาย** | คำอธิบายและตัวอย่างประโยค | ตั้งใจทำงานสม่ำเสมอ |

**คำนำทาง** ช่วยให้รู้ทันทีว่าคำที่หาอยู่หน้านี้หรือไม่ เช่น หน้าที่มีคำนำทาง "ขนม … ขยัน" จะมีคำว่า "ขนุน" แน่นอน เพราะ ขนุน อยู่ระหว่าง ขนม กับ ขยัน

ในพจนานุกรมจริง คำอ่านใช้เครื่องหมายพินทุ ( ฺ ) ช่วย เช่น ขยัน [ขะหฺยัน] บทนี้ใช้ขีดคั่นพยางค์แทนเพื่อให้อ่านง่าย

### อักษรย่อชนิดของคำ

| อักษรย่อ | ชนิด | อักษรย่อ | ชนิด |
|---|---|---|---|
| น. | นาม | บ. | บุพบท |
| ส. | สรรพนาม | สัน. | สันธาน |
| ก. | กริยา | อ. | อุทาน |
| ว. | วิเศษณ์ | | |

บางคำมีวงเล็บบอก **ที่มา** เช่น (ป.) บาลี (ส.) สันสกฤต (อ.) อังกฤษ หรือบอก **ลักษณะการใช้** เช่น (ปาก) คือภาษาปาก ระวังอย่าสับสน **ส.** ที่ไม่มีวงเล็บ (สรรพนาม) กับ **(ส.)** ในวงเล็บ (สันสกฤต)

## เลือกความหมายให้ตรงกับบริบท

คำหนึ่งอาจมีหลายความหมาย พจนานุกรมใส่ **เลข ๑ ๒ ๓** กำกับ ดูตัวอย่างคำว่า "ขัน"

- ขัน ๑ น. ภาชนะตักน้ำ
- ขัน ๒ ก. ร้องอย่างไก่ตัวผู้
- ขัน ๓ ก. หมุนให้แน่น
- ขัน ๔ ว. น่าหัวเราะ

วิธีเลือก

1. อ่านประโยคที่พบคำนั้น
2. ดูว่าคำนั้นทำหน้าที่อะไร เป็นชื่อสิ่งของ (นาม) การกระทำ (กริยา) หรือขยาย (วิเศษณ์)
3. ลองนำความหมายแต่ละข้อไปแทนในประโยค ข้อที่อ่านแล้วเข้าใจคือข้อที่ถูก

"พ่อ**ขัน**ฝาขวดให้แน่น" → ขัน เป็นการกระทำ แทนด้วย "หมุนให้แน่น" ได้ความ จึงเป็น **ขัน ๓**

## ข้อผิดพลาดที่พบบ่อย

- **หาคำที่มีสระหน้าใต้ตัวสระ** เช่น หา "เงิน" ใต้ เ ที่ถูกคือหาใต้ ง
- **คิดว่าสระมาก่อนพยัญชนะ** ที่จริงคำที่ตัวถัดไปเป็นพยัญชนะมาก่อน เช่น กอด มาก่อน กะทิ
- **ลืมว่า อ เป็นพยัญชนะ** นอน จึงอยู่ก่อน นา
- **เลือกความหมายข้อแรกเสมอ** ต้องดูบริบทและชนิดของคำ
- **อ่านคำตามตัวเขียน** โดยไม่ดูคำอ่าน เช่น อ่าน ขนม เป็น ขน-ม
