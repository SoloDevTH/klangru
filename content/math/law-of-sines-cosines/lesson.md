## วัดระยะที่เดินไปวัดไม่ได้

ช่างสำรวจต้องการรู้ระยะจากริมแม่น้ำฝั่งนี้ไปยังต้นไม้ฝั่งตรงข้าม เขาข้ามแม่น้ำไม่ได้ แต่วัดระยะบนฝั่งตัวเองและวัดมุมด้วยกล้องได้ สามเหลี่ยมที่เกิดขึ้นไม่มีมุมฉาก จึงใช้ [อัตราส่วนตรีโกณมิติ](/topic/math.geometry.trig-ratios/) ในสามเหลี่ยมมุมฉากโดยตรงไม่ได้ บทนี้มีเครื่องมือสองอย่างสำหรับ **สามเหลี่ยมใด ๆ** คือ กฎของไซน์และกฎของโคไซน์

**สัญลักษณ์** ในสามเหลี่ยม ABC ให้ $a$ เป็นความยาวด้านที่อยู่ **ตรงข้าม** มุม $A$ ทำนองเดียวกัน $b$ ตรงข้าม $B$ และ $c$ ตรงข้าม $C$

## ไซน์และโคไซน์ของมุมป้าน

สามเหลี่ยมใด ๆ อาจมีมุมป้าน จึงต้องรู้ค่าตรีโกณมิติของมุมระหว่าง 90° กับ 180° ซึ่งนิยามด้วยพิกัดของจุดบนวงกลมหนึ่งหน่วย (จะเรียนละเอียดในเรื่องฟังก์ชันตรีโกณมิติ) สิ่งที่ใช้ในบทนี้คือ

$$\sin(180° - \theta) = \sin\theta \qquad \cos(180° - \theta) = -\cos\theta$$

เช่น $\sin 150° = \sin 30° = \tfrac12$ แต่ $\cos 120° = -\cos 60° = -\tfrac12$ โคไซน์ของมุมป้านจึงเป็นลบ และ $\cos 90° = 0$

## พื้นที่สามเหลี่ยม $\tfrac12 ab\sin C$

ลากส่วนสูง $h$ จาก A ตั้งฉากกับ BC (ดูภาพ) ในสามเหลี่ยมมุมฉาก ADC จะได้ $h = b\sin C$ จึง

$$\text{พื้นที่} = \tfrac12 \times \text{ฐาน} \times \text{สูง} = \tfrac12 ab\sin C$$

ใช้ได้เมื่อรู้ด้านสองด้านและ **มุมที่อยู่ระหว่างด้านทั้งสอง** ถ้า C เป็นมุมป้าน ส่วนสูงตกนอกฐาน แต่ $\sin C = \sin(180° - C)$ สูตรจึงยังใช้ได้

## กฎของไซน์

ส่วนสูง $h$ เดียวกันเขียนได้สองแบบ: จากสามเหลี่ยม ABD ได้ $h = c\sin B$ และจากสามเหลี่ยม ADC ได้ $h = b\sin C$ จึง $c\sin B = b\sin C$ หารด้วย $\sin B\sin C$ แล้วทำซ้ำกับส่วนสูงอีกเส้น ได้

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$$

ใช้เมื่อรู้ **มุมกับด้านที่อยู่ตรงข้ามกันหนึ่งคู่** และรู้อีกหนึ่งค่า เช่น มุมสองมุมกับด้านหนึ่งด้าน (ม.ม.ด. หรือ ม.ด.ม. หามุมที่สามจาก 180° ก่อน)

## กฎของโคไซน์

วางสามเหลี่ยมบนระนาบพิกัดให้ C อยู่ที่จุดกำเนิด B อยู่ที่ $(a, 0)$ และ A อยู่ที่ $(b\cos C, b\sin C)$ ใช้สูตรระยะทางหา $c = AB$

$$c^2 = (b\cos C - a)^2 + (b\sin C)^2 = b^2(\cos^2 C + \sin^2 C) - 2ab\cos C + a^2$$

เพราะ $\cos^2 C + \sin^2 C = 1$ จึงได้

$$c^2 = a^2 + b^2 - 2ab\cos C$$

และในรูปอื่น $a^2 = b^2 + c^2 - 2bc\cos A$ ใช้เมื่อรู้ **ด้านสองด้านกับมุมระหว่าง** (ด.ม.ด.) เพื่อหาด้านที่สาม หรือรู้ **ด้านทั้งสาม** (ด.ด.ด.) เพื่อหามุม โดยจัดรูป

$$\cos C = \frac{a^2 + b^2 - c^2}{2ab}$$

เมื่อ $C = 90°$ จะได้ $\cos C = 0$ สูตรกลายเป็นทฤษฎีบทพีทาโกรัส ถ้า $\cos C$ เป็นลบ แปลว่า C เป็นมุมป้าน

## เลือกกฎให้ถูก

| สิ่งที่รู้ | เริ่มด้วย |
|---|---|
| มุมสองมุมกับด้านหนึ่งด้าน | กฎของไซน์ |
| ด้านสองด้านกับมุมระหว่าง | กฎของโคไซน์ (หาด้านที่สาม) |
| ด้านทั้งสาม | กฎของโคไซน์ (หามุม) |
| ด้านสองด้านกับมุมที่ไม่อยู่ระหว่าง | กฎของไซน์ แต่ระวังกรณีกำกวม |

**กรณีกำกวม (ด.ด.ม.)** เมื่อหามุมจาก $\sin B = k$ จะมีมุมแหลม $B_1$ และมุมป้าน $B_2 = 180° - B_1$ ที่ให้ค่าไซน์เท่ากัน ต้องตรวจว่ามุมป้านนั้นรวมกับมุมที่รู้แล้วยังน้อยกว่า 180° หรือไม่ จึงอาจได้สามเหลี่ยม 0, 1 หรือ 2 รูป

## การนำไปใช้

- **การสำรวจ** วัดเส้นฐานบนฝั่งที่เข้าถึงได้และวัดมุม แล้วใช้กฎของไซน์หาระยะข้ามแม่น้ำหรือความสูงของสิ่งที่เข้าไปใกล้ไม่ได้
- **การเดินเรือ** เรือเปลี่ยนทิศ ระยะจากจุดเริ่มต้นหาได้ด้วยกฎของโคไซน์ (ใช้ความรู้เรื่องแบริงหามุมภายในก่อน)
- **แรงลัพธ์** แรงสองแรงที่ทำมุม $\theta$ กันรวมกันเป็นเส้นทแยงมุมของรูปสี่เหลี่ยมด้านขนาน มุมภายในของสามเหลี่ยมคือ $180° - \theta$ จึงได้ $R^2 = F_1^2 + F_2^2 + 2F_1F_2\cos\theta$

## ข้อผิดพลาดที่พบบ่อย

- **จับคู่ด้านกับมุมผิด** ด้าน $a$ ต้องอยู่ตรงข้ามมุม $A$
- **ลืมเครื่องหมายลบ** หรือใช้มุมที่ไม่อยู่ระหว่างสองด้านในกฎของโคไซน์
- **คิดว่า $\cos$ ของมุมป้านเป็นบวก** $\cos 120° = -\tfrac12$
- **ลืมคำตอบที่สองในกรณีกำกวม** $\sin B = 0.8$ ได้ทั้ง $B \approx 53.1°$ และ $B \approx 126.9°$
- **เครื่องคิดเลขอยู่ในโหมดเรเดียน** ต้องตั้งเป็นองศา (DEG)
