## งานที่ต้องใช้คน เรียงตามลำดับ

1. สร้างรีโพ GitHub ของโครงการ แล้ว push โค้ดนี้ขึ้นไป (CI จะเริ่มทำงาน)
2. หาครูผู้เชี่ยวชาญตรวจเนื้อหาคณิตและฟิสิกส์ เปลี่ยนหัวข้อที่ผ่านเป็น `published` และใส่ `reviewed_by`
3. สร้างโปรเจกต์ Supabase, ตั้ง SMTP และอีเมลรหัส, deploy edge functions, ใส่คีย์ Anthropic
4. เขียนประกาศความเป็นส่วนตัวและให้ผู้รู้ PDPA ตรวจ (ADR 0007)
5. deploy เว็บ static (เช่น Cloudflare Pages หรือ GitHub Pages) และตั้ง `CONTENT_BASE_URL`
6. ทดสอบกับผู้เรียน 20 คน ปรับค่าตั้งต้นของระดับความชำนาญจากผล
7. สร้าง keystore, บัญชี Play Console, ส่ง internal testing
8. เมื่อมีผู้เรียนพอ: อ่านผล A/B และรัน calibrate
