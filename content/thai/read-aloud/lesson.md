## อ่านให้คนอื่นฟังเข้าใจ

ตอนเช้าครูให้น้องอ่านข่าวหน้าเสาธง ถ้าอ่านเสียงเบา อ่านผิดคำ หรือหยุดผิดที่ ผู้ฟังจะไม่เข้าใจ การ **อ่านออกเสียง** ที่ดีต้อง **ถูกต้อง** (ออกเสียงคำถูก) **คล่องแคล่ว** (ไม่ติดขัด) และ **เหมาะสมกับเรื่อง** (น้ำเสียงเข้ากับเนื้อหา)

> แอปนี้ฟังเสียงผู้เรียนไม่ได้ ให้ฝึกอ่านให้เพื่อนหรือผู้ปกครองฟัง หรืออัดเสียงตัวเองแล้วฟังซ้ำ โจทย์ในบทนี้ฝึกความรู้ที่ต้องใช้ตอนอ่าน

## เตรียมตัวก่อนอ่าน

1. **อ่านในใจก่อน** ให้รู้ว่าเรื่องเกี่ยวกับอะไร อารมณ์ของเรื่องเป็นอย่างไร
2. **หาคำยาก** และคำที่อ่านไม่ตรงรูป ถ้าไม่แน่ใจให้เปิดพจนานุกรมดูคำอ่าน
3. **แบ่งวรรคตอน** ขีดเส้นบอกจุดที่ควรหยุดหายใจ
4. **ฝึกอ่านออกเสียง** แล้วจึงอ่านจริง

ท่าทาง: ยืนหรือนั่งตัวตรง ถือหนังสือห่างจากตาพอดี เงยหน้าสบตาผู้ฟังเป็นระยะ

## ออกเสียงคำให้ถูก

- **ร ล ชัดเจน** เช่น รัก ไม่ใช่ ลัก · เรือ ไม่ใช่ เลือ
- **คำควบกล้ำ** ออกเสียงทั้งสองตัว เช่น ปลา กราบ ขวาน ครู (ไม่ใช่ ปา กาบ ขาน คู)
- **วรรณยุกต์ถูกเสียง** เช่น ค่ะ (ตอบรับ) กับ คะ (ถาม) ใช้ความรู้จากบท [การผันวรรณยุกต์](/topic/thai.writing.tone-rules/)

### คำที่อ่านไม่ตรงรูป

| คำ | อ่านว่า | เหตุผล |
|---|---|---|
| ตลาด | ตะ-หลาด | ล ออกเสียงตามอักษรนำ |
| สมุด | สะ-หมุด | อักษรนำ |
| จริง | จิง | ควบไม่แท้ ไม่ออกเสียง ร |
| ทราย | ซาย | ทร ออกเสียง ซ |
| ธรรมชาติ | ทำ-มะ-ชาด | รร ออกเสียง อำ และอ่านเชื่อมพยางค์ |
| ผลไม้ | ผน-ละ-ไม้ | ล ออกเสียงทั้งตัวสะกดและพยางค์ถัดไป |
| ประวัติศาสตร์ | ประ-หวัด-ติ-สาด | อ่านเชื่อมพยางค์ |
| คุณภาพ | คุน-นะ-พาบ | อ่านเชื่อมพยางค์ |
| ปรารถนา | ปราด-ถะ-หนา | อ่านเชื่อมพยางค์ และ น ออกเสียงตามอักษรนำ |

ถ้าไม่แน่ใจ ให้เปิดดู **คำอ่าน** ในพจนานุกรม (ดูบท [การใช้พจนานุกรม](/topic/thai.grammar.dictionary-use/))

## แบ่งวรรคตอนให้ถูก

ภาษาไทยเขียนติดกัน ไม่เว้นระหว่างคำ ผู้อ่านต้องรู้ว่าคำแบ่งตรงไหน ถ้าแบ่งผิด ความหมายเปลี่ยน

- "เสื้อที่**ตากลม**ไว้แห้งแล้ว" ต้องอ่าน **ตาก-ลม** (ผึ่งลม) ไม่ใช่ ตา-กลม
- "น้องมี**ตากลม**โต" อ่าน **ตา-กลม** (ดวงตากลม)
- "ยานี้ดี กินแล้วแข็งแรง ไม่มีโรค" ถ้าหยุดผิดเป็น "กินแล้วแข็ง แรงไม่มี" ความหมายผิดไปหมด

หลักการหยุด: หยุดสั้นที่เว้นวรรค หยุดยาวขึ้นเมื่อจบประโยคหรือย่อหน้า และไม่หยุดกลางคำ

## อ่านร้อยแก้ว

ร้อยแก้วคือข้อความธรรมดา เช่น นิทาน ข่าว บทความ

- **เสียงดังพอ** ให้คนแถวหลังได้ยิน
- **ความเร็วพอดี** ไม่รีบจนฟังไม่ทัน ไม่ช้าจนน่าเบื่อ
- **ไม่อ่านตก อ่านเติม หรืออ่านซ้ำ** อ่านตามตัวหนังสือทุกคำ
- **ใส่อารมณ์ตามเรื่อง** ข่าวอ่านเรียบ ชัดเจน นิทานตลกอ่านสนุกสนาน เรื่องเศร้าอ่านช้าลงและเสียงเบาลง ตัวละครพูดก็เปลี่ยนน้ำเสียงตามตัวละคร

## อ่านร้อยกรองตามจังหวะ

ร้อยกรองคือข้อความที่แต่งตามแบบแผน มีจำนวนคำและสัมผัสกำหนดไว้ อ่านให้ไพเราะต้อง **แบ่งจังหวะ** ตามชนิดของบท (ดูภาพด้านบน)

- **กลอนสุภาพ** วรรคละ 8 คำ (7–9 ได้) อ่านเป็น **3 / 2 / 3** เช่น "ยามเช้าตรู่ / ดูฟ้า / สีทองผ่อง"
- **กาพย์ยานี 11** วรรคหน้า 5 คำ อ่าน **2 / 3** วรรคหลัง 6 คำ อ่าน **3 / 3** เช่น "เช้านี้ / ฟ้าแจ่มใส · ลมโชยไกล / พาชื่นบาน"

ฉันทลักษณ์และการแต่งอยู่ในบทเรียนเรื่องร้อยกรองต่อไป บทนี้เน้นการอ่าน

### หลักการอ่านทำนองเสนาะเบื้องต้น

**ทำนองเสนาะ** คือการอ่านร้อยกรองให้มีทำนองไพเราะ

1. **แบ่งจังหวะ** ตามชนิดของบท
2. **เน้นคำสัมผัส** ให้ได้ยินชัดว่าเสียงรับกัน
3. **ทอดเสียง** ที่ท้ายวรรค โดยเฉพาะท้ายบท
4. **ออกเสียงคำให้ถูก** ไม่เปลี่ยนวรรณยุกต์เพื่อให้เข้าทำนอง จนคำผิดความหมาย
5. **ใส่อารมณ์** ให้เข้ากับเนื้อเรื่อง

## ข้อผิดพลาดที่พบบ่อย

- **อ่าน ร เป็น ล** และ **อ่านควบกล้ำไม่ชัด**
- **อ่านตามตัวเขียน** คำที่อ่านไม่ตรงรูป เช่น อ่าน ธรรมชาติ เป็น ทัน-มะ-ชาด
- **หยุดผิดที่** จนความหมายเปลี่ยน
- **อ่านร้อยกรองด้วยจังหวะร้อยแก้ว** ไม่แบ่งจังหวะ ไม่เน้นสัมผัส
- **ใช้น้ำเสียงเดียวทั้งเรื่อง** ไม่เข้ากับอารมณ์ของเรื่อง
