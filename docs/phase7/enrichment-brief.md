# เฟส 7: เติมเนื้อหาให้ทุกหัวข้อ (คู่มือผู้เขียนและ agent)

เป้าหมาย: ทุกหัวข้อมีโจทย์มากพอให้ฝึกซ้ำ มีตัวอย่างแสดงวิธีทำ คำถามชวนคิด และภาพประกอบ และครอบคลุมเนื้อหาที่หลักสูตรต่างประเทศสอนในหัวข้อเดียวกัน ไม่ยึดหลักสูตรของกระทรวงอย่างเดียว

อ่านก่อน: `docs/authoring-guide.md` (โดยเฉพาะ "สื่อประกอบ" และ "ภาพประกอบ"), `docs/phase1/authoring-brief.md`, `docs/decisions/0004-content-model.md` และตัวอย่างที่ทำครบแล้วใน `content/math/pythagoras/`

## สิ่งที่ต้องเพิ่มในแต่ละหัวข้อ

1. **โจทย์รวมอย่างน้อย 20 ข้อ** (เพิ่มจากเดิม ห้ามแก้รหัสโจทย์เดิม ใช้รหัสต่อจากเลขสุดท้าย)
   - ความยาก 1–5 ครบทุกระดับ อย่างน้อย 3 ข้อต่อระดับ 2–4
   - ชนิดโจทย์อย่างน้อย 4 แบบที่เหมาะกับเรื่อง ใช้ `expression` เมื่อคำตอบเป็นสูตรหรือนิพจน์
   - โจทย์สถานการณ์จริงในไทยอย่างน้อย 5 ข้อ
   - คำใบ้ 2–3 ขั้น เฉลยเต็ม misconception เป็นค่าที่ความผิดพลาดจริงให้ออกมา **คำนวณทุกตัวเลขด้วย python3**
   - ไม่ซ้ำแนวกับข้อเดิม ให้ครอบคลุมทักษะที่ยังขาด (ดูข้อ 4)
2. **ตัวอย่างแสดงวิธีทำ (`worked-example`) 2 ตัวอย่าง** ระดับง่ายและระดับกลางถึงยาก วางหลังบล็อก explanation แต่ละขั้นทำงานชิ้นเดียว ใส่ `why` ในขั้นที่ผู้เรียนมักสงสัย
3. **คำถามชวนคิด (`check`) 1–2 ข้อ** อ้างโจทย์ระดับ 1–3 ในคลังของหัวข้อ วางคั่นระหว่างบล็อก
4. **ภาพประกอบ 1–3 ภาพ** ในบทเรียน และในโจทย์ที่ภาพช่วยให้เข้าใจโจทย์ (เรขาคณิต แรง วงจร กราฟ ตาราง แผนผัง)
   - วาดเป็น SVG ด้วยสคริปต์ที่คำนวณพิกัดจริง แล้ว **เรนเดอร์เป็น PNG ด้วย Chromium และเปิดดูทุกภาพ** (`/opt/pw-browsers/chromium-1243/chrome-linux64/chrome`, Playwright ที่ `/opt/node22/lib/node_modules/playwright/index.mjs`) แก้จนป้ายไม่ทับกัน อ่านง่าย และสัดส่วนถูก
   - หรือใช้ภาพจาก Wikimedia Commons ที่สัญญาอนุญาตใช้ได้ ตรวจสัญญาอนุญาตผ่าน API (`prop=imageinfo&iiprop=extmetadata|url`) ใส่ `credit`, `source` (หน้า File: บน Commons), `license` ตามจริง ย่อภาพถ่ายให้ไม่เกิน 400 KB
   - `alt` บอกสิ่งที่ภาพสื่อครบพอให้แก้โจทย์ได้โดยไม่เห็นภาพ ภาพในโจทย์ต้องไม่เฉลยคำตอบ
5. **บูรณาการหลักสูตรต่างประเทศ** ดูตัวชี้วัดของหลักสูตรต่างประเทศที่จับคู่กับหัวข้อนี้แบบ `partial` หรือที่ควรอยู่ในหัวข้อนี้แต่ยังไม่ได้จับคู่
   - คำสั่ง: `npm run curriculum -- --framework=<id> --missing` และดูไฟล์ใน `curriculum/mappings/`
   - หลักสูตรที่มี: `us-ccss-math`, `us-ngss`, `th-core-*` และ (ถ้ามีแล้ว) `au-ac9-*`, `uk-nc-*`, `csta-k12-cs`
   - เพิ่มเนื้อหาในบทเรียน (lesson.md) และโจทย์ให้ครอบคลุมส่วนที่ขาด **เฉพาะที่อยู่ในขอบเขตของหัวข้อ** เรื่องที่เป็นหัวข้อใหม่ทั้งเรื่องให้จดไว้ ไม่ต้องยัดลงหัวข้อเดิม
   - **ห้ามแก้ไฟล์ใน `curriculum/`** (หลาย agent ทำพร้อมกัน) ให้บันทึกผลในไฟล์บันทึกของชุดงาน (ด้านล่าง)
6. บทเรียนที่สั้นกว่า 600 คำหรือขาดหัวข้อย่อยที่หลักสูตรต่างประเทศสอน ให้ขยายได้ คงเนื้อหาเดิมที่ถูกต้องไว้
