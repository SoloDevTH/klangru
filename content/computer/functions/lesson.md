## เขียนครั้งเดียว ใช้ได้ทุกครั้ง

ฟ้าเขียนโปรแกรมคำนวณพื้นที่ห้องเรียนเพื่อสั่งกระเบื้อง แล้วต้องคำนวณอีก 12 ห้อง ถ้าคัดลอกโค้ดเดิมไปวาง 12 รอบ โปรแกรมจะยาว และถ้าพบที่ผิดก็ต้องแก้ 12 ที่ วิธีที่ดีกว่าคือรวมขั้นตอนไว้เป็น **ฟังก์ชัน** แล้วเรียกใช้ซ้ำ บทนี้ต่อจากตัวแปร เงื่อนไข และวงวนในบท Python เบื้องต้น

## สร้างและเรียกใช้ฟังก์ชัน

```python
def rect_area(width, height):   # width, height คือพารามิเตอร์
    area = width * height
    return area                  # ส่งค่ากลับไปให้ผู้เรียก

print(rect_area(3, 4))           # 3 และ 4 คืออาร์กิวเมนต์ ได้ 12
total = rect_area(3, 4) + rect_area(2, 5)
print(total)                     # 22
```

- `def` บอกว่ากำลังสร้างฟังก์ชัน ตามด้วยชื่อและวงเล็บ
- **พารามิเตอร์** คือตัวแปรในวงเล็บที่รอรับค่า ส่วนค่าจริงที่ส่งตอนเรียกเรียกว่า **อาร์กิวเมนต์** ค่าจะถูกจับคู่ตามลำดับ
- `return` ส่ง **ค่าที่คืน** กลับไปยังจุดที่เรียก แล้วจบฟังก์ชันทันที คำสั่งหลัง `return` จะไม่ถูกทำ
- การเรียก `rect_area(3, 4)` จึงใช้เหมือนตัวเลข 12 นำไปบวก เก็บในตัวแปร หรือส่งต่อให้ฟังก์ชันอื่นได้

**`print` ไม่ใช่ `return`** `print` แค่แสดงบนจอ ถ้าฟังก์ชันไม่มี `return` ผลที่คืนคือค่าว่าง `None` ซึ่งนำไปคำนวณต่อไม่ได้

## ฟังก์ชันแก้โจทย์คณิตศาสตร์และวิทยาศาสตร์

สูตรใดที่ใช้บ่อยก็เขียนเป็นฟังก์ชันได้ เช่น สมการเชิงเส้น $ax + b = c$ มีคำตอบ $x = \frac{c - b}{a}$ และการแปลงองศาเซลเซียสเป็นฟาเรนไฮต์ $F = \frac{9}{5}C + 32$

```python
def solve_linear(a, b, c):
    return (c - b) / a

def c_to_f(c):
    return 9 / 5 * c + 32

print(solve_linear(2, 3, 11))   # 4.0
print(c_to_f(25))               # 77.0
```

ฟังก์ชันใช้ **ตรรกะ** ได้ เช่น คืนค่า `True` หรือ `False` หรือใช้ `if` เลือกค่าที่คืน และใช้วงวนข้างในได้ เช่น หาว่าเงินฝาก 100 บาท ดอกเบี้ยทบต้นปีละ 10% ต้องฝากกี่ปีจึงถึง 200 บาท

```python
def is_even(n):
    return n % 2 == 0

def years_to_double(rate):
    money = 100
    years = 0
    while money < 200:
        money = money * (1 + rate / 100)
        years = years + 1
    return years

print(is_even(7))             # False
print(years_to_double(10))    # 8
```

ฟังก์ชันรับลิสต์ได้ด้วย วงวน `for` ไล่สมาชิกทีละตัว และแก้ค่าในลิสต์ด้วยดัชนี เช่น `scores[i] = scores[i] + 1`

## ขอบเขตของตัวแปร

ตัวแปรที่สร้างในฟังก์ชันเป็น **ตัวแปรเฉพาะที่ (local)** มีอยู่ระหว่างที่ฟังก์ชันทำงานเท่านั้น และไม่ปนกับตัวแปรชื่อเดียวกันข้างนอก (ดูภาพขอบเขต)

```python
count = 0
def add_one():
    count = 10          # count ตัวนี้อยู่ในฟังก์ชันเท่านั้น
    count = count + 1
    return count

print(add_one())   # 11
print(count)       # 0  count ข้างนอกไม่เปลี่ยน
```

ฟังก์ชันที่ดีรับข้อมูลทาง **พารามิเตอร์** และส่งผลทาง **return** ไม่แอบไปแก้ตัวแปรข้างนอก จึงทดสอบแยกได้และนำไปใช้ที่อื่นได้

## แยกปัญหาเป็นฟังก์ชันและโมดูล

ปัญหาใหญ่แยกเป็นงานย่อยได้ งานย่อยละหนึ่งฟังก์ชัน เช่น โปรแกรมตัดเกรด แยกเป็น หาคะแนนรวม → แปลงเป็นเกรด → แสดงผล แต่ละฟังก์ชันสั้น ตั้งชื่อบอกหน้าที่ และทดสอบทีละตัวได้

ฟังก์ชันที่เกี่ยวข้องกันเก็บรวมเป็นไฟล์เดียวเรียกว่า **โมดูล** แล้วนำมาใช้ด้วย `import` เช่น โมดูล `math` ที่มากับ Python

```python
import math
print(math.sqrt(16))   # 4.0
```

## ฟังก์ชันที่เรียกตัวเอง

**การเรียกซ้ำ (recursion)** คือฟังก์ชันที่เรียกตัวเองกับปัญหาที่เล็กลง ต้องมี **กรณีฐาน** ที่ตอบได้ทันทีโดยไม่เรียกซ้ำอีก เช่น แฟกทอเรียล $n! = n \times (n-1)!$ และ $0! = 1$

```python
def fact(n):
    if n == 0:              # กรณีฐาน
        return 1
    return n * fact(n - 1)

print(fact(4))   # 24
```

`fact(4)` รอ `fact(3)` ซึ่งรอ `fact(2)` ไปจนถึง `fact(0)` ที่คืน 1 แล้วค่าจึงคูณย้อนกลับขึ้นมา: 1 → 1 → 2 → 6 → 24 ถ้าไม่มีกรณีฐาน ฟังก์ชันจะเรียกตัวเองไม่สิ้นสุดจน Python หยุดพร้อมข้อผิดพลาด

## ข้อผิดพลาดที่พบบ่อย

- **ใช้ `print` แทน `return`** แล้วนำผลไปคำนวณต่อ ได้ `None`
- **ลืมเรียกฟังก์ชัน** เขียน `def` แล้วแต่ไม่เคยเรียก ฟังก์ชันจึงไม่ทำงาน
- **ส่งอาร์กิวเมนต์สลับลำดับ** `solve_linear(11, 3, 2)` ไม่เท่ากับ `solve_linear(2, 3, 11)`
- **คิดว่าตัวแปรในฟังก์ชันใช้ข้างนอกได้** ตัวแปรเฉพาะที่หายไปเมื่อฟังก์ชันจบ
- **วาง `return` ไว้ในวงวนโดยไม่ตั้งใจ** ฟังก์ชันจะจบตั้งแต่รอบแรก
- **เรียกซ้ำโดยไม่มีกรณีฐาน** หรือปัญหาไม่เล็กลง จะเรียกไม่สิ้นสุด
