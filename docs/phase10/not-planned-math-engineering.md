# เฟส 10 กลุ่ม math-engineering: ตัวชี้วัดที่ไม่วางแผนเป็นหัวข้อ

ตัวชี้วัดในรายการนี้แอปสอนหรือวัดไม่ได้ เพราะต้องลงมือเก็บข้อมูลหรือทำการทดลองจริง เป็นโครงงานออกแบบยาว ต้องใช้ซอฟต์แวร์เฉพาะทาง หรือเป็นเกณฑ์รับรองหลักสูตรของสถาบัน จึงไม่สร้างหัวข้อ ความรู้ที่อยู่เบื้องหลังส่วนใหญ่มีหัวข้อในคลังหรือในแผนอยู่แล้ว (ระบุไว้ในวงเล็บ)

## th-coe-engineering-basics (3 ข้อ)

| ตัวชี้วัด | เหตุผล |
|---|---|
| `IE-3.6` | การบูรณาการองค์ความรู้ตั้งแต่สองด้านขึ้นไปเพื่อแก้ปัญหาซับซ้อน เป็นโครงงานบูรณาการ (capstone) ไม่ใช่เนื้อหาเดี่ยว องค์ความรู้แต่ละด้านอยู่ในหัวข้อ IE ของคลังและแผน |
| `CHE-3.5` | การออกแบบอุปกรณ์และโรงงานวิศวกรรมเคมีเป็นโครงงานออกแบบยาวหลายสัปดาห์ หลักที่ใช้อยู่ใน engineering.process.mass-energy-balance และแผน engineering.process.reactor-design, engineering.process.separation-processes, engineering.thermo.heat-transfer |
| `CHE-3.7` | การจำลองกระบวนการต้องใช้ซอฟต์แวร์จำลองกระบวนการเฉพาะทาง (เช่น Aspen, DWSIM) และแบบจำลองสมบัติทางอุณหพลศาสตร์ แอปสอนการใช้ซอฟต์แวร์เหล่านี้ไม่ได้ |

## abet-eac (20 ข้อ)

นิยามและเกณฑ์ระดับหลักสูตร ใช้ประเมินว่าหลักสูตรของสถาบันจัดเนื้อหา หน่วยกิต ห้องปฏิบัติการ และประสบการณ์ออกแบบครบหรือไม่ ไม่ใช่สิ่งที่ผู้เรียนรายคนเรียนจบได้ในบทเรียนเดียว

| ตัวชี้วัด | เหตุผล |
|---|---|
| `DEF Basic Science` | นิยามศัพท์ที่ใช้ในเกณฑ์ ไม่ใช่ผลการเรียนรู้ |
| `DEF College-Level Mathematics` | นิยามศัพท์ที่ใช้ในเกณฑ์ (เนื้อหาคณิตศาสตร์ที่ยกตัวอย่างมีหัวข้อในคลังและแผน math.*) |
| `DEF Engineering Science` | นิยามศัพท์ที่ใช้ในเกณฑ์ |
| `DEF Complex Engineering Problems` | นิยามศัพท์ที่ใช้ในเกณฑ์ |
| `Criterion 3 (1)` | ผลลัพธ์ของผู้เรียนระดับหลักสูตร (แก้ปัญหาวิศวกรรมที่ซับซ้อน) วัดจากงานตลอดหลักสูตร |
| `Criterion 3 (3)` | การสื่อสารกับผู้ฟังหลายกลุ่ม ต้องฝึกพูดและเขียนจริงและให้ผู้สอนประเมิน |
| `Criterion 3 (5)` | การทำงานเป็นทีมและภาวะผู้นำร่วม ต้องทำงานกลุ่มจริง |
| `Criterion 3 (6)` | ออกแบบและทำการทดลอง ต้องทำในห้องปฏิบัติการ (การวิเคราะห์ข้อมูลมีใน math.stats.* และ science.inquiry.*) |
| `Criterion 3 (7)` | การแสวงหาความรู้ใหม่ด้วยตนเอง เป็นคุณลักษณะที่วัดตลอดหลักสูตร |
| `Criterion 5 a.` | ข้อกำหนดหน่วยกิตคณิตศาสตร์และวิทยาศาสตร์และประสบการณ์ทดลองของหลักสูตร |
| `Criterion 5 b.` | ข้อกำหนดหน่วยกิตหัวข้อวิศวกรรมและการใช้เครื่องมือสมัยใหม่ของหลักสูตร |
| `Criterion 5 c.` | ข้อกำหนดส่วนการศึกษาทั่วไปของหลักสูตร |
| `Aerospace 1` | เกณฑ์ของหลักสูตรอากาศยาน/อวกาศยาน ระบุขอบเขตทั้งหลักสูตรและประสบการณ์ออกแบบที่ตรงชื่อหลักสูตร |
| `Biomedical 1.b` | เกณฑ์หลักสูตรชีวการแพทย์ระดับทั้งสาขา (ปฏิสัมพันธ์ระบบมีชีวิตกับไม่มีชีวิต) เกินขอบเขตบทเรียนเดียว |
| `Biomedical 1.c` | การออกแบบและสร้างอุปกรณ์ชีวการแพทย์เป็นโครงงานออกแบบ |
| `Biomedical 1.d` | การวัดและตีความข้อมูลจากระบบที่มีชีวิตต้องทำในห้องปฏิบัติการ (หลักการวัดอยู่ในแผน engineering.electrical.instrumentation) |
| `Civil 1.b` | เกณฑ์ให้หลักสูตรแก้ปัญหาซับซ้อนอย่างน้อยสี่สาขาเฉพาะของงานโยธา เป็นข้อกำหนดโครงสร้างหลักสูตร |
| `Civil 1.c` | การทดลองในบริบทงานโยธาและเขียนรายงาน ต้องทำในห้องปฏิบัติการ |
| `Environmental 1.c` | การทดลองปฏิบัติการและวิเคราะห์ข้อมูลสิ่งแวดล้อมหลายด้าน ต้องทำในห้องปฏิบัติการ |
| `Materials 1.c` | การใช้วิธีทดลอง สถิติ และการคำนวณกับปัญหาวัสดุ เป็นทักษะบูรณาการระดับหลักสูตรที่ต้องทำการทดลองจริง |
