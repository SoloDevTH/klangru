## เขียนให้ผู้อ่านเห็นภาพตาม

"วันนี้ไปทะเล สนุกมาก" กับ "ลมทะเลเค็ม ๆ พัดผมยุ่ง เม็ดทรายร้อนจนต้องกระโดดไปทีละก้าว" ประโยคแรกบอกว่าเกิดอะไร ประโยคที่สองทำให้ผู้อ่าน **เห็นภาพและรู้สึกตาม** บทนี้ฝึกเขียนเล่าเรื่อง บรรยาย และพรรณนา ต่อจากบท [การเขียนสื่อสารด้วยถ้อยคำที่ถูกต้องเหมาะสม](/topic/thai.composition.word-choice/) (ถ้าเคยเรียนบท [ความหมายของคำและข้อความจากบริบท](/topic/thai.reading.word-meaning-in-context/) จะรู้จักโวหารบรรยายและพรรณนาจากด้านผู้อ่านมาแล้ว บทนี้เป็นด้านผู้เขียน)

## เขียนเล่าเรื่องจากประสบการณ์

เรื่องที่ดีมาจากเหตุการณ์จริงที่เรา **จำได้ชัด** เช่น วันแรกที่ขี่จักรยานได้ วางแผนด้วยคำถาม

1. **ใคร** อยู่ในเหตุการณ์
2. **ที่ไหน เมื่อไร**
3. **เกิดอะไรขึ้น** เรียงตามเวลา
4. **รู้สึกอย่างไร** และ **ได้เรียนรู้อะไร**

ใช้ **คำบอกลำดับ** ให้ผู้อ่านตามทัน เช่น ตอนเช้า ต่อมา ทันใดนั้น ในที่สุด และเลือกเล่าเฉพาะตอนสำคัญ ไม่ต้องเล่าทุกนาที

ผู้เรียนชั้นโตเขียน **บรรยายประสบการณ์** ให้มี **สาระสำคัญ** (ประสบการณ์นี้สำคัญอย่างไร) ในประโยคแรกหรือประโยคสุดท้าย แล้วมี **รายละเอียดสนับสนุน** คือเหตุการณ์ ตัวอย่าง ความรู้สึก ที่ช่วยให้สาระนั้นชัด

## เขียนเรื่องจากจินตนาการ

ดูภาพ **โครงเรื่องแบบภูเขา** ด้านบน เรื่องแต่งส่วนใหญ่มี 5 ช่วง

1. **เปิดเรื่อง** แนะนำตัวละครและฉาก
2. **ปมปัญหา** เกิดปัญหาที่ตัวละครต้องแก้
3. **จุดสูงสุด** ตอนที่ตื่นเต้นที่สุด
4. **คลี่คลาย** ปัญหาค่อย ๆ หมดไป
5. **จบเรื่อง** ตัวละครเปลี่ยนไปหรือได้เรียนรู้อะไร

จินตนาการได้เต็มที่ เช่น ดินสอที่พูดได้ หรือเมืองใต้ทะเล แต่ต้อง **สมเหตุสมผลภายในเรื่อง** ปัญหาควรคลี่คลายด้วยการกระทำของตัวละคร ไม่ใช่ "แล้วก็ตื่นขึ้นมา" ทุกครั้ง

## บันทึกประจำวัน

บันทึกประจำวันเขียนถึงตัวเอง มีส่วนประกอบ

- **วัน เดือน ปี** (บางคนเขียนสภาพอากาศด้วย)
- **เหตุการณ์สำคัญของวัน** ไม่ต้องเขียนทุกเรื่อง
- **ความรู้สึกและความคิด** ต่อเหตุการณ์นั้น
- **สิ่งที่ได้เรียนรู้หรือแผนวันพรุ่งนี้**

ใช้สรรพนามบุรุษที่หนึ่ง เช่น ฉัน ผม หนู ภาษาเป็นกันเองได้ แต่ควรสะกดถูก

## บรรยาย กับ พรรณนา

| | บรรยาย | พรรณนา |
|---|---|---|
| จุดประสงค์ | ให้รู้ว่าเป็นอะไร เกิดอะไร ตามลำดับ | ให้เห็นภาพและรู้สึกตาม |
| ใช้อะไร | ข้อมูลชัดเจน ขนาด สี รูปร่าง ส่วนประกอบ ลำดับ | ประสาทสัมผัส 5 คำขยาย คำเลียนเสียง การเปรียบเทียบ |
| ตัวอย่าง | กระเป๋าสีน้ำเงิน มีสองช่อง สายสะพายปรับได้ | กระเป๋าสีน้ำเงินเข้มเหมือนท้องฟ้ายามค่ำ ผ้าลื่นมือ |

**บรรยายสิ่งของให้ชัดเจน** เรียงจากภาพรวมไปส่วนย่อย: ชื่อและหน้าที่ → ขนาด รูปร่าง สี → ส่วนประกอบ → วิธีใช้หรือจุดเด่น ผู้อ่านที่ไม่เคยเห็นต้องนึกภาพออก

**พรรณนา** ใช้ **ประสาทสัมผัสทั้ง 5** ดูภาพประสาทสัมผัสด้านล่าง: เห็นอะไร ได้ยินอะไร ได้กลิ่นอะไร รับรสอะไร สัมผัสอะไร แล้วเลือกคำที่เจาะจง เช่น "แดง" → "แดงก่ำ" "เสียงดัง" → "เสียงฟ้าคำรามครืน ๆ"

## ชีวประวัติและอัตชีวประวัติ

- **ชีวประวัติ** เขียนเรื่องชีวิตของ **ผู้อื่น** ใช้สรรพนาม เขา เธอ ท่าน
- **อัตชีวประวัติ** เขียนเรื่องชีวิตของ **ตนเอง** ใช้ ฉัน ผม ข้าพเจ้า

ทั้งสองแบบมี: ข้อมูลพื้นฐาน (เกิดที่ไหน ครอบครัว) → **เหตุการณ์สำคัญตามลำดับเวลา** → **ข้อคิดเห็นและทัศนคติ** ของเจ้าของชีวิต → สิ่งที่ผู้อ่านได้เรียนรู้ ชีวประวัติต้องใช้ **ข้อเท็จจริงที่ตรวจได้** เช่น สัมภาษณ์ญาติ ดูเอกสาร และบอกแหล่งที่มา

## ผลิตงานเขียนของตนเอง

เลือก **รูปแบบ** ให้เหมาะกับจุดประสงค์และผู้อ่าน เช่น เล่าความทรงจำ → บันทึกหรือเรื่องสั้น ชวนคนมาเที่ยวงานบุญ → พรรณนาบรรยากาศ แล้วเขียนเป็นขั้น: **วางแผน → ร่าง → อ่านทบทวน → แก้ไข → เผยแพร่** การอ่านออกเสียงร่างของตนช่วยให้เห็นประโยคที่วกวน

## ข้อผิดพลาดที่พบบ่อย

- **เล่าทุกอย่างเท่ากันหมด** ไม่เน้นตอนสำคัญ
- **ใช้คำกว้าง ๆ** เช่น สวยมาก สนุกมาก แทนรายละเอียดที่เห็นภาพ
- **สลับลำดับเวลา** จนผู้อ่านงง
- **เรื่องจินตนาการไม่มีปมปัญหา** จึงไม่น่าติดตาม หรือจบแบบไม่สมเหตุสมผล
- **ใช้สรรพนามสลับ** ในอัตชีวประวัติ เดี๋ยว ฉัน เดี๋ยว เขา
- **บันทึกประจำวันมีแต่เหตุการณ์** ไม่มีความรู้สึกหรือสิ่งที่ได้เรียนรู้
