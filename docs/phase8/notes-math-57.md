# บันทึกชุดงาน math-57 (คณิตศาสตร์ระดับมหาวิทยาลัย 8 หัวข้อ)

ภาพทุกภาพวาดเองเป็น SVG ด้วยสคริปต์ Python ที่คำนวณพิกัดจริง (สนามความชันจากสมการจริง วงรีจากการแปลงวงกลมด้วยเมทริกซ์ ช่วงความเชื่อมั่น 20 ช่วงจากการจำลองด้วย seed ที่ให้ผลพลาด 1 ใน 20) เรนเดอร์เป็น PNG ด้วย Chromium และเปิดดูแล้วทุกภาพ ไม่มีภาพจาก Commons ภาพในโจทย์ (หน้าตัดคลอง แผนภาพเส้นระดับ แปลงที่ดิน ถังผสม) แสดงเฉพาะข้อมูลของโจทย์ ไม่แสดงคำตอบ

ทุกคำตอบคำนวณด้วย python3: sympy สำหรับปฏิยานุพันธ์ (ตรวจด้วยการหาอนุพันธ์กลับและเงื่อนไข F(0) = 0 หรือ F(1) = 0) ผลเฉลยสมการเชิงอนุพันธ์ (`dsolve` และแทนกลับในสมการ) ปริพันธ์หลายชั้น แรงก์ ปริภูมิศูนย์ และคู่ค่าเฉพาะ (ตรวจ Av = λv) ตารางการวนซ้ำของวิธีแบ่งครึ่ง นิวตัน การวนซ้ำจุดตรึง สี่เหลี่ยมคางหมู ซิมป์สัน และออยเลอร์คำนวณด้วย Python ทศนิยมลอยตัว ค่าความน่าจะเป็นปกติใช้ `statistics.NormalDist` และค่าวิกฤต t ในบทเรียน (องศาเสรี 4, 9, 15, 24, 29, 99) คำนวณด้วย mpmath (`betainc` + `findroot`) เพราะไม่มี scipy ตรงกับตาราง t มาตรฐาน โจทย์ที่ต้องใช้ t ให้ค่าวิกฤตในโจทย์ไว้ด้วย คำตอบชนิด `expression` ทุกข้อ (13 ข้อ) ตรวจด้วย `evaluateLatex` ของ `@klangru/schema` เทียบกับ sympy ที่จุดสุ่ม 5 จุด และตรวจว่า misconception ไม่เท่ากับคำตอบ สูตรของกราฟโต้ตอบทุกชุดตรวจด้วย `compileLatex` แล้วเทียบค่ากับการคำนวณมือ ค่า misconception ของโจทย์ numeric ทุกค่าคำนวณจากความผิดพลาดนั้นจริง (ค่าที่หาที่มาไม่ได้ถูกตัดออก) และปรับโจทย์ที่คำตอบเล็กมาก (ค่า p ความคลาดเคลื่อน) ให้ตอบเป็นร้อยละหรือจำนวนเท่า เพื่อไม่ให้ช่วงจับ misconception (±0.01) ทับคำตอบที่ใกล้ถูก

ลิงก์อ้างอิงทุกลิงก์ได้ HTTP 200 ด้วย User-Agent ของโครงการและตรวจชื่อหน้าแล้ว (ไม่มีลิงก์ที่ยังไม่ได้ตรวจ ไม่เจอ 429) แก้สองลิงก์ระหว่างตรวจ: OpenStax 4.7 ใช้ slug `4-7-maxima-minima-problems` และวิกิพีเดียไทยใช้ชื่อหน้า "ค่าลักษณะเฉพาะและเวกเตอร์ลักษณะเฉพาะ" (ตามลิงก์ข้ามภาษาจากหน้าภาษาอังกฤษ) ไฟล์จับคู่ครบทั้ง 8 หัวข้อใน `docs/phase8/mappings/` ตรวจด้วยสคริปต์ว่าทุกตัวชี้วัดในแถว topics และ extend อยู่ในไฟล์ ไม่ซ้ำ และมีอยู่จริงใน `curriculum/frameworks/`

## math.calculus.integration-techniques

- 19 ข้อ ภาพ 1 ภาพ (เทียบพื้นที่ใต้ 1/x² กับ 1/x บน [1, 10]) บริบทไทย: AUC ของยาในโรงพยาบาลชุมชน ถังน้ำรั่วในขอนแก่น ค่าเช่าที่ดินเชียงใหม่ (มูลค่าปัจจุบันแบบต่อเนื่อง)
- CALC2 3.2 เป็น partial: สอน sinᵐx cosⁿx ครบ แต่ tanᵐx secⁿx มีแค่หนึ่งประโยค
- ข้อเสนอแผน: การแทนค่าด้วยตรีโกณมิติ (CALC2 3.3) ไม่อยู่ในแผนของหัวข้อใด ถ้าต้องการให้ครบ CALC2 บทที่ 3 ควรเพิ่มในหัวข้อนี้หรือหัวข้อใหม่

## math.stats.inference

- 18 ข้อ ภาพ 2 ภาพ (ช่วงความเชื่อมั่น 20 ช่วงจากการจำลอง ค่า p สองทางที่ z = ±2.1) และตาราง t* ที่ 95% บริบทไทย: ไข่ไก่นครปฐม โพลนักศึกษา โพลนายก อบจ. ข้าวสารถุง 5 กิโลกรัม แปลงนาทดลองสุพรรณบุรี
- โจทย์การทดสอบแบบสุ่มจัดกลุ่มใหม่ (p015–p016) ไล่ครบทั้ง 252 แบบด้วย Python ได้ 2 แบบที่ผลต่าง ≥ 20.4 จึงเป็นค่า p ที่แน่นอน ไม่ขึ้นกับ seed
- S-IC.4, S-IC.5, IE-2.5, CHE-2.2 เป็น partial (ผู้เรียนไม่ได้รันการจำลองเอง ไม่มีการเปรียบเทียบสองกลุ่มแบบพารามิเตอร์และการออกแบบการทดลองแบบแฟกทอเรียล)
- ข้อเสนอแผน: เพิ่ม `math.stats.sampling-surveys` เป็น prerequisite (บทเรียนต่อยอดเรื่องความแปรผันระหว่างตัวอย่างและขอบเขตความคลาดเคลื่อนคร่าว ๆ จากหัวข้อนั้น) และอาจมีหัวข้อต่อยอด "การเปรียบเทียบสองกลุ่ม (t สองกลุ่ม ไคกำลังสอง)" สำหรับ six-sigma-dmaic

## math.numerical.basic-methods

- 18 ข้อ ภาพ 3 ภาพ (เส้นสัมผัสของนิวตัน สนามความชันของ y′ = t − y กับวิธีของออยเลอร์ หน้าตัดคลองในโจทย์ p009) ตารางการวนซ้ำทุกตารางคำนวณด้วย Python และบทเรียนมีโค้ด Python ของวิธีของนิวตันพร้อมเงื่อนไขหยุดที่ปลอดภัย บริบทไทย: คลองชลประทานอยุธยา ถังน้ำทรงกลมหมู่บ้านในน่าน ถังประปาหมู่บ้าน
- บทเรียนเขียนเรื่องความคลาดเคลื่อนจากเลขทศนิยมลอยตัวอย่างตรงไปตรงมา (0.1 + 0.2, ห้ามใช้ f(x) == 0, h เล็กเกินไปทำให้ความคลาดเคลื่อนจากการปัดสะสม) และโจทย์ p017 ถามเรื่องนี้
- MIT18.03 L2 partial (ออยเลอร์ปรับปรุงและรุงเง–คุททากล่าวถึงเท่านั้น) Civil 1.a partial
- ข้อเสนอแผน: CALC2 4.2 (สนามความชัน) ผูกกับหัวข้อนี้ ส่วน math.de.first-order อ้างภาพสนามความชันจากที่นี่ อาจเพิ่ม `math.numerical.basic-methods` เป็น prerequisite ทางเลือกของ math.de.first-order หรือย้าย CALC2 4.2 ไปผูกทั้งสองหัวข้อ

## math.calculus.partial-derivatives

- 17 ข้อ ภาพ 2 ภาพ (เส้นระดับของ x² + 2y² กับเกรเดียนต์ แผนภาพเส้นระดับในโจทย์ p006 ที่ไม่ระบุเครื่องหมายของ fₓ, f_y) บริบทไทย: เนินเขาเชียงราย ลังลำไยลำพูน กระทะหมูกระทะ
- ข้อเสนอแผน: ตัวคูณลากรองจ์ (CALC3 4.8) ไม่อยู่ในแผนของหัวข้อใด ถ้าต้องการอาจเพิ่มในหัวข้อนี้ ส่วนระนาบสัมผัสและการประมาณเชิงเส้น (CALC3 4.4) ก็ยังไม่มีหัวข้อผูก

## math.linalg.vector-spaces

- 17 ข้อ ภาพ 1 ภาพ (ภาพฉายของ b ลงเส้นในทิศ a พร้อม e ตั้งฉาก) สื่อโต้ตอบใช้ vector-add แสดงผลรวมเชิงเส้นและการแผ่ทั่ว บริบทไทย: อาหารไก่ฉะเชิงเทรา (b อยู่ในปริภูมิหลักหรือไม่) ร้านชาไทยหาดใหญ่ (เส้นกำลังสองน้อยสุด) ค่าคงตัวสปริงในห้องปฏิบัติการพิษณุโลก
- โจทย์เส้นตรงกำลังสองน้อยสุดใช้ 4 จุด เพราะ 3 จุดที่ห่างเท่ากันให้ความชันเท่ากับความชันระหว่างจุดปลายเสมอ (misconception จะเท่ากับคำตอบ)
- ข้อเสนอแผน: การหาตัวผกผัน 3 × 3 ด้วยเกาส์–จอร์แดน (ข้อเสนอจาก math-46) ยังไม่ได้สอนที่นี่ เพราะไม่อยู่ในตัวชี้วัด MIT18.06 6, 7, 10, 11, 16

## math.de.first-order

- 17 ข้อ ภาพ 2 ภาพ (สนามความชันของการเย็นตัวพร้อมเส้นข้าวต้มและน้ำเย็น ถังผสมที่ใช้ในโจทย์ p013) บริบทไทย: ข้าวต้มเย็นตัว บ่อพักน้ำเลี้ยงกุ้งจันทบุรี ผักตบชวาในบึงสุพรรณบุรี การให้ยาทางหลอดเลือดดำในโรงพยาบาลจังหวัด
- ครึ่งชีวิตของยา (4 ชั่วโมง) อัตราการให้ยา และค่า k ทั้งหมดเป็นค่าสมมติ ไม่ได้อ้างยาจริง
- prerequisite `math.calculus.integration-techniques` อยู่ในชุดนี้ (ลอจิสติกใช้เศษส่วนย่อย ตัวประกอบอินทิเกรตใช้การแทนค่าและทีละส่วน)

## math.calculus.multiple-integrals

- 18 ข้อ ภาพ 2 ภาพ (บริเวณเดียวกันด้วยแถบแนวตั้งและแนวนอน แปลงที่ดินริมคลองในโจทย์ p006) บริบทไทย: แปลงที่ดินปทุมธานีเป็นไร่ น้ำฝนบนนาข้าวนครสวรรค์ แป้นหมุนปั้นดินเผาด่านเกวียน
- ไม่มีสื่อโต้ตอบ เพราะ function-plot วาดได้เฉพาะ y = f(x) และ vector-add เป็นสองมิติ ไม่ช่วยแสดงบริเวณหรือปริมาตร ข้อเสนอ: วิดเจ็ตบริเวณสองมิติที่ลากแถบ dx/dy ได้ หรือพื้นผิวสามมิติที่หมุนได้
- ข้อเสนอแผน: ขอบเขตของแผนรวมพิกัดทรงกระบอกและทรงกลม ซึ่งตรงกับ CALC3 5.5 แต่แผนไม่ได้ผูก CALC3 5.5 ไว้ บทเรียนและโจทย์ p010, p014 สอนส่วนนี้แล้ว ผู้ประสานงานอาจเพิ่ม CALC3 5.5 ในแผน/ไฟล์จับคู่ (ไม่ได้ใส่เองเพราะอยู่นอกแผน) ส่วนการเปลี่ยนตัวแปรด้วยจาโคเบียน (CALC3 5.7) ยังไม่มีหัวข้อผูก
- บทเรียนลิงก์ไป `physics.rotation.rotational-dynamics` สำหรับโมเมนต์ความเฉื่อย

## math.linalg.eigenvalues
