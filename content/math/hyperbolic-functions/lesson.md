## เริ่มจากสายที่ห้อยอยู่

ลองนึกถึงสายไฟที่แขวนระหว่างเสาสองต้น สายจะโค้งลงตรงกลางเพราะน้ำหนักของตัวมันเอง คนมักเข้าใจว่ารูปโค้งนี้เป็นพาราโบลา ซึ่งใกล้เคียงกันเมื่อโค้งตื้น แต่เมื่อสายยาวและห้อยลึกขึ้น รูปร่างจริงจะไม่ตรงกับพาราโบลาอีกต่อไป รูปร่างที่ถูกต้องเรียกว่า **โซ่ห้อย (catenary)** และมีสมการเป็น $y = a\cosh(x/a)$ ซึ่งใช้ฟังก์ชัน **ไฮเพอร์โบลิก** ที่เราจะศึกษาในหัวข้อนี้

ฟังก์ชันไฮเพอร์โบลิกไม่ได้มาจากวงกลมอย่างตรีโกณมิติ แต่มาจากเอกซ์โพเนนเชียล $e^x$ และ $e^{-x}$ โดยตรง ดังนั้นก่อนจะนิยามมัน เราต้องรู้จักลอการิทึมธรรมชาติก่อน

## ลอการิทึมธรรมชาติจากปริพันธ์

สำหรับ $x > 0$ ให้นิยาม

$$\ln x = \int_1^x \frac{dt}{t}$$

ถ้า $x > 1$ ปริพันธ์นี้เป็นพื้นที่ใต้กราฟ $y = 1/t$ ตั้งแต่ $t = 1$ ถึง $t = x$ ถ้า $0 < x < 1$ ค่าจะเป็นลบ จากทฤษฎีบทมูลฐานของแคลคูลัส $\dfrac{d}{dx}\ln x = \dfrac{1}{x}$ เสมอ

ด้วยนิยามนี้ สมบัติ $\ln(ab) = \ln a + \ln b$ พิสูจน์ได้โดยดิฟฟังก์ชัน $f(b) = \ln(ab) - \ln b$ เทียบกับ $b$ จะได้ $f'(b) = \dfrac{1}{ab}\cdot a - \dfrac{1}{b} = 0$ ดังนั้น $f$ เป็นค่าคงที่ และที่ $b = 1$ จะได้ $f(1) = \ln a$

ฟังก์ชัน $\ln x$ เพิ่มขึ้นตลอดและรับค่าทุกจำนวนจริง จึงมีฟังก์ชันผกผัน ผกผันนั้นคือ $e^x$ โดยที่ $e$ คือจำนวนที่ทำให้ $\ln e = 1$ จากนั้นเราจึงนิยาม $a^x = e^{x\ln a}$ และ $\log_a x = \dfrac{\ln x}{\ln a}$ ได้สำหรับ $a > 0$

## นิยามฟังก์ชันไฮเพอร์โบลิก

จาก $e^x$ และ $e^{-x}$ เราสร้างฟังก์ชันสามตัว

- ไซน์ไฮเพอร์โบลิก $\sinh x = \dfrac{e^x - e^{-x}}{2}$
- โคไซน์ไฮเพอร์โบลิก $\cosh x = \dfrac{e^x + e^{-x}}{2}$
- แทนเจนต์ไฮเพอร์โบลิก $\tanh x = \dfrac{\sinh x}{\cosh x}$

สังเกตลักษณะของกราฟ $\sinh$ เป็นฟังก์ชันคี่ คือ $\sinh(-x) = -\sinh x$ ผ่านจุดกำเนิด และเพิ่มขึ้นตลอด ส่วน $\cosh$ เป็นฟังก์ชันคู่ มีค่าต่ำสุดเท่ากับ $1$ ที่ $x = 0$ และเพิ่มขึ้นเมื่อ $x > 0$ ค่าของ $\tanh x$ อยู่ระหว่าง $-1$ ถึง $1$ และเข้าใกล้ $\pm 1$ เมื่อ $x$ มากขึ้นหรือน้อยลงมาก ๆ

เอกลักษณ์สำคัญที่สุดคือ

$$\cosh^2 x - \sinh^2 x = 1$$

เครื่องหมายลบในเอกลักษณ์นี้ทำให้ชื่อ "ไฮเพอร์โบลิก" มีที่มา เพราะจุด $(\cosh t, \sinh t)$ ทั้งหมดอยู่บนส่วนหนึ่งของไฮเพอร์โบลา $x^2 - y^2 = 1$ ในขณะที่ $(\cos t, \sin t)$ อยู่บนวงกลม

## อนุพันธ์และปริพันธ์

จากนิยามด้วย $e^x$ เราดิฟได้ทันที

$$\frac{d}{dx}\sinh x = \cosh x, \qquad \frac{d}{dx}\cosh x = \sinh x$$

และจากกฎผลหาร $\dfrac{d}{dx}\tanh x = \dfrac{\cosh^2 x - \sinh^2 x}{\cosh^2 x} = \dfrac{1}{\cosh^2 x}$

สูตรเหล่านี้ย้อนกลับเป็นปริพันธ์ได้ทันที เช่น $\int \cosh x\,dx = \sinh x + C$ และ $\int \sinh x\,dx = \cosh x + C$ ระวังว่า $\int \sinh x\,dx$ **ไม่มี**เครื่องหมายลบ เพราะ $\dfrac{d}{dx}\cosh x = +\sinh x$

สำหรับ $\tanh x$ ใช้การแทนค่า $u = \cosh x$ จะได้ $\int \tanh x\,dx = \ln(\cosh x) + C$

เมื่อโจทย์มีตัวแปรอยู่ในวงเล็บ อย่าลืมตัวคูณจากกฎลูกโซ่ เช่น $\dfrac{d}{dx}\cosh(3x) = 3\sinh(3x)$

## ฟังก์ชันไฮเพอร์โบลิกผกผัน

ฟังก์ชันผกผันของ $\sinh$ เขียนได้ด้วยลอการิทึม

$$\sinh^{-1} x = \ln\!\big(x + \sqrt{x^2+1}\big)$$

ใช้ได้กับทุกจำนวนจริง ส่วนผกผันของ $\cosh$ มีโดเมน $x \ge 1$ และเป็น $\ln(x + \sqrt{x^2-1})$ ผลนี้ทำให้เราหาอนุพันธ์ได้ว่า $\dfrac{d}{dx}\sinh^{-1}x = \dfrac{1}{\sqrt{x^2+1}}$ ซึ่งเป็นสูตรที่ใช้บ่อยมากในการหาปริพันธ์ที่มีรากกำลังสอง

## โซ่ห้อยและความยาวสาย

ให้ $y = a\cosh(x/a)$ ความยาวส่วนโค้งเขียนได้เป็น $\displaystyle s = \int\sqrt{1 + (y')^2}\,dx$ โดย $y' = \sinh(x/a)$ จากเอกลักษณ์ $1 + \sinh^2 u = \cosh^2 u$ จะได้ $\sqrt{1+\sinh^2} = \cosh$ จึงเหลือปริพันธ์ง่าย ๆ ของ $\cosh$

สำหรับสายที่แขวนระหว่างจุดที่ $x = -L$ และ $x = L$ จะได้ความยาว

$$s = \int_{-L}^{L}\cosh(x/a)\,dx = 2a\sinh(L/a)$$

ค่าที่ได้จึงยาวกว่าระยะห่างระหว่างเสาเสมอ ซึ่งสอดคล้องกับความจริงที่ว่าสายโค้งลงยาวกว่าเส้นตรง ค่าของ $a$ ขึ้นกับน้ำหนักต่อความยาวและแรงดึงของสาย ดังนั้นในทางปฏิบัติจะต้องตรวจค่าจริงจากวิศวกรรม

## ข้อผิดพลาดที่พบบ่อย

- **สับสนกับตรีโกณมิติ** $\cosh$ ไม่ใช่ $\cos$ และเอกลักษณ์ $\cosh^2 x + \sinh^2 x = 1$ เป็นเท็จ
- **ลืมตัวหาร 2** ในนิยาม $\cosh$ และ $\sinh$ ทำให้ค่าผิดเป็นสองเท่า
- **ดิฟ $\sinh$ แล้วได้ $-\cosh$** อนุพันธ์ของ $\sinh$ คือ $+\cosh$ เสมอ
- **ใช้ระยะตรงระหว่างเสาแทนความยาวสาย** สายที่โค้งจะยาวกว่าระยะตรงเสมอ

ทบทวนนิยามผ่าน $e^x$ ให้แม่นก่อน ทุกสูตรในหัวข้อนี้ย้อนกลับไปหาเอกซ์โพเนนเชียลและลอการิทึมได้เสมอ
