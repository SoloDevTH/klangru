## เมื่อแรงแกว่งเข้าสู่ระบบ

รถกระบะที่วิ่งผ่านถนนลูกระนาดจะกระเทือนตามจังหวะของลูกระนาด ถ้าจังหวะนั้นใกล้กับความถี่ที่ระบบกันสะเทือนชอบสั่นเอง รถจะกระเทือนแรงมาก ปรากฏการณ์นี้คือ **เรโซแนนซ์** และคณิตศาสตร์ที่อธิบายมันคือการแก้สมการเชิงอนุพันธ์เชิงเส้นที่มีอินพุตเป็นไซน์ หัวข้อนี้จะแสดงว่าผลตอบสนองที่คงตัวของระบบเช่นนี้มีรูปอย่างไร และมีเกนกับเฟสล้าอย่างไร

## อินพุตเอกซ์โพเนนเชียลและเชิงซ้อน

พิจารณาสมการเชิงเส้นอันดับสอง $p(D)\,y = u(t)$ เมื่อ $D = d/dt$ และ $p(r)$ คือพหุนามลักษณะเฉพาะ ถ้าอินพุตเป็น $u(t) = e^{rt}$ และ $p(r) \ne 0$ จะมีผลตอบสนองที่คงตัว

$$y_p = \frac{e^{rt}}{p(r)}$$

เพราะการดิฟ $e^{rt}$ ได้ตัวคูณ $r$ ซ้ำไปมา จึงแทนค่า $p(D)$ ได้เป็น $p(r)$ คูณกับ $e^{rt}$ โดยตรง

ไซน์และโคไซน์เป็นส่วนจริงหรือส่วนจินตภาพของ $e^{i\omega t}$ เนื่องจาก $e^{i\omega t} = \cos\omega t + i\sin\omega t$ เมื่อ $u(t) = \cos\omega t = \operatorname{Re}(e^{i\omega t})$ ผลตอบสนองที่คงตัวคือส่วนจริงของผลตอบสนองต่อ $e^{i\omega t}$ ซึ่งเป็น

$$y_p = \operatorname{Re}\!\left(\frac{e^{i\omega t}}{p(i\omega)}\right)$$

## เกนและเฟสล้า

เขียน $p(i\omega)$ ในรูปขั้วเป็น $|p(i\omega)|\,e^{i\varphi_p}$ จะได้

$$y_p = \frac{1}{|p(i\omega)|}\cos(\omega t - \varphi_p)$$

สองค่านี้มีความหมายชัดเจน

- **เกน** $G(\omega) = \dfrac{1}{|p(i\omega)|}$ คืออัตราส่วนระหว่างแอมพลิจูดของผลตอบสนองกับแอมพลิจูดของอินพุต
- **เฟสล้า** $\varphi = \arg p(i\omega)$ คือมุมที่ผลตอบสนองตามหลังอินพุต ถ้าค่าเป็นบวกผลตอบสนองล้าหลัง

ภาพเวกเตอร์ในระนาบเชิงซ้อนช่วยให้เห็นได้ง่าย ความยาวของเวกเตอร์ $p(i\omega)$ ทำให้เกนลดลงเมื่อยาวขึ้น และมุมของมันคือเฟสล้า

## ระบบอันดับหนึ่งและอันดับสอง

สำหรับระบบอันดับหนึ่ง $y' + ay = \cos\omega t$ เรามี $p(s) = s + a$ จึง $p(i\omega) = a + i\omega$ เกนคือ $1/\sqrt{a^2 + \omega^2}$ เมื่อความถี่สูงขึ้น เกนจะลดลงเข้าใกล้ศูนย์ ระบบจึงกรองสัญญาณความถี่สูงออกไป

สำหรับระบบมวล-สปริง-ตัวหน่วง $m x'' + c x' + k x = F_0\cos\omega t$ จะได้

$$\text{แอมพลิจูด} = \frac{F_0}{\sqrt{(k - m\omega^2)^2 + c^2\omega^2}}$$

และแอมพลิจูดนี้มีค่าสูงสุดที่ความถี่

$$\omega_r = \sqrt{\frac{k}{m} - \frac{c^2}{2m^2}}$$

ถ้าไม่มีการหน่วง $c = 0$ ค่าสูงสุดจะเกิดที่ $\omega = \sqrt{k/m}$ ซึ่งเป็นความถี่ธรรมชาติพอดี การหน่วงทำให้จุดสูงสุดเลื่อนไปทางความถี่ที่ต่ำกว่า และลดค่าสูงสุดลง

## กราฟผลตอบสนองเชิงความถี่

เมื่อวาดเกนและเฟสเทียบกับความถี่ $\omega$ เราได้ **ผลตอบสนองเชิงความถี่** เกนมีพฤติกรรมที่ทำนายได้ ถ้าระบบมีตัวหน่วงน้อย เส้นโค้งจะแหลมมากที่ใกล้ความถี่เรโซแนนซ์ ส่วนเฟสจะเปลี่ยนจากศูนย์ไปเป็นค่าที่ใหญ่ขึ้นเมื่อความถี่ผ่านค่าธรรมชาติ

## หลักการซ้อนทับ

ระบบเชิงเส้นไม่แปรตามเวลาตอบสนองต่ออินพุตผลรวมด้วยผลรวมของผลตอบสนองแต่ละส่วน ถ้าอินพุตมีหลายความถี่ เราคำนวณผลตอบสนองของทุกความถี่แยกกันแล้วบวกกัน ความถี่ที่ไม่เท่ากันไม่ปะปนกันในผลตอบสนองที่คงตัว และการคูณอินพุตด้วยค่าคงที่จะคูณผลตอบสนองด้วยค่าเดียวกัน

## การประยุกต์

วงจร RC อนุกรมที่มีแรงดันไซน์ข้ามตัวเก็บประจุมีเกน $\dfrac{1}{\sqrt{1 + (\omega RC)^2}}$ เมื่อ $\omega RC$ ใหญ่ เกนเล็กลงมาก ทำให้วงจรลดความผันผวนความถี่สูง วงจร RLC อนุกรมที่ต่อกับแหล่งไซน์มีความถี่ที่กระแสสูงสุดคือ $\omega = 1/\sqrt{LC}$ ซึ่งเป็นหลักของการเลือกคลื่นวิทยุ ระบบกันสะเทือนรถก็ใช้แนวคิดเดียวกัน เพื่อให้ความถี่ของถนนลูกระนาดไม่ตรงกับความถี่เรโซแนนซ์ของตัวรถ

## ข้อผิดพลาดที่พบบ่อย

- **ใช้ $\omega^2$ แทน $-\omega^2$** เมื่อแทน $r = i\omega$ ในพหุนาม $r^2 + \cdots$
- **ตอบเฟสเป็นองศาแทนเรเดียน** เมื่อโจทย์ใช้เรเดียน ต้องตรวจหน่วยให้สอดคล้องกัน
- **ใช้ $\arctan$ โดยไม่ดูจตุภาค** อาร์กิวเมนต์ของจำนวนเชิงซ้อนที่ส่วนจริงเป็นลบต้องดูว่าอยู่ควอดแรนต์ใด
- **คิดว่าเรโซแนนซ์เกิดที่ความถี่ธรรมชาติพอดีเสมอ** ระบบที่มีการหน่วงจะเกิดที่ความถี่ที่ต่ำกว่าเล็กน้อย
