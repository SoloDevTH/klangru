# ตัวชี้วัดที่ไม่วางแผน กลุ่ม sciences (เฟส 10)

กลุ่มนี้คือตัวชี้วัด `university-foundations` สาระ `university-physics-1` `university-physics-2` `general-chemistry` และ `general-biology` ที่ยังไม่มีหัวข้อผูกไว้ 429 ข้อ ทุกข้อเป็นชื่อหัวข้อย่อยในสารบัญตำรา OpenStax ซึ่งเป็นเนื้อหาที่อ่าน คำนวณ และตอบโจทย์ในแอปได้ จึง **ไม่มีตัวชี้วัดที่ไม่วางแผน**

- จับคู่กับหัวข้อเดิมใน `docs/phase10/existing-sciences.yaml`
- หัวข้อใหม่ใน `docs/phase6/proposals-phase10-sciences.yaml`

หัวข้อย่อยที่ตำราสอนคู่กับการลงมือในห้องปฏิบัติการ เช่น CHEM 1.4 (การวัด) CHEM 4.5 (การวิเคราะห์เชิงปริมาณ) และ UPHYS2 10.4 (เครื่องมือวัดไฟฟ้า) จับคู่กับหัวข้อเดิมในส่วนที่เป็นความรู้และการคำนวณ (การเลือกเครื่องมือ การอ่านค่า การคำนวณจากผลการไทเทรตและมวลตะกอน การต่อมิเตอร์) ส่วนทักษะการลงมือทำจริงวัดในแอปไม่ได้ จึงไม่ได้สร้างหัวข้อแยก
