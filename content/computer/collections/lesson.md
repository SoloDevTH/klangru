## เก็บข้อมูลหลายค่าให้เป็นระเบียบ

ครูประจำชั้นต้องเก็บคะแนนของนักเรียนทั้งห้อง คะแนนของแต่ละคน และคะแนนรวมของทั้งวิชา ถ้าใช้ตัวแปรแยกกันทุกตัวจะยุ่งมาก Python มีโครงสร้างข้อมูลหลายแบบที่จัดกลุ่มค่าไว้ด้วยกัน บทนี้จะดูว่าตัวแปรทำงานอย่างไรกับข้อมูลเหล่านี้ และเรียงลำดับ วนซ้ำ และสร้างโครงสร้างซ้อนกันอย่างถูกต้อง

## ตัวแปรเป็นชื่อที่ชี้ไปยังวัตถุ

ตัวแปรไม่ได้เก็บข้อมูลไว้ในตัวเอง แต่เป็น **ชื่อ** ที่ชี้ไปยังวัตถุในหน่วยความจำ ดังนั้นถ้ามีตัวแปรสองตัวชี้ไปยังวัตถุเดียวกัน การแก้ไขผ่านตัวหนึ่งจะเห็นผลในอีกตัวหนึ่งด้วย

```python
a = [1, 2, 3]
b = a            # b ชี้ไปยังลิสต์เดิม ไม่ได้สร้างสำเนา
b.append(4)
print(a)         # [1, 2, 3, 4]
print(a is b)    # True  เป็นวัตถุเดียวกัน
print(a == b)    # True  ค่าเท่ากัน
```

- `is` ตรวจว่าสองชื่อชี้ไปยังวัตถุเดียวกันหรือไม่
- `==` ตรวจว่าค่าของสองวัตถุเท่ากันหรือไม่

วัตถุแบ่งได้เป็นสองพวก วัตถุที่ **แก้ไขได้** เช่น ลิสต์ ดิกชันนารี และเซต และวัตถุที่ **แก้ไขไม่ได้** เช่น จำนวน สตริง และทูเพิล ข้อนี้สำคัญเมื่อส่งข้อมูลเข้าฟังก์ชัน เพราะฟังก์ชันที่รับลิสต์สามารถแก้ไขลิสต์ของผู้เรียกได้โดยตรง

## ทูเพิล: กลุ่มค่าที่แก้ไม่ได้

ทูเพิลเขียนด้วยวงเล็บกลม เหมาะกับข้อมูลที่ไม่ควรเปลี่ยน เช่น พิกัดหรือวันเดือนปี และใช้คืนค่าหลายค่าจากฟังก์ชันได้

```python
def min_max(values):
    return min(values), max(values)   # คืนทูเพิลสองค่า

lo, hi = min_max([7, 2, 9])           # แตกค่าออกเป็นตัวแปรสองตัว
print(lo, hi)                         # 2 9
```

ทูเพิลที่มีสมาชิกตัวเดียวต้องมีเครื่องหมายคอมมา เช่น `(5,)` มิฉะนั้น Python จะมองเป็นเพียงวงเล็บคณิตศาสตร์

## การเรียงลำดับ

`sort()` เรียงลิสต์เดิมให้เปลี่ยนไปทันที ส่วน `sorted()` คืนลิสต์ใหม่และไม่แก้ของเดิม ทั้งสองรับอาร์กิวเมนต์ `reverse=True` เพื่อเรียงจากมากไปน้อย และ `key=` เพื่อบอกว่าจะเทียบกันด้วยค่าอะไร

```python
scores = [70, 95, 82]
print(sorted(scores, reverse=True))    # [95, 82, 70]
print(scores)                          # [70, 95, 82] ไม่เปลี่ยน
names = ["ปลื้ม", "ต้นกล้า", "ฟ้า"]
print(sorted(names, key=len))          # เรียงตามความยาวสตริง
```

เมื่อต้องเรียงตามหลายเกณฑ์ ให้ใช้ทูเพิลเป็นคีย์ ตัวเลขที่ใส่เครื่องหมายลบจะเรียงจากมากไปน้อย

```python
rows = [("ฟ้า", 70), ("ต้น", 95), ("มด", 70)]
print(sorted(rows, key=lambda r: (-r[1], r[0])))
# [('ต้น', 95), ('ฟ้า', 70), ('มด', 70)]
```

## ลิสต์ซ้อนเป็นตารางและกริด

ลิสต์ซ้อนในลิสต์ใช้แทนตารางได้ เข้าถึงช่องด้วย `grid[แถว][คอลัมน์]`

```python
grid = [[1, 2, 3], [4, 5, 6]]
print(grid[1][2])     # 6  แถวที่ 1 คอลัมน์ที่ 2 (นับจาก 0)
```

กับดักที่พบบ่อยคือการสร้างกริดด้วย `[[0] * 3] * 3` ผลดูเหมือนถูก แต่แถวทั้งสามชี้ไปยังลิสต์เดียวกัน เมื่อแก้แถวหนึ่งจะเปลี่ยนทุกแถว วิธีที่ถูกคือใช้ list comprehension สร้างแถวใหม่ทุกครั้ง

```python
grid = [[0] * 3 for _ in range(3)]
grid[0][1] = 5
print(grid)           # [[0, 5, 0], [0, 0, 0], [0, 0, 0]]
```

การคัดลอกลิสต์ซ้อนก็ต้องระวังเช่นกัน `grid[:]` คัดลอกเฉพาะชั้นนอก แถวข้างในยังเป็นวัตถุเดิม ต้องคัดลอกทุกแถว หรือใช้ `copy.deepcopy(grid)` จากโมดูลมาตรฐาน `copy`

## List comprehension

เขียนลิสต์ใหม่จากลิสต์เดิมในบรรทัดเดียวได้ ตามรูป `[นิพจน์ for ตัวแปร in ลำดับ if เงื่อนไข]`

```python
print([x * x for x in range(5) if x % 2 == 0])   # [0, 4, 16]
```

## ดิกชันนารี

ดิกชันนารีเก็บคู่ คีย์ และค่า สร้างได้จาก `dict(zip(คีย์, ค่า))` หรือ comprehension

```python
ages = dict(zip(["ฟ้า", "ต้น"], [17, 16]))
ages["มด"] = 18                    # เพิ่มคู่ใหม่
ages.update({"ฟ้า": 18})          # แก้ค่าของคีย์เดิม
print(ages.get("ปลื้ม", 0))       # 0  ถ้าไม่มีคีย์ คืนค่าที่กำหนดไว้
print(ages.pop("มด"))             # 18 ลบคู่และคืนค่า
del ages["ต้น"]                   # ลบคู่โดยไม่ต้องการค่ากลับ
ages.setdefault("ใหม่", 0)        # ถ้ายังไม่มีคีย์ ใส่ค่า 0 ให้
```

ดิกชันนารีซ้อนดิกชันนารีใช้เก็บระเบียนที่มีหลายช่อง เช่น คะแนนของนักเรียนแต่ละคนในแต่ละวิชา การวนผ่านต้องใช้ `items()` เพื่อได้ทั้งคีย์และค่า

```python
students = {"ฟ้า": {"math": 18, "eng": 15}, "ต้น": {"math": 12, "eng": 20}}
for name, marks in students.items():
    print(name, marks["eng"])
```

## ตัวอย่างการจัดกลุ่มรายการ

ต้องการจัดคะแนนตามห้องเรียน โดยเก็บรายการเป็นคู่ `(ห้อง, คะแนน)` และสร้างลิสต์ของคะแนนในแต่ละห้อง ขั้นแรกสร้างดิกชันนารีว่าง ขั้นที่สอง วนผ่านทุกคู่ แล้วใช้ `setdefault(ห้อง, [])` เพื่อให้ได้ลิสต์ของห้องนั้นเสมอ ขั้นสุดท้ายเพิ่มคะแนนลงไป วิธีนี้ไม่ต้องตรวจก่อนว่าห้องเคยมีหรือยัง

## ข้อผิดพลาดที่พบบ่อย

- คิดว่า `b = a` สร้างลิสต์ใหม่ แล้วแก้ `b` แล้วลืมว่า `a` เปลี่ยนไปด้วย
- ใช้ `==` ตรวจว่าเป็นวัตถุเดียวกัน ทั้งที่ควรใช้ `is`
- เรียกเมธอด `sort()` แล้วคาดหวังว่าจะได้ลิสต์ใหม่ ทั้งที่มันคืนค่า `None`
- ใช้ `d[คีย์]` กับคีย์ที่ไม่มี แล้วโปรแกรมหยุดด้วย KeyError ควรใช้ `get` หรือ `setdefault` แทน

## คำถามชวนคิด

ถ้าอยากเก็บข้อมูลบัตรประจำตัวนักเรียนที่ไม่ควรถูกแก้ไขระหว่างโปรแกรมทำงาน ควรใช้ลิสต์ ทูเพิล หรือดิกชันนารี และเพราะเหตุใด
