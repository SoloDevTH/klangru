## รากที่สองที่แทนค่าธรรมดาไม่ได้

พื้นที่ของวงกลมรัศมี $a$ คือ $4\int_0^a \sqrt{a^2 - x^2}\,dx$ ความยาวสายเคเบิลที่ห้อยเป็นรูปพาราโบลามีพจน์ $\sqrt{1 + k^2x^2}$ อยู่ในปริพันธ์ ปริพันธ์แบบนี้ไม่มีฟังก์ชันชั้นในที่อนุพันธ์คูณอยู่ การแทนค่า $u = a^2 - x^2$ จึงไม่ช่วย แต่เอกลักษณ์ตรีโกณมิติช่วยได้ เพราะ $a^2 - a^2\sin^2\theta = a^2\cos^2\theta$ เป็นกำลังสองสมบูรณ์ บทนี้ต่อจาก[เทคนิคการหาปริพันธ์](/topic/math.calculus.integration-techniques/) ซึ่งสอนปริพันธ์ $\sin^m x\cos^n x$ ไว้แล้ว และใช้เอกลักษณ์จาก[ฟังก์ชันตรีโกณมิติ](/topic/math.functions.trig-functions/)

## ปริพันธ์ของกำลังของ $\tan x$ และ $\sec x$

หลักการเหมือนกับ $\sin^m x\cos^n x$ คือแยกตัวประกอบหนึ่งตัวไว้เป็น $du$ แล้วเปลี่ยนที่เหลือด้วยเอกลักษณ์ $\sec^2 x = 1 + \tan^2 x$ โดยใช้ $(\tan x)' = \sec^2 x$ และ $(\sec x)' = \sec x\tan x$

- **กำลังของ $\sec x$ เป็นคู่** เก็บ $\sec^2 x$ ไว้ เปลี่ยน $\sec$ ที่เหลือเป็น $\tan$ แล้วให้ $u = \tan x$
- **กำลังของ $\tan x$ เป็นคี่** เก็บ $\sec x\tan x$ ไว้ เปลี่ยน $\tan$ ที่เหลือเป็น $\sec$ แล้วให้ $u = \sec x$
- กรณีอื่น เช่น $\int \sec^3 x\,dx$ ใช้ปริพันธ์ทีละส่วน

ปริพันธ์พื้นฐานที่ต้องจำคือ $\int \tan x\,dx = \ln|\sec x| + C$ และ $\int \sec x\,dx = \ln|\sec x + \tan x| + C$

ผลคูณของไซน์และโคไซน์ที่ **มุมต่างกัน** เปลี่ยนเป็นผลบวกด้วย **สูตรผลคูณเป็นผลบวก**

$$\sin mx\cos nx = \tfrac12\big[\sin(m + n)x + \sin(m - n)x\big]$$

$$\sin mx\sin nx = \tfrac12\big[\cos(m - n)x - \cos(m + n)x\big], \qquad \cos mx\cos nx = \tfrac12\big[\cos(m - n)x + \cos(m + n)x\big]$$

เช่น $\int \sin 5x\cos 2x\,dx = \tfrac12\int(\sin 7x + \sin 3x)\,dx = -\tfrac{\cos 7x}{14} - \tfrac{\cos 3x}{6} + C$ สูตรเหล่านี้ทำให้ได้ว่า $\int_{-\pi}^{\pi}\sin mx\sin nx\,dx = 0$ เมื่อ $m \ne n$ ซึ่งเป็นพื้นฐานของอนุกรมฟูริเยร์ที่ใช้แยกเสียงและสัญญาณเป็นความถี่

## การแทนค่าด้วยตรีโกณมิติ

| รูปในปริพันธ์ | แทนค่า | เอกลักษณ์ที่ใช้ |
|---|---|---|
| $\sqrt{a^2 - x^2}$ | $x = a\sin\theta$ | $a^2 - a^2\sin^2\theta = a^2\cos^2\theta$ |
| $\sqrt{a^2 + x^2}$ | $x = a\tan\theta$ | $a^2 + a^2\tan^2\theta = a^2\sec^2\theta$ |
| $\sqrt{x^2 - a^2}$ | $x = a\sec\theta$ | $a^2\sec^2\theta - a^2 = a^2\tan^2\theta$ |

ขั้นตอนคือ แทน $x$ และ $dx$ (เช่น $dx = a\cos\theta\,d\theta$) ตัดรากที่สองออก หาปริพันธ์ในตัวแปร $\theta$ แล้ว **วาดสามเหลี่ยมอ้างอิง** เพื่อกลับเป็น $x$ ดังภาพ เช่น $x = a\sin\theta$ แปลว่า $\sin\theta = \tfrac{x}{a}$ จึงวาดด้านตรงข้าม $x$ ด้านตรงข้ามมุมฉาก $a$ และด้านประชิดได้ $\sqrt{a^2 - x^2}$ จากพีทาโกรัส

**ตัวอย่าง** $\displaystyle\int \frac{dx}{x^2\sqrt{9 - x^2}}$ ให้ $x = 3\sin\theta$, $dx = 3\cos\theta\,d\theta$ และ $\sqrt{9 - x^2} = 3\cos\theta$ จะได้

$$\int \frac{3\cos\theta\,d\theta}{9\sin^2\theta \cdot 3\cos\theta} = \frac19\int \csc^2\theta\,d\theta = -\frac19\cot\theta + C$$

จากสามเหลี่ยม $\cot\theta = \dfrac{\sqrt{9 - x^2}}{x}$ คำตอบคือ $-\dfrac{\sqrt{9 - x^2}}{9x} + C$

**ปริพันธ์จำกัดเขต** เปลี่ยนขอบเขตเป็น $\theta$ ไปพร้อมกันได้เลยโดยไม่ต้องกลับเป็น $x$ เช่น พื้นที่วงรี $\tfrac{x^2}{a^2} + \tfrac{y^2}{b^2} = 1$ คือ $4\int_0^a \tfrac{b}{a}\sqrt{a^2 - x^2}\,dx$ แทน $x = a\sin\theta$ ขอบเขต $x = 0 \to a$ กลายเป็น $\theta = 0 \to \tfrac{\pi}{2}$ ได้ $4ab\int_0^{\pi/2}\cos^2\theta\,d\theta = 4ab \cdot \tfrac{\pi}{4} = \pi ab$ ถ้า $a = b$ ก็ได้พื้นที่วงกลม $\pi a^2$

## เติมกำลังสองก่อน

นิพจน์กำลังสองที่มีพจน์ $x$ เช่น $\sqrt{x^2 + 4x + 13}$ ให้เติมกำลังสองเป็น $\sqrt{(x + 2)^2 + 9}$ แล้วแทน $x + 2 = 3\tan\theta$

## เลือกเทคนิคให้เหมาะ และใช้ตารางปริพันธ์

ก่อนลงมือ ลองถามตามลำดับ

1. จัดรูปหรือกระจายแล้วหาได้ทันทีหรือไม่
2. มีฟังก์ชันชั้นในที่อนุพันธ์คูณอยู่หรือไม่ ถ้ามี ใช้การแทนค่า
3. เป็นผลคูณของสองชนิด (พหุนามคูณ $e^x$ หรือ $\ln x$) ใช้ปริพันธ์ทีละส่วน
4. เป็นฟังก์ชันตรรกยะ ใช้เศษส่วนย่อย
5. เป็นกำลังของฟังก์ชันตรีโกณมิติ ใช้เอกลักษณ์ในบทนี้
6. มี $\sqrt{a^2 \pm x^2}$ หรือ $\sqrt{x^2 - a^2}$ ใช้การแทนค่าด้วยตรีโกณมิติ

**ตารางปริพันธ์** ในท้ายตำราและโปรแกรมคำนวณสัญลักษณ์ช่วยได้มาก แต่ต้องจัดรูปปริพันธ์ให้ตรงกับรูปในตาราง เช่น สูตร $\int \frac{du}{a^2 - u^2} = \frac{1}{2a}\ln\left|\frac{a + u}{a - u}\right| + C$ ใช้กับ $\int \frac{dx}{9 - 4x^2}$ ได้เมื่อให้ $u = 2x$ และอย่าลืม $dx = \tfrac12du$ ทุกคำตอบตรวจได้ด้วยการหาอนุพันธ์กลับ ฟังก์ชันบางตัวอย่าง $e^{-x^2}$ ไม่มีปฏิยานุพันธ์ในรูปฟังก์ชันพื้นฐาน ต้องใช้วิธีเชิงตัวเลข

## ข้อผิดพลาดที่พบบ่อย

- ลืมแทน $dx$ เป็น $a\cos\theta\,d\theta$ (หรือ $a\sec^2\theta\,d\theta$) แทนเฉพาะ $x$
- ตอบในตัวแปร $\theta$ โดยไม่กลับเป็น $x$ ด้วยสามเหลี่ยมอ้างอิง
- ใช้ขอบเขตเดิมของ $x$ กับปริพันธ์ในตัวแปร $\theta$
- เลือกการแทนค่าผิดรูป เช่น ใช้ $x = a\sin\theta$ กับ $\sqrt{a^2 + x^2}$
- ใช้สูตรผลคูณเป็นผลบวกแล้วลืม $\tfrac12$ หรือสลับเครื่องหมายในสูตร $\sin mx\sin nx$
- จำ $\int \tan x\,dx$ เป็น $\sec^2 x$ (สับสนกับอนุพันธ์)
