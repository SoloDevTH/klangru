## ข้อควรรู้ก่อนเขียน

- หัวข้อวิศวกรรมบางหัวข้อใช้หัวข้อในแผนวิทยาศาสตร์เป็น prerequisite (เช่น การออกแบบเครื่องปฏิกรณ์ต้องรอกฎอัตรา การถ่ายเทความร้อนต้องรออัตราการถ่ายเทความร้อน) ต้องเขียนหัวข้อวิทยาศาสตร์ก่อน
- ตัวรันโค้ดในแอปมีแต่ไลบรารีมาตรฐานของ Python (ไม่มี sqlite3, NumPy, Pandas, matplotlib, threading) หัวข้อฐานข้อมูลขั้นสูง การทำงานพร้อมกัน และการแสดงผลข้อมูลจึงใช้โจทย์ไล่โค้ดหรือการจำลองแทน
- ตัวชี้วัดหลายข้อของ OpenStax เป็นแคลคูลัส หัวข้อ ม.ปลายที่สอนแนวคิดเดียวกันโดยไม่ใช้แคลคูลัสนับเป็น full ตามแนวเดิมของคลัง ถ้าต้องการเข้มกว่านี้ให้ปรับเป็น partial
- เรื่องอ่อนไหว (ความผิดปกติของระบบประสาท สุขภาพจิต ความหลากหลายและความสัมพันธ์) ต้องให้ผู้เชี่ยวชาญตรวจก่อนเผยแพร่
- ค่าที่ต้องตรวจกับแหล่งปัจจุบันตอนเขียน: อัตราเงินสมทบประกันสังคมและ กอช. ขนาดพาเลท ISO เงื่อนไขประกันภัยขนส่งตาม Incoterms 2020 กฎหมายสิ่งแวดล้อมและ EIA ของไทย
