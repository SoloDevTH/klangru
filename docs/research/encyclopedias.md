# สารานุกรมและแหล่งอ้างอิงเปิดสำหรับคลังรู้

ตรวจเมื่อ 24 ต.ค. 2569 รายการเต็มพร้อมใบอนุญาต วิธีเรียก API และหน้าที่ใช้เป็นหลักฐาน อยู่ใน [`curriculum/sources.yaml`](../../curriculum/sources.yaml) ทุกใบอนุญาตตรวจจากหน้าของแหล่งนั้นเองในวันที่ตรวจ ไม่ได้อ้างจากความจำ

## สรุป

- รวบรวมไว้ 24 แหล่ง ดัดแปลงข้อความได้ (`adapt`) 9 แหล่ง และใช้ได้แค่ลิงก์ (`link-only`) 15 แหล่ง
- ใส่ `references` ครบทั้ง 92 หัวข้อ รวม 338 ลิงก์ ได้แก่ Wikipedia ไทย 119, Wikipedia อังกฤษ 126, Wikipedia จีน 3, Wiktionary 1 และ OpenStax 89 ลิงก์ทุกอันเปิดได้ (HTTP 200) ใช้ชื่อบทความหลักหลังตาม redirect แล้ว ไม่ใช่หน้าแก้ความกำกวม และอ่านเทียบกับบทเรียนแล้วว่าตรงเรื่อง

## ดัดแปลงได้ หรือได้แค่ลิงก์

เกณฑ์มาจาก ADR 0001 เนื้อหาที่ทีมเขียนใช้ CC BY-SA 4.0 เป็นค่าเริ่มต้น จึงดัดแปลงได้เฉพาะจากแหล่งที่งานดัดแปลงเป็น CC BY-SA ได้

| กลุ่ม | แหล่ง | เหตุผล |
|---|---|---|
| ดัดแปลงได้ | Wikipedia (th, en, simple, zh), Wikibooks, Wikiversity, Wiktionary, CC-CEDICT | CC BY-SA 4.0 ตรงกับค่าเริ่มต้นของคลัง |
| ดัดแปลงได้ | Wikidata | ข้อมูลเป็น CC0 ใช้กับใบอนุญาตใดก็ได้ |
| ลิงก์เท่านั้น (เว้นแต่หัวข้อเลือก CC BY-NC-SA) | OpenStax (เกือบทุกเล่ม), Khan Academy, MIT OCW, PhET | เป็น NC หรือ NC-SA งานดัดแปลงต้องเป็น CC BY-NC(-SA) ซึ่งเข้ากับ CC BY-SA ไม่ได้ |
| ลิงก์เท่านั้น | LibreTexts | ใบอนุญาตต่างกันทุกหน้า บางหน้าเป็น ND หรือไม่ระบุ ต้องตรวจทีละหน้า |
| ลิงก์เท่านั้น | CK-12 | ใช้ใบอนุญาตของตัวเอง (Curriculum Materials License) ไม่ใช่ CC เพิกถอนได้ และจำกัด "Educational Purposes" ไว้แคบ |
| ลิงก์เท่านั้น | สารานุกรมไทยฯ, ราชบัณฑิตยสภา, SciMath (สสวท.), ทรูปลูกปัญญา, Thai MOOC, HyperPhysics, MathWorld, Britannica, Stanford Encyclopedia of Philosophy | สงวนลิขสิทธิ์ ห้ามทำซ้ำหรือดัดแปลงโดยไม่ได้รับอนุญาต |

ข้อยกเว้นใน OpenStax: เล่ม *Physics* และ *Statistics* (ระดับมัธยมปลาย) ยังเป็น CC BY 4.0 ดัดแปลงได้ และเป็นเล่มที่ใช้มากที่สุดในหัวข้อฟิสิกส์ ส่วนเล่มอื่นที่อ้างถึงเป็น CC BY-NC-SA 4.0 ทั้งหมด (ดู `per_book` ใน sources.yaml)

## ใบอนุญาตที่เปลี่ยนไปจากที่ ADR 0001 เขียนไว้

ADR 0001 สั่งให้ยืนยันใบอนุญาตก่อนดัดแปลง และการตรวจครั้งนี้พบว่าข้อมูลเดิมล้าสมัย 3 แหล่ง

1. **OpenStax** ประกาศเมื่อ 22 เม.ย. 2569 ว่าเปลี่ยนทั้งคลังจาก CC BY ผสม CC BY-NC-SA มาเป็น CC BY-NC-SA สำหรับเล่มที่ออกใหม่และเล่มที่ปรับปรุง "with limited exceptions" ข้อมูลรายเล่มจาก CMS API ของ OpenStax ยืนยันว่า Prealgebra 2e, Elementary/Intermediate Algebra 2e, Algebra and Trigonometry 2e, Calculus Volume 1, Chemistry 2e, College Physics 2e และ Contemporary Mathematics เป็น CC BY-NC-SA 4.0 แล้ว
2. **PhET** simulation ที่เผยแพร่ตั้งแต่ 29 มี.ค. 2569 เป็น CC BY-NC 4.0 ส่วนรุ่นก่อนหน้านั้นยังเป็น CC BY 4.0 การฝัง simulation ใน `lessons` ยังทำได้เพราะคลังรู้ไม่หารายได้ แต่ต้องใช้ข้อความเครดิตแบบใหม่ และห้ามบังโลโก้ PhET
3. **CK-12** เปลี่ยนจาก CC BY-NC เป็น CK-12 Curriculum Materials License ตั้งแต่ ก.พ. 2564 จึงดัดแปลงมาใส่คลังไม่ได้แม้จะใช้ CC BY-NC-SA

Khan Academy ยังเป็น CC BY-NC-SA ตามที่ ADR เขียนไว้ (หน้า Help Center แก้ไขล่าสุด 19 ต.ค. 2569) และ MIT OCW เป็น CC BY-NC-SA 4.0 ควรแก้ ADR 0001 ส่วน "สิ่งที่การตัดสินใจนี้เปิดให้ใช้ได้" ให้ตรงกับข้อมูลนี้

## แอปควรใช้แหล่งเหล่านี้อย่างไร

**ตอนนี้: ลิงก์ "อ่านเพิ่มเติม"** แอปแสดง `references` ของแต่ละหัวข้อเป็นลิงก์ออกไปภายนอก ลิงก์ไม่ใช่การทำซ้ำ จึงลิงก์ไปแหล่งที่สงวนลิขสิทธิ์หรือเป็น NC ได้ทั้งหมด ลำดับในไฟล์คือบทความภาษาไทยก่อน ตามด้วยภาษาอังกฤษ ภาษาจีน และ OpenStax แอปควรแสดงชื่อแหล่งและภาษากำกับลิงก์ เพราะลิงก์ภาษาอังกฤษส่วนใหญ่ยากกว่าระดับบทเรียน

**ดัดแปลงข้อความจาก Wikipedia มาใส่บทเรียนได้** ถ้าทำตามนี้

- ใส่ `adapted_from` (ชื่อบทความ, URL, `CC-BY-SA-4.0`) ในหัวข้อหรือโจทย์ที่ดัดแปลง ตัวตรวจ `npm run validate` จะบังคับให้ชิ้นนั้นใช้ CC BY-SA 4.0
- ShareAlike ทำให้ชิ้นนั้นเปลี่ยนเป็นใบอนุญาตอื่นไม่ได้อีก ซึ่งตรงกับค่าเริ่มต้นของคลังอยู่แล้ว
- ภาพใน Wikipedia มีใบอนุญาตแยกตามไฟล์บน Wikimedia Commons ต้องตรวจทีละภาพ ไม่ได้เป็น CC BY-SA ทั้งหมด

**ห้ามดัดแปลงจากแหล่ง NC-SA (OpenStax ส่วนใหญ่, Khan Academy, MIT OCW) ลงในหัวข้อ CC BY-SA** ถ้าดัดแปลง หัวข้อหรือโจทย์นั้นต้องเปลี่ยนเป็น CC BY-NC-SA 4.0 ทั้งชิ้น ซึ่งเข้ากับค่าเริ่มต้น CC BY-SA ไม่ได้ และห้ามมีข้อความจาก Wikipedia ในชิ้นเดียวกัน ตาม ADR 0001 แหล่งเหล่านี้จึงเป็น link-only เว้นแต่หัวข้อนั้นเลือกใช้ BY-NC-SA โดยตั้งใจ ถ้าจะดัดแปลง OpenStax ให้เลือกเล่ม Physics หรือ Statistics ที่ยังเป็น CC BY ก่อน และเปิดหน้าใบอนุญาตตรวจซ้ำทุกครั้ง เพราะเล่มที่ปรับปรุงจะเปลี่ยนเป็น NC-SA

**ใช้ Wikidata และ CC-CEDICT เป็นข้อมูล** Wikidata (CC0) ใช้จับคู่บทความไทย อังกฤษ และจีน และดึงค่าข้อเท็จจริงได้ CC-CEDICT (CC BY-SA) ใช้เติมพินอินและคำแปลอังกฤษให้คำศัพท์จีนได้ แต่ไม่มีคำแปลภาษาไทย

## ความเสี่ยง

- **คุณภาพบทความ Wikipedia ภาษาไทยไม่สม่ำเสมอ** บางบทความยาวและดี เช่น อะตอม ตารางธาตุ และกฎการเคลื่อนที่ของนิวตัน แต่หลายบทความเป็นโครง (stub) สั้นไม่กี่ร้อยตัวอักษร เช่น อสมการ (153 ตัวอักษร จึงไม่ได้ใส่), เลนส์ (ทัศนศาสตร์) (209 จึงใช้ เลนส์บาง แทน), การเปลี่ยนสถานะ, มวล, เลขนัยสำคัญ และ ชนิดของคำ บางบทความเขียนระดับมหาวิทยาลัย เช่น ฟังก์ชันเลขชี้กำลัง ที่เน้น $e^x$ และจำนวนเชิงซ้อน บางบทความแปลมาไม่สละสลวย จึงต้องอ่านก่อนดัดแปลงทุกครั้ง และไม่ควรใช้เป็นแหล่งอ้างอิงข้อเท็จจริงเพียงแหล่งเดียว
- **หัวข้อที่ไม่มีบทความภาษาไทยที่ตรงเรื่อง (8 หัวข้อ)** ได้แก่ chinese/basic-strokes (ลำดับขีด), english/past-simple, english/present-perfect, english/present-simple, math/data-display (แผนภูมิแท่ง วงกลม ฮิสโทแกรม), math/linear-inequalities, physics/inclined-plane (บทความ "พื้นเอียง" พูดถึงเครื่องกลผ่อนแรง ไม่ใช่การแยกแรงบนพื้นเอียง) และ physics/motion-graphs ส่วนที่ตรงแค่บางส่วนคือ thai/word-types (บทความ "ชนิดของคำ" พูดถึงชนิดของคำทั่วไป ไม่ใช่ 7 ชนิดของไวยากรณ์ไทย) และ math/rearranging-formulas (บทความ "สูตร" ไม่ได้สอนการจัดรูป) หัวข้อเหล่านี้ควรเขียนบทความหรือ Wikibooks ภาษาไทยเอง
- **ยังไม่พบหน้าของสารานุกรมไทยฯ ที่ตรงกับหัวข้อ** เนื้อหาจัดเป็นเล่ม ค้นจากเครื่องมือภายนอกไม่เจอ ต้องให้คนไล่ดูสารบัญเล่ม
- **ใบอนุญาตเปลี่ยนได้** ในรอบปีนี้มีแหล่งเปลี่ยนจาก CC BY เป็น NC แล้ว 2 แหล่ง ใบอนุญาตใน `references[].license` เป็นค่า ณ วันที่ตรวจ ก่อนดัดแปลงจริงต้องเปิดหน้าใบอนุญาตตรวจซ้ำ และบันทึก URL ไว้ใน `adapted_from`
- **ลิงก์เสีย** บทความ Wikipedia ถูกเปลี่ยนชื่อหรือรวมกันได้ และหน้า OpenStax ผูกกับ slug ของรุ่นหนังสือ ควรเพิ่มงานตรวจลิงก์ตามรอบ (ใช้ redirect และ HTTP status) ใน CI
- **การจำกัดอัตราของ Wikimedia API** การเรียกจาก IP ที่ใช้ร่วมกันโดน HTTP 429 บ่อย เครื่องมือที่ดึงข้อมูลอัตโนมัติต้องใส่ User-Agent ที่ระบุช่องทางติดต่อ เว้นช่วงระหว่างคำขอ และเก็บแคช
- **ภาษาและระดับ** ลิงก์ภาษาอังกฤษและ OpenStax ส่วนใหญ่เป็นระดับมหาวิทยาลัยหรือมัธยมปลายของสหรัฐฯ ยากกว่าบทเรียนระดับต้น และ Wikipedia ภาษาจีนเหมาะกับครูมากกว่าผู้เรียน
- **แหล่งที่มีโฆษณาหรือต้องสมัคร** Britannica และทรูปลูกปัญญามีโฆษณา Britannica บางบทความต้องสมัครสมาชิก จึงไม่ได้ใส่ใน `references` ของหัวข้อใด
