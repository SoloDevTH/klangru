# เฟส 10: วางแผนปิดช่องว่างของหลักสูตรที่เหลือ (แนวทางสำหรับผู้วางแผนและ agent)

หลังเฟส 9 คลังมี 637 หัวข้อ และตัวชี้วัดจาก 39 หลักสูตร (5,901 ข้อ) ยังไม่มีหัวข้อใดผูกไว้ 1,371 ข้อ กลุ่มใหญ่คือวิชาพื้นฐานมหาวิทยาลัย (`university-foundations` 751 ข้อ), CSTA 2026 (144), ACM CS2023 (117), AC9 HPE (95), องค์ความรู้สภาวิศวกร (82), ABET (35), การงานอาชีพ (35), สุขศึกษาและพลศึกษา (25) ดูตัวเลขล่าสุดด้วย `npm run curriculum -- --missing`

ตัวชี้วัดจำนวนมากอาจมีหัวข้อในคลังสอนอยู่แล้วแต่ยังไม่ได้จับคู่ (เช่น เคมีทั่วไประดับมหาวิทยาลัยกับหัวข้อเคมี ม.ปลาย 38 หัวข้อ) แผนเฟส 10 จึงมีสองส่วน

## ส่วน ก: จับคู่กับหัวข้อที่มีอยู่แล้ว (ไม่ต้องเขียนหัวข้อใหม่)

สำหรับตัวชี้วัดแต่ละข้อ อ่าน `lesson.md` และ `problems.yaml` ของหัวข้อที่น่าจะสอน ถ้าหัวข้อนั้นสอนสิ่งที่ตัวชี้วัดเขียนไว้จริง ให้บันทึกใน `docs/phase10/existing-<กลุ่ม>.yaml`

```yaml
# ตัวชี้วัดที่หัวข้อเดิมสอนแล้ว ผู้ประสานงานตรวจแล้วรวมเข้า curriculum/mappings/
- { topic: chemistry.stoichiometry.reactions, framework: university-foundations, indicators: ["CHEM 4.1", "CHEM 4.2"], coverage: full, note: "..." }
- { topic: chemistry.gases.gas-laws, framework: university-foundations, indicators: ["CHEM 9.2"], coverage: partial, note: "ยังไม่มี ..." }
```

ตัดสินจากเนื้อหาจริงเท่านั้น ห้ามเดา `full` เมื่อหัวข้อสอนครบตามขอบเขตของตัวชี้วัด `partial` เมื่อสอนบางส่วน และเขียนใน note ว่าขาดอะไร

## ส่วน ข: หัวข้อใหม่ (รูปแบบเดียวกับแผนเฟส 6)

ตัวชี้วัดที่ไม่มีหัวข้อใดสอน ให้จัดกลุ่มเป็นหัวข้อใหม่ใน `docs/phase6/proposals-phase10-<กลุ่ม>.yaml` รูปแบบเดียวกับ `docs/phase6/proposals-phase9.yaml` (อ่าน `packages/content-tools/src/plan.ts` และไฟล์นั้นก่อน)

- หนึ่งหัวข้อ = หนึ่งบทเรียนที่เรียนจบได้ใน 30–60 นาที รวมตัวชี้วัดจากหลายหลักสูตรได้ ไม่แยกหนึ่งตัวชี้วัดต่อหนึ่งหัวข้อ
- รหัส `subject.area.slug` ไม่ซ้ำกับหัวข้อหรือโฟลเดอร์ที่มีอยู่ (เช็ก `content/<subject>/`)
- ความยากไม่ต่ำกว่าหัวข้อที่ต้องรู้ก่อนข้อใด และสอดคล้องกับหัวข้อในคลัง
- prerequisite ต้องมีอยู่จริงในคลังหรือในไฟล์แผน
- `scope` ภาษาไทย บอกสิ่งที่สอนให้ชัดพอให้ผู้เขียนเขียนได้
- ตัวชี้วัดที่แอปสอนหรือวัดไม่ได้ (ลงมือปฏิบัติจริง ออกกำลังกาย ทำงานกลุ่ม โครงงานยาว ห้องปฏิบัติการ เกณฑ์รับรองหลักสูตรของสถาบัน) ไม่ต้องสร้างหัวข้อ ให้ระบุใน `docs/phase10/not-planned-<กลุ่ม>.md` พร้อมเหตุผลสั้น ๆ
- เรียงความสำคัญ: ใส่ความคิดเห็นเหนือแต่ละหัวข้อว่า `# ลำดับ 1` (จำเป็น เป็นพื้นฐานของหลายเรื่อง) `# ลำดับ 2` หรือ `# ลำดับ 3` (เสริม)

## ตรวจ

- `npm run plan` และ `npm run plan -- --order` ไม่มี error
- `npm run validate -- --strict` ไม่มี error
- ทุกรหัสตัวชี้วัดต้องมีอยู่ใน `curriculum/frameworks/`
- ห้ามแก้ `content/`, `curriculum/`, `content/subjects.yaml` หรือไฟล์แผนของกลุ่มอื่น ไม่ commit ไม่ push

## รายงานท้ายงาน

จำนวนตัวชี้วัดในกลุ่ม → จับคู่กับหัวข้อเดิมได้กี่ข้อ (full/partial) → อยู่ในหัวข้อใหม่กี่ข้อ (กี่หัวข้อ แยกตามลำดับความสำคัญ) → ไม่วางแผนกี่ข้อเพราะอะไร และสิ่งที่ไม่แน่ใจ
