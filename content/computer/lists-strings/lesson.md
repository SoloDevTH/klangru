## ตัวแปร 40 ตัว หรือลิสต์เดียว

ครูต้องเก็บคะแนนสอบย่อยของนักเรียน 40 คน ถ้าใช้ตัวแปร `s1`, `s2`, ... ไปจนถึง `s40` จะต้องเขียนบวกยาว 40 ตัว และถ้าห้องนี้มี 41 คนก็ต้องแก้โปรแกรม วิธีที่ดีกว่าคือเก็บทั้งหมดไว้ใน **ลิสต์ (list)** ตัวเดียว แล้วใช้วงวนจัดการทุกตัวด้วยโค้ดชุดเดียว โปรแกรมจึงสั้นลงและใช้ได้กับข้อมูลกี่ตัวก็ได้ บทนี้ต่อจากบทฟังก์ชัน และเป็นพื้นฐานของบทค้นหาและเรียงลำดับ

## ลิสต์: ข้อมูลเรียงเป็นแถว

```python
scores = [12, 15, 9, 18, 11]
print(scores[0])      # 12  ดัชนีเริ่มที่ 0
print(scores[-1])     # 11  ดัชนีลบนับจากท้าย
print(len(scores))    # 5   จำนวนสมาชิก
print(scores[1:3])    # [15, 9]  ตัดช่วง ได้ดัชนี 1 ถึง 2
print(sum(scores), max(scores))   # 65 18
```

- **ดัชนี (index)** ของสมาชิกตัวแรกคือ 0 ตัวสุดท้ายคือ `len(scores) - 1` ถ้าใช้ดัชนีที่ไม่มีจะเกิด `IndexError`
- **การตัดช่วง (slicing)** `a[i:j]` ได้ตั้งแต่ดัชนี `i` ถึง `j - 1` ไม่รวม `j`
- วนผ่านทุกตัวด้วย `for x in scores:` หรือวนดัชนีด้วย `for i in range(len(scores)):` เมื่อต้องรู้ตำแหน่งหรือต้องแก้ค่า

```python
for i in range(len(scores)):
    scores[i] = scores[i] + 2     # บวกคะแนนช่วยทุกคน
print(scores)                     # [14, 17, 11, 20, 13]
```

## เพิ่ม ลบ และแก้สมาชิก

ลิสต์เปลี่ยนขนาดได้ระหว่างโปรแกรมทำงาน

| คำสั่ง | ผล |
|---|---|
| `a.append(x)` | เพิ่ม x ต่อท้าย |
| `a.insert(i, x)` | แทรก x ที่ดัชนี i |
| `a.remove(x)` | ลบ x **ตัวแรก** ที่พบ |
| `a.pop()` | ลบตัวสุดท้ายและคืนค่านั้น |
| `x in a` | `True` ถ้ามี x ในลิสต์ |

ข้อควรระวัง: `b = a` ไม่ได้คัดลอกลิสต์ แต่ทำให้ชื่อ `b` ชี้ไปที่ลิสต์เดียวกัน แก้ผ่าน `b` แล้ว `a` ก็เปลี่ยนด้วย ถ้าต้องการสำเนาให้ใช้ `b = a.copy()` และอย่าลบสมาชิกออกจากลิสต์ขณะวน `for` ผ่านลิสต์นั้น เพราะสมาชิกจะเลื่อนตำแหน่งจนบางตัวถูกข้ามไป ให้สร้างลิสต์ใหม่เก็บเฉพาะตัวที่ต้องการแทน

## ดิกชันนารี: ค้นด้วยชื่อ ไม่ใช่ด้วยตำแหน่ง

ร้านส้มตำมีรายการอาหารกับราคา ถ้าเก็บเป็นลิสต์ต้องจำว่าราคาไก่ย่างอยู่ช่องที่เท่าไร **ดิกชันนารี (dictionary)** เก็บเป็นคู่ **คีย์ (key)** กับ **ค่า (value)** จึงค้นด้วยชื่อได้ทันที

```python
price = {"ส้มตำ": 50, "ไก่ย่าง": 120, "ข้าวเหนียว": 10}
print(price["ไก่ย่าง"])           # 120
price["ลาบ"] = 80                  # เพิ่มคู่ใหม่
price["ส้มตำ"] = 55                # แก้ค่าเดิม
print("ลาบ" in price)              # True  ตรวจว่ามีคีย์นี้หรือไม่
print(price.get("น้ำตก", 0))       # 0  ไม่มีคีย์ จึงได้ค่าที่กำหนด
for food, baht in price.items():
    print(food, baht)
```

คีย์ในดิกชันนารีไม่ซ้ำกัน ถ้าเรียก `price["น้ำตก"]` ที่ไม่มีคีย์นี้จะเกิด `KeyError` จึงควรใช้ `get` หรือตรวจด้วย `in` ก่อน งานที่พบบ่อยคือ **นับความถี่** เช่น `count[w] = count.get(w, 0) + 1`

## เซต: กลุ่มที่ไม่มีตัวซ้ำ

**เซต (set)** เก็บสมาชิกที่ไม่ซ้ำกันและไม่สนลำดับ เหมาะกับคำถามว่า "มีหรือไม่" และ "มีกี่แบบ"

```python
visited = {"เชียงใหม่", "ระยอง", "เชียงใหม่"}
print(len(visited))                 # 2  ตัวซ้ำถูกตัดทิ้ง
visited.add("น่าน")
friend = {"น่าน", "กระบี่"}
print(visited & friend)            # {'น่าน'}  ไปด้วยกันทั้งคู่
```

## ประมวลผลข้อความ

**สตริง (string)** คือลำดับของอักขระ จึงใช้ดัชนี การตัดช่วง และ `len` ได้เหมือนลิสต์

```python
code = "TH-2568-BKK"
print(code[3:7])               # 2568
print(code.find("-"))          # 2   ดัชนีแรกที่พบ ไม่พบได้ -1
print(code.count("-"))         # 2
print(code.split("-"))         # ['TH', '2568', 'BKK']
print("/".join(["1", "6", "2568"]))   # 1/6/2568
print("  สวัสดี ".strip())        # สวัสดี  ตัดช่องว่างหัวท้าย
print("bkk".upper())           # BKK
```

สตริงแก้ทีละตัวไม่ได้ `code[0] = "X"` จะเกิดข้อผิดพลาด ต้องสร้างสตริงใหม่ เช่น `code.replace("BKK", "CNX")`

ภาษาไทยมีเรื่องต้องระวัง วรรณยุกต์และสระบนล่างนับเป็นอักขระแยก `len("น้ำ")` จึงได้ 3 (น, ไม้โท, สระอำ) ไม่ใช่ 1 การตัดคำไทยด้วย `split()` ก็ทำได้เฉพาะเมื่อมีช่องว่างคั่น เพราะภาษาไทยไม่เว้นวรรคระหว่างคำ

## เลือกโครงสร้างให้เหมาะกับปัญหา

- **ลิสต์** เมื่อลำดับสำคัญหรือมีตัวซ้ำได้ เช่น คะแนนตามเลขที่ คิวลูกค้า
- **ดิกชันนารี** เมื่อต้องค้นค่าด้วยชื่อหรือรหัส เช่น ราคาตามชื่อเมนู จำนวนตามคำ
- **เซต** เมื่อสนใจเพียงว่ามีหรือไม่ หรือต้องตัดตัวซ้ำ
- **สตริง** สำหรับข้อความ แปลงเป็นลิสต์ด้วย `split` เมื่อต้องจัดการทีละคำ

การเลือกมีผลต่อความเร็วด้วย `x in a` เมื่อ `a` เป็นลิสต์ Python ต้องเทียบทีละตัว ลิสต์ยาวล้านตัวอาจต้องเทียบล้านครั้ง แต่ดิกชันนารีและเซตใช้ตารางแฮช จึงหาเจอเกือบทันทีไม่ว่าจะมีข้อมูลมากเท่าไร

## ข้อผิดพลาดที่พบบ่อย

- **นับดัชนีจาก 1** สมาชิกตัวแรกคือ `a[0]` และ `a[len(a)]` เกินขอบเสมอ
- **คิดว่าการตัดช่วงรวมตัวท้าย** `a[1:3]` มีสองตัว คือดัชนี 1 และ 2
- **คิดว่า `remove` ลบทุกตัว** ลบเฉพาะตัวแรกที่พบ
- **ใช้ `b = a` แล้วคิดว่าได้สำเนา**
- **เรียกคีย์ที่ไม่มีในดิกชันนารี** ได้ `KeyError`
- **พยายามแก้อักขระในสตริงตรง ๆ** ต้องสร้างสตริงใหม่
