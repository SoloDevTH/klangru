# กติกาสำหรับผู้แก้คำเตือนคุณภาพ (validate --lint) ของหัวข้อเดิม

รากของรีโพ: ใช้ worktree ของชุดตัวเองที่ระบุในคำสั่งงาน ห้ามแตะโฟลเดอร์อื่น ห้าม push ห้ามสลับ branch commit บน branch ของชุดใน worktree ได้ (git add -A && git commit) เมื่อเสร็จทีละหัวข้อ

## งาน
ไฟล์รายการ (อ่านอย่างเดียว) ระบุหัวข้อและคำเตือนของแต่ละหัวข้อ แก้ทีละหัวข้อ ให้จบก่อนไปหัวข้อถัดไป โฟลเดอร์หัวข้อคือ content/<วิชา>/<โฟลเดอร์> (บทเรียน lesson.md โจทย์ problems.yaml)

## แก้ตามชนิดคำเตือน
1. **คำตอบ X ปรากฏในบทเรียนหรือตัวอย่างแสดงวิธีทำ** (โจทย์ numeric): อ่านบทเรียนและโจทย์ แล้วตัดสิน
   - ถ้าผู้เรียนหาคำตอบได้โดยคัดลอกตัวเลขจากบทเรียน (ตัวอย่างคำนวณเดียวกัน) ให้เปลี่ยนตัวเลขในโจทย์ใหม่ คำนวณคำตอบใหม่ด้วย python3 แล้วแก้ stem, answer, misconceptions, hints, solution และรูปประกอบโจทย์ (ถ้ามี) ให้สอดคล้องกัน ตัวเลขคำตอบใหม่ต้องไม่ปรากฏในบทเรียน (ต้องไม่ซ้ำกับตัวอย่างที่เหลือ) ความยากและแนวคิดของโจทย์เท่าเดิม
   - ถ้าโจทย์ให้อ่านค่าจากตารางหรือค่าคงที่ที่บทเรียนแจกให้ใช้ (เช่น ตารางแจกแจงปกติ ค่าคงที่ทางฟิสิกส์) หรือคำตอบเป็นตัวเลขทั่วไปที่บังเอิญตรงกัน ให้ไม่เปลี่ยนโจทย์ และเพิ่ม `lint_ignore: [answer-in-lesson]` ในข้อนั้นของ problems.yaml แล้วเขียนเหตุผลสั้น ๆ ลงไฟล์ notes
   - ห้ามเปลี่ยนรหัสโจทย์ ห้ามลบโจทย์
2. **บทเรียนยาวเกิน 1,000 คำ**: ตัดให้ไม่เกิน 1,000 คำ (นับด้วย `npm run validate -- --lint --only=<วิชา>/<โฟลเดอร์>`) ตัดตัวอย่างซ้ำ ประโยคฟุ่มเฟือย และส่วนซ้ำกับตัวอย่างแสดงวิธีทำ ห้ามตัดเนื้อหาที่ตัวชี้วัดของหัวข้อต้องการ (ดูไฟล์จับคู่ docs/phase8/mappings หรือ curriculum/mappings) และห้ามลบสมการหรือภาพที่โจทย์อ้างถึง
3. **บทเรียนสั้นกว่า 500 คำ**: เพิ่มเนื้อหาที่ตัวชี้วัดต้องการแต่ยังขาด ถึง 500–1,000 คำ ห้ามเขียนข้อความที่ไม่แน่ใจ
4. **โจทย์อ้าง "ข้อก่อนหน้า" "ภาพด้านบน" "ตัวเลือก ก"**: เขียน stem ให้อ่านจบในข้อเดียว (ใส่ข้อมูลที่อ้างลงใน stem) และแก้คำใบ้และเฉลยที่อ้างตัวอักษรนำหน้าตัวเลือก
5. **หัวข้อสอน Python แต่ไม่มีโจทย์เขียนโค้ด**: เพิ่มโจทย์ code หนึ่งข้อ (reference ผ่าน tests, starter ไม่ผ่าน, ไลบรารีมาตรฐานเท่านั้น) หรือถ้าเนื้อหาไม่ใช่การเขียนโปรแกรมจริง ให้บันทึกใน notes

## ข้อกำหนดทั่วไป
- ตัวเลขทุกตัวคำนวณด้วย python3 ห้ามเดา ถ้าข้อมูลภายนอกยืนยันไม่ได้ให้เก็บค่าเดิม
- ไม่ใส่ข้อความตอบแทนผู้เรียน เนื้อหาเป็นภาษาไทยธรรมชาติ
- เมื่อแก้โจทย์ ตรวจว่า misconception ไม่ตกในช่วงยอมรับของคำตอบใหม่ และตำแหน่งของคำตอบปรนัยไม่เปลี่ยนโดยไม่จำเป็น
- ตรวจ: `npm run validate -- --strict --lint --only=<วิชา>/<โฟลเดอร์>,...` ต้องไม่มี error และคำเตือน lint ของหัวข้อที่รับผิดชอบหมดไป (ยกเว้นข้อที่ตั้ง lint_ignore) แล้ว `npm test -w @klangru/content-tools`
- บันทึกผลที่ docs/batches/<ชื่อชุด>.md (ต่อหัวข้อ: แก้อะไร ข้อที่คงไว้และเหตุผล)

## รายงานกลับ (ไม่เกิน 150 คำ)
จำนวนโจทย์ที่เปลี่ยนตัวเลข ที่ตั้ง lint_ignore บทเรียนที่ตัด/เพิ่ม และเรื่องที่ไม่แน่ใจ
