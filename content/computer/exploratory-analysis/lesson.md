## เริ่มจากคำถาม ไม่ใช่จากตัวเลข

ครูคนหนึ่งสงสัยว่า นักเรียนที่อ่านหนังสือนอกเวลาเรียนมากขึ้นจะได้คะแนนสอบสูงขึ้นจริงหรือไม่ เขาได้ข้อมูลจากแบบฟอร์มของโรงเรียนสมมติ มีเวลาอ่านต่อสัปดาห์และคะแนนสอบของนักเรียนหลายสิบคน ก่อนคำนวณอะไร ครูควรตั้งคำถามให้ชัดว่าอยากรู้อะไร และดูข้อมูลว่าพร้อมตอบคำถามนั้นหรือไม่

**การวิเคราะห์ข้อมูลเชิงสำรวจ** (exploratory data analysis) คือการดูข้อมูลอย่างเปิดใจ สรุปให้เห็นรูปร่าง ค่ากลาง การกระจาย ค่าผิดปกติ และความสัมพันธ์ก่อนจะสร้างข้อสรุปหรือแบบจำลอง คำถามที่ดีจะบอกว่าควรดูอะไรก่อน

## สรุปข้อมูลเชิงปริมาณ

ค่ากลางที่ใช้บ่อยมีสองตัว คือ **ค่าเฉลี่ย** (mean) ซึ่งได้จากผลรวมหารด้วยจำนวน และ **มัธยฐาน** (median) ซึ่งเป็นค่าที่อยู่ตรงกลางเมื่อเรียงข้อมูลแล้ว ถ้ามีค่าสุดขั้วหนึ่งค่า ค่าเฉลี่ยจะถูกดึงไปตามค่านั้น แต่มัธยฐานแทบไม่ขยับ

ความกระจายวัดได้ด้วย **ควอร์ไทล์** คือค่าที่แบ่งข้อมูลที่เรียงแล้วเป็นสี่ส่วน Q1 คือค่าที่ 25 เปอร์เซ็นต์ Q3 คือค่าที่ 75 เปอร์เซ็นต์ และ **พิสัยระหว่างควอร์ไทล์** (IQR) คือ Q3 − Q1 ซึ่งบอกว่าครึ่งกลางของข้อมูลกระจายกว้างแค่ไหน

ใน Python มีโมดูล `statistics` ที่ทำงานเหล่านี้ได้ เช่น `statistics.mean(data)` และ `statistics.median(data)` สำหรับควอร์ไทล์ใช้ `statistics.quantiles(data, n=4)` ซึ่งคืนค่า Q1 มัธยฐาน และ Q3 ตามลำดับ วิธีคำนวณควอร์ไทล์มีหลายแบบ โปรแกรมต่างกันอาจให้ค่าต่างกันเล็กน้อย จึงควรระบุวิธีที่ใช้ทุกครั้ง

**ค่าผิดปกติ** (outlier) คือค่าที่อยู่นอกช่วง Q1 − 1.5 × IQR ถึง Q3 + 1.5 × IQR กฎนี้ไม่ได้บอกว่าค่านั้นผิด เพียงบอกให้ตรวจก่อน อาจเป็นการพิมพ์ผิด หรืออาจเป็นเหตุการณ์จริงที่น่าสนใจ

**ตัวอย่าง: เวลาอ่านของนักเรียนสิบคน (ข้อมูลสมมติ)**

ถ้านักเรียนคนหนึ่งกรอกว่าอ่าน 35 ชั่วโมงต่อสัปดาห์ เมื่อวาดแผนภาพกล่อง ค่านี้จะอยู่นอกหนวดและเห็นได้ทันที ครูต้องตรวจว่าเป็นการกรอกผิดหรือไม่ ไม่ใช่รีบลบออก

## ข้อมูลกลุ่มและตารางไขว้

ข้อมูลเชิงคุณภาพ เช่น ชั้นเรียน หรือชนิดของกิจกรรม นับได้เป็น **ตารางความถี่** โดยใช้ `collections.Counter` ถ้าต้องการดูสองตัวแปรพร้อมกัน ใช้ **ตารางไขว้** ที่นับจำนวนคนในแต่ละคู่ของค่า แล้วคำนวณร้อยละเทียบกับแถวหรือคอลัมน์ที่เหมาะสม

ควรระวังว่าร้อยละต้องหารด้วยกลุ่มที่ถูกต้อง เช่น ถ้าอยากรู้สัดส่วนของคนที่เล่นกีฬาในกลุ่มที่อ่านมาก ตัวหารคือจำนวนคนที่อ่านมาก ไม่ใช่จำนวนคนทั้งหมด

## ข้อมูลมีลำดับชั้นและหลายมิติ

ข้อมูลจำนวนมากไม่ได้เป็นตารางเรียบ เช่น ไฟล์ JSON ที่มีห้องเรียน ซึ่งมีนักเรียนหลายคนอยู่ข้างใน ใน Python ใช้ `json.loads` แปลงข้อความเป็นดิกชันนารีและลิสต์ จากนั้นวนเข้าไปทีละชั้นเพื่อรวบรวมค่าที่ต้องการ

ไลบรารีอย่าง NumPy และ Pandas ช่วยทำงานกับตารางขนาดใหญ่ได้เร็วกว่า เช่น Pandas มี `DataFrame` ที่เลือกคอลัมน์ กรองแถว และจัดกลุ่มด้วย `groupby` ได้ในบรรทัดเดียว เนื้อหานี้ในแอปให้อ่านและไล่โค้ดตัวอย่าง เพราะแอปรันได้เฉพาะไลบรารีมาตรฐาน ดังตัวอย่างต่อไปนี้

```python
import pandas as pd
df = pd.read_csv("scores.csv")
print(df.groupby("class")["score"].mean())
```

โค้ดนี้คำนวณค่าเฉลี่ยของคะแนนแยกตามห้อง แนวคิดเดียวกันทำได้ด้วย `collections.defaultdict` และ `statistics.mean` ในโค้ดที่เขียนเองได้

## ความสัมพันธ์ของตัวแปร

เมื่อสองตัวแปรเปลี่ยนไปด้วยกัน จะวัดความเกี่ยวข้องได้ด้วย **สหสัมพันธ์** (correlation) ค่า r อยู่ระหว่าง −1 ถึง 1 ค่าใกล้ 1 หมายถึงเพิ่มขึ้นพร้อมกันเกือบเป็นเส้นตรง ค่าใกล้ −1 หมายถึงตัวหนึ่งเพิ่มขณะที่อีกตัวลด ค่าใกล้ 0 หมายถึงแทบไม่มีแนวโน้มเชิงเส้น

ใน Python 3.10 ขึ้นไป ใช้ `statistics.correlation(xs, ys)` ได้

สิ่งสำคัญคือ สหสัมพันธ์ไม่ได้บอกว่าอันหนึ่งเป็นสาเหตุของอีกอันหนึ่ง นักเรียนที่อ่านมากอาจได้คะแนนดีเพราะมีพื้นความรู้เดิม หรือได้รับการสนับสนุนจากบ้าน ต้องตรวจตัวแปรอื่นก่อนสรุปเรื่องเหตุผล

**ตัวอย่าง: ชั่วโมงอ่านกับคะแนนแปดคน (ข้อมูลสมมติ)**

เมื่อวาดกราฟกระจาย จุดเรียงใกล้เส้นตรงที่เอียงขึ้น แสดงว่ามีความสัมพันธ์เชิงบวกที่แรง แต่ยังไม่ได้บอกว่าการอ่านทำให้คะแนนสูงขึ้น

## ตีความและโยงกลับไปยังคำถาม

ผลของการวิเคราะห์ต้องถูกแปลกลับเป็นคำตอบของคำถามเดิม ถ้าค่าเฉลี่ยสูงแต่มัธยฐานต่ำ ให้ถามว่ามีค่าสุดขั้วหรือไม่ ถ้าความสัมพันธ์แรงแต่มีจุดหนึ่งอยู่ห่างจากกลุ่มมาก ให้ดูว่าจุดนั้นเกิดจากอะไร ถ้าแนวโน้มชัดเจนมาก ก็ยังควรบอกขอบเขตที่สรุปได้

การจำแนกอย่างง่ายก็เป็นแนวคิดเดียวกัน เช่น ตั้งเกณฑ์ว่าอ่านอย่างน้อย 5 ชั่วโมงให้ทำนายว่าผ่าน แล้วตรวจว่าทำนายถูกกี่เปอร์เซ็นต์เมื่อเทียบกับผลจริง
