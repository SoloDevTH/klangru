## ข้อความคือลำดับของอักขระ

ใบเสร็จร้านกาแฟมีชื่อเมนู จำนวน ราคา และเวลาที่พิมพ์ ทุกอย่างเป็นข้อความที่โปรแกรมต้องอ่าน ตัดแต่ง เปรียบเทียบ และจัดให้อยู่ในแนวเดียวกัน บทนี้จะให้เครื่องมือกับข้อความ และวิธีจัดรูปแบบผลลัพธ์ให้อ่านง่าย

ใน Python เขียนข้อความในเครื่องหมายคำพูดเดี่ยว `'...'` หรือคู่ `"..."` ก็ได้ ข้อความแต่ละข้อความเรียกว่า **สตริง (string)** สตริงคือลำดับของอักขระที่ **แก้ไขไม่ได้** ถ้าเขียน `s = "กาแฟ"` แล้วสั่ง `s[0] = "ข"` จะเกิด `TypeError` ต้องสร้างสตริงใหม่แทน เช่น `s = "ข" + s[1:]`

```python
name = "กาแฟ"
print(len(name))   # 4  นับจำนวนอักขระทั้งหมด
print(name[0])     # ก  ดัชนีเริ่มที่ 0 เหมือนลิสต์
```

### อักขระหลีกและข้อความหลายบรรทัด

เครื่องหมาย `\` บอกว่าอักขระถัดไปมีความหมายพิเศษ `\n` คือการขึ้นบรรทัดใหม่ `\t` คือการเว้นแท็บ และ `\"` คือเครื่องหมายคำพูดที่เป็นส่วนของข้อความ ถ้าต้องการข้อความหลายบรรทัดโดยไม่ต้องใช้ `\n` ให้ใช้เครื่องหมายคำพูดสามชั้น `"""` ครอบไว้

### ยูนิโค้ด: อักษรไทยหลายอักขระ

คอมพิวเตอร์เก็บอักขระทุกตัวเป็นรหัสตามมาตรฐานยูนิโค้ด `ord("ก")` ได้ 3585 และ `chr(97)` ได้ `"a"` ที่สำคัญคือในภาษาไทย สระและวรรณยุกต์เป็นอักขระแยกจากพยัญชนะ คำว่า "ก่า" ประกอบจาก ก สระอา และไม้เอก รวมเป็นสามอักขระ จึงให้ `len("ก่า")` เท่ากับ 3 ทั้งที่อ่านเป็นพยางค์เดียว

ข้อนี้มีผลกับการจัดแนว การใช้ `len` วัดความกว้างบนจอจะได้ผลไม่ตรงกับที่เห็นเสมอ ถ้าต้องจัดตารางข้อความภาษาไทย ควรออกแบบโดยไม่ยึดจำนวนอักขระเป็นความกว้าง

### การต่อ การคูณ และการเปรียบเทียบ

- `"ฟ้า" + "ใส"` ได้ `"ฟ้าใส"` และ `"ha" * 3` ได้ `"hahaha"`
- การเปรียบเทียบเรียงตามรหัสยูนิโค้ด ตัวพิมพ์ใหญ่ `"B"` มีรหัสน้อยกว่าตัวพิมพ์เล็ก `"a"` ดังนั้น `"B" < "a"` เป็นจริง
- ตัวเลขที่เป็นสตริงเปรียบเทียบเหมือนตัวอักษร `"10" < "9"` จึงเป็นจริง เพราะ `"1"` มีรหัสน้อยกว่า `"9"` ถ้าต้องเปรียบเทียบเป็นตัวเลข ต้องแปลงด้วย `int()` ก่อน

### เมธอดที่ใช้บ่อย

สตริงมีเมธอดให้เรียกใช้โดยไม่ต้องเขียนฟังก์ชันเอง เมธอดเหล่านี้คืนค่าใหม่ ไม่ได้แก้สตริงเดิม

```python
code = "  AB-2024  "
clean = code.strip()            # ตัดช่องว่างหัวท้าย: "AB-2024"
print(clean.lower())            # ab-2024
print(clean.startswith("AB"))   # True
print("2024" in clean)          # True
print(clean.replace("-", "/"))  # AB/2024
```

- `strip()` ตัดช่องว่างหัวท้าย ใช้ก่อนเปรียบเทียบข้อความที่มาจากผู้ใช้เสมอ
- `lower()`, `upper()`, `title()` เปลี่ยนตัวพิมพ์
- `isdigit()` และ `isalpha()` ตรวจว่าข้อความประกอบด้วยตัวเลขหรือตัวอักษรล้วนหรือไม่ ข้อความว่างคืนค่า `False`
- `replace(เดิม, ใหม่)` แทนที่ทุกจุด และ `in` ใช้ตรวจว่ามีข้อความย่อยอยู่หรือไม่

เมื่อต้องการเก็บเฉพาะตัวเลขจากข้อความที่ปนกัน ใช้วนผ่านทีละอักขระแล้วรวมเฉพาะตัวที่ `isdigit()` เป็นจริง

```python
raw = " 08x-123-4567 "
s = raw.strip()
digits = "".join(ch for ch in s if ch.isdigit())
print(digits)   # 081234567
```

### f-string และรูปแบบตัวเลข

f-string คือสตริงที่มี `f` นำหน้า ใส่ตัวแปรในวงเล็บปีกกาได้โดยตรง และกำหนดรูปแบบการแสดงผลหลังเครื่องหมาย `:`

```python
price = 1234.5
print(f"ราคา {price:,.2f} บาท")   # ราคา 1,234.50 บาท
print(f"{0.256:.1%}")             # 25.6%   คูณ 100 และใส่เครื่องหมาย %
print(f"{7:03}")                  # 007     เติมศูนย์ข้างหน้าให้ครบ 3 หลัก
```

- `:.2f` ทศนิยมสองตำแหน่ง
- `:,` ใส่เครื่องหมายคั่นหลักพัน
- `:>10` ชิดขวาในช่องกว้าง 10 ส่วน `:<10` ชิดซ้าย และ `:^10` อยู่กลาง
- `:.1%` คูณด้วย 100 แล้วแสดงทศนิยมหนึ่งตำแหน่งพร้อมเครื่องหมาย %

ทำให้ใบเสร็จอ่านง่ายได้ โดยกำหนดความกว้างของแต่ละคอลัมน์ให้เท่ากันทุกบรรทัด

```python
items = [("Latte", 2, 65.0), ("Croissant", 1, 45.5)]
for name, qty, price in items:
    print(f"{name:<10}{qty:>3}{price:>9,.2f}")
```

### ข้อผิดพลาดที่พบบ่อย

- ลืม `strip()` แล้วคิดว่า `" ok"` เท่ากับ `"ok"` ทั้งที่เปรียบเทียบไม่เท่ากัน
- เก็บตัวเลขเป็นสตริงแล้วเรียง หรือเปรียบเทียบ ทำให้ `"10"` มาก่อน `"9"`
- คิดว่าเมธอดแก้สตริงเดิม เช่น เขียน `s.upper()` เฉย ๆ แล้วคาดหวังว่า `s` จะเปลี่ยน ต้องเก็บค่าที่คืนมาไว้ เช่น `s = s.upper()`
- ใช้ `len` จัดคอลัมน์ข้อความภาษาไทยที่มีวรรณยุกต์ ทำให้แนวเพี้ยน
