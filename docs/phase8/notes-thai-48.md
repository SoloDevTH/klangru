หัวข้อภาษาไทย 8 หัวข้อจาก `docs/phase6/proposals-languages.yaml` ไม่มีแถว `extend:` ที่ผูกกับหัวข้อในชุดนี้ ภาพทุกภาพ (24 ภาพ) วาดเป็น SVG ด้วยสคริปต์ (scratchpad `phase8-thai-48/fig_*.py` ใช้ `svg.py`) เรนเดอร์เป็น PNG ด้วย Chromium และเปิดตรวจทุกภาพแล้ว ไม่มีภาพจาก Commons โจทย์สร้างด้วย `p_*.py` ผ่าน `build.py` แบบเดียวกับ thai-26/31/36 ตัวเลขทุกตัว (แผนภูมิรูปภาพ มาตราส่วน ปริมาณน้ำ นาทีอ่านหนังสือ จำนวนวันลา ร้อยละ เวลาเดินทาง วันในสัปดาห์ของ พ.ย. 2569) คำนวณด้วย python3 บทเรียนนับด้วย `Intl.Segmenter` ได้ 688–865 คำ

**ตัวชี้วัดการฟัง การพูด และการเขียนอิสระ** (ร้อง เล่า นำเสนอ เขียนจดหมาย เขียนเรื่อง แสดงความคิดเห็นด้วยคำของตน) จับคู่เป็น partial ทั้งหมด ตามแนวของ thai-31/36 การกรอกแบบรายการจับคู่ full เพราะโจทย์ตรวจกฎที่ชัดเจนได้ (ขีด - จำนวนเงินเป็นตัวอักษร)

**การตรวจคำ**: ตรวจด้วยแบบฟอร์มค้นของพจนานุกรมฉบับราชบัณฑิตยสถานออนไลน์ (`orst.py`) ความหมายของคำที่สอน (ทะนาน เบี้ย คด ๓ ใต้ถุน มุขปาฐะ ร้องเรือ ซอ ๓ ลูกคู่ ฉ่อย ลำตัด หมอลำ เหน็บ ๓ สิ้นซาก ลมปาก แคลน อนุมาน ข้อเท็จจริง ข้อคิดเห็น ถ้วน จ่าหน้า ฯลฯ) และคำสะกดที่มักผิดในบทเรียนและโจทย์อีกราว 50 คำ ที่ไม่พบใน ORST เป็นคำประสมหรือคำยืม (ขี้ลืม ผุพัง รีไซเคิล คอมเมนต์ โพสต์ ผิงไฟ กราบเท้า คาดคะเน) เขียนความหมายด้วยคำของเราเอง ไม่ได้คัดนิยาม

**ตัวบทที่ยกมา (ตรวจทุกวรรคกับวิกิซอร์ซ ทั้งหมดเป็นสาธารณสมบัติ)**:
- รีรีข้าวสาร 6 วรรค ตรงกับ `th.wikisource.org/wiki/รีรีข้าวสาร` (หมวดการละเล่นเด็กไทย) วิกิพีเดีย th:การละเล่นเด็กไทย ให้อีกสำนวน (สลับวรรค คดข้าว/เก็บเบี้ย และจบว่า "...ไว้ให้ดี") บทเรียนใช้เป็นตัวอย่างว่าวรรณกรรมพื้นบ้านมีหลายสำนวน
- มอญซ่อนผ้า 4 วรรคแรก ตรงกันทั้งวิกิซอร์ซและวิกิพีเดีย · โยกเยก 5 วรรค ตามวิกิซอร์ซ (หน้านั้นไม่ระบุแหล่งพิมพ์)
- เจ้าเนื้อละมุนเอย 5 วรรค ตามวิกิซอร์ซ ซึ่งระบุที่มาว่า "บทกล่อมเด็ก ปลอบเด็ก เด็กเล่น พ.ศ. 2511"
- สุนทรภู่ เพลงยาวถวายโอวาท "อันอ้อยตาลหวานลิ้นแล้วสิ้นซาก..." 4 วรรค ตามวิกิซอร์ซ (หน้านั้นติดป้าย "ไม่เสร็จ" แต่วรรคที่ใช้ครบ)
- ไม่ได้ยกจ้ำจี้ทั้งบท เพราะวิกิซอร์ซเขียน "มะเขือเปราะ/กะเทาะ" ส่วนวิกิพีเดียเขียน "มะเขือเปาะ/กระเทาะ" (ORST มีเฉพาะ กะเทาะ) ไม่ได้ใช้สุภาษิตพระร่วงหรือพระอภัยมณี เพราะหาตัวบทในวิกิซอร์ซไม่พบ
- นิทานอีสป (ราชสีห์กับหนู เด็กเลี้ยงแกะ กากับเหยือกน้ำ) เล่าใหม่ด้วยคำของเราเอง ไม่ซ้ำกับนิทานที่ใช้แล้วในคลัง (กระต่ายกับเต่า สุนัขกับเงา มดกับตั๊กแตน) เรื่องสั้น บทความ ประกาศ แบบฟอร์ม ซองจดหมาย และคู่มือทั้งหมดแต่งขึ้นและติดป้าย "สมมุติ" ชื่อจังหวัด "สุขสันต์" และรหัสไปรษณีย์ 12345/12340 เป็นของสมมุติ

## ลิงก์อ้างอิง

ลิงก์วิกิพีเดียทั้ง 25 ลิงก์ตรวจผ่าน MediaWiki API (คำขอเดียวต่อภาษา) ว่ามีหน้าอยู่จริง ไม่ใช่ redirect และไม่ใช่หน้าแก้ความกำกวม อ่านบทนำว่าตรงเรื่อง และได้ HTTP 200 ทุกลิงก์ เปลี่ยน 2 ลิงก์ที่เป็น redirect: th:นิทานอีสป → อีสป, th:รหัสไปรษณีย์ไทย → รหัสไปรษณีย์ในประเทศไทย API ของวิกิมีเดียถูกจำกัดอัตรา (HTTP 429) หนักมากระหว่างทำ จึงดึงบางหน้าไม่ได้ (เช่น th:นิทานพื้นบ้าน th:ศรีธนญชัย) และไม่ได้ใช้ข้อมูลจากหน้าเหล่านั้น
