## ข้อจำกัดที่ยังค้าง

- จำนวนคำของบทเรียนนับไม่ได้จริง เพราะติดตั้งตัวตัดคำภาษาไทยไม่ได้ในรอบนี้ ประมาณจากจำนวนอักษร (2,500–3,100 อักษรต่อบท ราว 600–800 คำ)
- ปีในหัวข้อ computing-careers-history ตรวจกับวิกิพีเดียอังกฤษในรอบตรวจ (2026-11): ทัวริง 1936 (Turing machine), ฮอปเปอร์เข้าทีม Harvard Mark I 1944 และเขียน A-0 ช่วง 1951–1952 (A-0 System), แคเทอรีน จอห์นสันเข้า NACA 1953 ซึ่งต่อมาเป็นนาซา (Katherine Johnson), โทรด้วยมือถือต้นแบบ 1973 และ DynaTAC วางขายมีนาคม 1983 (Motorola DynaTAC), TIS-620 ฉบับ 2529 และ 2533 (Thai Industrial Standard 620-2533) ยังไม่ได้ตรวจกับแหล่งปฐมภูมิ (เช่น ราชกิจจานุเบกษา) ควรตรวจก่อนเผยแพร่
- ภาษาในบทเรียนของหัวข้อความยาก 3.5 ขึ้นไปใช้ประโยคสั้นตามความยากแต่ยังไม่เท่าระดับประถมเต็มรูปแบบ
