## ตู้เย็นที่ไม่ยอมขยับ

ตอนย้ายบ้าน ลองผลักตู้เย็นบนพื้นกระเบื้อง ผลักเบา ๆ ตู้ไม่ขยับ ผลักแรงขึ้นอีกหน่อยก็ยังไม่ขยับ จนถึงจังหวะหนึ่งตู้ก็ "หลุด" ไถลออกไป และหลังจากนั้นการผลักให้ไถลต่อไปกลับรู้สึกเบากว่าตอนแรก

สิ่งที่ต้านเราอยู่คือ **แรงเสียดทาน** ซึ่งเกิดที่ผิวสัมผัสระหว่างวัตถุกับพื้น และมีทิศต้านการไถล (หรือต้านแนวโน้มที่จะไถล) ระหว่างผิวทั้งสองเสมอ

## แรงเสียดทานสองแบบ

**แรงเสียดทานสถิต** ($f_s$) เกิดขณะวัตถุยังไม่ไถล มันมีขนาด **เท่าที่จำเป็น** เพื่อไม่ให้ไถล ผลัก $10\ \mathrm{N}$ ก็ต้าน $10\ \mathrm{N}$ ผลัก $30\ \mathrm{N}$ ก็ต้าน $30\ \mathrm{N}$ แต่เพิ่มได้ไม่เกินค่าสูงสุด

$$0 \le f_s \le \mu_s N$$

**แรงเสียดทานจลน์** ($f_k$) เกิดขณะวัตถุไถลอยู่ มีขนาดเกือบคงตัว

$$f_k = \mu_k N$$

| สัญลักษณ์ | ความหมาย | หน่วย |
|---|---|---|
| $\mu_s$ | สัมประสิทธิ์ความเสียดทานสถิต | ไม่มีหน่วย |
| $\mu_k$ | สัมประสิทธิ์ความเสียดทานจลน์ | ไม่มีหน่วย |
| $N$ | แรงปฏิกิริยาตั้งฉาก | $\mathrm{N}$ |
| $f$ | แรงเสียดทาน | $\mathrm{N}$ |

ข้อสังเกตสำคัญ

- โดยทั่วไป $\mu_k < \mu_s$ จึงต้องออกแรงเริ่มขยับมากกว่าแรงที่ใช้ให้ไถลต่อ ตรงกับเรื่องตู้เย็น
- แรงเสียดทานขึ้นกับ **ชนิดของผิว** (ผ่าน $\mu$) และ **แรงที่ผิวกดกัน** (ผ่าน $N$) ในแบบจำลองนี้ไม่ขึ้นกับพื้นที่ผิวสัมผัสและอัตราเร็ว
- บนพื้นราบที่ไม่มีแรงอื่นในแนวดิ่ง $N = mg$ (ในหัวข้อนี้ใช้ $g = 9.8\ \mathrm{m/s^2}$)

ค่าประมาณของ $\mu$ เช่น ยางรถบนถนนแห้งราว 0.7–0.8 บนถนนเปียกลดลงเหลือราว 0.4–0.5 ส่วนไม้บนไม้ราว 0.3–0.5

## ลากกล่องบนพื้นราบ

ขั้นตอนเมื่อมีแรงดึงในแนวราบ $F$

1. หา $N$ จากแนวดิ่ง: $N = mg$
2. ตรวจว่ากล่องขยับหรือไม่ โดยเทียบ $F$ กับ $\mu_s N$
3. ถ้า $F \le \mu_s N$ กล่องนิ่ง แรงเสียดทานเท่ากับ $F$ และ $a = 0$
4. ถ้า $F > \mu_s N$ กล่องไถล ใช้ $f_k = \mu_k N$ แล้ว $a = \dfrac{F - f_k}{m}$

### ตัวอย่างที่ 1: ผลักแล้วไม่ขยับ

กล่องมวล $20\ \mathrm{kg}$ บนพื้นที่มี $\mu_s = 0.5$ และ $\mu_k = 0.4$ ผลักด้วยแรง $60\ \mathrm{N}$

1. $N = mg = (20\ \mathrm{kg})(9.8\ \mathrm{m/s^2}) = 196\ \mathrm{N}$
2. แรงเสียดทานสถิตสูงสุด $\mu_s N = 0.5 \times 196\ \mathrm{N} = 98\ \mathrm{N}$
3. $60\ \mathrm{N} < 98\ \mathrm{N}$ กล่องไม่ขยับ แรงเสียดทานจึงเป็น $60\ \mathrm{N}$ **ไม่ใช่** $98\ \mathrm{N}$

### ตัวอย่างที่ 2: ลากจนไถล

กล่องเดิม ลากด้วยแรง $120\ \mathrm{N}$

1. $120\ \mathrm{N} > 98\ \mathrm{N}$ กล่องไถล
2. แรงเสียดทานจลน์ $f_k = \mu_k N = 0.4 \times 196\ \mathrm{N} = 78.4\ \mathrm{N}$
3. $a = \dfrac{F - f_k}{m} = \dfrac{120\ \mathrm{N} - 78.4\ \mathrm{N}}{20\ \mathrm{kg}} = 2.08\ \mathrm{m/s^2}$

### ตัวอย่างที่ 3: ไถลจนหยุดเอง

ถ้ากล่องกำลังไถลและไม่มีใครดึงแล้ว แรงในแนวราบเหลือแค่แรงเสียดทานจลน์ ความเร่ง (หน่วง) มีขนาด

$$a = \frac{\mu_k mg}{m} = \mu_k g$$

มวลตัดกันหมด กล่องหนักหรือเบาจึงหน่วงเท่ากัน เช่น $\mu_k = 0.4$ ได้ $a = 0.4 \times 9.8 = 3.92\ \mathrm{m/s^2}$

## แรงเสียดทานไม่ได้มีแต่ข้อเสีย

แรงเสียดทานทำให้เครื่องจักรสึกหรอและเสียพลังงานเป็นความร้อน แต่ชีวิตประจำวันก็ขาดมันไม่ได้ ตอนเราเดิน เท้าดันพื้นไปข้างหลัง แรงเสียดทานสถิตจากพื้นดันเท้าเราไปข้างหน้า ถ้าพื้นเปียกหรือมีคราบน้ำมัน $\mu_s$ ลดลง เราจึงลื่นล้มได้ง่าย รถยนต์ก็ออกตัว เลี้ยว และเบรกได้เพราะแรงเสียดทานระหว่างยางกับถนน นี่คือเหตุผลที่ต้องขับช้าลงเมื่อฝนตก เพราะถนนเปียกทำให้แรงเสียดทานสูงสุดน้อยลง รถจึงต้องใช้ระยะเบรกยาวขึ้น

## ข้อผิดพลาดที่พบบ่อย

- **ใช้ $\mu_s N$ ทุกครั้งที่กล่องนิ่ง** $\mu_s N$ เป็นแค่ค่าสูงสุด ถ้ากล่องนิ่ง แรงเสียดทานเท่ากับแรงที่พยายามทำให้ไถล
- **ลืมคูณ $g$** $f = \mu N$ ใช้แรงปฏิกิริยาตั้งฉาก (นิวตัน) ไม่ใช่มวล (กิโลกรัม)
- **ใช้ $\mu_s$ กับกล่องที่ไถลอยู่แล้ว** เมื่อไถลต้องใช้ $\mu_k$
- **ให้แรงเสียดทานมีทิศเดียวกับการเคลื่อนที่** แรงเสียดทานต้านการไถล จึงต้องลบออกจากแรงดึง
- **คิดว่าพื้นที่ผิวมากขึ้นทำให้ฝืดขึ้น** ในแบบจำลองนี้แรงเสียดทานขึ้นกับ $\mu$ และ $N$ เท่านั้น
