## ย้อนกลับจากพื้นที่ไปหาความยาวด้าน

ครูให้นักเรียนทำแปลงผักรูปสี่เหลี่ยมจัตุรัสที่มีพื้นที่ $49\ \mathrm{m^2}$ ต้องตัดไม้ทำขอบแปลงยาวด้านละกี่เมตร เรารู้ว่าพื้นที่สี่เหลี่ยมจัตุรัสคือด้านยกกำลังสอง จึงถามกลับว่า "จำนวนใดยกกำลังสองแล้วได้ 49" คำตอบคือ 7 เมตร การคิดย้อนกลับจากการยกกำลังแบบนี้เรียกว่า **การหาราก**

## รากที่สอง

รากที่สองของ $a$ คือจำนวนที่ยกกำลังสองแล้วได้ $a$ จำนวน 49 มีรากที่สองสองจำนวน คือ $7$ และ $-7$ เพราะ $7^2 = 49$ และ $(-7)^2 = 49$

สัญลักษณ์ $\sqrt{a}$ (อ่านว่า "รากที่สองของ $a$" หรือ "สแควร์รูท $a$") หมายถึง **รากที่ไม่เป็นลบ** เท่านั้น ดังนั้น

$$\sqrt{49} = 7 \qquad -\sqrt{49} = -7$$

รากที่สองของจำนวนลบ เช่น $\sqrt{-9}$ ไม่มีในระบบจำนวนจริง เพราะไม่ว่าจำนวนจริงใดยกกำลังสองก็ไม่ติดลบ

จำนวนที่เป็นกำลังสองของจำนวนเต็ม เช่น 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144 เรียกว่า **กำลังสองสมบูรณ์** ควรจำไว้ให้คล่อง เพราะใช้ประมาณค่ารากได้

## รากที่สาม

ถ้ากล่องลูกบาศก์มีปริมาตร $64\ \mathrm{cm^3}$ ยาวด้านละเท่าใด เราต้องหาจำนวนที่ยกกำลังสามแล้วได้ 64 ซึ่งก็คือ 4 เขียนว่า

$$\sqrt[3]{64} = 4$$

รากที่สามต่างจากรากที่สองตรงที่หาได้จากจำนวนลบด้วย เช่น $\sqrt[3]{-8} = -2$ เพราะ $(-2)^3 = (-2)(-2)(-2) = -8$

## แก้สมการ $x^2 = p$ และ $x^3 = p$

รากช่วยแก้สมการที่ตัวแปรยกกำลังได้โดยตรง

- $x^2 = p$ เมื่อ $p > 0$ มี **สองคำตอบ** คือ $x = \sqrt{p}$ หรือ $x = -\sqrt{p}$ เช่น $x^2 = 81$ ได้ $x = \pm 9$ (ถ้าโจทย์เป็นความยาว เลือกเฉพาะค่าบวก)
- $x^3 = p$ มี **คำตอบเดียว** คือ $x = \sqrt[3]{p}$ ไม่ว่า $p$ เป็นบวกหรือลบ เช่น $x^3 = -8$ ได้ $x = -2$

## ประมาณค่ารากที่สอง

$\sqrt{50}$ ไม่ใช่จำนวนเต็ม แต่เราบอกได้ว่าอยู่ตรงไหน

### ตัวอย่างที่ 1: ประมาณ $\sqrt{50}$

1. หากำลังสองสมบูรณ์ที่ใกล้ 50 ที่สุดสองตัว: $49 = 7^2$ และ $64 = 8^2$
2. เพราะ $49 < 50 < 64$ จึงได้ $7 < \sqrt{50} < 8$
3. 50 ใกล้ 49 มากกว่า 64 มาก คำตอบจึงใกล้ 7 ลองทดสอบ $7.1^2 = 50.41$ ซึ่งเกิน 50 เล็กน้อย
4. ดังนั้น $\sqrt{50} \approx 7.07$ (เครื่องคิดเลขให้ $7.0710\ldots$)

### ตัวอย่างที่ 2: รากของทศนิยม

หา $\sqrt{0.09}$

1. เขียนเป็นเศษส่วน: $0.09 = \dfrac{9}{100}$
2. หารากเศษและส่วนแยกกัน: $\sqrt{\dfrac{9}{100}} = \dfrac{3}{10} = 0.3$
3. ตรวจ: $0.3 \times 0.3 = 0.09$ ✓

สังเกตว่าคำตอบ **ไม่ใช่** $0.03$ เพราะ $0.03^2 = 0.0009$

### ตัวอย่างที่ 3: รากที่สามของจำนวนลบ

หา $\sqrt[3]{-125}$

1. ถามตัวเองว่าจำนวนใดยกกำลังสามแล้วได้ 125 คำตอบคือ 5 เพราะ $5 \times 5 \times 5 = 125$
2. จำนวนลบยกกำลังสามยังคงเป็นลบ เพราะมีเครื่องหมายลบคูณกันสามตัว
3. ดังนั้น $\sqrt[3]{-125} = -5$ ตรวจ: $(-5)^3 = (-5)(-5)(-5) = -125$ ✓

ถ้าใช้เครื่องคิดเลข ให้มองคำตอบจากเครื่องเป็นค่าประมาณ แล้วถามตัวเองเสมอว่าคำตอบนั้นสมเหตุสมผลหรือไม่ เช่น $\sqrt{50}$ ต้องได้ค่าระหว่าง 7 กับ 8 ถ้าเครื่องแสดง 25 แปลว่ากดผิดปุ่ม

## จำนวนตรรกยะ จำนวนอตรรกยะ และจำนวนจริง

จำนวนที่เขียนเป็นเศษส่วนของจำนวนเต็มได้ เช่น $\tfrac{3}{4}$, $-5$, $0.25$, $0.333\ldots = \tfrac{1}{3}$ เรียกว่า **จำนวนตรรกยะ** ทศนิยมของจำนวนเหล่านี้จะรู้จบหรือซ้ำเป็นแบบแผนเสมอ

แต่ $\sqrt{2} = 1.41421356\ldots$ มีทศนิยมไม่รู้จบและไม่ซ้ำ นักคณิตศาสตร์พิสูจน์ได้ว่าไม่มีเศษส่วนใดเท่ากับ $\sqrt{2}$ ได้พอดี จำนวนแบบนี้เรียกว่า **จำนวนอตรรกยะ** ตัวอย่างอื่น ๆ ได้แก่ $\sqrt{3}$, $\sqrt{5}$, $\sqrt[3]{10}$ และ $\pi$ ส่วน $\sqrt{16} = 4$ เป็นจำนวนตรรกยะ เพราะ 16 เป็นกำลังสองสมบูรณ์

จำนวนตรรกยะกับจำนวนอตรรกยะรวมกันเรียกว่า **จำนวนจริง** ทุกจำนวนจริงมีตำแหน่งบนเส้นจำนวน และทุกจุดบนเส้นจำนวนคือจำนวนจริง เช่น $\sqrt{2}$ อยู่ระหว่าง 1.4 กับ 1.5 ส่วน $\pi$ อยู่ระหว่าง 3.14 กับ 3.15

ภาพหลังบทอ่านแสดงวิธีหาตำแหน่ง $\sqrt{2}$ บนเส้นจำนวนให้ตรงเป๊ะ: เส้นทแยงมุมของสี่เหลี่ยมจัตุรัสด้าน 1 ยาว $\sqrt{1^2 + 1^2} = \sqrt{2}$ หมุนเส้นนี้ด้วยวงเวียนลงมาบนเส้นจำนวน

### เปลี่ยนทศนิยมซ้ำเป็นเศษส่วน

ทศนิยมซ้ำทุกจำนวนเขียนเป็นเศษส่วนได้ จึงเป็นจำนวนตรรกยะ วิธีคือคูณด้วย $10$, $100$, … ให้ส่วนที่ซ้ำเลื่อนไปตรงกันแล้วลบกัน เช่น $x = 0.272727\ldots$

1. ซ้ำทีละ 2 หลัก จึงคูณ 100: $100x = 27.272727\ldots$
2. ลบ: $100x - x = 27$ ได้ $99x = 27$
3. $x = \dfrac{27}{99} = \dfrac{3}{11}$

ถ้ามีหลักที่ไม่ซ้ำนำหน้า เช่น $0.1666\ldots$ ให้ใช้ $100x - 10x = 16.666\ldots - 1.666\ldots = 15$ ได้ $x = \tfrac{15}{90} = \tfrac{1}{6}$

### บวกและคูณจำนวนตรรกยะกับอตรรกยะ

- ตรรกยะ $+$ ตรรกยะ และ ตรรกยะ $\times$ ตรรกยะ ได้ตรรกยะเสมอ (เศษส่วนบวกหรือคูณกันยังเป็นเศษส่วน)
- ตรรกยะ $+$ อตรรกยะ ได้ **อตรรกยะเสมอ** เช่น $1 + \sqrt{2}$ ถ้ามันเป็นตรรกยะ $r$ จะได้ $\sqrt{2} = r - 1$ เป็นตรรกยะ ซึ่งขัดแย้ง
- ตรรกยะที่ไม่ใช่ศูนย์ $\times$ อตรรกยะ ได้ **อตรรกยะเสมอ** เช่น $3\sqrt{2}$ (เหตุผลแบบเดียวกัน หารด้วย 3 กลับได้)
- อตรรกยะกับอตรรกยะ **เป็นได้ทั้งสองแบบ** เช่น $\sqrt{2} \times \sqrt{2} = 2$ และ $\sqrt{2} + (-\sqrt{2}) = 0$ เป็นตรรกยะ แต่ $\sqrt{2} + \sqrt{3}$ เป็นอตรรกยะ

## ข้อผิดพลาดที่พบบ่อย

- **หารสองแทนการถอดราก** เช่น ตอบ $\sqrt{16} = 8$ ที่ถูกคือ 4 เพราะ $4 \times 4 = 16$
- **กระจายรากเข้าไปในผลบวก** $\sqrt{9 + 16}$ ไม่เท่ากับ $\sqrt{9} + \sqrt{16} = 7$ ต้องบวกก่อน: $\sqrt{25} = 5$
- **นับตำแหน่งทศนิยมผิด** เช่น $\sqrt{0.09} = 0.03$ ให้ยกกำลังสองกลับเพื่อตรวจทุกครั้ง
- **คิดว่ารากที่สามของจำนวนลบหาไม่ได้** ข้อนี้เป็นจริงเฉพาะรากที่สอง ส่วน $\sqrt[3]{-125} = -5$
- **คิดว่าทศนิยมยาวทุกตัวเป็นอตรรกยะ** $0.333\ldots$ ยาวไม่รู้จบแต่ซ้ำ จึงเป็นตรรกยะ ($\tfrac{1}{3}$)
- **ลืมคำตอบลบของ $x^2 = p$** สมการ $x^2 = 81$ มีคำตอบ $\pm 9$ ส่วน $\sqrt{81}$ มีค่าเดียวคือ 9
- **เขียนทศนิยมซ้ำเป็นเศษส่วนส่วนร้อย** $0.4545\ldots \ne \tfrac{45}{100}$ ส่วนต้องเป็น $99$ ได้ $\tfrac{45}{99} = \tfrac{5}{11}$
