# คลังรู้

คลังเนื้อหาและโจทย์ทุกวิชา ตั้งแต่พื้นฐานไปจนถึงวิชาเฉพาะ **ไม่แบ่งระดับชั้น** แต่เรียงตามกราฟความรู้ว่าเรื่องไหนต้องรู้ก่อน เนื้อหากับโจทย์เก็บแยกกัน โจทย์ทุกข้อมีคำใบ้ทีละขั้น วิธีทำ และคำอธิบายเฉพาะสำหรับคำตอบผิดที่พบบ่อย ระบบนัดทบทวนให้อัตโนมัติ

โครงการไม่หารายได้ โค้ดใช้ MIT เนื้อหาใช้ Creative Commons เป็นรายชิ้น (ดู `content/LICENSE.md`)

> สถานะ: **เฟส 0** มี schema v1, เครื่องมือตรวจเนื้อหา, หัวข้อนำร่อง 10 หัวข้อ 79 โจทย์ (ฉบับร่าง) และ prototype เว็บ 5 หน้าจอ

## เริ่มใช้งาน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run validate        # ตรวจเนื้อหาทั้งคลัง
npm run dev             # build เนื้อหาแล้วเปิดเว็บที่ http://localhost:3000
npm run build           # สร้างเว็บ static ใน apps/web/out
npm test                # เทสต์เครื่องมือเนื้อหา
npm test -w @klangru/web  # เทสต์ตรรกะตรวจคำตอบและระดับความชำนาญ
```

## โครงสร้าง

```
content/                 เนื้อหา (YAML + Markdown) แยกโฟลเดอร์ตามวิชาและหัวข้อ
packages/schema/         schema เนื้อหา (zod) + กฎใบอนุญาต ใช้ร่วมกันทุกส่วน
packages/content-tools/  ตัวตรวจ (validate) และตัว build content pack → dist/content
apps/web/                เว็บแอป Next.js (static export) ที่จะห่อเป็นแอป Android ในเฟส 2
docs/decisions/          บันทึกการตัดสินใจ (ADR)
docs/phase0/             เกณฑ์ผ่านเฟส 0 และชุดทดสอบกับผู้เรียน
docs/authoring-guide.md  คู่มือเขียนเนื้อหา
```

## หน้าจอ prototype

| หน้า | path | ทำอะไร |
|---|---|---|
| แผนที่ความรู้ | `/` | กราฟหัวข้อทุกวิชา สถานะแต่ละหัวข้อ ปุ่ม "เรียนต่อ" และลำดับที่แนะนำ |
| บทเรียน | `/topic/<id>/` | คำอธิบาย สมการ ซิมูเลชัน คำสำคัญ แฟลชการ์ด |
| ทำโจทย์ | `/topic/<id>/practice/` | ทำโจทย์ทีละข้อ ขอคำใบ้ ดูเฉลย สรุประดับ |
| ทบทวน | `/review/` | หัวข้อที่ถึงกำหนดทบทวน (FSRS) และนัดครั้งถัดไป |
| ความคืบหน้า | `/profile/` | สถิติ ระดับรายหัวข้อ ส่งออกหรือล้างข้อมูล |

ความคืบหน้าในเฟส 0 เก็บใน localStorage ของเบราว์เซอร์ เฟส 1 จะย้ายไป Supabase
