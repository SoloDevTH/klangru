## ถ้าไม่มีสระ ก็อ่านไม่ได้

ลองอ่านตัว ก เฉย ๆ เราต้องใส่เสียง "ออ" เข้าไปจึงอ่านว่า "กอ" ได้ ถ้าเติม า เป็น "กา" ก็ได้คำใหม่ทันที พยัญชนะต้องมี **สระ** ช่วยจึงออกเสียงเป็นพยางค์ได้ บทนี้พาไปรู้จักรูปสระ เสียงสระ สระสั้นสระยาว และตำแหน่งที่สระอยู่รอบพยัญชนะ

## รูปสระกับเสียงสระไม่เท่ากัน

**รูปสระ** คือเครื่องหมายที่เราเขียน ส่วน **เสียงสระ** คือเสียงที่เราอ่าน รูปสระมี **21 รูป**

| รูป | ชื่อ | รูป | ชื่อ | รูป | ชื่อ |
|---|---|---|---|---|---|
| ะ | วิสรรชนีย์ | ◌ั | ไม้หันอากาศ | ◌็ | ไม้ไต่คู้ |
| า | ลากข้าง | ◌ิ | พินทุ์อิ | ◌่ | ฝนทอง |
| ◌ํ | นฤคหิต (หยาดน้ำค้าง) | ◌" | ฟันหนู | ◌ุ | ตีนเหยียด |
| ◌ู | ตีนคู้ | เ | ไม้หน้า | ใ | ไม้ม้วน |
| ไ | ไม้มลาย | โ | ไม้โอ | อ | ตัว ออ |
| ย | ตัว ยอ | ว | ตัว วอ | ฤ | ตัว รึ |
| ฤๅ | ตัว รือ | ฦ | ตัว ลึ | ฦๅ | ตัว ลือ |

สระหนึ่งตัวอาจใช้หลายรูปประกอบกัน เช่น

- สระอี = พินทุ์อิ + ฝนทอง
- สระอึ = พินทุ์อิ + หยาดน้ำค้าง
- สระอือ = พินทุ์อิ + ฟันหนู + ตัว อ
- สระอำ = หยาดน้ำค้าง + ลากข้าง
- สระเอีย = ไม้หน้า + พินทุ์อิ + ฝนทอง + ตัว ย

แบบเรียนชั้นประถมสอนว่าสระมี **32 ตัว** อ่านได้ 32 เสียง ดังนี้

| สระเสียงสั้น | สระเสียงยาว |
|---|---|
| อะ อิ อึ อุ | อา อี อือ อู |
| เอะ แอะ โอะ เอาะ เออะ | เอ แอ โอ ออ เออ |
| เอียะ เอือะ อัวะ | เอีย เอือ อัว |

อีก 8 ตัว เรียกว่า **สระเกิน** คือ อำ ใอ ไอ เอา ฤ ฤๅ ฦ ฦๅ สระเกินมีเสียงพยัญชนะปนอยู่ เช่น อำ = อะ + ม ไอ = อะ + ย เอา = อะ + ว ฤ = ร + อึ

> **ตำราบางเล่มนับไม่เหมือนกัน** หัวข้อนี้ใช้ **รูปสระ 21 รูป สระ 32 ตัว** ตามแบบเรียนประถม ส่วนหนังสือหลักภาษาชั้นมัธยมนับเฉพาะ **เสียงสระแท้ 21 เสียง** คือ สระเดี่ยว 18 เสียง กับสระประสม 3 เสียง (เอีย เอือ อัว) เพราะสระเกินมีเสียงพยัญชนะปน และสระประสมเสียงสั้นมีใช้น้อยมาก บางตำรานับสระประสม 6 เสียง (รวมเอียะ เอือะ อัวะ) ได้ 24 เสียง ทุกแบบถูกตามหลักของตัวเอง ให้ดูว่าโจทย์นับแบบไหน

## สระเสียงสั้นและสระเสียงยาว

สระส่วนใหญ่มาเป็นคู่ สั้นกับยาว เสียงสั้นอ่านเร็วแล้วหยุด เสียงยาวลากได้นาน เช่น

- จะ กับ จา
- ติ กับ ตี
- ดุ กับ ดู
- เตะ กับ เต

สระยาวต่างจากสระสั้นจนคำเปลี่ยนความหมาย เช่น **ขัน** (ภาชนะตักน้ำ) กับ **ขาน** (ตอบรับ) จึงต้องอ่านและเขียนให้ถูกเสียง

## สระอยู่ตรงไหนของพยัญชนะ

ดูภาพด้านบน รูปสระอยู่ได้ 5 แบบ

1. **ข้างหน้า** เ แ โ ใ ไ เช่น เก แม โต ใจ ไป
2. **ข้างหลัง** ะ า อ เช่น จะ มา พอ
3. **ข้างบน** ิ ี ึ ื ั ็ เช่น มิ ดี
4. **ข้างล่าง** ุ ู เช่น ดุ ปู
5. **หลายตำแหน่ง** เช่น เสีย เรือ ตัว เกาะ

สระข้างหน้า **เขียนก่อนพยัญชนะ แต่อ่านทีหลัง** เช่น ไป เขียน ไ ก่อน ป แต่อ่าน ป + ไอ = ไป

## สระเปลี่ยนรูปและสระลดรูป

เมื่อพยางค์มีตัวสะกด สระบางตัวเขียนต่างไปจากเดิม

**สระเปลี่ยนรูป** (เปลี่ยนเป็นรูปอื่น)

- อะ → ไม้หันอากาศ: ก + อะ + น = **กัน**
- เอะ → ไม้ไต่คู้: ด + เอะ + ก = **เด็ก**
- แอะ → ไม้ไต่คู้: ข + แอะ + ง = **แข็ง**
- เออ → พินทุ์อิ: ด + เออ + น = **เดิน**

**สระลดรูป** (บางส่วนหายไป)

- โอะ หายทั้งตัว: น + โอะ + ก = **นก** ค + โอะ + น = **คน**
- ออ หายเมื่อมี ร สะกด: พ + ออ + ร = **พร** (อ่านว่า พอน)
- อัว ไม่มีไม้หันอากาศ: ข + อัว + ด = **ขวด**
- เออ ไม่มีตัว อ เมื่อ ย สะกด: ล + เออ + ย = **เลย**

### ตัวอย่างที่ 1: แยกคำว่า "เรือ"

1. พยัญชนะต้นคือ ร
2. รูปที่เหลือ เ ◌ื อ รวมกันเป็น **สระเอือ** เป็นสระเสียงยาว
3. สระเอืออยู่หลายตำแหน่ง คือ หน้า บน และหลังพยัญชนะ
4. อ่าน ร + เอือ = เรือ

### ตัวอย่างที่ 2: คำว่า "ขวด" ใช้สระอะไร

1. พยัญชนะต้นคือ ข ตัวสะกดคือ ด
2. ตรงกลางเหลือ ว ซึ่งไม่ได้อ่านเป็นเสียง วอ
3. อ่านว่า ข-วด คล้าย "ขัว" + ด จึงเป็น **สระอัวลดรูป** (ไม่มีไม้หันอากาศ)

## ใ ไม้ม้วน มีแค่ 20 คำ

คำที่ออกเสียง "ไอ" ส่วนใหญ่ใช้ ไ ไม้มลาย คำที่ใช้ **ใ ไม้ม้วน** มีเพียง 20 คำ จำง่ายด้วยกลอน

> ผู้**ใ**หญ่หาผ้า**ใ**หม่ **ใ**ห้สะ**ใ**ภ้**ใ**ช้คล้องคอ **ใ**ฝ่**ใ**จเอา**ใ**ส่ห่อ มิหลง**ใ**หล**ใ**ครขอดู
> จะ**ใ**คร่ลงเรือ**ใ**บ ดูน้ำ**ใ**สและปลาปู สิ่ง**ใ**ดอยู่**ใ**นตู้ มิ**ใ**ช่อยู่**ใ**ต้ตั่งเตียง
> บ้า**ใ**บ้ถือ**ใ**ยบัว หูตามัวมา**ใ**กล้เคียง เล่าท่องอย่าละเลี่ยง ยี่สิบม้วนจำจงดี

## ข้อผิดพลาดที่พบบ่อย

- **นับรูปสระกับตัวสระปนกัน** รูปสระมี 21 รูป แต่สระ (ตามแบบเรียนประถม) มี 32 ตัว
- **ลืมตัว อ ในสระอือ** เช่น เขียน "มือ" เป็น "มื" สระอือที่ไม่มีตัวสะกดต้องมี อ เสมอ แต่ถ้ามีตัวสะกด อ จะหายไป เช่น ปืน คืน
- **ใช้ ไ แทน ใ** เช่น เขียน "ใหม่" เป็น "ไหม่" ให้ตรวจกับกลอน 20 คำ
- **คิดว่าคำไม่มีสระ** เช่น "นก" "คน" ที่จริงมีสระโอะที่ลดรูป
