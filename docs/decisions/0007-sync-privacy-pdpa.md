# ADR 0007: บัญชีผู้ใช้ การซิงก์ และความเป็นส่วนตัว (PDPA)

- สถานะ: ยอมรับแล้ว
- วันที่: 23 ต.ค. 2569
- โค้ด: `supabase/migrations/`, `apps/web/lib/sync.ts`, `apps/web/lib/account.ts`

## การตัดสินใจ

1. **ใช้ได้โดยไม่ต้องมีบัญชี** ความคืบหน้าเก็บในเครื่องก่อนเสมอ (local-first) บัญชีมีไว้ซิงก์ข้ามเครื่องและใช้ผู้ช่วย AI
2. **เข้าสู่ระบบด้วยรหัส 6 หลักทางอีเมล** (Supabase Auth OTP) ไม่มีรหัสผ่านให้รั่ว และใช้ได้ทั้งในเว็บและแอป Android โดยไม่ต้องตั้ง deep link
3. **เก็บข้อมูลให้น้อยที่สุด** ไม่ถามชื่อจริง โรงเรียน หรือวันเกิด เก็บเพียงช่วงอายุ (`under10`, `10to19`, `20plus`)
4. **ผู้เยาว์** อายุบรรลุนิติภาวะในไทยคือ 20 ปี ผู้ที่อายุต่ำกว่า 20 ต้องยืนยันว่าได้รับความยินยอมจากผู้ปกครองก่อน แอปจึงจะส่งข้อมูลขึ้นเซิร์ฟเวอร์ (ซิงก์และผู้ช่วย AI) ถ้ายังไม่ยินยอม ทุกอย่างยังใช้ได้ในเครื่อง
5. **การซิงก์**
   - ความคืบหน้ารายหัวข้อ แฟลชการ์ด โน้ต และการตั้งค่า: ฝั่งที่ `updatedAt` ใหม่กว่าชนะ (last-write-wins)
   - การตอบโจทย์ (`attempts`): เพิ่มอย่างเดียว ใช้ UUID ที่สร้างในเครื่องจึงส่งซ้ำได้โดยไม่เกิดข้อมูลซ้ำ
   - ซิงก์อัตโนมัติ 3 วินาทีหลังมีการเปลี่ยนแปลง และเมื่อกลับมาออนไลน์
6. **Row Level Security ทุกตาราง** ผู้ใช้อ่านเขียนได้เฉพาะแถวของตัวเอง ครู (ตาราง `staff`) เห็นเพียงสถิติรวม
   - `problem_stats()` และ `experiment_summary()` คืนค่าเฉพาะโจทย์หรือกลุ่มที่มีผู้เรียนอย่างน้อย 5 คน เพื่อไม่ให้ระบุตัวบุคคลได้
   - รายงานโจทย์ผิดส่งได้โดยไม่ต้องเข้าสู่ระบบ
7. **สิทธิ์ของเจ้าของข้อมูล**
   - ส่งออกข้อมูลเป็น JSON และ xAPI ได้จากหน้าโปรไฟล์
   - ลบข้อมูลบนเซิร์ฟเวอร์ (`delete_my_data()`) หรือลบทั้งบัญชี (edge function `delete-account`) ได้เอง ข้อมูลที่ผูกกับบัญชีถูกลบตาม (`on delete cascade`)
8. **การทดลอง A/B** ผู้เรียนแต่ละคนถูกสุ่มเข้ากลุ่ม `adaptive` หรือ `fixed` ครั้งเดียวในเครื่อง บันทึกกลุ่มไว้กับทุกการตอบ หน้าคุณภาพแสดงค่ามัธยฐานของแต่ละกลุ่ม

## สิ่งที่ต้องทำก่อนเปิดให้คนทั่วไปใช้ (ต้องใช้คน)

- เขียนประกาศความเป็นส่วนตัว (privacy notice) ภาษาไทยที่อ่านง่าย ให้ผู้รู้กฎหมาย PDPA ตรวจ
- เลือกภูมิภาคของ Supabase (แนะนำสิงคโปร์) และระบุการโอนข้อมูลไปต่างประเทศในประกาศ
- กำหนดระยะเวลาเก็บ `attempts` และ `tutor_messages` (เสนอ 2 ปี และ 1 ปี) แล้วตั้งงานลบอัตโนมัติ
