## ใจเต้นแรงก่อนขึ้นพูดหน้าห้อง

ก่อนขึ้นพูดหน้าห้อง หลายคนใจเต้นแรงและมือเย็น เพราะต่อมหมวกไตส่วนในหลั่ง**อะดรีนาลีน**เข้าสู่เลือด และยังใจเต้นต่ออีกหลายนาทีแม้พูดจบแล้ว บทนี้ลงรายละเอียดระดับ ม.6 ต่อจาก[ระบบประสาทและระบบต่อมไร้ท่อ: ความสำคัญและการดูแล](/topic/health.body.nervous-endocrine-care/) และใช้หลักการป้อนกลับจาก[การรักษาดุลยภาพของร่างกาย](/topic/biology.animals.homeostasis/)

## ฮอร์โมนทำงานอย่างไร

**ต่อมไร้ท่อ**ปล่อยฮอร์โมนเข้าสู่เลือดโดยตรง ต่างจากต่อมมีท่อ เช่น ต่อมน้ำลาย ฮอร์โมนไปถึงทุกเซลล์ แต่มีผลเฉพาะ**เซลล์เป้าหมาย**ที่มี**ตัวรับ**ของฮอร์โมนนั้น ฮอร์โมนแบ่งตามสมบัติทางเคมีได้สองกลุ่ม

- **ฮอร์โมนที่ละลายน้ำ** เช่น อินซูลิน อะดรีนาลีน จับกับตัวรับที่เยื่อหุ้มเซลล์ แล้วกระตุ้นสารภายในเซลล์ให้ส่งสัญญาณต่อ จึงออกฤทธิ์เร็ว
- **ฮอร์โมนสเตียรอยด์** เช่น คอร์ติซอล เทสโทสเทอโรน ละลายในลิพิด จึงผ่านเยื่อหุ้มเซลล์เข้าไปจับตัวรับภายในเซลล์ แล้วควบคุมการแสดงออกของยีน ออกฤทธิ์ช้ากว่าแต่นานกว่า

## ไฮโพทาลามัสและต่อมใต้สมอง

**ไฮโพทาลามัส**เป็นจุดเชื่อมระหว่างระบบประสาทกับระบบต่อมไร้ท่อ หลั่งฮอร์โมนกระตุ้นหรือยับยั้งไปทางเส้นเลือดสู่**ต่อมใต้สมองส่วนหน้า** ซึ่งสร้างฮอร์โมนหลายชนิดไปควบคุมต่อมอื่นอีกทอดหนึ่ง (ดูภาพ) ส่วน ADH และ**ออกซิโทซิน**สร้างในไฮโพทาลามัส แล้วส่งไปตามแอกซอนไปเก็บและหลั่งที่**ต่อมใต้สมองส่วนหลัง**

**โกรทฮอร์โมน (GH)** กระตุ้นการเติบโตของกระดูกและกล้ามเนื้อ ถ้าหลั่งมากในวัยเด็กทำให้ร่างสูงใหญ่ผิดปกติ ถ้าหลั่งมากในผู้ใหญ่ซึ่งกระดูกหยุดยาวแล้ว กระดูกมือ เท้า และขากรรไกรจะหนาขึ้น ถ้าหลั่งน้อยในวัยเด็กทำให้ร่างแคระ

## ต่อมไร้ท่ออื่นและเนื้อเยื่อที่สร้างฮอร์โมน

| ต่อมหรือเนื้อเยื่อ | ฮอร์โมน | หน้าที่หลัก |
|---|---|---|
| ต่อมไทรอยด์ | ไทรอกซิน | เพิ่มอัตราเมแทบอลิซึม จำเป็นต่อการเติบโตของสมองในวัยเด็ก |
| | แคลซิโทนิน | ลดแคลเซียมในเลือด โดยเพิ่มการสะสมในกระดูก |
| ต่อมพาราไทรอยด์ | พาราทอร์โมน (PTH) | เพิ่มแคลเซียมในเลือด โดยสลายกระดูกและเพิ่มการดูดกลับที่ไต |
| ต่อมหมวกไตส่วนนอก | คอร์ติซอล | เพิ่มน้ำตาลในเลือดเมื่อเครียดนาน ลดการอักเสบ |
| | แอลโดสเตอโรน | เพิ่มการดูดกลับ Na⁺ ที่ไต |
| ต่อมหมวกไตส่วนใน | อะดรีนาลีน | เตรียมร่างกายสู้หรือหนี หัวใจเต้นเร็ว น้ำตาลในเลือดสูงขึ้น |
| ตับอ่อน (ไอส์เลตส์ออฟแลงเกอร์ฮานส์) | อินซูลิน | ลดน้ำตาลในเลือด เซลล์นำกลูโคสไปใช้และตับเก็บเป็นไกลโคเจน |
| | กลูคากอน | เพิ่มน้ำตาลในเลือด ตับสลายไกลโคเจนเป็นกลูโคส |
| รังไข่ | อีสโทรเจน โพรเจสเทอโรน | ลักษณะเพศหญิง รอบประจำเดือน การตั้งครรภ์ |
| อัณฑะ | เทสโทสเทอโรน | ลักษณะเพศชาย การสร้างอสุจิ |
| ต่อมไพเนียล | เมลาโทนิน | หลั่งมากตอนมืด เกี่ยวกับวงจรการหลับและตื่น |
| ลำไส้เล็กส่วนต้น | ซีเครติน | กระตุ้นตับอ่อนให้หลั่งไบคาร์บอเนตลดความเป็นกรด |
| รก | hCG | รักษาการตั้งครรภ์ระยะแรก เป็นฮอร์โมนที่ชุดตรวจครรภ์ตรวจหา |
| ไต | อีริโทรโพอิทิน | กระตุ้นไขกระดูกให้สร้างเซลล์เม็ดเลือดแดง |

## การควบคุมแบบป้อนกลับ

**การป้อนกลับเชิงลบ** เป็นวิธีหลักของระบบต่อมไร้ท่อ เมื่อไทรอกซินในเลือดสูง ไทรอกซินจะยับยั้งไฮโพทาลามัสและต่อมใต้สมองส่วนหน้า TRH และ TSH จึงลดลง ต่อมไทรอยด์จึงหลั่งไทรอกซินน้อยลง (ดูภาพ) ถ้าขาด**ไอโอดีน** ต่อมไทรอยด์สร้างไทรอกซินไม่ได้ TSH จึงสูงอยู่ตลอดและกระตุ้นต่อมไทรอยด์จนโตเป็น**คอพอก** ประเทศไทยจึงส่งเสริมให้ใช้เกลือเสริมไอโอดีน

ฮอร์โมนบางคู่ทำงาน**ตรงข้ามกัน** เช่น หลังกินข้าว น้ำตาลในเลือดสูง ตับอ่อนหลั่งอินซูลิน เมื่ออดอาหาร น้ำตาลต่ำ ตับอ่อนหลั่งกลูคากอน แคลซิโทนินกับพาราทอร์โมนก็เป็นคู่ตรงข้ามที่รักษาแคลเซียมในเลือด

**การป้อนกลับเชิงบวก**พบน้อยกว่า ผลของการตอบสนองไปเสริมสิ่งเร้าให้แรงขึ้น เช่น ขณะคลอด ศีรษะทารกดันปากมดลูก กระตุ้นการหลั่งออกซิโทซิน มดลูกหดตัวแรงขึ้น ดันทารกมากขึ้น

## เมื่อฮอร์โมนผิดปกติ

**เบาหวานชนิดที่ 1** เกิดจากเซลล์ที่สร้างอินซูลินถูกทำลาย ต้องฉีดอินซูลิน **เบาหวานชนิดที่ 2** ซึ่งพบมากกว่า เกิดจากเซลล์ตอบสนองต่ออินซูลินลดลง สัมพันธ์กับน้ำหนักเกินและการขาดการออกกำลังกาย ตามเกณฑ์ขององค์การอนามัยโลก ระดับน้ำตาลในเลือดหลังอดอาหารตั้งแต่ 126 mg/dL ขึ้นไปจากการตรวจซ้ำบ่งชี้เบาหวาน ฮอร์โมนทุกชนิดเป็นยาที่ต้องใช้ตามคำสั่งแพทย์ การซื้อฮอร์โมนหรือสเตียรอยด์มาใช้เองอาจกดการทำงานของต่อมในร่างกายผ่านการป้อนกลับเชิงลบ

## ข้อผิดพลาดที่พบบ่อย

- คิดว่าฮอร์โมนไปถึงเฉพาะอวัยวะเป้าหมาย ความจริงไปทั่วร่างกาย แต่มีผลเฉพาะเซลล์ที่มีตัวรับ
- คิดว่าขาดไอโอดีนแล้วต่อมไทรอยด์เล็กลง ความจริงต่อมโตขึ้นเพราะ TSH กระตุ้นตลอด
- คิดว่า ADH และออกซิโทซินสร้างที่ต่อมใต้สมองส่วนหลัง ความจริงสร้างที่ไฮโพทาลามัส ต่อมใต้สมองส่วนหลังเป็นที่เก็บและหลั่ง
