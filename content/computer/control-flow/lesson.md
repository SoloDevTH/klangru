## ทำไมต้องซ้อนโครงสร้าง

โปรแกรมจริงแทบไม่เคยตัดสินใจเรื่องเดียวแล้วจบ ลองนึกถึงร้านกาแฟที่คิดส่วนลด ร้านจะดูก่อนว่ายอดซื้อเกินเกณฑ์หรือไม่ ถ้าเกินแล้วจึงดูต่อว่าลูกค้าเป็นสมาชิกหรือเปล่า การตัดสินใจชั้นที่สองอยู่ข้างในชั้นแรก นี่คือ **เงื่อนไขซ้อน** ส่วนงานที่ต้องทำซ้ำหลายรอบ เช่น เช็กชื่อทุกแถวของห้องเรียน ก็มักมีวงวนอยู่ข้างในวงวนอีกที เรียกว่า **วงวนซ้อน**

บทนี้จะฝึกเขียนโครงสร้างเหล่านี้ให้อ่านง่าย และรู้จักคำสั่งสองตัวที่ช่วยควบคุมวงวนคือ `break` กับ `continue`

## เงื่อนไขซ้อนและ elif

ถ้าเขียนเงื่อนไขซ้อนลึกหลายชั้น โค้ดจะเยื้องไปทางขวาเรื่อย ๆ อ่านยาก วิธีที่ดีกว่าคือใช้ `elif` ซึ่งหมายถึง "ถ้าไม่ใช่เงื่อนไขก่อนหน้า แล้วเข้าเงื่อนไขนี้"

```python
x = 7
if x > 5:
    print("ใหญ่")
elif x > 2:
    print("กลาง")
else:
    print("เล็ก")
```

โค้ดนี้พิมพ์ "ใหญ่" เพราะ `x > 5` เป็นจริงตั้งแต่ทางแรก เมื่อทางหนึ่งทำงานแล้ว ทางที่เหลือของ `if`, `elif` และ `else` จะถูกข้ามทั้งหมด

ถ้าเงื่อนไขชั้นในทำงานเฉพาะเมื่อชั้นนอกจริง และไม่มีทางอื่นให้ทำ ก็รวมเป็นเงื่อนไขเดียวด้วย `and` ได้ โค้ดสองชุดนี้ให้ผลเหมือนกัน แต่ชุดที่สองอ่านง่ายกว่า

```python
if total > 1000:
    if member:
        discount = 150
```

```python
if total > 1000 and member:
    discount = 150
```

แต่ถ้าชั้นนอกจริงแล้วต้องทำบางอย่างเสมอ ไม่ว่าชั้นในจะเป็นอย่างไร เช่น ลด 100 บาททุกคนที่ยอดเกิน 1,000 แล้วสมาชิกได้ลดเพิ่ม การซ้อนจะสื่อความหมายนี้ได้ตรงกว่า

เงื่อนไขหลายส่วนรวมกันด้วย `and` (ทั้งสองต้องจริง) หรือ `or` (อย่างน้อยหนึ่งจริง) เช่น ช่วงอายุ 13 ถึง 19 ปีรวมสองปลาย เขียนได้ว่า `13 <= อายุ <= 19` ไม่ต้องแยกเป็นสองเงื่อนไข

## นิพจน์เงื่อนไข

บางครั้งต้องการเลือกค่าเพียงค่าเดียวจากสองค่า เขียนได้ในบรรทัดเดียวด้วยรูปแบบ `a if เงื่อนไข else b` เช่น

```python
total = 280
fee = 0 if total >= 300 else 40
```

ค่าของ `fee` จะเป็น 40 เพราะ 280 ไม่ถึง 300 รูปแบบนี้เหมาะกับการเลือกค่าง่าย ๆ ถ้าเงื่อนไขซับซ้อนควรใช้ `if` ปกติ เพื่อให้คนอ่านติดตามได้

## วงวนซ้อน

ตารางสูตรคูณแสดงแนวคิดนี้ชัด วงนอกนับแถว วงในนับคอลัมน์ วงในจะทำงานครบทุกรอบทุกครั้งที่วงนอกขยับหนึ่งรอบ ดังนั้น ถ้าวงนอกวน 3 รอบ และวงในวน 3 รอบ คำสั่งในวงในจะทำงานทั้งหมด 3 × 3 = 9 ครั้ง ไม่ใช่ 3 + 3

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end=" ")
    print()
```

การพิมพ์รูปดาวที่แถวที่ i มีดาว i ดวง ทำได้ด้วยวงในที่วนตามค่า i ของวงนอก

## break หยุดวงวน และ continue ข้ามรอบ

`break` หยุดวงวนที่อยู่ล้อมรอบคำสั่งนั้นทันที และไปทำคำสั่งถัดจากวงวน ส่วน `continue` ข้ามการทำงานที่เหลือของรอบนั้น แล้วไปเริ่มรอบถัดไปของวงวน

ข้อควรจำคือ `break` ที่อยู่ในวงในหยุดแค่วงใน วงนอกยังทำงานต่อ ส่วน `continue` ก็ข้ามรอบของวงในเท่านั้น

ใช้ `while True` คู่กับ `break` ได้เมื่อไม่รู้ล่วงหน้าว่าต้องวนกี่รอบ เช่น วนรับค่าจนกว่าจะได้ค่าที่ต้องการ โดยเงื่อนไขการหยุดอยู่ข้างใน

## else ของวงวน

วงวนใน Python มี `else` ได้ โดย `else` จะทำงานก็ต่อเมื่อวงวนจบเองตามปกติ คือไม่ได้ถูกหยุดด้วย `break` ใช้ได้ดีในการตรวจจำนวนเฉพาะ คือหาตัวหารที่เป็นไปได้ทั้งหมดแล้วไม่เจอเลย

```python
n = 7
for d in range(2, n):
    if n % d == 0:
        print("ไม่ใช่จำนวนเฉพาะ")
        break
else:
    print("เป็นจำนวนเฉพาะ")
```

ถ้าเจอตัวหารแล้วจะพิมพ์ข้อความแรกและ `break` ทำให้ `else` ถูกข้าม ถ้าไม่เจอเลย วงวนจบเอง `else` จึงทำงาน

## การไล่โปรแกรมด้วยตารางค่า

วิธีตรวจว่าโค้ดซ้อนทำอะไรคือเขียนตารางค่าตัวแปรไว้ข้าง ๆ แล้วทำทีละบรรทัด ทุกครั้งที่วงวนเริ่มรอบใหม่ให้เพิ่มแถวหนึ่งแถว ตารางนี้ทำให้เห็นว่า `count` เปลี่ยนไปเมื่อไร และ `break` หยุดตรงรอบใด

## ค้นหาสิ่งแรกที่ตรงเงื่อนไข

งานที่พบบ่อยที่สุดของ `break` คือการค้นหา สมมติมีรายการอุณหภูมิที่วัดได้ทุกชั่วโมง และต้องการรู้ว่าชั่วโมงแรกที่อุณหภูมิเกิน 35 องศาคือชั่วโมงไหน เราวนไปทีละค่า เมื่อเจอค่าที่ใช่ก็พิมพ์ผลแล้ว `break` ไม่จำเป็นต้องวนต่อไปอีก

ส่วน `continue` เหมาะกับการคัดข้อมูลเสีย เช่น ค่าที่เป็นค่าว่างหรือค่าติดลบซึ่งไม่ควรเอาไปรวม โค้ดจะข้ามรอบนั้นแล้วสนใจเฉพาะค่าที่ใช้ได้

## เลือกโครงสร้างให้อ่านง่าย

โค้ดที่ดีอ่านแล้วเข้าใจได้โดยไม่ต้องไล่ทุกบรรทัด ถ้าเงื่อนไขซ้อนเกินสองชั้น ลองแยกเป็นฟังก์ชันย่อยหรือเปลี่ยนเป็น `elif` ที่เรียงจากกรณีที่เฉพาะเจาะจงไปกรณีทั่วไป การมีคำสั่ง `break` หรือ `continue` มากเกินไปในวงเดียวก็ทำให้ยากจะติดตามเช่นกัน ควรพิจารณาว่าโค้ดจะชัดขึ้นหรือไม่ก่อนเลือกใช้

## ข้อผิดพลาดที่พบบ่อย

- **เยื้องย่อหน้าผิดระดับ** คำสั่งที่ควรอยู่ในวงในแต่เขียนออกมานอกวง โปรแกรมจะไม่ error แต่ผลลัพธ์ผิด
- **คิดว่า `break` หยุดทุกวงวน** จริง ๆ หยุดเฉพาะวงที่ล้อมอยู่ ถ้าต้องหยุดทั้งสองวง ต้องตั้งธงหรือแยกเป็นฟังก์ชันแล้วใช้ `return`
- **ใช้ `=` แทน `==` ในเงื่อนไข** `=` คือการกำหนดค่า ส่วน `==` คือการเปรียบเทียบ
- **เข้าใจ `else` ของ `for` ผิดเป็น `else` ของ `if`** `else` ของวงวนขึ้นกับว่าวงจบเองหรือไม่ ไม่เกี่ยวกับเงื่อนไขภายในวง
- **ลืมว่า `continue` ข้ามเฉพาะรอบเดียว** ผู้เรียนบางคนคิดว่ามันข้ามทั้งวงวน ซึ่งไม่ถูกต้อง
