# บันทึกชุดงาน computer-23 (คอมพิวเตอร์ 8 หัวข้อ)

ภาพทุกภาพวาดเองเป็น SVG ด้วยสคริปต์ Python ที่คำนวณพิกัด เรนเดอร์เป็น PNG ด้วย Chromium และเปิดดูแล้วทุกภาพ ไม่มีภาพจาก Commons ภาพในโจทย์ไม่มีคำตอบ โค้ด Python ทุกชิ้นในบทเรียน ตัวอย่างแสดงวิธีทำ และโจทย์รันด้วย python3 แล้ว ผลตรงกับที่เขียนไว้ ทุกคำตอบและค่า misconception คำนวณด้วย python3 คำสั่ง SQL ทุกคำสั่งในบทเรียนและโจทย์รันด้วยโมดูล sqlite3 ของ python3 กับข้อมูลชุดเดียวกับภาพตาราง (รวมการปฏิเสธคีย์นอกที่ไม่มีอยู่จริง และผลของการต่อข้อความผู้ใช้เข้าคำสั่ง) เครื่องหมายความขัดแย้งในการรวมของ Git ตรวจด้วย git จริงในโฟลเดอร์ชั่วคราว ลิงก์อ้างอิงทุกลิงก์ได้ HTTP 200 ไฟล์จับคู่อยู่ใน `docs/phase8/mappings/` และตรวจด้วยสคริปต์แล้วว่าชุดตัวชี้วัดตรงกับแถว topics และ extend ของแผนพอดี (ยกเว้นแถว PY 9.1 ที่เพิ่มตามข้อเสนอของ computer-16)

## computer.programming.recursion

- 17 ข้อ ภาพ 3 ภาพ: กองการเรียกของ sum_to(3) ต้นไม้การเรียกของ fib(4) และต้นไม้โฟลเดอร์ (โจทย์)

## computer.data.databases

- 17 ข้อ ภาพ 3 ภาพ: แผนภาพตารางพร้อม PK/FK ตารางข้อมูลห้องสมุดสามตาราง (ใช้ในโจทย์ 4 ข้อ) และการเติมซอลต์ก่อนแฮช ชื่อหนังสือในตารางเป็นชื่อสมมติ
- **การเก็บรหัสผ่าน** สอนระดับแนวคิดตามข้อเสนอของ computer-16: ไม่เก็บข้อความตรง ๆ ไม่เข้ารหัสแบบถอดกลับได้ ใช้แฮชที่ตั้งใจให้ช้า (bcrypt, scrypt, Argon2, PBKDF2) พร้อมซอลต์ต่างกันแต่ละบัญชี (lesson, ภาพ, p014, p015) จึงจับ DM-Security เป็น full
- ข้อเสนอแผน: ควรเพิ่ม computer.security.cybersecurity-basics (หรือ computer.security.encryption) เป็น prerequisite เพราะบทนี้อ้างแฮชและการป้องกันการโจมตี ตอนนี้ใส่ใน encompasses ไม่ได้เพราะไม่ได้เป็น prerequisite (ตัวตรวจเตือน)
- หลีกเลี่ยง ORDER BY กับข้อความไทยในโจทย์ เพราะ SQLite เรียงตามรหัสอักขระ ไม่ใช่ตามพจนานุกรมไทย
- DM-Querying และ SEC-Coding เป็น partial (ไม่มี GROUP BY, UPDATE, DELETE และช่องโหว่ชนิดอื่น) AC9TDI8P03 และ AC9TDI10P03 เป็น partial เพราะผู้เรียนไม่ได้สร้างและสืบค้นฐานข้อมูลเองในเครื่องมือจริง
