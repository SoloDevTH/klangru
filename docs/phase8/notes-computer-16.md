# บันทึกชุดงาน computer-16 (คอมพิวเตอร์ 8 หัวข้อ)

ภาพทุกภาพวาดเองเป็น SVG ด้วยสคริปต์ Python ที่คำนวณพิกัด เรนเดอร์เป็น PNG ด้วย Chromium และเปิดดูแล้วทุกภาพ ไม่มีภาพจาก Commons ภาพในโจทย์ไม่มีคำตอบ ทุกคำตอบและค่า misconception คำนวณด้วย python3 ได้แก่ อัตราส่วนความต่างของสีตามสูตร WCAG ตัวจำลองการจัดคิว FCFS SJF และวนรอบ การนับกลุ่มเพื่อหา k-anonymity เวลาส่งข้อมูลและความหน่วง การเลื่อนอักษร XOR และ `pow` ของ RSA จำลอง โค้ด Python ทุกชิ้นในบทเรียน ตัวอย่าง และโจทย์รันด้วย python3 แล้ว ผลตรงกับที่เขียนไว้ ส่วน HTML ในบทเรียนตรวจการซ้อนแท็กด้วย `html.parser` และตรวจพฤติกรรม CSS ในโจทย์ด้วย Chromium (ขาด `;` ทำให้ทิ้งการประกาศทั้งก้อน ตัวเลือกคลาสชนะชื่อแท็ก `.sale` เลือกได้ 3 อิลิเมนต์ ความกว้างกล่อง 224/264 px) ลิงก์อ้างอิงทุกลิงก์ได้ HTTP 200 ไฟล์จับคู่อยู่ใน `docs/phase8/mappings/` และตรวจด้วยสคริปต์แล้วว่าชุดตัวชี้วัดตรงกับแถว topics และ extend ของแผนพอดี

แอปไม่มีตัวแก้ไขหรือตัวรันโปรแกรม ตัวชี้วัดที่ให้ลงมือเขียนโปรแกรม เข้าบัญชีจริง หรือทดสอบชิ้นงานของตนเองกับผู้ใช้จริง จึงเป็น partial เหมือน computer-6 และ computer-9 ความปลอดภัยและการเข้ารหัสสอนเฉพาะการป้องกันและความเข้าใจ ไม่มีวิธีโจมตี (โจทย์ `eval` อธิบายว่าเป็นช่องโหว่และวิธีแก้ ส่วนการลองทุกกุญแจและการนับความถี่ใช้กับรหัสแบบดั้งเดิมเพื่ออธิบายว่าทำไมต้องใช้กุญแจยาว)

## การตรวจข้อกฎหมายและหมายเลขติดต่อ

ใช้วิธีเดียวกับ computer-9 คือดึงข้อความ พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 จากวิกิซอร์ซไทย (`th.wikisource.org/w/index.php?title=พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล_พ.ศ._2562&action=render`) ซึ่งอ้างราชกิจจานุเบกษา เล่ม 136 ตอน 69 ก หน้า 52–95 (24 พ.ค. 2562) วิกิซอร์ซตอบ 429 ครั้งแรก รอแล้วดึงได้ ข้อความที่ใช้

- มาตรา 6 นิยามข้อมูลส่วนบุคคล (ระบุตัวได้ทั้งทางตรงหรือทางอ้อม) และผู้ควบคุมข้อมูล
- มาตรา 19 ความยินยอมโดยชัดแจ้ง แจ้งวัตถุประสงค์ อ่านง่าย ไม่หลอกลวง ถอนได้ง่ายเท่ากับตอนให้
- มาตรา 21 ใช้ตามวัตถุประสงค์ที่แจ้ง มาตรา 22 เก็บเท่าที่จำเป็น มาตรา 23 แจ้งรายละเอียดก่อนหรือขณะเก็บ มาตรา 24 ข้อยกเว้นที่ไม่ต้องขอความยินยอม
- มาตรา 26 รายการข้อมูลอ่อนไหว (รวมข้อมูลสุขภาพ ความพิการ ข้อมูลพันธุกรรม ข้อมูลชีวภาพ)
- มาตรา 30–34 สิทธิขอเข้าถึง ขอรับข้อมูล คัดค้าน ขอให้ลบ ขอให้ระงับการใช้
- มาตรา 37 (4) แจ้งเหตุละเมิดต่อสำนักงานภายใน 72 ชั่วโมงนับแต่ทราบเหตุ (โจทย์ p012 ใช้เส้นตายนี้)
- วันใช้บังคับเต็มรูปแบบ 1 มิ.ย. 2565 ตรวจจากกล่องข้อมูลของบทความวิกิพีเดียไทยเรื่อง พ.ร.บ. นี้

หมายเลขติดต่อ: ใช้สายด่วน 1212 ตามที่ computer-6 ตรวจไว้ และระบบแจ้งความออนไลน์ thaipoliceonline.go.th (ตรวจแล้วได้ HTTP 200 ชื่อหน้าเป็นศูนย์ปราบปรามอาชญากรรมทางเทคโนโลยีสารสนเทศ สำนักงานตำรวจแห่งชาติ) ไม่ได้ใส่สายด่วน 1441 เพราะ aoc.go.th เปิดจากเครื่องนี้ไม่ได้ (502) จึงตรวจไม่ได้

## computer.society.privacy

- 18 ข้อ ภาพ 4 ภาพ: ร่องรอยดิจิทัลสามทาง วงจรข้อมูลตาม PDPA กับสิทธิของเจ้าของข้อมูล หน้าจอขออนุญาตของแอปไฟฉายสมมติ (โจทย์) และตารางน้ำหนักที่ลบชื่อแล้ว (โจทย์ p009 ชี้ตัวได้ 6 แถว p013 ลบปีเกิดแล้ว k = 2)
- AC9TDI10P14 เป็น partial เพราะสอนหลักของ PDPA ไทยซึ่งคล้าย Australian Privacy Principles แต่ไม่ได้สอน APP 13 ข้อโดยตรง SEP-Privacy เป็น partial (ไม่มี differential privacy)
- ตัวเลขรายได้โฆษณาของแอปเกมใน p017 เป็นค่าสมมติ โจทย์ระบุไว้แล้ว
- บทเรียนยาว 997 คำ ใกล้ขอบบน เพราะขอบเขตกว้าง (ข้อมูลส่วนบุคคล ร่องรอยดิจิทัล การชั่งน้ำหนัก PDPA การออกแบบ และผลทางสังคม)

## computer.systems.operating-systems

- 17 ข้อ ภาพ 4 ภาพ: ชั้นของระบบคอมพิวเตอร์ แผนภาพสถานะของกระบวนการ แผนภูมิแกนต์ FCFS กับ SJF และแผนภูมิวนรอบ (โจทย์)
- OS-Principles เป็น partial (ยังไม่มีอินเทอร์รัปต์และเธรด)
- ไม่แน่ใจ: บทเรียนเขียนว่าระบบปฏิบัติการสลับกระบวนการ "หลายร้อยครั้งต่อวินาที" ซึ่งเป็นลำดับขนาดโดยประมาณ ค่าจริงขึ้นกับระบบ และจำนวนชั้นการเรียกซ้ำสูงสุดของ Python ใน p013 ใช้ค่าเริ่มต้น 1,000 ที่ตรวจด้วย `sys.getrecursionlimit()`

## computer.networks.performance

- 17 ข้อ ภาพ 4 ภาพ: ความหน่วงสี่ส่วน คอขวดบนเส้นทาง กราฟ 1/(1 − ρ) และแผนผังเครือข่ายโรงเรียนสมมติ (ใช้ในโจทย์ 5 ข้อ)
- ไม่แน่ใจ: อัตราเร็วสัญญาณในใยแก้ว 2 × 10⁸ m/s ระยะสายกรุงเทพฯ–หาดใหญ่ 950 km (โจทย์บอกว่าเป็นระยะสมมติ) และความสูงดาวเทียมค้างฟ้า 36,000 km (ค่าจริงราว 35,786 km) เป็นค่าประมาณ กราฟคิวใช้แบบจำลองคิวอย่างง่าย (M/M/1) บทเรียนและภาพระบุไว้แล้ว
- ใช้ 1 MB = 1,000,000 ไบต์ทั้งบท และบอกในโจทย์ที่เกี่ยวข้อง
- ข้อเสนอ: ชื่อโฟลเดอร์ `performance` ตามกติกาส่วนท้ายของรหัส แต่ค่อนข้างกว้าง ถ้าภายหลังมีหัวข้อประสิทธิภาพอื่นในวิชาคอมพิวเตอร์อาจชนกัน

## computer.security.encryption

- 17 ข้อ ภาพ 4 ภาพ: แถบรหัสซีซาร์ k = 3 กุญแจสมมาตรกับกุญแจสาธารณะ ขั้นตอน HTTPS แบบย่อ และแผนภูมิความถี่ของข้อความเข้ารหัส (โจทย์ ตัวที่พบบ่อยที่สุดคือ L จึง k = 7)
- ตัวอย่างกุญแจสาธารณะใช้ RSA ตัวเลขเล็ก (e, n) = (3, 33), d = 7 และบอกว่าใช้จำลองแนวคิดเท่านั้น
- SEC-Crypto เป็น partial เพราะยังไม่มีฟังก์ชันแฮชและ MAC ข้อเสนอแผน: การเก็บรหัสผ่านด้วยแฮชควรอยู่ในหัวข้อนี้หรือ computer.data.databases (DM-Security)
- เวลาลองกุญแจ 56 บิตที่ 10¹² ค่าต่อวินาที (ราว 20 ชั่วโมง) เป็นสมมติฐานอัตราการลองเพื่อเปรียบเทียบ ไม่ใช่ความเร็วของเครื่องจริงเครื่องใด
