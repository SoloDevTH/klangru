## พื้นผิวโค้ง แต่ใกล้ ๆ ดูเหมือนแผ่นเรียบ

ยืนอยู่บนเนินเขา พื้นรอบเท้าเราดูเหมือนพื้นเอียงเรียบ ๆ แม้ทั้งเนินจะโค้ง ใน[บทการประยุกต์ของอนุพันธ์](/topic/math.calculus.derivative-applications/) เราประมาณเส้นโค้งด้วยเส้นสัมผัส $L(x) = f(a) + f'(a)(x - a)$ บทนี้ทำแบบเดียวกันในสามมิติ คือประมาณพื้นผิว $z = f(x, y)$ ด้วย **ระนาบสัมผัส** ซึ่งสร้างจาก[อนุพันธ์ย่อย](/topic/math.calculus.partial-derivatives/)สองตัว

## สมการระนาบสัมผัส

ตัดพื้นผิวด้วยระนาบ $y = b$ ได้เส้นโค้งที่มีความชัน $f_x(a, b)$ ตัดด้วยระนาบ $x = a$ ได้เส้นโค้งที่มีความชัน $f_y(a, b)$ ระนาบสัมผัสคือระนาบที่มีเส้นสัมผัสทั้งสองเส้นนี้อยู่ในตัว

$$z = f(a, b) + f_x(a, b)(x - a) + f_y(a, b)(y - b)$$

ตัวอย่างในภาพ $f(x, y) = 4 - x^2 - y^2$ ที่ $(1, 1)$ มี $f = 2$, $f_x = -2x = -2$, $f_y = -2y = -2$ ระนาบสัมผัสคือ $z = 2 - 2(x - 1) - 2(y - 1) = 6 - 2x - 2y$ เวกเตอร์ตั้งฉากกับระนาบคือ $(-f_x, -f_y, 1) = (2, 2, 1)$

## พื้นผิวระดับ $F(x, y, z) = k$

พื้นผิวบางแบบเขียนเป็น $z = f(x, y)$ ไม่สะดวก เช่น ทรงกลมหรือทรงรี ใช้ข้อเท็จจริงจากบทอนุพันธ์ย่อยว่า **เกรเดียนต์ตั้งฉากกับเซตระดับ** ระนาบสัมผัสของ $F(x, y, z) = k$ ที่จุด $(x_0, y_0, z_0)$ จึงเป็น

$$F_x(x - x_0) + F_y(y - y_0) + F_z(z - z_0) = 0$$

เมื่อหาอนุพันธ์ย่อยที่จุดนั้น เช่น ทรงรี $x^2 + 2y^2 + 3z^2 = 6$ ที่ $(1, 1, 1)$ มี $\nabla F = (2x, 4y, 6z) = (2, 4, 6)$ ระนาบสัมผัสคือ $2(x - 1) + 4(y - 1) + 6(z - 1) = 0$ หรือ $x + 2y + 3z = 6$ ส่วน **เส้นตั้งฉาก** ผ่านจุดนั้นในทิศ $\nabla F$ สูตรแรกเป็นกรณีพิเศษของสูตรนี้เมื่อ $F = f(x, y) - z$

## การประมาณเชิงเส้น

ใกล้จุด $(a, b)$ ใช้ระนาบสัมผัสแทนฟังก์ชัน

$$f(x, y) \approx L(x, y) = f(a, b) + f_x(a, b)(x - a) + f_y(a, b)(y - b)$$

เลือก $(a, b)$ ที่ใกล้จุดที่ต้องการและคำนวณ $f$ ได้ง่าย ลองเลื่อนจุดสัมผัสในกราฟโต้ตอบ จะเห็นว่าเส้นตรงจากระนาบสัมผัสใกล้พื้นผิวมากเฉพาะรอบจุดสัมผัส ยิ่งห่างยิ่งคลาดเคลื่อน

## ความหาอนุพันธ์ได้

สำหรับฟังก์ชันสองตัวแปร การมี $f_x$ และ $f_y$ ยัง **ไม่พอ** ให้มีระนาบสัมผัสที่ดี ตัวอย่างคลาสสิกคือ $f(x, y) = \dfrac{xy}{x^2 + y^2}$ เมื่อ $(x, y) \ne (0, 0)$ และ $f(0, 0) = 0$ บนแกนทั้งสองค่าเป็นศูนย์ จึงได้ $f_x(0, 0) = f_y(0, 0) = 0$ แต่บนเส้น $y = x$ ค่าเป็น $\tfrac12$ ตลอด ฟังก์ชันไม่ต่อเนื่องที่จุดกำเนิดด้วยซ้ำ เราจึงนิยามว่า $f$ **หาอนุพันธ์ได้** ที่ $(a, b)$ เมื่อความคลาดเคลื่อน $f - L$ เล็กลงเร็วกว่าระยะห่างจาก $(a, b)$ ทฤษฎีบทที่ใช้ตรวจง่ายคือ ถ้า $f_x, f_y$ มีอยู่ใกล้ $(a, b)$ และต่อเนื่องที่ $(a, b)$ แล้ว $f$ หาอนุพันธ์ได้ที่นั่น และฟังก์ชันที่หาอนุพันธ์ได้ต้องต่อเนื่องเสมอ

## ผลต่างเชิงอนุพันธ์รวมและความคลาดเคลื่อนจากการวัด

เขียนการประมาณเชิงเส้นในรูปการเปลี่ยนแปลงเล็ก ๆ ได้ **ผลต่างเชิงอนุพันธ์รวม**

$$dz = f_x\,dx + f_y\,dy$$

ใช้ประมาณ $\Delta z$ เมื่อ $x, y$ เปลี่ยนไป $dx, dy$ งานสำคัญคือ **การแพร่กระจายของความคลาดเคลื่อน** เช่น กระป๋องทรงกระบอก $V = \pi r^2h$ มี $dV = 2\pi rh\,dr + \pi r^2\,dh$ หารด้วย $V$ ได้

$$\frac{dV}{V} = 2\frac{dr}{r} + \frac{dh}{h}$$

ถ้าวัดรัศมีคลาดเคลื่อนได้ 1% และความสูง 0.5% ความคลาดเคลื่อนสัมพัทธ์ของปริมาตรไม่เกินราว $2(1\%) + 0.5\% = 2.5\%$ รัศมีมีผลเป็นสองเท่าเพราะอยู่ในรูปกำลังสอง ตัวต้านทานต่อขนาน $R = \dfrac{R_1R_2}{R_1 + R_2}$ ก็ใช้วิธีเดียวกัน โดย $\dfrac{\partial R}{\partial R_1} = \dfrac{R_2^2}{(R_1 + R_2)^2}$ เมื่อต้องการความคลาดเคลื่อนสูงสุด ให้รวมขนาดของแต่ละพจน์ (คิดเครื่องหมายในทางที่แย่ที่สุด)

## ข้อผิดพลาดที่พบบ่อย

- ลืมพจน์ $f(a, b)$ หรือแทน $x, y$ แทน $(x - a), (y - b)$ ในสมการระนาบ
- หาอนุพันธ์ย่อยแล้วไม่แทนค่าที่จุดสัมผัส ทำให้ "ระนาบ" มี $x^2$ หรือ $xy$
- ใช้มุมเป็นองศาใน $dz$ ทั้งที่อนุพันธ์ของฟังก์ชันตรีโกณมิติใช้มุมเป็นเรเดียน
- คิดว่ามีอนุพันธ์ย่อยครบแล้วต้องหาอนุพันธ์ได้
- บวกความคลาดเคลื่อนสัมพัทธ์โดยไม่คูณเลขชี้กำลัง เช่น ลืมเลข 2 ของ $r^2$
