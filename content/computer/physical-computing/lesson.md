## แปลงผักที่รดน้ำเองได้

ชมรมเกษตรของโรงเรียนปลูกผักสลัด แต่ช่วงปิดเทอมไม่มีใครมารดน้ำ นักเรียนจึงปักแท่งวัดความชื้นลงในดิน ต่อสายเข้ากับบอร์ดคอมพิวเตอร์ขนาดฝ่ามือ บอร์ดสั่งปั๊มน้ำเมื่อดินแห้ง และส่งค่าความชื้นขึ้นอินเทอร์เน็ตให้ครูดูจากโทรศัพท์ได้ ระบบแบบนี้คือ **ระบบสมองกลฝังตัว (embedded system)** คือคอมพิวเตอร์ที่ฝังอยู่ในสิ่งของเพื่อทำงานเฉพาะอย่างหนึ่ง บทนี้ต่อจากบทระบบคอมพิวเตอร์และบทฟังก์ชัน

## คอมพิวเตอร์ที่ซ่อนอยู่รอบตัว

หม้อหุงข้าวดิจิทัล เครื่องซักผ้า ไฟจราจร รีโมตแอร์ เครื่องวัดอุณหภูมิหน้าห้าง และนาฬิกาออกกำลังกาย ล้วนมีคอมพิวเตอร์อยู่ข้างใน ต่างจากแล็ปท็อปที่ใช้ทำงานได้หลายอย่าง ระบบสมองกลฝังตัวทำงานเดียวซ้ำไปเรื่อย ๆ มักต้องประหยัดพลังงาน ราคาถูก และตอบสนองทันเวลา

หัวใจของระบบคือ **ไมโครคอนโทรลเลอร์ (microcontroller)** ชิปเดียวที่รวมหน่วยประมวลผล หน่วยความจำ และขาเชื่อมต่อ (ขา I/O) ไว้ด้วยกัน บอร์ดสำหรับการเรียนที่พบบ่อยคือ micro:bit, Arduino และ KidBright ที่เนคเทค (สวทช.) พัฒนาเพื่อให้นักเรียนไทยฝึกเขียนโปรแกรม

## รับเข้า ประมวลผล ส่งออก

ระบบสมองกลฝังตัวทำงานตามแบบรับเข้า–ประมวลผล–ส่งออกเหมือนคอมพิวเตอร์ทั่วไป (ดูภาพ)

- **เซนเซอร์ (sensor)** แปลงปริมาณทางกายภาพเป็นสัญญาณไฟฟ้า เช่น ความชื้นในดิน อุณหภูมิ แสง ระยะทาง (อัลตราโซนิก) การเคลื่อนไหว (PIR) และปุ่มกด
- **ไมโครคอนโทรลเลอร์** อ่านสัญญาณ ตัดสินใจตามโปรแกรม แล้วสั่งงาน
- **ตัวขับเคลื่อน (actuator)** เปลี่ยนคำสั่งเป็นการกระทำ เช่น มอเตอร์ เซอร์โว LED ลำโพงบัซเซอร์ และรีเลย์ที่เปิดปิดปั๊ม
- **โมดูลสื่อสาร** เช่น Wi-Fi บลูทูธ หรือ LoRa ส่งข้อมูลออกไปและรับคำสั่งเข้ามา

เซนเซอร์หลายชนิดให้สัญญาณ **แอนะล็อก** คือแรงดันไฟฟ้าที่เปลี่ยนต่อเนื่อง ตัวแปลงแอนะล็อกเป็นดิจิทัล (ADC) ขนาด 10 บิตแปลงแรงดันเป็นจำนวนเต็ม $2^{10} = 1024$ ระดับ คือ 0 ถึง 1023 (เช่นใน micro:bit และ Arduino Uno) ค่าดิบนี้ยังไม่มีหน่วย โปรแกรมต้อง **ปรับเทียบ (calibrate)** ก่อน เช่น วัดค่าตอนดินแห้งสนิทได้ 800 และตอนแช่น้ำได้ 300 แล้วแปลงเป็นเปอร์เซ็นต์

$$\text{ความชื้น} = \frac{\text{ค่าแห้ง} - \text{ค่าที่อ่าน}}{\text{ค่าแห้ง} - \text{ค่าเปียก}} \times 100\%$$

```python
def to_percent(raw, dry=800, wet=300):
    return (dry - raw) / (dry - wet) * 100

print(to_percent(550))   # 50.0
```

## โปรแกรมวนตลอดเวลา

โปรแกรมบนไมโครคอนโทรลเลอร์มักเป็นวงวนไม่รู้จบ: อ่านเซนเซอร์ → แปลงค่า → ตัดสินใจ → สั่งตัวขับเคลื่อน → ส่งข้อมูล → รอ แล้ววนใหม่ ตัวอย่างนี้จำลองบนคอมพิวเตอร์ โดยใช้ลิสต์แทนค่าที่อ่านจากเซนเซอร์จริง (บนบอร์ดจริง ฟังก์ชันอ่านค่ามาจากไลบรารีของบอร์ด)

```python
readings = [45, 38, 29, 26, 33]   # ความชื้นดิน (%) จำลองแทนเซนเซอร์

def read_moisture(t):
    return readings[t]

for t in range(len(readings)):
    m = read_moisture(t)
    if m < 30:
        print(t, m, "เปิดปั๊ม")
    else:
        print(t, m, "ปิดปั๊ม")
```

ถ้าใช้เกณฑ์เดียว ค่าที่แกว่งรอบ 30% จะทำให้ปั๊มเปิดปิดถี่จนเสียเร็ว ระบบจริงจึงใช้ **สองเกณฑ์** เช่น เปิดเมื่อต่ำกว่า 30% และปิดเมื่อเกิน 60% ช่วงระหว่างกลางให้คงสถานะเดิมไว้ วิธีนี้เรียกว่า **ฮิสเทอรีซิส (hysteresis)** แบบเดียวกับที่แอร์ใช้คุมอุณหภูมิ

## เก็บและส่งข้อมูล

ระบบจะมีประโยชน์ขึ้นมากเมื่อเก็บค่าไว้ดูย้อนหลังและส่งถึงคนที่อยู่ไกล บอร์ดจัดข้อมูลเป็นข้อความรูปแบบที่ตกลงกัน เช่น JSON แล้วส่งผ่าน Wi-Fi ไปยังเซิร์ฟเวอร์หรือบริการคลาวด์ ซึ่งแสดงเป็นกราฟบนโทรศัพท์ การเชื่อมสิ่งของจำนวนมากเข้ากับอินเทอร์เน็ตแบบนี้เรียกว่า **อินเทอร์เน็ตของสรรพสิ่ง (IoT)**

```python
import json
msg = {"id": "แปลง1", "moisture": 42, "pump": False}
print(json.dumps(msg, ensure_ascii=False))
# {"id": "แปลง1", "moisture": 42, "pump": false}
```

การออกแบบต้องชั่งหลายเรื่อง อ่านและส่งถี่ได้ข้อมูลละเอียด แต่เปลืองแบตเตอรี่และพื้นที่ เช่น อ่านทุก 10 นาทีได้ $24 \times 60 \div 10 = 144$ ค่าต่อวัน ส่วนการเลือกช่องทางขึ้นกับระยะ บลูทูธเหมาะกับระยะไม่กี่เมตร Wi-Fi ต้องอยู่ใกล้จุดกระจายสัญญาณ ส่วน LoRa ส่งข้อมูลก้อนเล็กได้ไกลหลายกิโลเมตรโดยใช้พลังงานน้อย เหมาะกับไร่นา

## นามธรรมซ่อนรายละเอียด

คนหุงข้าวกดปุ่มเดียว ไม่ต้องรู้ว่าข้างในมีเซนเซอร์วัดอุณหภูมิ มีโปรแกรมที่ลดไฟเมื่อน้ำงวดและอุณหภูมิก้นหม้อสูงเกิน 100 °C หรือมีวงจรแปลงแรงดันเป็นตัวเลข นี่คือ **นามธรรม (abstraction)** ที่ซ้อนกันเป็นชั้น แต่ละชั้นเห็นเฉพาะสิ่งที่จำเป็นและใช้บริการของชั้นล่างโดยไม่ต้องรู้วิธีทำ

- ผู้ใช้เห็นแค่ปุ่มและไฟสถานะ
- โปรแกรมหลักเรียก `read_temperature()` โดยไม่สนว่าเซนเซอร์ต่ออยู่ขาไหน
- ไลบรารีของบอร์ดสั่ง ADC อ่านแรงดัน แล้วแปลงเป็นองศา
- วงจรอิเล็กทรอนิกส์เปลี่ยนความร้อนเป็นแรงดันไฟฟ้า

ข้อดีคือเปลี่ยนชั้นล่างได้โดยชั้นบนไม่ต้องแก้ เช่น เปลี่ยนรุ่นเซนเซอร์แล้วแก้แค่ไลบรารี ข้อเสียคือเมื่อมีปัญหา ผู้ใช้มองไม่เห็นสาเหตุ ช่างจึงต้องไล่ลงไปทีละชั้น

**ความปลอดภัย:** ขาของบอร์ดจ่ายไฟได้น้อยมาก ห้ามต่อมอเตอร์หรือปั๊มตรงกับขา ให้ใช้รีเลย์หรือวงจรขับ และงานที่เกี่ยวกับไฟบ้าน 220 V ต้องให้ครูหรือผู้ใหญ่ที่มีความรู้ทำ

## ข้อผิดพลาดที่พบบ่อย

- **คิดว่าค่าที่อ่านจาก ADC มีหน่วยแล้ว** ค่า 0–1023 ต้องปรับเทียบก่อนใช้
- **สลับเซนเซอร์กับตัวขับเคลื่อน** เซนเซอร์รับรู้ ตัวขับเคลื่อนลงมือทำ
- **ใช้เกณฑ์เดียว** ทำให้อุปกรณ์เปิดปิดถี่เมื่อค่าแกว่งรอบเกณฑ์
- **ส่งข้อมูลถี่เกินจำเป็น** แบตเตอรี่หมดเร็วและข้อมูลล้น
- **ต่ออุปกรณ์กำลังสูงตรงกับขาบอร์ด** บอร์ดเสียหรือเกิดอันตราย
