## ข้อมูลที่อยู่ต่อหลังโปรแกรมจบ

ตัวแปรในโปรแกรมหายไปเมื่อโปรแกรมปิด ถ้าร้านกาแฟต้องเก็บยอดขายของวันนี้ไว้ให้เปิดดูได้พรุ่งนี้ ต้องบันทึกลง **ไฟล์** ซึ่งอยู่บนดิสก์และยังอยู่หลังโปรแกรมจบ บทนี้จะอ่านและเขียนไฟล์ ใช้โมดูล `csv` กับข้อมูลตาราง และจัดการกับข้อผิดพลาดที่เกิดขึ้นได้จริงโดยไม่ทำให้โปรแกรมพังทั้งหมด

## เปิด อ่าน และเขียนไฟล์

`open()` รับชื่อไฟล์และโหมดการเปิด

- `"r"` อ่านอย่างเดียว ถ้าไม่มีไฟล์จะเกิด `FileNotFoundError`
- `"w"` เขียนใหม่ทั้งหมด เนื้อหาเดิมจะถูกลบ
- `"a"` เขียนต่อท้ายจากเนื้อหาเดิม

```python
with open("sales.txt", "w", encoding="utf-8") as f:
    f.write("ลาเต้ 2\n")
    f.write("ชา 1\n")

with open("sales.txt", encoding="utf-8") as f:
    for line in f:          # อ่านทีละบรรทัด ไม่ต้องโหลดทั้งไฟล์เข้าหน่วยความจำ
        print(line.strip())
```

ควรใช้คำสั่ง `with` เสมอ เพราะเมื่อจบบล็อก Python จะปิดไฟล์ให้อัตโนมัติ แม้เกิดข้อผิดพลาดกลางคันก็ตาม ส่วนการระบุ `encoding="utf-8"` ทำให้ตัวอักษรไทยถูกแปลงเป็นไบต์และแปลงกลับได้ตรงกันบนทุกเครื่อง

## เส้นทางของไฟล์

ชื่อไฟล์แบบ **สัมพัทธ์** เช่น `"data/sales.csv"` หมายถึงตำแหน่งที่เทียบกับโฟลเดอร์ที่รันโปรแกรม ส่วน **สัมบูรณ์** เริ่มจากราก เช่น `/home/ร้าน/sales.csv` โมดูล `pathlib` ช่วยต่อเส้นทางด้วยเครื่องหมาย `/` ได้โดยไม่ต้องพิมพ์ตัวคั่นเอง

```python
from pathlib import Path
path = Path("data") / "sales.csv"
print(path.name)     # sales.csv
```

## ไฟล์ CSV

CSV คือไฟล์ข้อความที่แต่ละบรรทัดเป็นแถว และคั่นแต่ละช่องด้วยจุลภาค โมดูล `csv` จัดการเรื่องเครื่องหมายคำพูดและการขึ้นบรรทัดใหม่ให้ `DictReader` อ่านแถวหัวตารางเป็นชื่อคอลัมน์ ทำให้เรียกค่าด้วยชื่อได้

```python
import csv
import io

text = "ชื่อ,จำนวน\nลาเต้,2\nชา,1\n"
for row in csv.DictReader(io.StringIO(text)):
    print(row["ชื่อ"], row["จำนวน"])
```

## ข้อผิดพลาดและการจัดการ

ข้อผิดพลาดที่เกิดขึ้นขณะทำงาน เรียกว่า **ข้อยกเว้น (exception)** ถ้าไม่จับ โปรแกรมจะหยุดทันที โครงสร้าง `try` ให้ลองทำงานที่อาจพลาด `except` รับมือเมื่อเกิดข้อยกเว้นที่ระบุ `else` ทำเมื่อไม่มีข้อผิดพลาด และ `finally` ทำเสมอ

```python
raw = "สิบแปด"
try:
    value = int(raw)
except ValueError:
    print("ข้อมูลนี้ไม่ใช่ตัวเลข ข้ามไป")
else:
    print("คะแนนคือ", value)
finally:
    print("จบการตรวจหนึ่งรายการ")
```

หลักสำคัญมีสามข้อ

1. **จับเฉพาะชนิดที่คาดว่าจะเกิด** เช่น `except ValueError` ไม่ควรเขียน `except:` เปล่า ๆ เพราะจะซ่อนข้อผิดพลาดที่ไม่ได้คาดไว้
2. **ห้ามกลืนข้อผิดพลาดเงียบ ๆ** การเขียน `except ValueError: pass` ทำให้ไม่รู้ว่ามีข้อมูลเสียอยู่ ควรบันทึกหรือนับจำนวนที่ข้ามไว้
3. **โยนข้อยกเว้นพร้อมข้อความที่บอกค่า** ด้วย `raise` ถ้าต้องการชนิดเฉพาะของโปรแกรม สร้างคลาสที่สืบทอดจากข้อยกเว้นที่ใกล้เคียง

```python
class ScoreError(ValueError):
    pass

def check_score(value):
    if not 0 <= value <= 100:
        raise ScoreError(f"คะแนนต้องอยู่ระหว่าง 0 ถึง 100 แต่ได้ {value}")
    return value
```

## ในแอปนี้ไม่มีไฟล์จริง

ตัวรันโค้ดในแอปไม่มีระบบไฟล์ให้เขียนลงดิสก์ จึงใช้ `io.StringIO` แทน ซึ่งมีเมธอด `write`, `seek` และ `read` เหมือนไฟล์ ผู้เรียนจึงฝึกวิธีคิดเดียวกันได้โดยไม่ต้องมีไฟล์จริง

```python
import io
buf = io.StringIO()
buf.write("ฟ้า,18\n")
buf.seek(0)          # ย้ายกลับไปต้นข้อความก่อนอ่าน
print(buf.read())
```

## ข้อผิดพลาดที่พบบ่อย

- เปิดไฟล์ด้วย `"w"` เพื่อเพิ่มข้อมูล แล้วพบว่าข้อมูลเดิมหายไป ต้องใช้ `"a"`
- อ่านไฟล์หลังจากเขียนโดยไม่ย้ายตัวชี้กลับต้นทาง ทำให้ได้ข้อความว่าง
- ไม่ระบุ encoding ทำให้ภาษาไทยอ่านผิดบนบางระบบ
- ใช้ `int()` กับข้อมูลที่อาจผิดรูปแล้วไม่จับข้อยกเว้น โปรแกรมจึงหยุดกลางคันทั้งที่ควรข้ามเพียงบรรทัดเดียว
