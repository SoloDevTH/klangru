# บันทึกชุดงาน physics-15 (เฟส 8)

ฟิสิกส์ 8 หัวข้อจาก `docs/phase6/proposals-science-core.yaml`, `proposals-science-additional.yaml` และ `proposals-international.yaml` (รวมแถว `extend:` ทุกแถว) ภาพทุกภาพวาดเองเป็น SVG ด้วยสคริปต์ Python ที่คำนวณพิกัด (scratchpad `phase8-physics-15/fig_*.py` ตัวช่วย `svg.py`) เรนเดอร์เป็น PNG ด้วย Chromium และเปิดตรวจทุกภาพ ไม่มีภาพจาก Commons คำตอบและค่า misconception ทุกตัวคำนวณด้วย python3 สูตรในสื่อโต้ตอบทุกสูตรตรวจแล้วว่า `compileLatex` ของแอปคำนวณได้ จำนวนคำของบทเรียนนับด้วย `Intl.Segmenter` อยู่ที่ 649–986 คำ ลิงก์อ้างอิงและ PhET ทุกลิงก์ตรวจแล้วได้ HTTP 200 (หน้าวิกิพีเดียไทยที่เป็นหน้าเปลี่ยนทางใช้ชื่อหน้าปลายทาง) ไฟล์จับคู่หลักสูตรอยู่ใน `docs/phase8/mappings/` ครบ 41 ตัวชี้วัด

สัญลักษณ์ตามหนังสือ สสวท.: อีเอ็มเอฟใช้ $E$ และความต้านทานภายใน $r$ มอดุลัสของยังใช้ $Y$ ความเค้น $\sigma$ ความเครียด $\varepsilon$ สูตรเลนส์ $\tfrac1f = \tfrac1s + \tfrac1{s'}$ (เลนส์นูน $f$ บวก ภาพเสมือน $s'$ ลบ เหมือน `physics.light.ray-diagrams`) กำลังของเลนส์ $P = 1/f$ หน่วยไดออปเตอร์ ดอปเพลอร์ $f_L = f_S\frac{v \pm v_L}{v \mp v_S}$ คลื่นกระแทก $\sin\theta = v/v_S$ ภาพแผนภาพรังสีของตา แว่น และกล้องจุลทรรศน์ไล่รังสีด้วยเลนส์บางจริง (ตำแหน่งภาพตรงกับสูตร) ภาพหน้าคลื่นดอปเพลอร์และกรวยคลื่นกระแทกวาดจากตำแหน่งที่แหล่งกำเนิดปล่อยหน้าคลื่นจริง ภาพวงโคจรวาดตามมาตราส่วน ขั้วแบตเตอรี่ (เส้นยาว = บวก) ตรวจให้ตรงกับทิศกระแสในภาพ
