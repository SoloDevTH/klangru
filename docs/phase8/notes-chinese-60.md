# บันทึกชุดงาน chinese-60 (เฟส 8)

หัวข้อภาษาจีน 8 หัวข้อจาก `docs/phase6/proposals-languages.yaml` (ไม่มีแถว `extend:`) โจทย์สร้างจาก `p_*.py` ผ่าน `build.py` แบบเดียวกับชุด chinese-53 (หมุนตำแหน่งตัวเลือกที่ถูก และขยายคำตอบ text ให้รับทั้งแบบมีและไม่มี 。 . ？ ? ท้ายประโยค) ภาพวาดด้วย `figs.py` (font-family มีรายชื่อฟอนต์ CJK และไทย) เรนเดอร์เป็น PNG ด้วย Chromium และเปิดดูทุกภาพแล้ว อักษรจีนและไทยแสดงถูก สคริปต์อยู่ใน scratchpad `phase8-chinese-60/` ตัวเลขทุกตัวคำนวณด้วย python3 คำในบทเรียนนับด้วย `Intl.Segmenter`: 603–774 คำ

**แบบพินอินที่ใช้** (เหมือนชุด chinese-53): เขียนเสียงที่เปลี่ยนของ 一 และ 不 ตามที่พูดจริง (yí gè, bú qù, yìdiǎnr, búyòng) แต่ไม่เขียนเสียง 3 ที่เปลี่ยนเป็นเสียง 2 (kěyǐ, nǐ hǎo) พยางค์เสียงเบาตาม CC-CEDICT (xuésheng, háishi, duōshao, rènshi, piányi) คำต่อท้าย 过 着 ไม่ใส่วรรณยุกต์ (qùguo, xiězhe) ส่วนคำบอกทิศหลังคำนามเขียนวรรณยุกต์เต็ม (zhuōzi shàng, shūbāo lǐ) อักษรและพินอินทุกคำตรวจกับ CC-CEDICT (ไฟล์ mdbg ชุดเดียวกับ chinese-53) จำนวนขีดและลำดับขีดของอักษรในโจทย์ `hanzi` (吗 在 没 叫 钱 会 都 过) ตรวจกับ hanzi-writer-data ทั้งจำนวนขีดและทิศของเส้นกลางแต่ละขีด

## chinese/guo-zhe-shi-de (`chinese.grammar.guo-zhe-shi-de`)

- โจทย์ 17 ข้อ (1:1 2:4 3:5 4:5 5:2; mcq match order text numeric hanzi 过; บริบทไทย: ทุเรียน ต้มยำกุ้ง (冬荫功) สนามบินสุวรรณภูมิ เยาวราชช่วงตรุษจีน โรงเรียนในภูเก็ต) ภาพ 1 (`aspect-timeline.svg`)
- ไม่ซ้ำกับหัวข้อในแผน `chinese.grammar.progressive-bi` (在/正在) บทนี้บอกเพียงว่า "กำลังทำ" ใช้ 在 正在 โดยไม่ลิงก์ เพราะหัวข้อนั้นยังไม่มีในคลัง
- ตำแหน่งของ 次 กับกรรมที่เป็นชื่อสถานที่ (去过北京三次 / 去过三次北京) ใช้ได้ทั้งสองแบบ จึงไม่ทำเป็นโจทย์ · 是…的 กับกรรม (是在曼谷买的这本书 / 买这本书的) ไม่ได้สอน
- ข้อเสนอแก้แผน: prerequisite ควรเพิ่ม `chinese.grammar.word-order` (หรือ `location-you-zai`) เพราะรูป 是 + สถานที่/เวลา + กริยา + 的 และ สถานที่ + V着 + สิ่งของ ต้องใช้ลำดับเวลา สถานที่ และ 在 ที่สอนในสองบทนั้น
