## ทำไมต้องเรียน Python

**Python** เป็นภาษาโปรแกรมที่คนนิยมมาก ถูกสร้างโดยคีโด ฟัน โรสซึม (Guido van Rossum) และเปิดตัวครั้งแรกในปี ค.ศ. 1991 (พ.ศ. 2534) เด็กและผู้ใหญ่ใช้เรียนรู้ได้ง่ายเพราะโค้ดอ่านคล้ายประโยคภาษาอังกฤษ และนำไปใช้กับงานหลายอย่าง เช่น การวิเคราะห์ข้อมูล เว็บไซต์ และเกม

## เชลล์และการพิมพ์ผล

เชลล์ (shell) เป็นช่องที่พิมพ์คำสั่งทีละบรรทัดแล้วเห็นผลทันที ถ้าพิมพ์ `2 + 3` แล้วกด Enter จะเห็น `5`

คำสั่ง `print` ใช้แสดงผล และรับได้หลายค่า ค่าเริ่มต้นจะคั่นด้วยช่องว่าง เช่น `print("สวัสดี", "ชาวโลก")` ได้ `สวัสดี ชาวโลก` ถ้าต้องการเปลี่ยนตัวคั่นให้ใส่ `sep` ถ้าต้องการเปลี่ยนตัวจบบรรทัดให้ใส่ `end`

ข้อความที่อยู่หลัง `#` คือ **คอมเมนต์** โปรแกรมจะไม่ทำงานกับมัน ใช้เขียนบันทึกให้คนอ่านเข้าใจ

## ชนิดข้อมูลและการแปลง

ทุกค่าใน Python มีชนิด ที่ใช้บ่อยคือ

- **int** จำนวนเต็ม เช่น `12`
- **float** ทศนิยม เช่น `12.0`
- **str** ข้อความ เช่น `"12"` ต้องอยู่ในเครื่องหมายคำพูด

ค่าที่เป็นข้อความ `"12"` กับจำนวน `12` ดูเหมือนกัน แต่ทำงานต่างกัน `int("25") * 2` ได้ `50` แต่ `"25" * 2` ได้ `"2525"` เพราะเครื่องต่อข้อความสองครั้ง

การแปลงทำได้ด้วยฟังก์ชัน `int()`, `float()` และ `str()` แต่ระวังว่า `int("12.5")` จะเกิด **ValueError** เพราะข้อความทศนิยมแปลงเป็นจำนวนเต็มโดยตรงไม่ได้ ต้องแปลงเป็นทศนิยมก่อน และ `int(12.9)` ได้ `12` เพราะตัดทศนิยมทิ้ง ไม่ได้ปัดเศษ

ฟังก์ชัน `input()` รับค่าที่พิมพ์เข้ามาเป็นข้อความเสมอ แม้ผู้ใช้พิมพ์ตัวเลข ในบทเรียนนี้โจทย์ทุกข้อใช้ค่าที่กำหนดไว้ในโค้ดแทน

ฟังก์ชัน `round(x, 2)` ปัดทศนิยมให้เหลือ 2 ตำแหน่ง เช่น `round(3.14159, 2)` ได้ `3.14` ฟังก์ชัน `len()` นับจำนวนสมาชิก และเมธอด `split(",")` แยกข้อความที่คั่นด้วยเครื่องหมายจุลภาคเป็นรายการ เช่น `"70,85".split(",")` ได้รายการสองค่า

## ฟังก์ชันที่คืนค่า

เราสร้างฟังก์ชันของตัวเองได้ด้วยคำว่า `def` เช่น

```python
def c2f(c):
    """แปลงอุณหภูมิจากองศาเซลเซียสเป็นองศาฟาเรนไฮต์"""
    return c * 9 / 5 + 32
```

ข้อความในเครื่องหมายคำพูดสามตัว `"""..."""` ที่อยู่บรรทัดแรกในฟังก์ชันเรียกว่า **docstring** ใช้บอกว่าฟังก์ชันทำอะไร ต่างจากคอมเมนต์ `#` ตรงที่ Python เก็บ docstring ไว้กับฟังก์ชัน และแสดงให้ดูได้เมื่อพิมพ์ `help(c2f)` ในเชลล์

คำว่า `return` คืนค่าออกจากฟังก์ชันเพื่อให้โปรแกรมเอาค่านั้นไปใช้ต่อ ส่วน `print` เพียงแสดงผลบนหน้าจอ ฟังก์ชันที่ไม่มี `return` จะคืนค่า `None` ดังนั้นเมื่อโจทย์ให้เขียนฟังก์ชันที่คืนค่า ต้องใช้ `return` ส่งคำตอบออกมา

## นิพจน์ชนิดผสม

เมื่อนำจำนวนเต็มกับทศนิยมมารวมกัน ผลจะเป็นทศนิยมเสมอ `2 + 3.0` ได้ `5.0` แต่ถ้านำข้อความมาบวกกับตัวเลขโดยตรง เช่น `"5" + 3` จะเกิด **TypeError** ทันที ต้องแปลงให้ชนิดตรงกันก่อน

## ลำดับการดำเนินการ

Python ทำตามลำดับเดียวกับคณิตศาสตร์ แต่มีบางจุดต้องระวัง

1. วงเล็บ
2. ยกกำลัง `**`
3. คูณ หาร `*` `/` หารปัดลง `//` หารเอาเศษ `%`
4. บวก ลบ `+` `-`
5. เปรียบเทียบ เช่น `==` และ `<`
6. `not`, `and`, `or` ตามลำดับ

ตัวอย่าง `2 + 3 * 4` ได้ `14` เพราะคูณก่อนบวก และ `-2 ** 2` ได้ `-4` เพราะยกกำลังทำก่อนใส่เครื่องหมายลบ ถ้าไม่แน่ใจให้ใช้วงเล็บ

## ทศนิยมคลาดเคลื่อนและโมดูล math

คอมพิวเตอร์เก็บทศนิยมแบบประมาณ ทำให้ `0.1 + 0.2` ได้ `0.30000000000000004` จึงเทียบ `0.1 + 0.2 == 0.3` ได้ `False` ควรใช้ `math.isclose(a, b)` เพื่อเทียบว่าใกล้กันพอหรือไม่

โมดูล `math` มีฟังก์ชันที่ใช้บ่อย เช่น `math.sqrt(144)` ได้ `12.0`, `math.floor(3.9)` ได้ `3`, `math.ceil(7.2)` ได้ `8` และ `math.pi` ได้ค่าประมาณ 3.14159 ต้องใส่ `import math` ก่อนใช้

## อ่านข้อความแจ้งข้อผิดพลาด

เมื่อโค้ดผิด Python จะบอก 3 อย่าง คือ ชนิดของข้อผิดพลาด เช่น `NameError` หมายเลขบรรทัดที่เกิดปัญหา และข้อความอธิบาย เช่น ตัวแปรที่ยังไม่เคยกำหนดค่า อ่านทั้งสามอย่างก่อนแก้โค้ดในบรรทัดนั้นแล้วรันใหม่

ข้อผิดพลาดที่พบบ่อยมี 4 ชนิด ได้แก่ `NameError` ใช้ชื่อที่ยังไม่ได้กำหนด `TypeError` ใช้ค่าผิดชนิด เช่น `"ราคา " + 50` `ValueError` ชนิดถูกแต่ค่าแปลงไม่ได้ เช่น `int("abc")` และ `ZeroDivisionError` หารด้วยศูนย์ เช่น `10 / 0`

## การจัดรูปโค้ด

โค้ดที่ดีควรอ่านง่าย แนวทางที่นิยมคือ **PEP 8** เช่น เว้นช่องรอบเครื่องหมาย `=` และ `+` เขียน `x = 1 + 2` ไม่ใช่ `x=1+2` และย่อหน้าด้วยการเว้น 4 ช่อง นอกจากนี้ควรมีคอมเมนต์อธิบายสิ่งที่ซับซ้อน

เมื่อต้องการแสดงตัวเลขเป็นข้อความที่อ่านง่าย ใช้ f-string เช่น `f"{1234.5:,.2f}"` ได้ `1,234.50` โดย `,` ทำให้มีลูกน้ำคั่นหลักพัน และ `.2f` ให้ทศนิยม 2 ตำแหน่ง

## ข้อผิดพลาดที่พบบ่อย

- **คิดว่า `"25" * 2` ได้ 50** จริง ๆ ได้ `"2525"` เพราะเป็นข้อความ
- **คิดว่า `int("12.5")` ได้ 12** จริง ๆ เกิด ValueError
- **ลืมว่าคูณและยกกำลังทำก่อนบวก** ทำให้ได้ผลผิด
- **ใช้ `==` เทียบทศนิยมตรง ๆ** ควรใช้ `math.isclose`
