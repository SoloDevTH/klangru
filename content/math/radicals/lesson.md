## เขียนรากให้อยู่ในรูปที่ง่ายที่สุด

ที่ดินรูปสี่เหลี่ยมจัตุรัสพื้นที่ 72 ตารางวา ยาวด้านละ $\sqrt{72}$ วา เครื่องคิดเลขบอกว่าประมาณ 8.49 วา แต่ในคณิตศาสตร์เรามักเขียนค่าที่แม่นยำว่า $6\sqrt{2}$ วา เพราะคำนวณต่อได้ง่ายและไม่มีความคลาดเคลื่อน จำนวนในรูป $\sqrt{a}$ หรือ $\sqrt[n]{a}$ เรียกว่า **จำนวนในรูปกรณฑ์** บทนี้ต่อจาก [รากที่สองและรากที่สาม](/topic/math.number.roots/) และ [กฎของเลขยกกำลัง](/topic/math.algebra.exponent-laws/)

บทนี้เรียงจากง่ายไปยาก: สมบัติของจำนวนจริง → ทำรากให้อยู่ในรูปอย่างง่าย → บวก ลบ คูณ หาร → ทำตัวส่วนไม่ให้ติดกรณฑ์ → เปรียบเทียบ → ค่าสัมบูรณ์

## สมบัติของจำนวนจริง

จำนวนจริงทุกจำนวน (ทั้งตรรกยะและอตรรกยะ) มีสมบัติเดียวกัน เช่น

- **ปิด** การบวกและการคูณ ($a + b$ และ $ab$ เป็นจำนวนจริง)
- **สลับที่** $a + b = b + a$, $ab = ba$ และ **เปลี่ยนกลุ่ม** $(a + b) + c = a + (b + c)$
- **เอกลักษณ์** $a + 0 = a$, $a \times 1 = a$ และ **ตัวผกผัน** $a + (-a) = 0$, $a \times \tfrac1a = 1$ เมื่อ $a \ne 0$
- **แจกแจง** $a(b + c) = ab + ac$
- **การไม่เท่ากัน** ถ้า $a < b$ แล้ว $a + c < b + c$ และถ้า $c > 0$ แล้ว $ac < bc$ แต่ถ้า $c < 0$ เครื่องหมายกลับ

ผลบวกและผลคูณของจำนวนตรรกยะเป็นจำนวนตรรกยะเสมอ แต่ **จำนวนตรรกยะบวกจำนวนอตรรกยะได้จำนวนอตรรกยะเสมอ** เหตุผล: ถ้า $r + x = s$ โดย $r, s$ เป็นตรรกยะ จะได้ $x = s - r$ เป็นตรรกยะ ขัดแย้งกับที่ $x$ เป็นอตรรกยะ ทำนองเดียวกัน จำนวนตรรกยะที่ไม่ใช่ศูนย์คูณจำนวนอตรรกยะได้อตรรกยะ เช่น $2 + \sqrt3$ และ $5\sqrt2$ เป็นอตรรกยะ แต่ผลคูณของอตรรกยะสองจำนวนอาจเป็นตรรกยะ เช่น $\sqrt2 \times \sqrt8 = 4$

## ทำรากให้อยู่ในรูปอย่างง่าย

ใช้ $\sqrt{ab} = \sqrt a\,\sqrt b$ เมื่อ $a, b \ge 0$ แยกตัวที่ **เป็นกำลังสองสมบูรณ์ที่ใหญ่ที่สุด** ออกมา

$$\sqrt{72} = \sqrt{36 \times 2} = 6\sqrt2 \qquad \sqrt{12} = \sqrt{4 \times 3} = 2\sqrt3$$

ภาพตารางแสดงว่าทำไม $\sqrt8 = 2\sqrt2$: เส้นทแยงมุมของสี่เหลี่ยม $2 \times 2$ ประกอบด้วยเส้นทแยงมุมของช่อง $1 \times 1$ สองเส้นต่อกัน

## บวก ลบ คูณ หาร

- **บวกลบ** ได้เฉพาะกรณฑ์ที่เหมือนกัน เหมือนการรวมพจน์คล้าย $3\sqrt2 + 5\sqrt2 = 8\sqrt2$ ถ้าไม่เหมือนกันให้ทำรูปอย่างง่ายก่อน $\sqrt8 + \sqrt{18} = 2\sqrt2 + 3\sqrt2 = 5\sqrt2$ แต่ $\sqrt2 + \sqrt3 \ne \sqrt5$
- **คูณ** $\sqrt a \times \sqrt b = \sqrt{ab}$ เช่น $\sqrt6 \times \sqrt{15} = \sqrt{90} = 3\sqrt{10}$
- **หาร** $\dfrac{\sqrt a}{\sqrt b} = \sqrt{\dfrac ab}$ เมื่อ $b > 0$
- **กระจาย** ใช้สมบัติการแจกแจง เช่น $(\sqrt3 + \sqrt2)^2 = 3 + 2\sqrt6 + 2 = 5 + 2\sqrt6$ และ $(a + \sqrt b)(a - \sqrt b) = a^2 - b$

## ทำตัวส่วนไม่ให้ติดกรณฑ์

คูณทั้งเศษและส่วนด้วยจำนวนที่ทำให้กรณฑ์ที่ส่วนหายไป (คูณด้วย 1 จึงไม่เปลี่ยนค่า)

- ส่วนเป็น $\sqrt b$: คูณด้วย $\tfrac{\sqrt b}{\sqrt b}$ เช่น $\dfrac{6}{\sqrt3} = \dfrac{6\sqrt3}{3} = 2\sqrt3$
- ส่วนเป็น $a - \sqrt b$: คูณด้วย **สังยุค** $a + \sqrt b$ เพราะ $(a - \sqrt b)(a + \sqrt b) = a^2 - b$ เช่น $\dfrac{4}{\sqrt5 - 1} = \dfrac{4(\sqrt5 + 1)}{5 - 1} = \sqrt5 + 1$

## เปรียบเทียบจำนวนในรูปกรณฑ์และเลขยกกำลัง

เขียนเป็นเลขชี้กำลังตรรกยะ $\sqrt[n]{a} = a^{1/n}$ แล้วทำให้รากมีอันดับเท่ากัน เช่น เทียบ $\sqrt[3]{3}$ กับ $\sqrt2$: ยกกำลัง 6 ทั้งคู่ ได้ $3^2 = 9$ กับ $2^3 = 8$ จึง $\sqrt[3]{3} > \sqrt2$ วิธีนี้ใช้ได้เพราะจำนวนบวกที่มากกว่าเมื่อยกกำลังบวกก็ยังมากกว่า

## ค่าสัมบูรณ์

**ค่าสัมบูรณ์** $|a|$ คือระยะจาก $a$ ถึง 0 บนเส้นจำนวน จึงไม่เป็นลบ

$$|a| = \begin{cases} a & a \ge 0 \\ -a & a < 0 \end{cases}$$

ระยะระหว่าง $a$ กับ $b$ คือ $|a - b|$ เช่น ระยะระหว่าง $-2$ กับ $5$ คือ $|5 - (-2)| = 7$ สมบัติที่ใช้บ่อย $|ab| = |a||b|$, $\left|\tfrac ab\right| = \tfrac{|a|}{|b|}$, $|a + b| \le |a| + |b|$ และที่สำคัญ

$$\sqrt{a^2} = |a| \quad \text{ไม่ใช่ } a$$

เช่น $\sqrt{(-5)^2} = \sqrt{25} = 5$

## ข้อผิดพลาดที่พบบ่อย

- **บวกใต้รากเลย** $\sqrt2 + \sqrt3 \ne \sqrt5$ และ $\sqrt{9 + 16} \ne 3 + 4$
- **ลืมถอดรากตัวที่ดึงออก** $\sqrt{75} = 5\sqrt3$ ไม่ใช่ $25\sqrt3$
- **ลืมพจน์กลาง** $(\sqrt3 + \sqrt2)^2 \ne 3 + 2$
- **ทำส่วนไม่ติดกรณฑ์แล้วลืมหาร** $\tfrac{6}{\sqrt3} = \tfrac{6\sqrt3}{3}$ ไม่ใช่ $6\sqrt3$
- **คิดว่า $\sqrt{a^2} = a$ เสมอ** เมื่อ $a < 0$ ต้องได้ $-a$
- **คิดว่า $|a + b| = |a| + |b|$ เสมอ** เช่น $|3 + (-5)| = 2$ แต่ $|3| + |-5| = 8$
