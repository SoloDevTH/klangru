# บันทึกชุดงาน english-13 (เฟส 8)

หัวข้อภาษาอังกฤษ 8 หัวข้อจาก `docs/phase6/proposals-languages.yaml` ไม่มีแถว `extend:` ที่ผูกกับหัวข้อในชุดนี้ ภาพทุกภาพวาดเป็น SVG ด้วยสคริปต์ (scratchpad `phase8-english-13/fig_t*.py` ใช้ `svg.py` ชุดเดียวกับ english-8) เรนเดอร์เป็น PNG ด้วย Chromium และเปิดตรวจทุกภาพแล้ว ไม่มีภาพจาก Commons ภาพในโจทย์ที่ถามสิ่งที่บทเรียนเฉลยไว้ใช้ภาพแยกที่ไม่มีป้ายเฉลย (`plant-quiz.svg`, `map-quiz.svg`, `festival-symbols-quiz.svg`, `signs-quiz.svg`) จำนวนคำของบทเรียนนับด้วย `Intl.Segmenter` อยู่ที่ 654–860 คำ ทุกตัวเลข (วันที่ Thanksgiving อายุจากวันเกิด จำนวนวันของยา ผลรวมและผลต่างในแผนภูมิ ระยะเวลาเดินทาง) คำนวณด้วย python3 แอปไม่มีเสียง ตัวชี้วัดด้านการฟัง การพูด น้ำเสียง และท่าทางจึงจับคู่แบบ partial พร้อมเหตุผลในไฟล์จับคู่ (ตัวชี้วัดที่เขียนว่า "พูด/เขียน" หรือ "ฟังหรืออ่าน" จับคู่เป็น full ได้ ส่วน "พูดและเขียน" หรือ "ฟังและอ่าน" เป็น partial) โจทย์ข้อความ (`text`) ใส่รูปย่อและรูปเต็ม (wasn't / was not, Don't / Do not) แบบมีและไม่มีเครื่องหมายวรรคตอนท้าย และคำตอบอื่นที่ใช้ได้ในภาษาพูด (เช่น No touching, wakes, till, Shall/Can/Should/May) ไว้ใน `accepted` ตัวลวงทุกตัวเป็นรูปที่ผิดจริง ไม่ใช่รูปที่ใช้ได้ในภาษาพูด

ข้อสังเกตเรื่องตัวตรวจ: ตัวตรวจคำตอบไม่สนตัวพิมพ์ใหญ่เล็ก (และตัวตรวจตัวเลือกซ้ำของ mcq ก็ไม่สนเช่นกัน) จึงทดสอบการใช้ตัวพิมพ์ใหญ่ด้วยโจทย์พิมพ์คำตอบหรือ mcq ที่ต่างกันแค่ตัวพิมพ์ไม่ได้ ใน describing-self จึงใช้ mcq แบบเลือกคำที่ต้องขึ้นต้นด้วยตัวใหญ่ (p003) แทน
