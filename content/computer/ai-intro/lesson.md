## AI อยู่รอบตัวมากกว่าที่คิด

กล้องที่ด่านเก็บเงินอ่านป้ายทะเบียนรถได้เอง แอปแปลภาษาแปลป้ายเมนูจากภาพถ่าย โรงคัดแยกผลไม้ใช้กล้องแยกมะม่วงตามความสุก หุ่นยนต์ดูดฝุ่นหลบขาโต๊ะ และแอปดูคลิปเลือกคลิปถัดไปให้ ทั้งหมดใช้ **ปัญญาประดิษฐ์ (artificial intelligence, AI)** คือระบบคอมพิวเตอร์ที่ทำงานซึ่งปกติต้องใช้ความสามารถแบบมนุษย์ เช่น รับรู้ภาพและเสียง ตัดสินใจ วางแผน หรือเรียนรู้จากตัวอย่าง บทนี้ใช้ความรู้จาก [การค้นหาและการเรียงลำดับ](/topic/computer.algorithms.searching-sorting/) [การประมวลผลข้อมูล](/topic/computer.data.data-processing/) และ [ผลกระทบของคอมพิวเตอร์](/topic/computer.society.computing-impacts/)

AI ไม่ได้ "คิด" หรือ "เข้าใจ" แบบมนุษย์ แต่ทำงานด้วยอัลกอริทึมและข้อมูล วิธีหลักมีสองแบบ คือ **ค้นหาทางเลือก** ตามกติกาที่มนุษย์เขียน และ **เรียนรู้รูปแบบจากข้อมูล**

## AI ในซอฟต์แวร์และระบบทางกายภาพ

ระบบทางกายภาพ เช่น หุ่นยนต์ดูดฝุ่น ระบบเบรกฉุกเฉินของรถ หรือโดรนพ่นยา ทำงานเป็นวงจร **รับรู้ → คิด → ลงมือ** (ดูภาพ) เซนเซอร์และกล้องรับข้อมูล ส่วน AI ตีความและเลือกการกระทำ แล้วมอเตอร์หรือล้อทำตาม ส่วนในซอฟต์แวร์ AI ใช้กรองอีเมลขยะ แนะนำสินค้า และแปลงเสียงพูดเป็นข้อความ

## ค้นหาทางเลือกในเกมด้วยมินิแมกซ์

ในเกมสองฝ่าย คอมพิวเตอร์มองไปข้างหน้าเป็น **ต้นไม้เกม** แต่ละกิ่งคือการเดินหนึ่งครั้ง ปลายกิ่งให้คะแนน (มาก = ดีต่อคอมพิวเตอร์) อัลกอริทึม **มินิแมกซ์ (minimax)** สมมติว่าคู่แข่งเล่นเก่งที่สุด ชั้นของคอมพิวเตอร์เลือกค่า **มากที่สุด (MAX)** ชั้นของคู่แข่งเลือกค่า **น้อยที่สุด (MIN)** แล้วส่งค่าขึ้นไปทีละชั้น (ดูภาพ) ทางขวามีใบที่ได้ 9 แต่คู่แข่งจะเลือกให้เหลือ 2 คอมพิวเตอร์จึงเลือกทางซ้ายที่รับประกันได้ 3

ตัวอย่างเกมหยิบไม้: มีไม้กองหนึ่ง ผลัดกันหยิบ 1 หรือ 2 อัน ใครหยิบอันสุดท้ายชนะ

```python
def minimax(sticks, computer_turn):
    if sticks == 0:                     # ฝ่ายที่เพิ่งหยิบอันสุดท้ายชนะ
        return -1 if computer_turn else 1
    scores = []
    for take in (1, 2):
        if take <= sticks:
            scores.append(minimax(sticks - take, not computer_turn))
    if computer_turn:
        return max(scores)              # คอมพิวเตอร์เลือกทางที่ดีที่สุดของตัวเอง
    return min(scores)                  # คู่แข่งเลือกทางที่แย่ที่สุดสำหรับคอมพิวเตอร์

def best_move(sticks):
    best_score, best_take = -2, None
    for take in (1, 2):
        if take <= sticks:
            score = minimax(sticks - take, False)
            if score > best_score:
                best_score, best_take = score, take
    return best_take

print(best_move(4))   # 1
```

เหลือไม้ 4 อัน คอมพิวเตอร์หยิบ 1 ให้เหลือ 3 ซึ่งคู่แข่งหยิบอย่างไรก็แพ้ เกมจริงอย่างหมากรุกมีทางเลือกมากเกินกว่าจะค้นทั้งต้นไม้ จึงค้นแค่บางชั้นแล้วประมาณคะแนน

## การเรียนรู้ของเครื่อง

งานหลายอย่างเขียนกติกาให้ครบไม่ได้ เช่น แยกภาพแมว **การเรียนรู้ของเครื่อง (machine learning)** จึงให้คอมพิวเตอร์หา **รูปแบบจากตัวอย่าง** แต่ละตัวอย่างมี **คุณลักษณะ (feature)** ที่วัดได้ และ **ป้ายกำกับ (label)** คือคำตอบที่ถูก

ข้อมูลที่มีแบ่งเป็นสองส่วน **ข้อมูลฝึก (training data)** ใช้สร้างแบบจำลอง ส่วน **ข้อมูลทดสอบ (test data)** เก็บแยกไว้ ไม่ให้แบบจำลองเห็นระหว่างฝึก ใช้วัดว่าทำนายข้อมูลใหม่ได้ดีแค่ไหน ถ้าวัดด้วยข้อมูลฝึก แบบจำลองที่ "จำข้อสอบ" ได้จะดูเก่งเกินจริง เรียกว่า **การเรียนรู้เกิน (overfitting)**

$$\text{ความแม่นยำ} = \frac{\text{จำนวนที่ทำนายถูก}}{\text{จำนวนข้อมูลทดสอบทั้งหมด}} \times 100\%$$

## จำแนกมะม่วงด้วยเพื่อนบ้านใกล้ที่สุด

งาน **จำแนกประเภท (classification)** คือการทำนายว่าข้อมูลเป็นกลุ่มใด วิธีที่เข้าใจง่ายคือ **k เพื่อนบ้านใกล้ที่สุด (k-nearest neighbours)** วัดระยะจากข้อมูลใหม่ไปทุกตัวอย่างในข้อมูลฝึก แล้วให้ $k$ ตัวที่ใกล้ที่สุดโหวต

มะม่วง 8 ผลมีคุณลักษณะสองอย่าง คือ ความเหลืองของผิวและความนิ่ม (0–10) พร้อมป้ายกำกับ สุก หรือ ดิบ ผลใหม่อยู่ที่ (6, 6) ระยะไปผล (6, 8) คือ

$$\sqrt{(6-6)^2 + (6-8)^2} = 2$$

สามผลที่ใกล้ที่สุดคือ (6, 8) ระยะ 2, (8, 7) ระยะ 2.24 และ (9, 6) ระยะ 3 สุกทั้งหมด จึงทำนายว่า **สุก** (ดูภาพ)

```python
import math
train = [
    ((8, 7), "สุก"), ((7, 9), "สุก"), ((9, 6), "สุก"), ((6, 8), "สุก"),
    ((2, 2), "ดิบ"), ((3, 4), "ดิบ"), ((1, 3), "ดิบ"), ((4, 1), "ดิบ"),
]

def classify(new, k):
    dist = []
    for (x, y), label in train:
        d = math.dist(new, (x, y))      # ระยะทางแบบยุคลิด
        dist.append((d, label))
    dist.sort()                          # ใกล้สุดอยู่หน้า
    votes = [label for d, label in dist[:k]]
    return max(set(votes), key=votes.count)

print(classify((6, 6), 3))   # สุก
```

## ความลำเอียงและความเป็นธรรม

แบบจำลองเรียนรู้จากข้อมูล ถ้าข้อมูลลำเอียง ผลก็ลำเอียง เช่น ระบบจดจำเสียงที่ฝึกด้วยเสียงคนกรุงเทพฯ เป็นส่วนใหญ่อาจฟังสำเนียงอีสานหรือใต้ผิดบ่อย ระบบคัดใบสมัครงานที่ฝึกจากการตัดสินใจในอดีตอาจรับความลำเอียงแบบเดิมมาด้วย ความแม่นยำรวมสูงอาจซ่อนความแม่นยำที่ต่ำมากของคนบางกลุ่ม วิธีลดปัญหา คือ เก็บข้อมูลให้ครอบคลุมทุกกลุ่ม วัดความแม่นยำ **แยกตามกลุ่ม** ให้คนตรวจการตัดสินใจที่สำคัญ และเปิดให้ผู้ได้รับผลกระทบโต้แย้งได้

## AI แบบรู้สร้าง: ประโยชน์และข้อจำกัด

**ปัญญาประดิษฐ์แบบรู้สร้าง หรือ AI แบบรู้สร้าง (generative AI)** สร้างข้อความ ภาพ หรือเสียงใหม่ โดยเรียนรู้รูปแบบจากข้อมูลจำนวนมหาศาล แล้วสร้างผลที่ "น่าจะเป็น" ทีละส่วน มันไม่ได้ค้นข้อเท็จจริงจากฐานข้อมูลทุกครั้ง จึงอาจ **สร้างข้อมูลผิดที่ฟังดูน่าเชื่อ (hallucination)** เช่น ตัวเลขผิด หรือแหล่งอ้างอิงที่ไม่มีอยู่จริง

- **ตรวจสอบ** ข้อเท็จจริงและแหล่งอ้างอิงจากแหล่งต้นทางทุกครั้ง
- **ไม่ใส่ข้อมูลส่วนตัว** ของตนเองหรือผู้อื่น รหัสผ่าน หรือข้อมูลลับ เพราะข้อความที่พิมพ์อาจถูกเก็บไว้
- **บอกว่าใช้ AI ช่วย** ตามกติกาของโรงเรียน และอ้างแหล่งข้อมูลจริงที่ตรวจแล้ว ไม่ใช่อ้าง AI แทนแหล่งต้นทาง
- **รับผิดชอบงานเอง** ผลจาก AI เป็นร่างที่ต้องตรวจ ไม่ใช่คำตอบสุดท้าย

## ข้อผิดพลาดที่พบบ่อย

- **วัดความแม่นยำด้วยข้อมูลฝึก** ได้ตัวเลขสูงเกินจริง
- **เชื่อความแม่นยำรวมอย่างเดียว** ข้อมูลที่กลุ่มหนึ่งมีน้อยมาก แบบจำลองที่ทายกลุ่มใหญ่เสมอก็ได้ความแม่นยำสูง
- **ใช้เพื่อนบ้านใกล้สุดตัวเดียว** ตัวอย่างที่ผิดปกติตัวเดียวอาจทำให้ทายผิด
- **คิดว่า AI เป็นกลางเสมอ** AI สะท้อนข้อมูลและการตัดสินใจของคนที่สร้าง
- **คัดลอกคำตอบของ AI แบบรู้สร้างโดยไม่ตรวจ**
