## math.de.second-order-linear

- 18 ข้อ ภาพ 3 ภาพ (`damping-cases.svg` สี่กรณีของ x″ + cx′ + 4x = 0, `resonance-growth.svg` ω = 1.6 เทียบ ω = 2, `p-quarter-car.svg` ใช้ใน p012) บริบทไทย 4 ข้อ: รถกระบะที่อู่ในขอนแก่น (ความหน่วงวิกฤต) รถข้ามลูกระนาดในหมู่บ้าน ฐานเครื่องสูบน้ำในนาสุพรรณบุรี ตาชั่งสปริงในตลาดเชียงราย
- บทเรียนลิงก์ไป `physics.waves.shm` (กรณีไม่หน่วง) `physics.waves.resonance-standing-waves` และ `math.number.complex-numbers` (สูตรออยเลอร์) ไม่สอนซ้ำ SHM
- Mechanical 1.a partial (ครอบคลุมเฉพาะส่วนสมการเชิงอนุพันธ์อันดับสอง)
- ค่าสมมติ: มวล 300–400 kg ของรถหนึ่งในสี่คัน k = 30,000–40,000 N/m c = 3,000 N·s/m ประโยค "ระบบกันสะเทือนรถยนต์มักออกแบบให้ ζ ราว 0.2–0.5" เป็นช่วงที่ตำราวิศวกรรมใช้ทั่วไป ผู้ตรวจอาจยืนยัน
- ข้อเสนอแผน: MIT18.03 L13–L14 (ผลตอบสนองแบบเอกซ์โพเนนเชียล อัตราขยายเชิงซ้อน) ใกล้กับเนื้อหาแอมพลิจูดสถานะคงตัวที่สอนไว้ ถ้าต้องการอาจผูกเป็น partial ในแผน ส่วนวรอนสเกียนสอนเพียงแนวคิด "ผลเฉลยสองตัวที่ไม่เป็นพหุคูณกัน" ไม่ได้คำนวณ และไม่มีวิธีแปรผันพารามิเตอร์ (ไม่อยู่ในตัวชี้วัด)

## math.calculus.vector-calculus

- 18 ข้อ ภาพ 3 ภาพ (`div-curl-fields.svg` ⟨x, y⟩ กับ ⟨−y, x⟩, `p-two-paths.svg` ใช้ใน p011, `p-canal-section.svg` ใช้ใน p014) บริบทไทย 3 ข้อ: โดรนพ่นยาในนาข้าว ฟลักซ์ผ่านหน้าตัดคลองชลประทานสุพรรณบุรี ใบไม้หมุนในคลอง (เคิร์ลของการไหลแบบเฉือน)
- ไม่มีสื่อโต้ตอบ เพราะ function-plot วาดได้เฉพาะ y = f(x) และ vector-add แสดงได้เพียงเวกเตอร์สองตัว ไม่ช่วยแสดงสนามเวกเตอร์ ข้อเสนอ: วิดเจ็ตสนามเวกเตอร์สองมิติที่ลากเส้นทางแล้วแสดงงานสะสมได้
- **ข้อเสนอแผน:** ขอบเขตในแผนรวม "สนามอนุรักษ์" และ "ทฤษฎีบทสโตกส์" แต่แผนผูกเพียง CALC3 6.1, 6.2, 6.4, 6.5, 6.8 บทเรียนและโจทย์สอน CALC3 6.3 (Conservative Vector Fields) ครบ (p004, p006, p007 และตัวอย่างแสดงวิธีทำ) ส่วน CALC3 6.6 (Surface Integrals) และ 6.7 (Stokes' Theorem) สอนในระดับนิยามฟลักซ์ สูตร และการใช้กับผิวที่ง่าย (p013, p014) จึงควรเป็น partial ผู้ประสานงานอาจเพิ่มสามแถวนี้ในแผน/ไฟล์จับคู่ (ไม่ได้ใส่เองเพราะอยู่นอกแผน) การอิงตัวแปรเสริมของผิวทั่วไปและผิวมีทิศ (CALC3 6.6 เต็มรูป) ยังไม่มีหัวข้อผูก
- prerequisite ตามแผน (`math.calculus.multiple-integrals` ความยาก 9) เพียงพอ เพราะเกรเดียนต์และผลคูณไขว้ที่บทเรียนใช้มาจาก `math.calculus.partial-derivatives` และ `math.calculus.vectors-3d` ซึ่งเป็น prerequisite ทางอ้อมผ่าน multiple-integrals อยู่แล้ว (บทเรียนลิงก์ไว้)
