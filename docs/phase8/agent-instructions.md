# คำสั่งสำหรับ agent ที่เขียนชุดงานเฟส 8

1. อ่าน `docs/phase8/new-topics-brief.md` และทำตามทุกข้อ (มีลิงก์ไปยังคู่มืออื่นและตัวอย่าง) ดูชุดที่ทำเสร็จแล้วเป็นตัวอย่างได้จาก `docs/phase8/notes-*.md`
2. เขียนหัวข้อตามลำดับในงานมอบหมาย (prerequisite ของแต่ละหัวข้อมีในคลังแล้วหรืออยู่ก่อนหน้าในรายการ)
3. ต่อหัวข้อ: `grep -n "<รหัสหัวข้อ>" docs/phase6/proposals-*.yaml` เพื่อดูแถวในแผนและแถว extend ทั้งหมด อ่านข้อความตัวชี้วัดใน `curriculum/frameworks/` แล้วสอนให้ตรงตามนั้น อย่าซ้ำกับหัวข้อที่มีอยู่แล้วในคลัง ให้อ้างเป็น prerequisite แทน
4. บันทึก `docs/phase8/notes-<ชุด>.md` และไฟล์จับคู่ `docs/phase8/mappings/<รหัสหัวข้อ>.yaml`
5. กติกา:
   - สร้างหรือแก้ได้เฉพาะโฟลเดอร์หัวข้อของชุดตัวเอง ไฟล์บันทึก และไฟล์จับคู่ของตัวเอง
   - ห้าม commit หรือ push (ผู้ประสานงานอาจ commit ไฟล์ของคุณระหว่างทำ ซึ่งไม่เป็นไร)
   - ห้ามใส่อีเมลหรือข้อมูลส่วนตัวในคำขอเว็บ header URL หรือไฟล์ใด ๆ ใช้ User-Agent `KlangruBot/0.1 (+https://github.com/SoloDevTH/klangru)`
   - คำนวณทุกตัวเลขด้วย python3
   - เรนเดอร์ภาพทุกภาพเป็น PNG แล้วเปิดดู
6. ตรวจเมื่อเสร็จ: `npm run validate -- --strict` (ต้องไม่มี error/warning จากโฟลเดอร์ของตัวเอง) และ `npm test -w @klangru/content-tools`
7. ตอบกลับสั้น ๆ:
   - ต่อหัวข้อ: จำนวนโจทย์และภาพ
   - เรื่องที่ไม่แน่ใจ
   - ข้อเสนอให้แก้แผนหรือ prerequisite
   - error จากโฟลเดอร์ของชุดอื่น (ไม่ต้องแก้)
