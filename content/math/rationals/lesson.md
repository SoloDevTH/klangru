## จำนวนที่อยู่ระหว่างจำนวนเต็ม

ยอดดอยอินทนนท์บางเช้าในฤดูหนาวมีอุณหภูมิ $-1.5\ ^\circ\mathrm{C}$ แม่ค้าขายส้มครึ่งกิโลกรัม บัญชีออมทรัพย์ติดลบ $250.75$ บาท จำนวนเหล่านี้ไม่ใช่จำนวนเต็ม แต่ก็เป็นจำนวนที่เราใช้ทุกวัน

**จำนวนตรรกยะ** คือจำนวนที่เขียนได้ในรูป $\dfrac{a}{b}$ เมื่อ $a$ และ $b$ เป็นจำนวนเต็ม และ $b \ne 0$

- จำนวนเต็มทุกจำนวนเป็นจำนวนตรรกยะ เช่น $-4 = \tfrac{-4}{1}$
- เศษส่วนบวกและลบ เช่น $\tfrac23$, $-\tfrac34$ (เขียนเป็น $\tfrac{-3}{4}$ หรือ $\tfrac{3}{-4}$ ก็ได้ ค่าเท่ากัน)
- ทศนิยมรู้จบ เช่น $-1.5 = -\tfrac32$ และทศนิยมซ้ำ เช่น $0.333\ldots = \tfrac13$

เศษส่วนเป็นการหารด้วย: $\tfrac{a}{b} = a \div b$ ถ้าแบ่งข้าวสาร 3 กิโลกรัมให้ 4 คนเท่า ๆ กัน แต่ละคนได้ $3 \div 4 = \tfrac34$ กิโลกรัม และ $\tfrac34 \times 4 = 3$ กลับมาเท่าเดิม

## ทศนิยมกับเศษส่วน

หลักทางขวาของจุดทศนิยมคือ ส่วนสิบ ส่วนร้อย และส่วนพัน แต่ละหลักเป็น $\tfrac{1}{10}$ ของหลักทางซ้าย ส่วนสิบเกิดจากการแบ่งของหนึ่งชิ้นเป็น 10 ส่วนเท่ากัน ส่วนร้อยเกิดจากการแบ่งส่วนสิบอีก 10 ส่วน

- $0.71 = \tfrac{71}{100}$ และ $0.125 = \tfrac{125}{1000} = \tfrac18$
- $\tfrac{3}{10} + \tfrac{4}{100} = \tfrac{30}{100} + \tfrac{4}{100} = \tfrac{34}{100} = 0.34$

ค่าที่ควรจำ (เศษส่วน = ทศนิยม = ร้อยละ): $\tfrac12 = 0.5 = 50\%$, $\tfrac14 = 0.25 = 25\%$, $\tfrac34 = 0.75 = 75\%$, $\tfrac15 = 0.2 = 20\%$, $\tfrac25 = 0.4 = 40\%$, $\tfrac45 = 0.8 = 80\%$ ส่วนเศษส่วนที่ตัวส่วนเป็น 25 หรือ 50 ให้ขยายเป็นส่วนร้อย เช่น $\tfrac{3}{25} = \tfrac{12}{100} = 12\%$

## เปรียบเทียบบนเส้นจำนวน

จำนวนที่อยู่ทางขวามีค่ามากกว่าเสมอ จำนวนลบจึงยิ่ง "ไกลจากศูนย์" ยิ่งน้อย เช่น $-0.8 < -\tfrac34 < -\tfrac12$ เพราะ $-0.8$ อยู่ซ้ายสุด

## บวก ลบ คูณ หาร

ใช้กฎเครื่องหมายเดียวกับจำนวนเต็ม และวิธีคำนวณเดียวกับเศษส่วน

- **บวกลบ** ทำตัวส่วนให้เท่ากัน: $-\tfrac23 + \tfrac56 = -\tfrac46 + \tfrac56 = \tfrac16$
- **คูณ** คูณตัวเศษกับตัวเศษ ตัวส่วนกับตัวส่วน เครื่องหมายเหมือนกันได้บวก ต่างกันได้ลบ: $(-1.5) \times \tfrac23 = -\tfrac32 \times \tfrac23 = -1$
- **หาร** คูณด้วยส่วนกลับของตัวหาร: $\left(-\tfrac34\right) \div \left(-\tfrac12\right) = -\tfrac34 \times \left(-\tfrac21\right) = \tfrac32$

การหารกับการคูณเป็น **การดำเนินการผกผัน** กัน ใช้ตรวจคำตอบได้ เช่น $\tfrac32 \times \left(-\tfrac12\right) = -\tfrac34$ ตรงกับตัวตั้ง

## สมบัติของจำนวนตรรกยะ

- **ปิด** ผลบวก ผลลบ ผลคูณ ของจำนวนตรรกยะเป็นจำนวนตรรกยะเสมอ ผลหารก็เช่นกัน ถ้าตัวหารไม่ใช่ 0
- **สลับที่และเปลี่ยนหมู่** ใช้ได้กับการบวกและการคูณ แต่ใช้กับการลบและการหารไม่ได้
- **แจกแจง** $a(b + c) = ab + ac$ เช่น $\tfrac23 \times 99 = \tfrac23 \times (100 - 1)$
- **เอกลักษณ์** $a + 0 = a$ และ $a \times 1 = a$
- **อินเวอร์ส** ทุกจำนวนมีอินเวอร์สการบวก ($a + (-a) = 0$) ทุกจำนวนที่ไม่ใช่ 0 มีอินเวอร์สการคูณ ($a \times \tfrac1a = 1$)

## ทศนิยมซ้ำเป็นเศษส่วน

จำนวนตรรกยะทุกจำนวนเขียนเป็นทศนิยมรู้จบหรือทศนิยมซ้ำ และทศนิยมซ้ำทุกจำนวนเขียนกลับเป็นเศษส่วนได้ ให้ $x$ เป็นทศนิยมนั้น คูณด้วย 10, 100, … ให้ส่วนที่ซ้ำตรงกัน แล้วลบ

$$x = 0.\dot{3}\dot{6} = 0.3636\ldots \Rightarrow 100x = 36.3636\ldots \Rightarrow 99x = 36 \Rightarrow x = \tfrac{36}{99} = \tfrac{4}{11}$$

ถ้ามีหลักที่ไม่ซ้ำนำหน้า เช่น $x = 0.1\dot{6} = 0.1666\ldots$ ใช้ $100x - 10x = 16.666\ldots - 1.666\ldots = 15$ ได้ $x = \tfrac{15}{90} = \tfrac16$

ทศนิยมที่ไม่รู้จบและไม่ซ้ำ เช่น $\sqrt2 = 1.41421\ldots$ และ $\pi$ เขียนเป็นเศษส่วนไม่ได้ เรียกว่า **จำนวนอตรรกยะ** จำนวนตรรกยะกับจำนวนอตรรกยะรวมกันเป็น **จำนวนจริง**

## ประมาณก่อนคำนวณ

โจทย์หลายขั้นควรประมาณคำตอบก่อน เช่น ซื้อผ้า $2\tfrac34$ เมตร เมตรละ 120 บาท ประมาณ $3 \times 120 = 360$ บาท คำตอบจริง $330$ บาท ใกล้เคียงกัน ถ้าคำนวณได้ 3,300 บาทก็รู้ทันทีว่าผิด

## ข้อผิดพลาดที่พบบ่อย

- **บวกตัวเศษกับตัวเศษ ตัวส่วนกับตัวส่วน** $\tfrac{-2}{3} + \tfrac56 \ne \tfrac{3}{9}$
- **ลืมเครื่องหมายลบ** หรือคิดว่า $-\tfrac12 < -\tfrac34$ เพราะ $\tfrac12 < \tfrac34$
- **หารโดยไม่กลับตัวหาร** หรือกลับตัวตั้งแทน
- **คิดว่า $0.\dot{3}\dot{6} = \tfrac{36}{100}$** ทศนิยมซ้ำต้องใช้ตัวส่วน 99 ไม่ใช่ 100
- **คิดว่าหารด้วย 0 ได้** จำนวนใดหารด้วย 0 ไม่มีความหมาย
