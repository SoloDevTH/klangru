## ป้ายที่ไม่บอกว่าใครทำ

ในพิพิธภัณฑ์มีป้าย *Photography **is not allowed**.* บนขวดยามีข้อความ *This medicine **should be taken** after meals.* และในหนังสือประวัติศาสตร์เขียนว่า *The Grand Palace **was built** in 1782.* ทั้งสามประโยคไม่ได้บอกว่า **ใคร** ห้าม ใครกิน หรือใครสร้าง แต่เน้นที่ **สิ่งที่ถูกกระทำ** โครงสร้างนี้เรียกว่า **passive voice** (กรรมวาจก)

## active กับ passive

- **active**: ผู้กระทำเป็นประธาน *Workers **clean** the classroom every day.*
- **passive**: สิ่งที่ถูกกระทำเป็นประธาน *The classroom **is cleaned** every day.*

วิธีเปลี่ยน (ดูภาพด้านบน)

1. ย้ายกรรมของ active (the classroom) มาเป็นประธาน
2. ใช้ **be + past participle (V3)** โดย be เปลี่ยนตามเวลาและประธาน
3. ผู้กระทำจะใส่หลัง **by** หรือตัดทิ้งก็ได้ ถ้าไม่สำคัญหรือไม่รู้ว่าใคร

## โครงสร้าง

| เวลา | โครงสร้าง | ตัวอย่าง |
|---|---|---|
| ปัจจุบัน | **am / is / are + V3** | *Rice **is grown** in the north-east of Thailand.* |
| อดีต | **was / were + V3** | *The Grand Palace **was built** in 1782.* |
| ปฏิเสธ | **is not / was not + V3** | *Food **is not allowed** in the library.* |
| คำถาม | **Is / Was + ประธาน + V3?** | ***Was** this temple **built** in the Ayutthaya period?* |
| กับ modal | **must / should / can + be + V3** | *Shoes **must be removed**.* |

ประธานเอกพจน์และนามนับไม่ได้ใช้ *is / was* ประธานพหูพจน์ใช้ *are / were*: *Tickets **are checked** at the gate.*
รูปย่อ: *isn't, aren't, wasn't, weren't* เช่น *Food **isn't allowed** here.*

### V3 ที่พบบ่อยในป้ายและฉลาก

| V1 | V3 | | V1 | V3 |
|---|---|---|---|---|
| allow | allowed | | keep | kept |
| take | taken | | make | made |
| build | built | | speak | spoken |
| grow | grown | | steal | stolen |
| write | written | | sell | sold |

## ใช้ passive เมื่อไร

1. **ไม่รู้ว่าใครทำ**: *My bike **was stolen** yesterday.*
2. **ผู้กระทำไม่สำคัญหรือรู้กันอยู่แล้ว**: *English **is spoken** in many countries.*
3. **ป้าย คำแนะนำ และฉลาก** ซึ่งต้องการให้สั้นและเป็นทางการ: *Children under 12 **are admitted** free.* · *Keep in a cool, dry place.* (ฉลากบางบรรทัดใช้ประโยคคำสั่งแทน)
4. **อยากเน้นสิ่งที่ถูกกระทำ** ถ้าต้องการบอกผู้กระทำด้วย ใช้ by: *The Mona Lisa **was painted by** Leonardo da Vinci.*

## อ่านคำแนะนำแล้วทำตาม

ป้ายและฉลากเขียนแบบ passive บ่อยมาก อ่านให้ออกว่าต้องทำอะไร

- *Bags **must be left** at the counter.* → ต้องฝากกระเป๋าที่เคาน์เตอร์
- *This medicine **should be taken** three times a day.* → ควรกินยาวันละ 3 ครั้ง
- *Shoes **must be removed** before entering.* → ถอดรองเท้าก่อนเข้า

ถ้าไม่แน่ใจเรื่องยา ให้ถามเภสัชกรหรือแพทย์เสมอ

### ตัวอย่างที่ 1: เปลี่ยน active เป็น passive

*Somebody stole my bike yesterday.*

1. กรรมคือ *my bike* → เป็นประธานใหม่
2. เป็นอดีต และ my bike เป็นเอกพจน์ → *was*
3. steal → V3 *stolen*
4. ผู้กระทำคือ somebody (ไม่รู้ว่าใคร) → ตัดทิ้ง
5. ***My bike was stolen yesterday.***

### ตัวอย่างที่ 2: passive กับ modal

*You must keep this medicine in the fridge.*

1. กรรมคือ *this medicine* → ประธาน
2. คง modal ไว้ แล้วเติม *be + V3*: *must be kept*
3. ***This medicine must be kept in the fridge.***

## ข้อผิดพลาดที่พบบ่อย

- **ลืม be** ~~The classroom cleaned every day.~~ → *The classroom **is** cleaned every day.* (ภาษาไทยพูด "ห้องถูกทำความสะอาด" โดยไม่มีคำแบบ is)
- **ใช้ V2 แทน V3** ~~My bike was stole.~~ → *was **stolen*** · ~~is spoke~~ → *is **spoken***
- **ใช้ passive กับกริยาที่ไม่มีกรรม** เช่น happen, arrive, die ~~The accident was happened.~~ → *The accident **happened** last night.*
- **ใช้ be ผิดกับประธาน** ~~Tickets is checked.~~ → *Tickets **are** checked.*
- **ใช้ from แทน by** ~~painted from Leonardo~~ → *painted **by** Leonardo*
- **หลัง modal ลืม be** ~~must kept~~ → *must **be** kept*
