## ก๋วยเตี๋ยว ถนน ศึกษา และคอมพิวเตอร์

ประโยค "นักเรียนนั่งกินก๋วยเตี๋ยวริมถนนหลังเลิกศึกษาคอมพิวเตอร์" มีคำที่มาจากภาษาอื่นอย่างน้อยสี่ภาษา **ก๋วยเตี๋ยว** มาจากภาษาจีน **ถนน** มาจากภาษาเขมร **ศึกษา** มาจากภาษาสันสกฤต และ **คอมพิวเตอร์** มาจากภาษาอังกฤษ คนไทยติดต่อกับชนชาติอื่นทั้งทางศาสนา การค้า และการศึกษามาหลายร้อยปี จึงยืมคำมาใช้มาก บทนี้ต่อจากบท [คำควบกล้ำ อักษรนำ ตัวการันต์ และคำที่มักเขียนผิด](/topic/thai.writing.special-spellings/) ซึ่งฝึกสะกดคำเหล่านี้ไว้แล้ว ส่วนบทนี้ฝึก **สังเกตว่าคำมาจากภาษาใด** และ **ใช้คำยืมให้ถูก**

วิธีตรวจที่แน่นอนที่สุดคือเปิดพจนานุกรมฉบับราชบัณฑิตยสถาน ท้ายคำอธิบายมีวงเล็บบอกที่มา เช่น (ป.) บาลี (ส.) สันสกฤต (ข.) เขมร (จ.) จีน (อ.) อังกฤษ ลักษณะที่จะเรียนต่อไปนี้ใช้ **คาดเดา** ได้ แต่มีข้อยกเว้นเสมอ

## คำบาลีและสันสกฤต

สองภาษานี้เข้ามาพร้อมพระพุทธศาสนาและศาสนาพราหมณ์ คำจำนวนมากมีคู่ที่ความหมายเดียวกันแต่รูปต่างกัน

| บาลี | สันสกฤต | สังเกต |
|---|---|---|
| วิชา | วิทยา | สันสกฤตมี ย ควบ |
| กิริยา | กริยา | สันสกฤตมี ร ควบ |
| ปฐม | ประถม | สันสกฤตมี ร ควบ |
| สิกขา | ศึกษา | สันสกฤตใช้ ศ ษ |
| อิตถี | สตรี | สันสกฤตมี ร ควบ |
| ธัมมะ | ธรรม | สันสกฤตใช้ รร |
| วุฒิ | พฤฒิ | สันสกฤตใช้ ฤ |

**ลักษณะคำบาลี** ตัวสะกดและตัวตามมักเป็นพยัญชนะวรรคเดียวกันตามหลักบาลี เช่น อัคคี มัจฉา วุฒิ ภิกขุ ใช้ ฬ (กีฬา จุฬา) และไม่มี ศ ษ ฤ

**ลักษณะคำสันสกฤต** มี ศ ษ (ศึกษา ภิกษุ) ฤ (พฤฒิ ฤดู) รร (ธรรม) และคำควบกล้ำ (ประถม จักร) มาก

## คำเขมร

ภาษาเขมรให้คำแก่ภาษาไทยมาก โดยเฉพาะ **คำราชาศัพท์** และคำในวรรณคดี ลักษณะที่พบบ่อย

- **อักษรนำและคำควบกล้ำ** ถนน ขจี เขนย ไผท โปรด เขลา
- **ขึ้นต้นด้วย บัง บำ บรร ดำ กำ** บังคม บำเพ็ญ บรรทม ดำเนิน กำจัด
- **สะกดด้วย จ ญ ร ล ส** เผด็จ ผจญ สำราญ กังวล
- **ใช้เป็นราชาศัพท์** เสวย (กิน) บรรทม (นอน) ทูล (บอก) บังคม (ไหว้)
- **คำแผลง** คำหนึ่งแตกเป็นอีกคำด้วยการเติมเสียง เช่น ขจัด → กำจัด เดิน → ดำเนิน (พจนานุกรมให้ทั้งสองคำมาจากภาษาเขมร)

## คำจีน

คำจีนส่วนมากเข้ามาทางการค้าและอาหาร มักมาจากภาษาจีนถิ่นที่คนจีนในไทยพูด เช่น แต้จิ๋ว ลักษณะที่สังเกตได้คือ **อักษรกลางผันด้วยไม้ตรีหรือจัตวา** และเป็นคำเกี่ยวกับอาหาร ร้านค้า และธุรกิจ

- อาหาร: ก๋วยเตี๋ยว เกี๊ยว เต้าหู้ บะหมี่ ซาลาเปา เกาเหลา กุยช่าย
- การค้าและชีวิตประจำวัน: ห้าง ยี่ห้อ ตั๋ว เก้าอี้ เซ้ง เจ๊ง เฮง ซินแส

## คำอังกฤษ: ทับศัพท์ และ ศัพท์บัญญัติ

**คำทับศัพท์** คือเขียนคำต่างประเทศด้วยอักษรไทยตามเสียง เช่น คอมพิวเตอร์ ฟุตบอล วัคซีน **ศัพท์บัญญัติ** คือคำไทยที่ราชบัณฑิตยสถาน (ปัจจุบันคือสำนักงานราชบัณฑิตยสภา) คิดขึ้นแทน มักสร้างจากคำบาลีสันสกฤต

| อังกฤษ | ศัพท์บัญญัติ |
|---|---|
| telephone | โทรศัพท์ |
| information | สารสนเทศ |
| globalization | โลกาภิวัตน์ |
| password | รหัสผ่าน |
| file | แฟ้มข้อมูล |
| software | ส่วนชุดคำสั่ง หรือ ซอฟต์แวร์ |
| fake news | ข่าวลวง ข่าวปลอม |

บางคำใช้ได้ทั้งสองแบบ เช่น software งานเขียนชิ้นหนึ่งควรใช้แบบเดียวตลอด

### หลักเกณฑ์การทับศัพท์ภาษาอังกฤษ (โดยย่อ)

ราชบัณฑิตยสถานวางหลักเกณฑ์ไว้ (ประกาศใช้ พ.ศ. 2532) ข้อที่ใช้บ่อย

- **เขียนตามเสียง** ไม่ใช่ตามตัวอักษร เทียบพยัญชนะตามตาราง เช่น t ต้นพยางค์ใช้ ท ท้ายพยางค์ใช้ ต (อินเทอร์เน็ต) p ต้นใช้ พ ท้ายใช้ ป (แคปซูล) k ต้นใช้ ค ท้ายใช้ ก (คลินิก)
- **ไม่ใส่วรรณยุกต์** เว้นแต่เสียงซ้ำกับคำไทยจนสับสน เช่น coma เขียน โคม่า เพราะ โคมา อ่านเป็น วัวมา
- **ไม้ไต่คู้** ใช้เพื่อให้ต่างจากคำไทย เช่น log เขียน ล็อก ไม่ให้ซ้ำกับ ลอก
- **ตัวที่ไม่ออกเสียงใส่ทัณฑฆาต (การันต์)** เช่น horn ฮอร์น คอมพิวเตอร์ กอล์ฟ
- **พยัญชนะซ้อนท้ายคำ** ศัพท์ทั่วไปตัดเหลือตัวเดียว (football ฟุตบอล) ศัพท์วิชาการเก็บไว้และใส่การันต์ (cell เซลล์)

คำที่ใช้กันมานานบางคำสะกดต่างจากหลักเกณฑ์ เช่น แท็กซี่ เค้ก และคอมพิวเตอร์ (ใช้ ต ไม่ใช่ ท) จึงใช้ตามพจนานุกรม คำที่มักเขียนผิด: อินเทอร์เน็ต (ไม่ใช่ อินเตอร์เน็ต) ดิจิทัล (ไม่ใช่ ดิจิตอล) ไอศกรีม (ไม่ใช่ ไอศครีม) คลินิก (ไม่ใช่ คลีนิค) เกม (ไม่ใช่ เกมส์)

## ศัพท์วิชาการและวิชาชีพ

แต่ละวิชาและอาชีพมีศัพท์เฉพาะ ควรรู้ความหมายให้ตรงสาขา เช่น เศรษฐศาสตร์: **อุปสงค์** (ความต้องการซื้อ) **อุปทาน** (ปริมาณที่ผู้ขายนำออกขาย) · การแพทย์: **ผู้ป่วยนอก** (มาตรวจแล้วกลับบ้าน ไม่นอนโรงพยาบาล) · ธุรกิจ: **นวัตกรรม** (สิ่งหรือวิธีที่ทำขึ้นใหม่) **วิสัยทัศน์** (การมองการณ์ไกล)

## อิทธิพลของภาษาต่างประเทศและภาษาถิ่น

- **คำศัพท์** เช่น คำบาลีสันสกฤตในศัพท์ทางการ คำอังกฤษในเทคโนโลยี
- **เสียง** ภาษาไทยรับเสียงควบกล้ำที่ไม่มีในคำไทยแท้ เช่น ดร ฟร บร ในคำทับศัพท์
- **โครงสร้างประโยค** สำนวนแปลจากอังกฤษ เช่น "มันเป็นการยากที่จะ..." (ควรใช้ "...ทำได้ยาก") "เขาถูกเชิญไปงาน" (คำว่า ถูก ในภาษาไทยมักใช้กับเรื่องไม่ดี ควรใช้ "เขาได้รับเชิญ")
- **ภาษาถิ่น** คำถิ่นเข้ามาในภาษากลางพร้อมอาหารและวัฒนธรรม เช่น แซ่บ (ถิ่นอีสาน อร่อย) ข้าวซอย (ถิ่นพายัพ)

## ข้อผิดพลาดที่พบบ่อย

- **เดาที่มาจากรูปคำอย่างเดียว** เช่น คิดว่าคำที่มีไม้ตรีเป็นคำจีนทุกคำ
- **สับสน บาลีกับสันสกฤต** ให้ดู ศ ษ ฤ รร และ ร ควบ ซึ่งเป็นของสันสกฤต
- **เติม ส์ หรือวรรณยุกต์ในคำทับศัพท์โดยไม่จำเป็น** เช่น เกมส์ อินเตอร์เน็ต
- **ใช้ศัพท์บัญญัติกับคำทับศัพท์ปนกัน** ในงานเขียนชิ้นเดียว
- **ใช้สำนวนแปลจากอังกฤษ** เช่น ถูกเชิญ มันเป็นการยากที่จะ
