# บันทึกชุดงาน chemistry-34 (เฟส 8)

เคมี 8 หัวข้อจาก `proposals-science-core.yaml` (ประถม), `proposals-science-additional.yaml` (ม.4) และแถว `extend:` ใน `proposals-international.yaml` กับ `proposals-science-core.yaml` ไฟล์จับคู่อยู่ใน `docs/phase8/mappings/` ครบทุกตัวชี้วัดที่แผนผูกไว้

ภาพที่วาดเองทุกภาพสร้างจากสคริปต์ Python ที่คำนวณพิกัด (scratchpad `phase8-chemistry-34/fig_*.py`) เรนเดอร์เป็น PNG ด้วย Chromium และเปิดตรวจทุกภาพ ภาพจาก Commons มีเฉพาะสัญลักษณ์ GHS (สาธารณสมบัติ ตรวจสัญญาอนุญาตผ่าน API) ทุกคำตอบและค่า misconception คำนวณด้วย python3 มวลอะตอมใช้ค่าย่อของ IUPAC (H 1.008, C 12.01, N 14.01, O 16.00, Cl 35.45, Fe 55.85, Au 196.97 ฯลฯ) เลขอาโวกาโดร 6.02 × 10²³ และปริมาตรแก๊สที่ STP 22.4 dm³ ตามหนังสือ สสวท. ลิงก์อ้างอิงทุกลิงก์ได้ HTTP 200 (หน้าวิกิพีเดียไทยตรวจชื่อหน้าปลายทางแล้ว) PhET ที่ใช้เป็น HTML5

ไฟล์โมเลกุลใหม่ (`content/_assets/molecules/`): 5793 กลูโคส, 241 เบนซีน, 6324 อีเทน, 6325 เอทีน, 6326 เอไทน์ ดาวน์โหลดจาก PubChem (3D SDF URL เดียวกับ `npm run fetch-assets`) ด้วย curl เพื่อใช้ User-Agent ของคลังรู้ ตั้งใจใช้ SF₆ (17358) และ PCl₅ (24819) แต่ PubChem ไม่มีโครงสร้าง 3 มิติ (404) จึงเปลี่ยนเป็นชุดอีเทน/เอทีน/เอไทน์เปรียบเทียบพันธะเดี่ยว คู่ สาม

## chemistry/covalent-naming-energy (`chemistry.bonding.covalent-naming-energy`)

- โจทย์ 16 ข้อ (1:2 2:3 3:5 4:4 5:2; mcq match text numeric order; บริบทไทย 5 ข้อ) ภาพ 2 ภาพ (`bond-energy-steps.svg` แผนภาพพลังงานตามมาตราส่วน, `p-hydrogenation.svg` ใช้ใน p013) โมเลกุล 3 มิติ อีเทน เอทีน เอไทน์
- ไม่ซ้ำ `chemistry.bonding.covalent`: เพิ่มลำดับธาตุในสูตรตาม IUPAC (OF₂, Cl₂O) การรวบเสียง มอนอกไซด์ สารไฮโดรเจนกับหมู่ 16–17 ชื่อสามัญ ชื่อ → สูตร รัศมีโคเวเลนต์ และการคำนวณ ΔH จากพลังงานพันธะ (H₂+Cl₂, NH₃, CH₄, โพรเพน, การเติม H₂, หาพลังงานพันธะที่ไม่รู้)
- ค่าพลังงานพันธะเฉลี่ยเลือกให้ตรงกับหัวข้อ covalent ที่มีอยู่ (C–C 348, C=C 614, C≡C 839, N≡N 945) ทุกโจทย์ให้ค่าในโจทย์ ผู้ตรวจควรเทียบกับตารางในหนังสือ สสวท. ฉบับปัจจุบัน
- ไม่แน่ใจ: การสะกดการรวบเสียงภาษาไทย (เพนตะออกไซด์/เพนทอกไซด์) จึงสอนเฉพาะ มอนอกไซด์ และรับทั้ง เดคะ/เดคา ใน p007

## chemistry/mole (`chemistry.stoichiometry.mole`)

- โจทย์ 17 ข้อ (1:2 2:3 3:5 4:4 5:3; mcq numeric match text; บริบทไทย 4 ข้อ) ภาพ 1 ภาพ (`mole-map.svg`) โมเลกุล 3 มิติ กลูโคส เบนซีน เอไทน์ (สูตรอย่างง่ายเหมือน/ต่างกัน) ไม่มีภาพในโจทย์เพราะเป็นการคำนวณจากค่าที่ให้
- ทบทวนมวลอะตอมเฉลี่ยสั้น ๆ (สอนแล้วใน atoms) แล้วเน้นโมล มวลต่อโมล ปริมาตรที่ STP กฎสัดส่วนคงที่ ร้อยละโดยมวล (ยูเรีย 46.7%) สูตรอย่างง่ายและสูตรโมเลกุล (วิตามินซี กลูโคส Fe₂O₃)
- โจทย์ที่คำตอบเป็นจำนวนมหาศาลให้ตอบเป็นตัวคูณของ 10²³ หรือ 10²² เพื่อให้ tolerance ทำงานได้

## chemistry/periodic-trends (`chemistry.matter.periodic-trends`)

- โจทย์ 17 ข้อ (1:1 2:3 3:6 4:5 5:2; mcq order numeric match; บริบทไทย 4 ข้อ) ภาพ 2 ภาพ (`period3-trends.svg` ค่าจริงของรัศมีและ IE₁, `ion-size.svg` วงกลมตามมาตราส่วน)
- ไม่ซ้ำ `chemistry.matter.periodic-table`: เน้นเหตุผล (ประจุนิวเคลียสยังผล การบัง) ขนาดไอออนและไอออนที่มีอิเล็กตรอนเท่ากัน ข้อยกเว้น IE (Mg>Al, P>S) และ EA (Cl>F) จุดหลอมเหลวคาบ 3 ตามชนิดโครงสร้าง ความว่องไวหมู่ 1 และการแทนที่ของแฮโลเจน ตารางเปรียบเทียบโลหะแทรนซิชันกับหมู่ 1–2 ประโยชน์และผลกระทบของธาตุ (ห้วยคลิตี้ ร่อนพิบูลย์)
- ข้อเสนอแผน: `เคมี 1 ม.4/4`, `ว 2.1 ม.5/5` และ `UKNC-SC-KS3-C-PT-02` สอนครบแล้วใน periodic-table จึงจับคู่ partial ที่หัวข้อนี้
- ค่าที่ควรตรวจ: รัศมีอะตอมเป็นรัศมีโลหะ (Na Mg Al) และโคเวเลนต์ (Si–Cl) ตามตารางที่ตำราไทยใช้ทั่วไป รัศมีไอออนเป็นค่าของ Shannon (เลขโคออร์ดิเนชัน 6) ตำราบางเล่มใช้ค่าต่างเล็กน้อย
