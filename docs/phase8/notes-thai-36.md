**การตรวจคำและความหมาย**: ใช้แบบฟอร์มค้นของพจนานุกรมฉบับราชบัณฑิตยสถานออนไลน์ (`dictionary.orst.go.th/func_lookup.php` สคริปต์ `orst.py`) ตรวจคำสะกดถูกทุกคำในตาราง "คำที่มักเขียนผิด" (และตรวจว่ารูปผิดไม่มีในพจนานุกรม) คำอ่านของคำควบกล้ำ อักษรนำ การันต์ รร ฤ เพลา ประสบ/ประสพ และความหมายของสำนวนทุกสำนวนที่ใช้ ไม่ได้คัดนิยามมาเป็นชุด (ORST เป็น link-only) เขียนความหมายด้วยคำของเราเอง

**บทร้อยกรองที่ยกมา (ตรวจทุกวรรคกับแหล่งแล้ว ทั้งหมดเป็นสาธารณสมบัติ)**:

- กาพย์พระไชยสุริยา (สุนทรภู่) บทแรก "สะธุสะจะขอไหว้ · พระศรีไตรสะระณา / พ่อแม่แลครูบา · เทวะตาในราศี" ตรงกับวิกิซอร์ซ `th.wikisource.org/wiki/พระไชยสุริยา` (ฉบับพิมพ์ พ.ศ. 2495) คงตัวสะกดตามฉบับนั้น และบทเรียนบอกว่าฉบับปัจจุบันเขียน สรณา เทวดา ไม่ได้ใช้บทที่สอง เพราะความหมายของ "ตรีชา" ยืนยันไม่ได้
- ลิลิตพระลอ "เสียงลือเสียงเล่าอ้าง..." (ตัวอย่างโคลงในจินดามณี) ตรงกับวิกิพีเดีย th:โคลงสี่สุภาพ ใช้ในบทฉันทลักษณ์เท่านั้น
- ไม่มีบทกวีสมัยใหม่ที่มีลิขสิทธิ์ ตัวอย่างกลอน กาพย์ยานี ฉบัง สุรางคนางค์ แต่งโดยคลังรู้ (กลอนและยานีชุดเดียวกับบท read-aloud) ตรวจจำนวนคำและตำแหน่งสัมผัสด้วย `poemcheck.py`

## thai/idioms-proverbs (`thai.grammar.idioms-proverbs`)

- โจทย์ 16 ข้อ (1:2 2:3 3:4 4:4 5:3; mcq match text order) ภาพ 1 ภาพ (`three-groups.svg` สำนวนความหมายกว้างกับ 3 กลุ่ม)
- ความหมายของสำนวนทั้ง 15 สำนวนตรวจกับ ORST (ทั้งหมดมีป้าย (สำ)) ไม่ใช้ "ไก่ได้พลอย" "ทำดีได้ดี" "รักวัวให้ผูก" เพราะไม่พบใน ORST และไม่ใช้ "ช้า ๆ ได้พร้าเล่มงาม" เพราะ ORST เขียนว่า "ช้า ๆ ได้พร้าสองเล่มงาม"
- **ธรรมเนียมการจัดกลุ่ม**: ORST ยก กระต่ายตื่นตูม เป็นตัวอย่าง "พังเพย" และ รำไม่ดีโทษปี่โทษกลอง เป็นตัวอย่าง "สำนวน" ขณะที่แบบเรียนหลายเล่มจัดต่างไป บทเรียนสอนหลักการ (สอนตรง = สุภาษิต · เปรียบเหตุการณ์ = คำพังเพย · วลีบอกลักษณะ = สำนวน) และโจทย์จำแนกใช้เฉพาะคำที่ชัด (น้ำขึ้นให้รีบตัก น้ำเชี่ยวอย่าขวางเรือ ขี่ช้างจับตั๊กแตน ไก่อ่อน ผักชีโรยหน้า) ผู้ตรวจควรเทียบกับแบบเรียนที่ใช้
- ที่มาของสำนวน (ใบเรือ ปิดทองพระพุทธรูป ผักชีโรยหน้า กระต่ายตื่นตูมจากนิทานชาดก) เขียนจากความรู้ทั่วไป
- ไม่มีข้อเสนอแก้แผน

## ลิงก์อ้างอิง

ลิงก์วิกิพีเดียทั้ง 23 ลิงก์ตรวจผ่าน MediaWiki API แล้วว่ามีหน้าอยู่จริง ไม่ใช่หน้า redirect และไม่ใช่หน้าแก้ความกำกวม และอ่านบทนำว่าตรงเรื่อง เปลี่ยน 3 ลิงก์ที่เป็น redirect: th:ภาพพจน์ → กลวิธีวัจนลีลา, th:กาพย์พระไชยสุริยา → พระไชยสุริยา, th:สุนทรภู่ → พระสุนทรโวหาร (ภู่) ลิงก์ dictionary.orst.go.th ได้ HTTP 200 (source: orst แบบ link-only) API ของวิกิพีเดียถูกจำกัดอัตรา (HTTP 429) บ่อยระหว่างทำ จึงใช้แคชและหน่วงเวลา
