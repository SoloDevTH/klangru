# ADR 0006: ผู้ช่วย AI แบบถามนำ

- สถานะ: ยอมรับแล้ว
- วันที่: 23 ต.ค. 2569
- โค้ด: `supabase/functions/_shared/tutor.ts`, `supabase/functions/tutor/index.ts`, `apps/web/components/TutorPanel.tsx`

## หลักการ

ผู้ช่วยมีไว้ให้ผู้เรียนคิดเอง ไม่ใช่ส่งคำตอบ (แนวเดียวกับ Khanmigo)

| โหมด | ใช้เมื่อ | ทำอะไร |
|---|---|---|
| `hint` | ระหว่างทำโจทย์ | หาจุดที่ติด ให้ขั้นถัดไปหรือคำถามนำหนึ่งข้อ ไม่บอกคำตอบสุดท้าย |
| `example` | ระหว่างทำโจทย์ | แก้โจทย์อื่นที่คล้ายกัน (เปลี่ยนตัวเลขและสถานการณ์) ทีละขั้น |
| `explain` | หลังตอบหรือเปิดเฉลยแล้วเท่านั้น | อธิบายเฉลยทีละขั้น ถ้ายังไม่ได้ตอบ เซิร์ฟเวอร์จะลดเป็น `hint` |
| `chat` | ทุกเวลา | ตอบคำถามเรื่องหัวข้อนี้ ถ้ามีโจทย์เปิดอยู่ให้ถามนำมากกว่าบอก |

## ข้อกำหนด

- **แหล่งความจริง:** บทเรียน โจทย์ และเฉลยโหลดจาก content pack ที่ deploy แล้ว (`CONTENT_BASE_URL`) ไม่รับเนื้อหาจากผู้ใช้ ข้อความของผู้เรียนถูกระบุว่าเป็นคำพูดของผู้เรียน ไม่ใช่คำสั่ง
- **ผู้ใช้:** ต้องเข้าสู่ระบบ ระบุช่วงอายุ และถ้าอายุต่ำกว่า 20 ปีต้องมีความยินยอมจากผู้ปกครอง (เงื่อนไขเดียวกับการซิงก์ เพราะข้อความถูกเก็บไว้ตรวจ)
- **จำกัด:** 60 ข้อความต่อ 24 ชั่วโมงต่อคน ข้อความยาวไม่เกิน 1,000 ตัวอักษร ส่งประวัติให้โมเดลไม่เกิน 12 รอบล่าสุด
- **ความปลอดภัย:** ไม่ขอข้อมูลส่วนตัว ถ้าผู้เรียนแสดงความทุกข์ใจหรือพูดถึงการทำร้าย ให้ตอบอย่างใส่ใจ แนะนำให้คุยกับผู้ใหญ่ที่ไว้ใจ และให้เบอร์สายด่วนสุขภาพจิต 1323 ถ้าโมเดลปฏิเสธคำขอ แอปแสดงข้อความสุภาพแทน
- **ตรวจคุณภาพ:** ทุกข้อความเก็บในตาราง `tutor_messages` ผู้เรียนอ่านของตัวเองได้ ครูในตาราง `staff` อ่านและตั้ง `review_status` (`ok`, `gave-answer`, `wrong`, `off-topic`, `unsafe`) ได้ ข้อความถูกลบพร้อมบัญชี
- **โมเดลและต้นทุน:** ใช้โมเดล Claude รุ่นล่าสุดผ่าน Anthropic SDK ตั้ง effort ระดับกลาง เปิด server-side fallback และ prompt caching ที่ส่วนคำสั่งระบบกับบทเรียน (ส่วนที่ซ้ำทุกคำขอ) ค่าใช้จ่ายเป็นต้นทุนของโครงการ ไม่เก็บจากผู้เรียน
- **ปิดได้:** ถ้าไม่ได้ตั้ง Supabase แอปจะไม่แสดงปุ่มผู้ช่วยเลย

## สิ่งที่ยังต้องทำโดยคน

- ครูสุ่มตรวจบทสนทนาอย่างน้อยสัปดาห์ละ 50 รายการในช่วงทดลอง และบันทึกกรณีที่บอกคำตอบตรงหรืออธิบายผิด
- ปรับคำสั่งระบบจากผลตรวจ แล้วรัน `npm run test:db` ทุกครั้ง
