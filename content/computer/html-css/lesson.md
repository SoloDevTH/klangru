## หน้าเว็บหนึ่งหน้ามีสามชั้น

ชมรมคอมพิวเตอร์ทำหน้าเว็บประกาศกีฬาสี เมื่อกดดู **ซอร์สโค้ด** ของหน้า (คลิกขวา แล้วเลือกดูซอร์ส) จะเห็นว่าข้อความที่อ่านอยู่ถูกห่อด้วยเครื่องหมาย `<` `>` และมีอีกไฟล์หนึ่งกำหนดสีกับขนาดตัวอักษร เอกสารบนเว็บแยกเป็นสามชั้น (ดูภาพหลังบทอ่านนี้)

1. **เนื้อหา (content)** ข้อความ ภาพ และลิงก์ที่อยากสื่อ เช่น "กีฬาสีวันที่ 15 ธันวาคม"
2. **โครงสร้าง (structure)** บอกว่าแต่ละส่วนคืออะไร เช่น นี่คือหัวเรื่อง นี่คือย่อหน้า นี่คือรายการ เขียนด้วยภาษามาร์กอัป **HTML**
3. **การแสดงผล (presentation)** บอกว่าแต่ละส่วนหน้าตาอย่างไร เช่น สี ขนาด ระยะห่าง เขียนด้วย **CSS**

เบราว์เซอร์รับไฟล์ HTML และ CSS ผ่าน HTTP แล้วรวมกันวาดเป็นหน้าเว็บ

## HTML: ใส่ป้ายบอกโครงสร้าง

HTML ประกอบด้วย **อิลิเมนต์** ส่วนใหญ่มี **แท็กเปิด** และ **แท็กปิด** ที่มีเครื่องหมาย `/` ครอบเนื้อหาไว้ เช่น `<p>สวัสดี</p>` แท็กเปิดใส่ **แอตทริบิวต์** เพิ่มข้อมูลได้ เช่น `<a href="...">`

```html
<!DOCTYPE html>
<html lang="th">
  <head>
    <meta charset="utf-8">
    <title>กีฬาสี 2568</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>กีฬาสีโรงเรียน</h1>
    <p>แข่งวันที่ <strong>15 ธันวาคม</strong> ที่สนามกลาง</p>
    <ul>
      <li>วิ่งผลัด</li>
      <li>ชักเย่อ</li>
    </ul>
    <img src="stadium.jpg" alt="สนามกลางของโรงเรียนมีลู่วิ่งสีแดงล้อมสนามหญ้า">
    <a href="schedule.html">ดูตารางแข่งขัน</a>
  </body>
</html>
```

- `<head>` เก็บข้อมูลเกี่ยวกับหน้า เช่น ชื่อบนแท็บ (`<title>`) การเข้ารหัสอักขระ และไฟล์ CSS ที่ใช้ ส่วน `<body>` คือสิ่งที่แสดงบนจอ
- `<h1>` ถึง `<h6>` หัวเรื่องตามลำดับความสำคัญ `<p>` ย่อหน้า `<ul>` รายการแบบไม่มีลำดับ `<ol>` รายการแบบมีลำดับ ทั้งสองแบบมี `<li>` เป็นแต่ละข้อ
- `<strong>` เน้นความสำคัญ `<a href="...">` ลิงก์ไปหน้าอื่น
- `<img>` ไม่มีแท็กปิด ใช้ `src` บอกไฟล์ภาพ และ `alt` บอกสิ่งที่ภาพสื่อให้โปรแกรมอ่านหน้าจอ
- อิลิเมนต์ต้อง **ซ้อนกันให้ถูก** แท็กที่เปิดทีหลังต้องปิดก่อน เช่น `<p><strong>...</strong></p>` ไม่ใช่ `<p><strong>...</p></strong>` อิลิเมนต์ทั้งหน้าจึงเป็นแผนภาพต้นไม้ (ดูภาพ)

ที่อยู่ในลิงก์มีสองแบบ **ที่อยู่สัมพัทธ์** เช่น `schedule.html` หมายถึงไฟล์ในโฟลเดอร์เดียวกัน ส่วน **ที่อยู่สัมบูรณ์** เช่น `https://school.example/schedule.html` ระบุโดเมนเต็ม

## CSS: กำหนดหน้าตา

CSS เขียนเป็น **กฎ** ประกอบด้วย **ตัวเลือก (selector)** ว่าจะตกแต่งอะไร และ **การประกาศ** `คุณสมบัติ: ค่า;` ในวงเล็บปีกกา

```css
h1 {
  color: darkgreen;
  font-size: 32px;
}
.important {
  background-color: lightyellow;
}
#footer {
  text-align: center;
}
```

- ตัวเลือกชื่อแท็ก เช่น `h1` ใช้กับทุก `<h1>`
- ตัวเลือก **คลาส** ขึ้นต้นด้วยจุด เช่น `.important` ใช้กับทุกอิลิเมนต์ที่มี `class="important"` ใช้ซ้ำได้หลายที่
- ตัวเลือก **ไอดี** ขึ้นต้นด้วย `#` เช่น `#footer` ใช้กับอิลิเมนต์เดียวที่มี `id="footer"`

ถ้ากฎหลายข้อขัดกัน ตัวเลือกที่เจาะจงกว่าชนะ (ไอดี > คลาส > ชื่อแท็ก) ถ้าเจาะจงเท่ากัน กฎที่เขียนทีหลังชนะ

### แบบจำลองกล่อง

ทุกอิลิเมนต์เป็นกล่องสี่ชั้นจากในออกนอก: **เนื้อหา** (`width`) **ระยะห่างภายใน** (`padding`) **เส้นขอบ** (`border`) และ **ระยะห่างภายนอก** (`margin`) ค่า `width` โดยปกติวัดแค่ส่วนเนื้อหา ความกว้างที่กล่องใช้บนหน้าจริงจึงต้องบวกทั้งสองข้าง

$$\text{ความกว้างรวม} = \text{width} + 2(\text{padding} + \text{border} + \text{margin})$$

## ทำไมต้องแยกโครงสร้างกับการแสดงผล

- **ดูแลง่าย** เว็บ 50 หน้าใช้ไฟล์ CSS เดียวกัน อยากเปลี่ยนสีหัวเรื่องทั้งเว็บก็แก้ที่เดียว
- **เข้าถึงได้** โปรแกรมอ่านหน้าจอใช้โครงสร้างพาผู้ใช้ข้ามไปทีละหัวเรื่องหรืออ่านรายการ ผู้ใช้สายตาเลือนรางเปลี่ยนสีหรือขยายตัวอักษรได้โดยเนื้อหาไม่เสีย
- **ใช้ได้หลายอุปกรณ์** HTML เดิมใช้ CSS คนละชุดสำหรับจอโทรศัพท์ จอคอมพิวเตอร์ หรือการพิมพ์
- **เครื่องมือค้นหาเข้าใจหน้า** หัวเรื่องและลิงก์ที่ใส่แท็กถูกบอกได้ว่าอะไรสำคัญ

จึงควรเลือกแท็กตาม **ความหมาย** ไม่ใช่ตามหน้าตา อยากได้ตัวใหญ่ให้ใช้ CSS ไม่ใช่ใส่ `<h1>` ให้ข้อความที่ไม่ใช่หัวเรื่อง และไม่ทำข้อความเป็นภาพ เพราะโปรแกรมอ่านหน้าจออ่านไม่ได้และขยายแล้วแตก

## ข้อผิดพลาดที่พบบ่อย

- **ลืมแท็กปิดหรือปิดสลับลำดับ** ทำให้หน้าแสดงผลเพี้ยน
- **ลืม `alt` ของภาพ** ผู้ใช้โปรแกรมอ่านหน้าจอไม่รู้ว่าภาพคืออะไร
- **ใช้หัวเรื่องเพราะอยากได้ตัวใหญ่** ทำให้โครงสร้างผิด
- **ลืม `;` หรือ `}` ใน CSS** กฎข้อนั้นหรือข้อถัดไปจะไม่ทำงาน
- **ลืมจุดหน้าชื่อคลาส** เขียน `important { }` จะหาแท็กชื่อ important ซึ่งไม่มี
- **คิดว่า `width` คือความกว้างทั้งกล่อง** ต้องบวก padding border และ margin
