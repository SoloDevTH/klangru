## พูดสั้น ๆ แต่ได้ความลึก

ตอนกีฬาสี เพื่อนชวนกันแอบออกไปซื้อน้ำ พอครูเรียกนับคนแล้วไม่ครบ ครูจึงสั่งห้ามออกนอกสนามตลอดงาน คุณยายที่มาดูพูดว่า "**วัวหายล้อมคอก**" คำพูดสั้น ๆ นี้แปลว่า เรื่องเกิดขึ้นแล้วจึงคิดแก้ไข ถ้อยคำแบบนี้เรียกรวม ๆ ว่า **สำนวน** คนไทยใช้กันมานาน ช่วยให้พูดสั้นแต่คมคาย บทนี้ต่อจากบท [ความหมายของคำและข้อความจากบริบท](/topic/thai.reading.word-meaning-in-context/) ซึ่งฝึกอ่านความหมายโดยนัยไว้แล้ว

## สำนวน คำพังเพย สุภาษิต

ทั้งสามแบบเป็นถ้อยคำที่กล่าวสืบต่อกันมานาน และ **มีความหมายไม่ตรงตามตัว** ในความหมายกว้าง พจนานุกรมเรียกรวมว่า สำนวน แต่แบบเรียนมักแยกเป็น 3 กลุ่ม

| กลุ่ม | ลักษณะ | ตัวอย่าง |
|---|---|---|
| **สำนวน** | ถ้อยคำสั้น ๆ มักเป็นวลี ใช้เปรียบลักษณะคนหรือการกระทำ | ไก่อ่อน · ผักชีโรยหน้า · ปิดทองหลังพระ · คมในฝัก |
| **คำพังเพย** | กล่าวกลาง ๆ เปรียบเหตุการณ์ ให้ผู้ฟังตีความเข้ากับเรื่อง ไม่ได้สั่งสอนตรง ๆ | รำไม่ดีโทษปี่โทษกลอง · ขี่ช้างจับตั๊กแตน · หนีเสือปะจระเข้ |
| **สุภาษิต** | เป็นคติสอนใจ บอกว่าควรหรือไม่ควรทำอะไร | น้ำเชี่ยวอย่าขวางเรือ · น้ำขึ้นให้รีบตัก |

ตำราแต่ละเล่มจัดกลุ่มไม่ตรงกันทุกคำ เช่น พจนานุกรมฉบับราชบัณฑิตยสถานยก **กระต่ายตื่นตูม** เป็นตัวอย่างพังเพย และยก **รำไม่ดีโทษปี่โทษกลอง** เป็นตัวอย่างสำนวน ส่วนแบบเรียนหลายเล่มจัดสลับกัน ดังนั้นให้ใช้ **หลักการ** ตัดสินคำที่ชัดเจน คือ

- ถ้า **สั่งสอนตรง ๆ** (ควร อย่า ให้) → สุภาษิต
- ถ้า **เล่าเหตุการณ์เปรียบเทียบ** ให้คิดเอาเอง → คำพังเพย
- ถ้าเป็น **วลีสั้นบอกลักษณะ** → สำนวน

## ความหมายของสำนวนที่ควรรู้

ความหมายในตารางตรวจกับพจนานุกรมฉบับราชบัณฑิตยสถานแล้ว

| สำนวน | ความหมาย |
|---|---|
| วัวหายล้อมคอก | เรื่องเกิดขึ้นแล้วจึงคิดแก้ไข |
| ผักชีโรยหน้า | ทำความดีเพียงผิวเผิน |
| ปิดทองหลังพระ | ทำความดีแต่ไม่มีใครเห็น ไม่ได้รับการยกย่อง |
| คมในฝัก | มีความสามารถแต่ยังไม่แสดงออก |
| ชักใบให้เรือเสีย | พูดหรือทำขวาง ๆ ให้เรื่องเขวออกนอกทาง |
| น้ำซึมบ่อทราย | มีรายได้มาเรื่อย ๆ |
| สอนจระเข้ให้ว่ายน้ำ | สอนสิ่งที่เขาถนัดอยู่แล้ว |
| ใกล้เกลือกินด่าง | มองข้ามของดีที่อยู่ใกล้ตัว |
| รำไม่ดีโทษปี่โทษกลอง | ทำผิดแล้วไม่รับผิด กลับโทษผู้อื่น |
| ขี่ช้างจับตั๊กแตน | ลงทุนมากแต่ได้ผลนิดเดียว |
| หนีเสือปะจระเข้ | หนีภัยหนึ่งแล้วไปพบอีกภัยหนึ่ง |
| น้ำเชี่ยวอย่าขวางเรือ | อย่าขวางผู้มีอำนาจหรือคนที่กำลังโกรธจัด |
| น้ำขึ้นให้รีบตัก | มีโอกาสดีควรรีบทำ |

## ที่มาของสำนวน

สำนวนไทยเกิดจากชีวิตความเป็นอยู่ของคนไทย ถ้ารู้ที่มาจะเข้าใจความหมายง่ายขึ้น

- **การเดินเรือและแม่น้ำ** ชักใบให้เรือเสีย (ดึงใบเรือผิดทาง เรือก็เสียทิศ) · น้ำเชี่ยวอย่าขวางเรือ · น้ำขึ้นให้รีบตัก
- **ศาสนา** ปิดทองหลังพระ (ปิดทองที่ด้านหลังพระพุทธรูป คนจึงไม่เห็น)
- **อาหารการกิน** ผักชีโรยหน้า (โรยผักชีไว้ข้างบนให้อาหารดูน่ากิน) · ใกล้เกลือกินด่าง
- **สัตว์และการเกษตร** วัวหายล้อมคอก · ขี่ช้างจับตั๊กแตน · หนีเสือปะจระเข้
- **การแสดง** รำไม่ดีโทษปี่โทษกลอง (คนรำพลาดแต่โทษวงดนตรี)
- **อาวุธ** คมในฝัก (มีดหรือดาบที่คมแต่ยังอยู่ในฝัก)
- **นิทาน** กระต่ายตื่นตูม (กระต่ายได้ยินเสียงผลไม้ตกดังตูม คิดว่าโลกแตก วิ่งหนีและทำให้สัตว์อื่นตื่นตกใจตาม)

## ใช้สำนวนให้ถูกสถานการณ์

1. **เข้าใจความหมายให้ถูก** ไม่แปลตามตัว
2. **ดูว่าความหมายดีหรือไม่ดี** เช่น ผักชีโรยหน้า เป็นคำติ ไม่ใช่คำชม
3. **ดูว่าเหมาะกับผู้ฟังไหม** สำนวนที่ติคนอื่นอาจทำให้เขาเสียใจ ใช้กับผู้ใหญ่ต้องระวัง
4. **เช็กว่าสถานการณ์ตรงกับความหมายทุกส่วน** เช่น ขี่ช้างจับตั๊กแตน ต้องมีทั้ง "ลงทุนมาก" และ "ได้ผลน้อย"

ตัวอย่าง: พี่เตรียมงานวันเกิดน้องอยู่เบื้องหลังทั้งคืน แต่ไม่มีใครรู้ เหมาะกับสำนวน **ปิดทองหลังพระ** ไม่ใช่ ผักชีโรยหน้า เพราะพี่ทำดีจริง ไม่ได้ทำเพียงผิวเผิน

## ข้อผิดพลาดที่พบบ่อย

- **แปลตามตัว** เช่น คิดว่า คมในฝัก พูดถึงมีด
- **สับสนสำนวนที่คล้ายกัน** เช่น ปิดทองหลังพระ (ทำดีแต่ไม่มีใครเห็น) กับ ผักชีโรยหน้า (ทำดีแค่ภายนอก)
- **ใช้คำติในโอกาสที่ควรชม**
- **จำคำผิด** เช่น หนีเสือปะจระเข้ เป็น หนีเสือเจอจระเข้ ซึ่งไม่ใช่รูปในพจนานุกรม
- **ยึดการจัดกลุ่มของเล่มเดียวว่าถูกเสมอ** ทั้งที่ตำราจัดต่างกัน
