## เมื่อตัวแปรอยู่ในตัวส่วนหรือในค่าสัมบูรณ์

ร้านรับพิมพ์เสื้อคิดค่าทำบล็อก 1,500 บาท และค่าเสื้อตัวละ 90 บาท ถ้าสั่ง $x$ ตัว ต้นทุนเฉลี่ยต่อตัวคือ $\dfrac{1500 + 90x}{x}$ บาท ถ้าอยากให้เฉลี่ยไม่เกินตัวละ 120 บาท ต้องแก้ **อสมการเศษส่วนของพหุนาม** ส่วนข้อกำหนดแบบ "น้ำหนัก 1 กิโลกรัม คลาดเคลื่อนได้ไม่เกิน 10 กรัม" เขียนเป็น **อสมการค่าสัมบูรณ์** $|w - 1000| \le 10$ บทนี้ต่อจาก [สมการและอสมการพหุนาม](/topic/math.algebra.polynomial-equations/) [อสมการเชิงเส้น](/topic/math.algebra.linear-inequalities/) และ [ค่าสัมบูรณ์](/topic/math.algebra.radicals/)

## นิพจน์ตรรกยะ

**นิพจน์ตรรกยะ** คือเศษส่วนของพหุนาม $\dfrac{a(x)}{b(x)}$ เมื่อ $b(x) \ne 0$ ค่า $x$ ที่ทำให้ตัวส่วนเป็นศูนย์ใช้ไม่ได้เสมอ นิพจน์ตรรกยะบวก ลบ คูณ หาร (ด้วยนิพจน์ที่ไม่เป็นศูนย์) แล้วยังเป็นนิพจน์ตรรกยะ เหมือนจำนวนตรรกยะ และใช้วิธีเดียวกับเศษส่วน: ทำให้อย่างง่ายโดยแยกตัวประกอบแล้วตัดตัวประกอบร่วม บวกลบโดยทำตัวส่วนให้เท่ากัน เช่น

$$\frac{2}{x} + \frac{1}{x + 1} = \frac{2(x + 1) + x}{x(x + 1)} = \frac{3x + 2}{x(x + 1)}$$

ตัดได้เฉพาะ **ตัวประกอบ** ไม่ใช่พจน์ $\dfrac{x + 6}{x + 2}$ ตัด $x$ ไม่ได้

ถ้าดีกรีของตัวเศษไม่น้อยกว่าตัวส่วน หารยาวแล้วเขียนเป็น **ผลหาร + เศษ/ตัวหาร** ได้ เช่น $\dfrac{2x^2 + 3x + 4}{x + 1} = 2x + 1 + \dfrac{3}{x + 1}$ รูปนี้บอกว่าเมื่อ $x$ ใหญ่มาก นิพจน์มีค่าใกล้ $2x + 1$

## สมการเศษส่วนและสมการที่มีกรณฑ์

คูณทั้งสองข้างด้วย ค.ร.น. ของตัวส่วนเพื่อกำจัดเศษส่วน แล้วแก้สมการพหุนาม **แต่ต้องตรวจคำตอบทุกครั้ง** เพราะการคูณด้วยนิพจน์ที่อาจเป็นศูนย์อาจสร้าง **คำตอบแปลกปลอม** เช่น

$$\frac{x}{x - 3} = \frac{3}{x - 3} + 2 \;\Rightarrow\; x = 3 + 2(x - 3) \;\Rightarrow\; x = 3$$

แต่ $x = 3$ ทำให้ตัวส่วนเป็นศูนย์ สมการนี้จึง **ไม่มีคำตอบ**

สมการที่มีกรณฑ์ก็เช่นกัน การยกกำลังสองทั้งสองข้างอาจเพิ่มคำตอบ เช่น $\sqrt{x + 6} = x$ ยกกำลังสองได้ $x^2 - x - 6 = 0$ จึง $x = 3$ หรือ $x = -2$ แต่ $\sqrt{4} = 2 \ne -2$ คำตอบจึงมีแค่ $x = 3$

## อสมการเศษส่วน: ใช้เส้นจำนวน

**ห้ามคูณไขว้** ด้วยตัวส่วนที่มีตัวแปร เพราะไม่รู้ว่าตัวส่วนบวกหรือลบ (ถ้าลบต้องกลับเครื่องหมาย) ให้ทำดังนี้

1. ย้ายทุกพจน์ไปข้างเดียว ให้อีกข้างเป็น 0 แล้วรวมเป็นเศษส่วนเดียว
2. แยกตัวประกอบเศษและส่วน หา **จุดวิกฤต** (ค่าที่ทำให้เศษหรือส่วนเป็นศูนย์)
3. วางจุดวิกฤตบนเส้นจำนวน หาเครื่องหมายของแต่ละช่วง (ลองแทนค่าหนึ่งค่าในช่วง)
4. เลือกช่วงตามเครื่องหมายที่ต้องการ จุดที่ตัวส่วนเป็นศูนย์เป็นวงกลมโปร่งเสมอ จุดที่ตัวเศษเป็นศูนย์รวมด้วยถ้ามี $\le$ หรือ $\ge$

## สมการและอสมการค่าสัมบูรณ์

$|A|$ คือระยะจาก $A$ ถึง 0 บนเส้นจำนวน จึงได้หลักต่อไปนี้ (เมื่อ $k > 0$)

| รูป | ความหมาย |
|---|---|
| $\lvert A\rvert = k$ | $A = k$ หรือ $A = -k$ |
| $\lvert A\rvert = \lvert B\rvert$ | $A = B$ หรือ $A = -B$ |
| $\lvert A\rvert < k$ | $-k < A < k$ |
| $\lvert A\rvert > k$ | $A < -k$ หรือ $A > k$ |

$|x - a| < k$ หมายถึง $x$ ห่างจาก $a$ น้อยกว่า $k$ บนกราฟคือช่วงที่กราฟรูปตัววี $y = |x - a|$ อยู่ใต้เส้น $y = k$ (ดูภาพ) ถ้า $k < 0$ สมการ $|A| = k$ และอสมการ $|A| < k$ ไม่มีคำตอบ ส่วน $|A| > k$ จริงทุกค่า

เมื่อในค่าสัมบูรณ์เป็นพหุนามดีกรีสอง ก็ใช้หลักเดียวกัน แล้วแก้สมการกำลังสองที่ได้ทั้งสองกรณี

## ข้อผิดพลาดที่พบบ่อย

- คูณไขว้อสมการเศษส่วนโดยไม่ดูเครื่องหมายของตัวส่วน
- ลืมตัดค่าที่ทำให้ตัวส่วนเป็นศูนย์ หรือรวมจุดนั้นเข้ากับคำตอบเมื่อมี $\ge$
- ไม่ตรวจคำตอบแปลกปลอมของสมการเศษส่วนและสมการที่มีกรณฑ์
- แก้ $|A| = k$ ได้แค่ $A = k$ ลืมกรณี $A = -k$
- เขียน $|x| > 3$ เป็น $-3 > x > 3$ ซึ่งไม่มีจำนวนใดเป็นจริง ที่ถูกคือ $x < -3$ หรือ $x > 3$
