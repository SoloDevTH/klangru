หัวข้อภาษาไทย 8 หัวข้อจาก `docs/phase6/proposals-languages.yaml` ไม่มีแถว `extend:` ที่ผูกกับหัวข้อในชุดนี้ ภาพทุกภาพวาดเป็น SVG ด้วยสคริปต์ (scratchpad `phase8-thai-31/fig_*.py`) เรนเดอร์เป็น PNG ด้วย Chromium และเปิดตรวจทุกภาพแล้ว ไม่มีภาพจาก Commons โจทย์สร้างด้วย `p_*.py` ผ่าน `build.py` ชุดเดียวกับ thai-26 ลำดับคำในพจนานุกรมทุกข้อตรวจด้วยสคริปต์ `dictsort.py` ซึ่งเขียนตามหลักการเรียงที่ใช้ในบทเรียน วันในสัปดาห์ (ศุกร์ 13 พ.ย. 2569, เสาร์ 5 ธ.ค. 2569) และตัวเลขอื่นทุกตัวคำนวณด้วย python3 บทเรียนนับด้วย `Intl.Segmenter` ได้ 610–955 คำ ลิงก์อ้างอิงทุกลิงก์ได้ HTTP 200 และตรวจผ่าน MediaWiki API แล้วว่าไม่ใช่หน้า redirect หรือหน้าแก้ความกำกวม (ไม่ใช้ th:การฟัง → การได้ยิน, th:มาตราตัวสะกด → ภาษาไทย, th:ภาษาพูด → สำนวนภาษาปาก, th:สัมผัส → ระบบประสาท, en:Summary ที่เป็นหน้าแก้ความกำกวม และเปลี่ยน en:Arbitrariness ที่เป็นความหมายทั่วไป ไม่ใช่ทางภาษาศาสตร์ เป็น en:Tone (linguistics))

แหล่งความรู้: หลักภาษาไทยตามแบบเรียน สพฐ. และหลักการเรียงคำของพจนานุกรมฉบับราชบัณฑิตยสถาน พ.ศ. 2554 (เขียนจากความรู้ทั่วไปของหลักภาษา ไม่ได้คัดลอกจากหนังสือ) ผู้ตรวจที่เป็นครูภาษาไทยควรอ่านทุกหัวข้อ เพราะตำราหลายเล่มนับและเรียกชื่อต่างกัน
