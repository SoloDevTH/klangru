## จำนวนที่ยกกำลังสองแล้วติดลบ

สมการ $x^2 + 1 = 0$ ไม่มีคำตอบเป็นจำนวนจริง เพราะจำนวนจริงยกกำลังสองแล้วไม่ติดลบ นักคณิตศาสตร์จึงสร้างจำนวนใหม่ $i$ ที่มีสมบัติ

$$i^2 = -1$$

แล้วขยายระบบจำนวนให้มี **จำนวนเชิงซ้อน** ทุกจำนวนอยู่ในรูป $z = a + bi$ เมื่อ $a, b$ เป็นจำนวนจริง เรียก $a$ ว่า **ส่วนจริง** เขียน $\operatorname{Re}(z) = a$ และเรียก $b$ ว่า **ส่วนจินตภาพ** เขียน $\operatorname{Im}(z) = b$ (ส่วนจินตภาพคือ $b$ ไม่ใช่ $bi$) จำนวนจริงคือกรณี $b = 0$ บทนี้ต่อจาก [สมการกำลังสอง](/topic/math.algebra.quadratic-eq/) [เวกเตอร์](/topic/math.geometry.vectors/) และ [ฟังก์ชันตรีโกณมิติ](/topic/math.functions.trig-functions/)

กำลังของ $i$ วนซ้ำทุก 4: $i^1 = i$, $i^2 = -1$, $i^3 = -i$, $i^4 = 1$ แล้ว $i^5 = i$ อีกครั้ง จึงหา $i^n$ ได้จากเศษของ $n \div 4$

## บวก ลบ คูณ หาร

ใช้สมบัติการสลับที่ การจัดหมู่ และการแจกแจงเหมือนพหุนาม แล้วแทน $i^2 = -1$

- บวกลบ: รวมส่วนจริงกับส่วนจริง ส่วนจินตภาพกับส่วนจินตภาพ เช่น $(4 + i) + (2 - 5i) = 6 - 4i$
- คูณ: กระจายแล้วแทน $i^2 = -1$ เช่น $(1 + 3i)(2 - i) = 2 - i + 6i - 3i^2 = 5 + 5i$

**สังยุค** ของ $z = a + bi$ คือ $\bar z = a - bi$ (เปลี่ยนเครื่องหมายเฉพาะส่วนจินตภาพ) สมบัติสำคัญคือ

$$z\bar z = (a + bi)(a - bi) = a^2 + b^2$$

ซึ่งเป็นจำนวนจริงเสมอ จึงใช้ **หาร** ได้: คูณทั้งเศษและส่วนด้วยสังยุคของตัวส่วน ตัวส่วนจะไม่มี $i$ เหลือ

## ระนาบเชิงซ้อนและค่าสัมบูรณ์

แทน $a + bi$ ด้วยจุด $(a, b)$ บน **ระนาบเชิงซ้อน** แกนนอนเป็นแกนจริง แกนตั้งเป็นแกนจินตภาพ (ดูภาพ) ระยะจากจุดกำเนิดคือ **ค่าสัมบูรณ์** (มอดุลัส)

$$|z| = \sqrt{a^2 + b^2} = \sqrt{z\bar z}$$

การบวกจำนวนเชิงซ้อนคือการบวกเวกเตอร์ $(a, b)$ แบบหางต่อหัว สังยุคคือการสะท้อนในแกนจริง ดังนั้น **ระยะระหว่างจำนวน $z_1$ กับ $z_2$** คือ $|z_1 - z_2|$ และ **จุดกึ่งกลาง** คือ $\dfrac{z_1 + z_2}{2}$

## รูปเชิงขั้วและสูตรออยเลอร์

ถ้า $r = |z|$ และ $\theta$ คือมุมจากแกนจริงบวกไปถึงจุด $z$ (เรียกว่า **อาร์กิวเมนต์**) จะได้ $a = r\cos\theta$, $b = r\sin\theta$ จึงเขียน **รูปเชิงขั้ว**

$$z = r(\cos\theta + i\sin\theta) = re^{i\theta}$$

สูตร $e^{i\theta} = \cos\theta + i\sin\theta$ คือ **สูตรของออยเลอร์** เมื่อ $\theta = \pi$ ได้ $e^{i\pi} + 1 = 0$ รูปสี่เหลี่ยม $a + bi$ และรูปเชิงขั้วเป็นจำนวนเดียวกัน เพียงบอกตำแหน่งจุดเดียวกันด้วยพิกัดต่างชนิด ระวังเลือกมุมให้ตรงจตุภาคของจุด

รูปเชิงขั้วทำให้การคูณง่าย: **คูณค่าสัมบูรณ์ บวกมุม** $\;r_1e^{i\theta_1}\cdot r_2e^{i\theta_2} = r_1r_2e^{i(\theta_1 + \theta_2)}$ เช่น คูณด้วย $i = e^{i\pi/2}$ คือหมุนจุด 90° ทวนเข็มนาฬิกา และได้ **ทฤษฎีบทของเดอมัวร์**

$$\big(r(\cos\theta + i\sin\theta)\big)^n = r^n(\cos n\theta + i\sin n\theta)$$

ตัวอย่างจากหลักสูตร: $-1 + \sqrt3\,i$ มี $r = 2$ และมุม $120^\circ$ จึง $(-1 + \sqrt3\,i)^3 = 2^3(\cos 360^\circ + i\sin 360^\circ) = 8$

สูตรออยเลอร์ยังใช้กับฟังก์ชันไซน์: $a\cos t + b\sin t$ คือส่วนจริงของ $(a - bi)e^{it}$ จึงเป็นคลื่นโคไซน์ที่มีแอมพลิจูด $|a - bi| = \sqrt{a^2 + b^2}$ วิศวกรไฟฟ้าใช้ความคิดนี้คำนวณวงจรกระแสสลับ

## รากที่ $n$

สมการ $z^n = w$ มีคำตอบ $n$ ตัว ถ้า $w = Re^{i\varphi}$ คำตอบคือ

$$z_k = \sqrt[n]{R}\,e^{i\left(\frac{\varphi + 360^\circ k}{n}\right)}, \quad k = 0, 1, \dots, n - 1$$

รากทั้ง $n$ ตัวอยู่บนวงกลมรัศมี $\sqrt[n]{R}$ ห่างกันเท่า ๆ กันทุก $\tfrac{360^\circ}{n}$ เช่น รากที่สามของ 8 คือ $2$, $-1 + \sqrt3\,i$, $-1 - \sqrt3\,i$ (ดูภาพ) รากของ $z^n = 1$ เรียกว่า **รากที่ $n$ ของหนึ่ง**

## สมการกำลังสองและทฤษฎีบทหลักมูลของพีชคณิต

ถ้าดิสคริมิแนนต์ $b^2 - 4ac < 0$ สมการ $ax^2 + bx + c = 0$ ยังมีคำตอบเป็นจำนวนเชิงซ้อนสองตัวที่เป็นสังยุคกัน เพราะ $\sqrt{-d} = i\sqrt d$ เมื่อ $d > 0$ เช่น $x^2 - 4x + 13 = 0$ ได้ $x = \dfrac{4 \pm \sqrt{-36}}{2} = 2 \pm 3i$

เอกลักษณ์พหุนามก็ขยายได้ เช่น $x^2 + 4 = (x + 2i)(x - 2i)$ ซึ่งแยกตัวประกอบไม่ได้ในจำนวนจริง **ทฤษฎีบทหลักมูลของพีชคณิต** กล่าวว่าพหุนามดีกรี $n \ge 1$ มีรากในจำนวนเชิงซ้อนพอดี $n$ ราก (นับรากซ้ำ) สำหรับดีกรีสอง เห็นได้จากสูตรข้างบนซึ่งให้คำตอบเสมอ และถ้าสัมประสิทธิ์เป็นจำนวนจริง รากที่ไม่จริงจะมาเป็นคู่สังยุคเสมอ

## ข้อผิดพลาดที่พบบ่อย

- ลืมแทน $i^2 = -1$ หลังกระจาย หรือแทนเป็น $+1$
- ตอบส่วนจินตภาพของ $3 - 5i$ เป็น $5$ หรือ $-5i$ (ที่ถูกคือ $-5$)
- หารโดยคูณด้วยตัวส่วนเดิมแทนสังยุค
- หาอาร์กิวเมนต์ด้วย $\tan^{-1}\tfrac{b}{a}$ โดยไม่ดูจตุภาค เช่น $-1 + \sqrt3\,i$ อยู่จตุภาคที่ 2 มุมคือ $120^\circ$ ไม่ใช่ $-60^\circ$
- หารากที่ $n$ ได้ตัวเดียว ทั้งที่มี $n$ ตัว
