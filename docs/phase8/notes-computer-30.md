ภาพทุกภาพวาดเองเป็น SVG ด้วยสคริปต์ Python ที่คำนวณพิกัด เรนเดอร์เป็น PNG ด้วย Chromium และเปิดดูแล้วทุกภาพ ไม่มีภาพจาก Commons ภาพในโจทย์ไม่มีคำตอบ (ต้นไม้มินิแมกซ์ในโจทย์ใช้ ? แทนค่าโหนด แผนภาพมะม่วงในโจทย์ไม่มีเส้นระยะ กราฟ A–G ไม่มีระยะ) โค้ด Python ทุกชิ้นในบทเรียน ตัวอย่างแสดงวิธีทำ และโจทย์รันด้วย python3 แล้ว ผลตรงกับที่เขียนไว้ (โมดูล shop_utils.py กับ main.py รันเป็นสองไฟล์จริง และตรวจว่าไฟล์ชื่อ statistics.py บังโมดูลมาตรฐานจริง) ทุกคำตอบและค่า misconception คำนวณด้วย python3 รวมทั้งระยะและการโหวตของ kNN ค่ามินิแมกซ์ของเกมหยิบไม้ (n = 1–10) ลำดับ BFS/DFS ค่า mod ของตารางแฮช และการวนไม่รู้จบของทวิภาคที่เขียน low = mid ลิงก์อ้างอิงทุกลิงก์ได้ HTTP 200 (เปลี่ยน th:ความซับซ้อนเชิงเวลา ที่ได้ 404 เป็น th:สัญกรณ์โอใหญ่) ไฟล์จับคู่อยู่ใน `docs/phase8/mappings/` และตรวจด้วยสคริปต์แล้วว่าชุดตัวชี้วัดตรงกับแถว topics และ extend ของแผนพอดี

## computer.programming.oop

- 16 ข้อ ภาพ 3 ภาพ: โมดูลที่เขียนเองกับไลบรารีมาตรฐาน คลาสกับวัตถุ (Account) และการประกอบวัตถุ (Cart มี Item)
- สอนโมดูล import/from ... import `__name__` ไลบรารีมาตรฐาน (statistics, json) API ทั้งของฟังก์ชันและบริการเว็บ (JSON ที่เป็นข้อความในโค้ด ไม่มีการเรียกเครือข่าย) คลาส วัตถุ แอตทริบิวต์ เมทอด การห่อหุ้ม การประกอบ และการสืบทอด (super)
- ทุกตัวชี้วัดเป็น partial (AC9TDI10P09, 3B-AP-14, 3B-AP-16) เพราะผู้เรียนไม่ได้เขียนและรันโปรแกรมเอง
- บทเรียนสั้นที่สุดในชุด (669 คำ) เพราะโค้ดมาก แต่ยังอยู่ในช่วง 500–1,000 คำ
- บริการข้อมูลฝนและโมดูลค่าส่งพัสดุใน p011 p012 เป็นตัวอย่างสมมติ อัตราภาษีมูลค่าเพิ่ม 7% ใช้ตามที่ทราบกันทั่วไป

## computer.algorithms.efficiency

- 17 ข้อ ภาพ 3 ภาพ: กราฟ 3n + 5 กับ 4n ที่ n0 = 5 ค่าคงตัวของ find_max ขณะ i = 3 และลิสต์คะแนนที่เรียงแล้ว (โจทย์) พร้อมสื่อโต้ตอบ function-plot เลื่อนค่า c ของ c·n เทียบกับ 3n + 5
- ไม่ซ้ำกับ searching-sorting: บทนั้นสอนการนับขั้นและบิ๊กโออย่างคร่าว ๆ บทนี้สอนนิยามด้วย c และ n0 กฎบวก/คูณ ขอบบนที่แนบ หน่วยความจำ ค่าคงตัวของวงวน (เริ่มต้น คงอยู่ จบ) การพิสูจน์ว่าวงวนจบ และการดัดแปลงทวิภาคเป็นการหาดัชนีแรกที่ค่าไม่น้อยกว่าเป้าหมาย
- 3B-AP-10 และ 3B-AP-11 เป็น full
- ข้อเสนอ: AL-Complexity ในไฟล์จับคู่ของ searching-sorting เขียนว่า "ยังไม่มีนิยามเชิงรูปนัยของบิ๊กโอ หน่วยความจำ" ตอนนี้หัวข้อนี้สอนแล้ว ถ้าแผนจะเพิ่ม acm-cs2023:AL-Complexity ให้หัวข้อนี้ (ยังเหลือ P/NP) ผู้ประสานงานพิจารณาได้ ชุดนี้ไม่ได้เพิ่มเอง

## computer.ai.intro

- 17 ข้อ ภาพ 5 ภาพ: วงจรรับรู้ คิด ลงมือของหุ่นยนต์ดูดฝุ่น ต้นไม้มินิแมกซ์สองชั้น แผนภาพ kNN ของมะม่วงพร้อมระยะ 2, 2.24, 3 ต้นไม้มินิแมกซ์สามกิ่งสำหรับโจทย์ (ค่ารากคือ 7) และแผนภาพมะม่วงสำหรับโจทย์ (ผลใหม่ (5, 5) k = 1 ได้ดิบ k = 3 ได้สุก)
- ครอบคลุมตามที่สั่ง: การเรียนรู้ของเครื่อง ข้อมูลฝึก/ทดสอบ การเรียนรู้เกิน การจำแนกด้วย kNN ด้วยมือและโค้ด ความลำเอียงและการวัดแยกกลุ่ม AI แบบรู้สร้าง (hallucination แหล่งอ้างอิงปลอม ความเป็นส่วนตัว การอ้างแหล่งต้นทางและเปิดเผยการใช้ AI) และมินิแมกซ์ตาม scope ของแผน
- 3B-AP-08 เป็น full 3B-AP-09 เป็น partial (ผู้เรียนไม่ได้เขียนอัลกอริทึมเองเพื่อเล่นกับคนจริง)
- **โฟลเดอร์** ตามกติกาส่วนท้ายของรหัสได้ `content/computer/intro/` ซึ่งกว้างมาก (ถ้ามี computer.*.intro อื่นจะชน) ข้อเสนอ: ถ้าผู้ประสานงานต้องการ เปลี่ยนเป็น `content/computer/ai-intro/` ได้โดยไม่กระทบรหัสหัวข้อ
- คำว่า "ปัญญาประดิษฐ์แบบรู้สร้าง" ใช้ตามชื่อบทความวิกิพีเดียไทย (ตรวจชื่อหน้าแล้ว) ตัวเลขความแม่นยำทุกตัวเป็นข้อมูลสมมติ ตัวอย่างความลำเอียง (สำเนียง สีผิว ใบสมัครทุน) เขียนเป็นสถานการณ์สมมติที่สะท้อนปัญหาที่มีรายงานทั่วไป ไม่ได้อ้างระบบจริงใด
- ข้อเสนอ prerequisite: โค้ดมินิแมกซ์ใช้การเรียกซ้ำ ควรพิจารณาเพิ่ม computer.programming.recursion เป็น prerequisite (ตอนนี้ใส่ใน encompasses ไม่ได้เพราะไม่ใช่บรรพบุรุษ ตัวตรวจจะเตือน) บทเรียนอธิบายโดยไม่ต้องรู้เรื่องกองการเรียก
