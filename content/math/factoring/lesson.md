## ย้อนกลับจากการคูณ

สมมติว่ามีแปลงผักรูปสี่เหลี่ยมผืนผ้าที่มีพื้นที่ $x^2 + 5x + 6$ ตารางเมตร และเรารู้ว่าความกว้างกับความยาวเป็นนิพจน์ที่มี $x$ ทั้งคู่ คำถามคือ ด้านทั้งสองยาวเท่าใด

ตอนเรียนพหุนาม เราคูณ $(x + 2)(x + 3)$ แล้วได้ $x^2 + 5x + 6$ (ดูแบบจำลองพื้นที่ในภาพด้านบน: สี่ช่องรวมกันคือ $x^2 + 3x + 2x + 6$) งานในบทนี้คือทำ **ย้อนกลับ** คือเริ่มจากพหุนามแล้วเขียนให้อยู่ในรูปผลคูณ เรียกว่า **การแยกตัวประกอบ** คำตอบของแปลงผักจึงเป็นด้าน $x + 2$ เมตร กับ $x + 3$ เมตร

การแยกตัวประกอบเหมือนการแยกตัวประกอบของจำนวน เช่น $12 = 3 \times 4$ ต่างกันแค่ตัวประกอบเป็นนิพจน์ ทักษะนี้ใช้แก้สมการกำลังสอง ทำเศษส่วนพหุนามให้อย่างง่าย และคิดเลขในใจได้เร็วขึ้น

## วิธีที่ 1: ดึงตัวร่วม

ทำเป็นอันดับแรกเสมอ หา ห.ร.ม. ของทุกพจน์ (ทั้งตัวเลขและตัวแปร) แล้วดึงออกมาไว้หน้าวงเล็บ

$$6x^2 + 9x = 3x(2x + 3)$$

ห.ร.ม. ของ 6 กับ 9 คือ 3 และทั้งสองพจน์มี $x$ อย่างน้อยหนึ่งตัว จึงดึง $3x$ ออก ตรวจด้วยการกระจายกลับ: $3x \cdot 2x + 3x \cdot 3 = 6x^2 + 9x$ ✓

## วิธีที่ 2: $x^2 + bx + c$

หาจำนวนสองจำนวน $p$ กับ $q$ ที่ **คูณกันได้ $c$** และ **บวกกันได้ $b$** แล้วเขียน

$$x^2 + bx + c = (x + p)(x + q)$$

### ตัวอย่างที่ 1

แยกตัวประกอบ $x^2 - 2x - 15$

1. ต้องการ $pq = -15$ และ $p + q = -2$
2. ไล่คู่ที่คูณกันได้ $-15$: $(1, -15)$, $(-1, 15)$, $(3, -5)$, $(-3, 5)$
3. คู่ที่บวกกันได้ $-2$ คือ $3$ กับ $-5$
4. คำตอบ $(x + 3)(x - 5)$ ตรวจ: $x^2 - 5x + 3x - 15 = x^2 - 2x - 15$ ✓

เคล็ดลับเรื่องเครื่องหมาย: ถ้า $c$ เป็นบวก $p$ กับ $q$ มีเครื่องหมายเดียวกับ $b$ ถ้า $c$ เป็นลบ $p$ กับ $q$ มีเครื่องหมายต่างกัน

## วิธีที่ 3: $ax^2 + bx + c$ เมื่อ $a \neq 1$

ใช้ "วิธีแยกพจน์กลาง"

### ตัวอย่างที่ 2

แยกตัวประกอบ $2x^2 + 7x + 3$

1. คูณ $a \times c = 2 \times 3 = 6$
2. หาจำนวนสองจำนวนที่คูณกันได้ 6 และบวกกันได้ 7 ได้ 1 กับ 6
3. แยกพจน์กลาง: $2x^2 + x + 6x + 3$
4. จับกลุ่มทีละคู่แล้วดึงตัวร่วม: $x(2x + 1) + 3(2x + 1)$
5. ดึง $(2x + 1)$ ออก ได้ $(2x + 1)(x + 3)$

ตรวจ: $(2x + 1)(x + 3) = 2x^2 + 6x + x + 3 = 2x^2 + 7x + 3$ ✓

## รูปแบบพิเศษที่ควรจำ

**ผลต่างกำลังสอง** สองพจน์ที่เป็นกำลังสองลบกัน

$$a^2 - b^2 = (a + b)(a - b)$$

เช่น $4x^2 - 25 = (2x)^2 - 5^2 = (2x + 5)(2x - 5)$ และใช้คิดเลขเร็วได้ เช่น $87^2 - 13^2 = (100)(74) = 7400$

**กำลังสองสมบูรณ์** พจน์แรกและพจน์สุดท้ายเป็นกำลังสอง และพจน์กลางเท่ากับสองเท่าของผลคูณของรากทั้งสอง

$$a^2 + 2ab + b^2 = (a + b)^2 \qquad a^2 - 2ab + b^2 = (a - b)^2$$

เช่น $x^2 + 10x + 25 = (x + 5)^2$ เพราะ $2 \times x \times 5 = 10x$ แต่ $x^2 + 6x + 36$ ไม่ใช่กำลังสองสมบูรณ์ เพราะพจน์กลางต้องเป็น $12x$

## วิธีที่ 4: จับกลุ่มเมื่อมีสี่พจน์

ถ้าพหุนามมีสี่พจน์และไม่มีตัวร่วมของทุกพจน์ ลองจับคู่ทีละสองพจน์ แล้วดึงตัวร่วมของแต่ละคู่ ถ้าวงเล็บที่เหลือเหมือนกัน ก็ดึงวงเล็บนั้นออกได้อีกชั้น

$$x^3 - 2x^2 - 9x + 18 = x^2(x - 2) - 9(x - 2) = (x - 2)(x^2 - 9) = (x - 2)(x + 3)(x - 3)$$

ระวังเครื่องหมาย: คู่หลังคือ $-9x + 18$ ดึง $-9$ ออก จึงเหลือ $(x - 2)$ ถ้าดึง $+9$ จะได้ $(-x + 2)$ ซึ่งไม่ตรงกับคู่แรก

## มองโครงสร้างก่อนลงมือ

บางนิพจน์ดูไม่คุ้น แต่ถ้ามองทั้งก้อนเป็นตัวแปรใหม่ ก็จะเห็นรูปที่รู้จัก

- $x^4 - 81 = (x^2)^2 - 9^2 = (x^2 + 9)(x^2 - 9) = (x^2 + 9)(x + 3)(x - 3)$ ส่วน $x^2 + 9$ (ผลบวกกำลังสอง) แยกต่อด้วยจำนวนจริงไม่ได้
- $x^4 - 10x^2 + 9$ ให้ $u = x^2$ จะได้ $u^2 - 10u + 9 = (u - 1)(u - 9)$ แล้วแทนกลับเป็น $(x^2 - 1)(x^2 - 9)$ ซึ่งยังแยกต่อได้เป็น $(x + 1)(x - 1)(x + 3)(x - 3)$
- ใช้คิดเลขในใจ: $99 \times 101 = (100 - 1)(100 + 1) = 100^2 - 1^2 = 9999$

## ใช้รูปผลคูณหาค่าที่ทำให้เป็นศูนย์

**สมบัติผลคูณเป็นศูนย์:** ถ้า $A \times B = 0$ แล้ว $A = 0$ หรือ $B = 0$ อย่างน้อยหนึ่งตัว รูปผลคูณจึงบอกทันทีว่า $x$ ใดทำให้พหุนามเป็นศูนย์

เช่น $y = x^2 - 2x - 3 = (x + 1)(x - 3)$ จะเป็นศูนย์เมื่อ $x + 1 = 0$ หรือ $x - 3 = 0$ คือ $x = -1$ หรือ $x = 3$ จุดเหล่านี้คือจุดที่กราฟตัดแกน $x$ (ดูภาพหลังบทอ่าน) สังเกตว่าเครื่องหมายกลับกัน วงเล็บ $(x + 1)$ ให้ $x = -1$ ไม่ใช่ $+1$

ถ้าสัมประสิทธิ์ของ $x^2$ เป็นลบ ให้ดึง $-1$ (หรือจำนวนลบ) ออกก่อน เช่น $-x^2 + x + 12 = -(x^2 - x - 12) = -(x - 4)(x + 3)$

## ลำดับการคิด

1. ดึงตัวร่วมก่อนเสมอ
2. ดูจำนวนพจน์: สองพจน์ลองผลต่างกำลังสอง สามพจน์ลองกำลังสองสมบูรณ์หรือหาคู่ $p, q$ สี่พจน์ลองจับกลุ่ม
3. ดูว่าตัวประกอบที่ได้ยังแยกต่อได้อีกไหม เช่น $3x^3 - 12x = 3x(x^2 - 4) = 3x(x + 2)(x - 2)$
4. กระจายกลับเพื่อตรวจคำตอบทุกครั้ง

พหุนามบางตัวแยกตัวประกอบเป็นจำนวนเต็มไม่ได้ เช่น $x^2 + x + 1$ เพราะไม่มีจำนวนเต็มสองจำนวนที่คูณกันได้ 1 และบวกกันได้ 1 ถ้าไล่คู่ครบทุกคู่แล้วไม่เจอ ก็สรุปได้เลย ไม่ต้องฝืน ในบทสมการกำลังสองจะมีสูตรที่ใช้ได้แม้แยกตัวประกอบไม่ได้

## ข้อผิดพลาดที่พบบ่อย

- **ดึงตัวร่วมไม่ครบทุกพจน์** เช่น เขียน $6x + 9 = 3(2x + 9)$ ลืมหาร 9 ด้วย 3
- **หาคู่ที่คูณกันถูกแต่บวกกันผิด** เช่น ตอบ $x^2 + 7x + 12 = (x + 2)(x + 6)$ ซึ่งกระจายได้ $x^2 + 8x + 12$
- **เครื่องหมายสลับ** เช่น ตอบ $x^2 - 2x - 15 = (x + 5)(x - 3)$ ซึ่งให้พจน์กลาง $+2x$
- **ลืมยกกำลังสองสัมประสิทธิ์** เช่น ตอบ $4x^2 - 25 = (4x + 5)(4x - 5)$ ที่ถูกคือ $(2x)^2 = 4x^2$ จึงใช้ $2x$
- **หยุดเร็วเกินไป** เช่น ตอบ $3x(x^2 - 4)$ ทั้งที่ $x^2 - 4$ ยังแยกได้อีก
- **อ่านค่าศูนย์ผิดเครื่องหมาย** $(x + 4)(x - 2) = 0$ ให้ $x = -4$ หรือ $x = 2$ ไม่ใช่ $4$ กับ $-2$

ทุกข้อจับได้ด้วยการกระจายกลับ ใช้เวลาไม่ถึงนาที
