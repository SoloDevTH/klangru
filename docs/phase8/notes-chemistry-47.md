# บันทึกชุดงาน chemistry-47 (เฟส 8)

เคมี 8 หัวข้อจาก `proposals-science-core.yaml` (ม.1–ม.3), `proposals-science-additional.yaml` (ม.4–ม.6) และแถว `extend:` ใน `proposals-international.yaml` กับ `proposals-science-core.yaml` ไฟล์จับคู่อยู่ใน `docs/phase8/mappings/` ครบทุกตัวชี้วัดที่แผนผูกไว้ (ตรวจด้วยสคริปต์ว่าไม่ขาดและไม่เกิน)

ภาพทุกภาพวาดเองจากสคริปต์ Python ที่คำนวณพิกัด (scratchpad `phase8-chemistry-47/fig_*.py`) เรนเดอร์เป็น PNG ด้วย Chromium และเปิดตรวจทุกภาพ ภาพในโจทย์ไม่มีป้ายเฉลย ทุกคำตอบและค่า misconception คำนวณด้วย python3 และทุกสมการในบทเรียนและโจทย์ตรวจการดุลอะตอมและประจุด้วยสคริปต์ (`bal.py`) มวลอะตอมใช้ค่าย่อของ IUPAC แบบเดียวกับชุด chemistry-34/40 ปริมาตรแก๊สที่ STP 22.4 dm³ ลิงก์วิกิพีเดียอังกฤษและ OpenStax ได้ HTTP 200 ทุกลิงก์ หน้าวิกิพีเดียไทยตรวจผ่าน REST API (ดูหมายเหตุท้ายไฟล์) PhET ที่ใช้เป็น HTML5 (build-a-molecule, balancing-chemical-equations, reactants-products-and-leftovers) ส่วน reactions-and-rates ไม่มีฉบับ HTML5 จึงใช้กราฟโต้ตอบ function-plot แทนในหัวข้ออัตราการเกิดปฏิกิริยา

ไฟล์โมเลกุลใหม่ (`content/_assets/molecules/`): 7843 บิวเทน, 6360 2-เมทิลโพรเพน, 176 กรดแอซีติก (ตรวจแล้วว่ายังไม่มีในคลัง ดึงด้วย `npm run fetch-assets` ได้โครงสร้าง 3 มิติทั้งหมด) เอทานอล (702) กับไดเมทิลอีเทอร์ (8254) มีอยู่แล้วจากชุด chemistry-40

ตามคำสั่งผู้ประสานงาน เพิ่ม `chemistry.stoichiometry.reactions` ใน prerequisites ของ `content/chemistry/gas-laws/topic.yaml` (แก้บรรทัดเดียว)
