## เมื่อการแทนค่าใช้ไม่ได้

ใน[บทปริพันธ์จำกัดเขต](/topic/math.calculus.definite-integral/) เราย้อนกฎลูกโซ่ด้วยการแทนค่า แต่ปริพันธ์อย่าง $\int x e^{x}\,dx$ ไม่มีฟังก์ชันชั้นในที่อนุพันธ์คูณอยู่ การแทนค่าจึงไม่ช่วย บทนี้รวบรวมเทคนิคสี่อย่างที่ใช้บ่อยที่สุดในวิศวกรรมและวิทยาศาสตร์: ปริพันธ์ทีละส่วน ปริพันธ์ของฟังก์ชันตรีโกณมิติ เศษส่วนย่อย และปริพันธ์ไม่ตรงแบบ ทุกคำตอบตรวจได้ด้วยการหาอนุพันธ์กลับตาม[กฎการหาอนุพันธ์](/topic/math.calculus.differentiation-rules/)

## ปริพันธ์ทีละส่วน

กฎผลคูณ $(uv)' = u'v + uv'$ เมื่อหาปริพันธ์ทั้งสองข้างแล้วจัดใหม่ ได้

$$\int u\,dv = uv - \int v\,du$$

เลือก $u$ เป็นส่วนที่หาอนุพันธ์แล้ว "ง่ายลง" และ $dv$ เป็นส่วนที่หาปฏิยานุพันธ์ได้ ลำดับช่วยจำ **LIATE** (ลอการิทึม ตรีโกณผกผัน พีชคณิต ตรีโกณ เอกซ์โพเนนเชียล) บอกว่าชนิดที่มาก่อนควรเป็น $u$

ตัวอย่าง $\int x\sin x\,dx$ ให้ $u = x$, $dv = \sin x\,dx$ จะได้ $du = dx$, $v = -\cos x$

$$\int x\sin x\,dx = -x\cos x + \int \cos x\,dx = -x\cos x + \sin x + C$$

ถ้าเลือกกลับ ($u = \sin x$, $dv = x\,dx$) จะได้ $\int \tfrac{x^2}{2}\cos x\,dx$ ซึ่งยากกว่าเดิม นี่คือสัญญาณว่าเลือกผิด บางครั้งต้องทำซ้ำสองรอบ เช่น $x^2 e^{x}$ และบางครั้งทำสองรอบแล้วได้ปริพันธ์เดิมกลับมา เช่น $\int e^{x}\sin x\,dx$ ให้ย้ายข้างแล้วแก้สมการหาปริพันธ์นั้น ฟังก์ชันที่ดูเหมือนมีตัวเดียวอย่าง $\ln x$ ก็ใช้วิธีนี้ได้โดยให้ $dv = dx$

สำหรับปริพันธ์จำกัดเขต: $\displaystyle\int_a^b u\,dv = \Big[uv\Big]_a^b - \int_a^b v\,du$

## ปริพันธ์ของฟังก์ชันตรีโกณมิติ

ปริพันธ์รูป $\int \sin^m x\cos^n x\,dx$ ใช้เอกลักษณ์ $\sin^2 x + \cos^2 x = 1$

- **มีกำลังคี่อย่างน้อยหนึ่งตัว** แยกตัวกำลังคี่ออกมาหนึ่งตัว เปลี่ยนที่เหลือด้วยเอกลักษณ์ แล้วแทนค่า เช่น $\int \sin^2 x\cos^3 x\,dx = \int \sin^2 x(1 - \sin^2 x)\cos x\,dx$ ให้ $u = \sin x$ ได้ $\tfrac{\sin^3 x}{3} - \tfrac{\sin^5 x}{5} + C$
- **กำลังคู่ทั้งคู่** ลดกำลังด้วยสูตรมุมสองเท่า $\sin^2 x = \tfrac{1 - \cos 2x}{2}$ และ $\cos^2 x = \tfrac{1 + \cos 2x}{2}$

ปริพันธ์ $\int \tan^m x\sec^n x\,dx$ ใช้แนวคิดเดียวกันกับ $1 + \tan^2 x = \sec^2 x$ และ $(\tan x)' = \sec^2 x$

## เศษส่วนย่อย

ฟังก์ชันตรรกยะ $\dfrac{P(x)}{Q(x)}$ แยกเป็นผลบวกของเศษส่วนที่หาปริพันธ์ได้ทันที ขั้นตอนคือ

1. ถ้าดีกรีของ $P$ ไม่น้อยกว่าดีกรีของ $Q$ ให้หารยาวก่อน
2. แยกตัวประกอบ $Q(x)$
3. ตัวประกอบเชิงเส้น $(x - a)$ ให้พจน์ $\dfrac{A}{x - a}$ ตัวประกอบซ้ำ $(x - a)^2$ ให้ $\dfrac{A}{x - a} + \dfrac{B}{(x - a)^2}$ และตัวประกอบกำลังสองที่แยกไม่ได้ $x^2 + k^2$ ให้ $\dfrac{Ax + B}{x^2 + k^2}$
4. คูณ $Q(x)$ ตลอด แล้วแทนค่า $x$ ที่ทำให้ตัวประกอบเป็นศูนย์ หรือเทียบสัมประสิทธิ์ เพื่อหาค่าคงตัว
5. หาปริพันธ์ทีละพจน์: $\int \tfrac{dx}{x - a} = \ln|x - a| + C$ และ $\int \tfrac{dx}{x^2 + k^2} = \tfrac1k\arctan\tfrac{x}{k} + C$

## ปริพันธ์ไม่ตรงแบบ

ปริพันธ์ที่ขอบเขตเป็นอนันต์ หรือฟังก์ชันไม่มีขอบเขตในช่วง นิยามด้วยลิมิต

$$\int_a^{\infty} f(x)\,dx = \lim_{b \to \infty}\int_a^b f(x)\,dx$$

ถ้าลิมิตมีค่าจำกัด ปริพันธ์ **ลู่เข้า** ถ้าไม่มี ปริพันธ์ **ลู่ออก** ภาพด้านล่างเทียบสองกรณี $\int_1^{\infty}\tfrac{dx}{x^2} = \lim_{b\to\infty}\big(1 - \tfrac1b\big) = 1$ แต่ $\int_1^{\infty}\tfrac{dx}{x} = \lim_{b\to\infty}\ln b$ ไม่มีค่าจำกัด แม้กราฟทั้งสองจะเข้าใกล้แกน $x$ เหมือนกัน โดยทั่วไป $\int_1^{\infty}\tfrac{dx}{x^p}$ ลู่เข้าเมื่อ $p > 1$ เท่านั้น

ถ้าฟังก์ชันพุ่งเป็นอนันต์ที่ขอบ เช่น $\int_0^1 \tfrac{dx}{\sqrt{x}}$ ก็ใช้ลิมิต $\lim_{a\to0^+}\big[2\sqrt{x}\big]_a^1 = 2$ ลู่เข้า ส่วนถ้าจุดที่ไม่มีขอบเขตอยู่กลางช่วง ต้องแยกปริพันธ์เป็นสองส่วนก่อน ถ้าหาค่าตรงไม่ได้ ใช้ **การทดสอบโดยการเปรียบเทียบ**: ถ้า $0 \le f(x) \le g(x)$ และ $\int g$ ลู่เข้า แล้ว $\int f$ ลู่เข้าด้วย

ปริพันธ์ไม่ตรงแบบพบบ่อยในงานจริง เช่น ปริมาณยาที่ร่างกายได้รับทั้งหมด (พื้นที่ใต้กราฟความเข้มข้นตั้งแต่ $t = 0$ ถึง $\infty$) หรือมูลค่าปัจจุบันของรายได้ที่ได้รับไปเรื่อย ๆ

## ข้อผิดพลาดที่พบบ่อย

- เลือก $u$ กับ $dv$ กลับกันจนปริพันธ์ใหม่ยากกว่าเดิม
- ลืมเครื่องหมายลบใน $uv - \int v\,du$ หรือในปฏิยานุพันธ์ของ $\sin x$
- ลดกำลังด้วยสูตรมุมสองเท่าแต่ลืมหารด้วย 2
- ทำเศษส่วนย่อยโดยไม่หารยาวก่อนเมื่อดีกรีตัวเศษไม่น้อยกว่าตัวส่วน
- ใช้ทฤษฎีบทหลักมูลตรง ๆ กับ $\int_{-1}^{1}\tfrac{dx}{x^2}$ ทั้งที่ฟังก์ชันไม่มีขอบเขตที่ $x = 0$
- คิดว่ากราฟเข้าใกล้ศูนย์แล้วพื้นที่ต้องจำกัดเสมอ
