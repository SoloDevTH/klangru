## ตู้เติมเงินหน้าร้านก็เป็นระบบคอมพิวเตอร์

เมื่อเราเสียบธนบัตร 20 บาทเข้าตู้เติมเงินหน้าร้าน แล้วกดเบอร์โทรศัพท์ ตู้จะอ่านธนบัตร ตรวจว่าเป็นของจริง คำนวณยอด ส่งข้อมูลไปยังบริษัทโทรศัพท์ แล้วพิมพ์ใบเสร็จ ตู้นี้คือ **ระบบคอมพิวเตอร์** ซึ่งมีองค์ประกอบ 3 ส่วนทำงานร่วมกัน

- **ฮาร์ดแวร์** ส่วนที่จับต้องได้ เช่น ช่องรับธนบัตร ปุ่มกด จอ เครื่องพิมพ์ใบเสร็จ
- **ซอฟต์แวร์** ชุดคำสั่งที่บอกฮาร์ดแวร์ว่าต้องทำอะไร
- **ผู้ใช้** คนที่ใส่ข้อมูลเข้าและใช้ผลลัพธ์

## ฮาร์ดแวร์ 5 หน่วย

คอมพิวเตอร์ทุกแบบ ตั้งแต่สมาร์ตโฟนถึงเครื่องแม่ข่าย มีหน่วยหลักเหมือนกัน (ดูแผนภาพหลังบทอ่านนี้)

1. **หน่วยรับเข้า (input)** รับข้อมูลจากภายนอก เช่น แป้นพิมพ์ เมาส์ ไมโครโฟน กล้อง จอสัมผัส เซนเซอร์อุณหภูมิ
2. **หน่วยประมวลผลกลาง (CPU)** มี **หน่วยควบคุม (CU)** ที่ดึงและถอดรหัสคำสั่งแล้วสั่งส่วนอื่น **หน่วยคำนวณและตรรกะ (ALU)** ที่บวก ลบ และเปรียบเทียบ และ **รีจิสเตอร์** ที่เก็บค่าที่กำลังใช้
3. **หน่วยความจำหลัก** RAM เก็บโปรแกรมและข้อมูลที่กำลังทำงาน ข้อมูลหายเมื่อไฟดับ ส่วน ROM เก็บโปรแกรมเริ่มเครื่องไว้ถาวร
4. **หน่วยเก็บถาวร** เช่น SSD ฮาร์ดดิสก์ แฟลชไดรฟ์ เก็บไฟล์ไว้แม้ปิดเครื่อง
5. **หน่วยส่งออก (output)** แสดงผล เช่น จอภาพ ลำโพง เครื่องพิมพ์ มอเตอร์

ชิ้นส่วนที่อยู่ในตัวเครื่อง (CPU, RAM, เมนบอร์ด, SSD) เรียกว่า **ส่วนภายใน** ส่วนอุปกรณ์ที่ต่อเพิ่ม (เมาส์ เครื่องพิมพ์ ลำโพง) เรียกว่า **อุปกรณ์ต่อพ่วง** ทุกหน่วยส่งข้อมูลถึงกันผ่าน **บัส** ซึ่งเป็นทางเดินของสัญญาณบนเมนบอร์ด

## ซอฟต์แวร์ทำงานคู่กับฮาร์ดแวร์

ซอฟต์แวร์แบ่งเป็น **ซอฟต์แวร์ระบบ** เช่น ระบบปฏิบัติการ (Windows, Android, Linux) และไดรเวอร์ที่คุยกับฮาร์ดแวร์แต่ละชิ้น กับ **ซอฟต์แวร์ประยุกต์** ที่ผู้ใช้ใช้ทำงาน เช่น โปรแกรมพิมพ์งาน เกม เบราว์เซอร์

เมื่อกดตัว ก บนแป้นพิมพ์: แป้นพิมพ์ส่งรหัสของปุ่ม → ไดรเวอร์และระบบปฏิบัติการรับรหัส → โปรแกรมพิมพ์งานเพิ่ม ก ลงในเอกสารที่อยู่ใน RAM → สั่งวาดตัวอักษร → จอแสดง ก ทุกขั้นต้องมีทั้งฮาร์ดแวร์และซอฟต์แวร์

## วงรอบดึง ถอดรหัส และทำคำสั่ง

คอมพิวเตอร์ส่วนใหญ่ใช้ **สถาปัตยกรรมฟอน นอยมันน์** คือเก็บทั้งคำสั่งและข้อมูลไว้ในหน่วยความจำเดียวกัน แล้ว CPU ทำงานเป็นวงรอบ

1. **ดึง (fetch)** อ่านที่อยู่จาก **ตัวนับโปรแกรม (PC)** แล้วดึงคำสั่งที่ที่อยู่นั้นมาไว้ใน **รีจิสเตอร์คำสั่ง (IR)** จากนั้นเพิ่ม PC ให้ชี้คำสั่งถัดไป
2. **ถอดรหัส (decode)** หน่วยควบคุมแปลว่าคำสั่งให้ทำอะไรกับข้อมูลใด
3. **ทำคำสั่ง (execute)** ALU คำนวณหรือย้ายข้อมูล แล้วเก็บผล เช่น ไว้ในรีจิสเตอร์ **ACC**

**สัญญาณนาฬิกา** กำหนดจังหวะ CPU ความถี่ 3 GHz มี 3 พันล้านจังหวะต่อวินาที CPU สมัยใหม่มี **หลายแกน (core)** แต่ละแกนทำวงรอบนี้ได้พร้อมกัน แต่โปรแกรมจะเร็วขึ้นเฉพาะส่วนที่แบ่งงานให้หลายแกนทำพร้อมกันได้

## ลำดับชั้นหน่วยความจำ

CPU เร็วกว่า RAM มาก ถ้าต้องรอ RAM ทุกครั้งจะเสียเวลา จึงจัดหน่วยความจำเป็นชั้น (ดูภาพพีระมิด) ชั้นบนเร็วแต่จุน้อยและแพง ชั้นล่างช้าแต่จุมากและถูก **แคช** เก็บสำเนาของข้อมูลที่เพิ่งใช้หรือใช้บ่อย ถ้าหาเจอในแคชก็ไม่ต้องรอ RAM เมื่อเปิดแอป ระบบจะคัดลอกแอปจาก SSD มาไว้ใน RAM ก่อน CPU จึงทำงานกับมันได้

## สเปกกับการเลือกเครื่อง

- **CPU** จำนวนแกนและความถี่ ช่วยงานคำนวณหนัก เช่น ตัดต่อวิดีโอ
- **RAM** ยิ่งมาก ยิ่งเปิดหลายโปรแกรมหรือไฟล์ใหญ่ได้โดยไม่ช้า
- **SSD** เปิดเครื่องและโหลดไฟล์เร็วกว่าฮาร์ดดิสก์มาก แต่ราคาต่อ GB สูงกว่า
- **การ์ดจอ (GPU)** ช่วยงานภาพ เกม และการฝึกปัญญาประดิษฐ์

ต้องเลือกให้ตรงกับงาน เครื่องสำหรับพิมพ์รายงานไม่จำเป็นต้องมีการ์ดจอแรง

## การสื่อสารระหว่างอุปกรณ์

การสื่อสารข้อมูลมี **ผู้ส่ง สื่อกลาง ผู้รับ** และ **โพรโทคอล** (กติกาที่ตกลงกัน) สื่อกลางมีทั้งแบบมีสาย เช่น สาย USB สาย LAN ใยแก้วนำแสง และแบบไร้สาย เช่น Wi-Fi บลูทูท ความเร็วบอกเป็น **บิตต่อวินาที (bps)** เช่น อินเทอร์เน็ตบ้าน 100 Mbps คือ 100 ล้านบิตต่อวินาที เมื่ออุปกรณ์มีข้อมูลเข้า เช่น กดปุ่ม มันจะส่ง **สัญญาณขัดจังหวะ (interrupt)** ให้ CPU พักงานที่ทำอยู่สั้น ๆ มารับข้อมูลก่อน

## ข้อผิดพลาดที่พบบ่อย

- **สับสน RAM กับหน่วยเก็บถาวร** RAM ใช้ระหว่างทำงานและหายเมื่อไฟดับ ไฟล์ที่บันทึกแล้วอยู่ใน SSD
- **สับสนบิตกับไบต์** 1 ไบต์ = 8 บิต ความเร็วเน็ตบอกเป็นบิต ขนาดไฟล์บอกเป็นไบต์
- **คิดว่าแกนมากขึ้น โปรแกรมเร็วขึ้นเท่านั้นเสมอ** ส่วนที่ทำทีละขั้นยังต้องรอ
- **คิดว่า CPU รู้เองว่าต้องทำอะไร** CPU ทำตามคำสั่งในหน่วยความจำทีละคำสั่งเท่านั้น
- **เรียกทุกอย่างในเครื่องว่าซีพียู** ซีพียูคือชิปประมวลผล ไม่ใช่ทั้งกล่องคอมพิวเตอร์
