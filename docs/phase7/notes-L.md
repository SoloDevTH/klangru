หัวข้อในชุด: เคมี 3 หัวข้อ ภาษาไทย 3 หัวข้อ ภาษาอังกฤษ 3 หัวข้อ ภาษาจีน 3 หัวข้อ

ทุกหัวข้อได้ตัวอย่างแสดงวิธีทำ 2 ตัวอย่าง (ง่าย และกลางถึงยาก) คำถามชวนคิด 2 ข้อ (อ้างโจทย์ระดับ 1–3) และภาพที่วาดเองเป็น SVG ด้วยสคริปต์ ทุกภาพเรนเดอร์เป็น PNG ด้วย Chromium และตรวจด้วยตาแล้ว รวมทั้งข้อความไทยและจีนในภาพ ชุดนี้ไม่ได้ใช้ภาพจาก Commons สคริปต์วาดภาพอยู่ในโฟลเดอร์ scratchpad `phase7-L/` (`*_fig.py`) ตัวเลขเคมีทุกตัวคำนวณด้วย python3

`npm run validate -- --strict --only=<12 โฟลเดอร์ของชุดนี้>` ได้ 0 error 0 warning และ `npm test` ผ่าน 30/30 ข้อ ส่วน validate ทั้งคลังมีคำเตือนจากโฟลเดอร์ที่ agent อื่นกำลังทำ (`physics/magnetic-field`, `math/data-display`: ภาพที่ยังไม่ได้ใช้) ไม่ใช่ของชุดนี้

## เรื่องที่ไม่แน่ใจ

- เส้นระดับเสียงวรรณยุกต์ไทยในภาพเป็นค่าประมาณตามตำราสัทศาสตร์ทั่วไป (สามัญ 33 เอก 21 โท 41 ตรี 45 จัตวา 14) ผู้เชี่ยวชาญอาจใช้ค่าต่างกันเล็กน้อย
- การจัดประเภทใน `periodic-map.svg`: ใช้กึ่งโลหะ 6 ตัวที่ยอมรับกันทั่วไป (B Si Ge As Sb Te) ส่วน At และ Po นับเป็นโลหะ ตำราไทยบางเล่มนับ At เป็นกึ่งโลหะ และธาตุ 113–117 ระบายเป็นโลหะทั้งที่ยังไม่ทราบสมบัติแน่ชัด
- `thai.word.p016` ใช้ลักษณนาม รูป สำหรับพระภิกษุ และ องค์ สำหรับพระพุทธรูป ตามแนวราชบัณฑิตฯ ในภาษาพูดบางถิ่นใช้ องค์ กับพระภิกษุด้วย
- `zh.num` บทเรียนบอกว่า 110 อ่าน yìbǎi yīshí (一 ใน 一十 ไม่เปลี่ยนเสียงเมื่ออยู่ในเลข) ควรให้ผู้สอนภาษาจีนตรวจ
- โจทย์ชนิด text ที่มีสองช่อง (เช่น `eng.pres.p022`, `eng.past.p021`, `eng.perf.p017`) รองรับรูปแบบการพิมพ์หลายแบบใน `accepted` แต่ผู้เรียนอาจคั่นด้วยรูปแบบอื่น ควรดูสถิติการตอบจริง
