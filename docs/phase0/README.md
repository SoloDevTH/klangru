## เกณฑ์ผ่านเฟส 0 (จากแผนงาน)

1. **schema v1 ผ่านการทดลองเขียน 10 หัวข้อจริง**: ✅ ผ่าน `npm run validate -- --strict` (ไม่มี error และไม่มีคำเตือน)
2. **prototype หน้าจอได้รับความเห็นจากผู้เรียน 5 คน**: ⬜ ยังไม่ได้ทำ

## สิ่งที่ได้เรียนรู้จากการเขียนหัวข้อจริง

- ชนิดโจทย์ `text` ตรวจสมการได้แค่แบบเทียบข้อความ ผู้เขียนต้องเดารูปแบบที่ผู้เรียนจะพิมพ์ (เช่น `h=2A/b`, `2A/b`, `h=(2A)/b`) และรูปที่เท่ากันแต่เขียนต่างไปจะถูกตัดสินว่าผิด จึงควรเลื่อนชนิด `expression` (MathLive + Compute Engine) มาไว้ในเฟส 1
- รหัสตัวชี้วัดหลักสูตรไทย (`curriculum_tags`) ยังว่างเกือบทั้งหมด เพราะต้องยืนยันกับเอกสารหลักสูตรจริงก่อน ควรมีครูช่วยใส่
- บล็อกซิมูเลชันของ PhET ต้องตรวจทีละลิงก์ เพราะบางหน้า (เช่น The Moving Man) โหลดไม่ได้
- เนื้อหาทั้ง 10 หัวข้อร่างโดย AI แล้วตรวจคำตอบทุกข้อด้วยการคำนวณซ้ำ แต่ยังไม่ผ่านผู้เชี่ยวชาญวิชา บทเรียนตัวอย่าง `linear-equations` ยาวราว 370 คำ สั้นกว่าเกณฑ์ 500 คำในคู่มือ ควรเติมตัวอย่างอีก 1 ข้อ

## การทดสอบที่ทำแล้ว

- เทสต์หน่วย: เครื่องมือเนื้อหา 13 เทสต์, ตรรกะตรวจคำตอบและระดับความชำนาญ 7 เทสต์
- เดินผ่านเว็บที่ build แล้วด้วย Playwright: ทำโจทย์ครบ 3 หัวข้อ (ตอบผิดเพื่อดู feedback, ขอคำใบ้, ดูเฉลย), หน้าทบทวน, หน้าความคืบหน้า, เดสก์ท็อปโหมดมืด และเปิดหน้าบทเรียนกับหน้าโจทย์ครบทั้ง 20 หน้าที่ความกว้างมือถือ 412 px ไม่พบ error ในคอนโซล และไม่มีหน้าที่กว้างเกินจอ
