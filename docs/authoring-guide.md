# คู่มือเขียนเนื้อหา

ใช้หัวข้อ `content/math/linear-equations/` เป็นตัวอย่างอ้างอิง กฎทั้งหมดของ schema อยู่ใน `docs/decisions/0004-content-model.md`

## เพิ่มหัวข้อใหม่

1. สร้างโฟลเดอร์ `content/<วิชา>/<ชื่อหัวข้อภาษาอังกฤษ>/`
2. คัดลอก `topic.yaml`, `lesson.md` และ `problems.yaml` จากหัวข้อตัวอย่าง แล้วแก้ไข
3. ตั้ง `id` ใหม่ที่ไม่ซ้ำ และใส่ `prerequisites` ให้ครบ
4. รัน `npm run validate` แก้จนไม่มี error
5. รัน `npm run dev` แล้วเปิดหัวข้อในเบราว์เซอร์ ลองทำโจทย์เองทุกข้อ
6. เปิด Pull Request ให้ผู้ตรวจอีกคนดู

## ชุดเนื้อหาต่อหัวข้อ

- **บทเรียน** 500–900 คำ เรียงเป็น: อธิบายด้วยภาพหรือสถานการณ์จริง → หลักการหรือสูตร → ตัวอย่างพร้อมวิธีทำอย่างน้อย 2 ข้อ → ข้อผิดพลาดที่พบบ่อย
- **คำสำคัญ** 2–4 คำ และ **แฟลชการ์ด** 3–5 ใบ
- **โจทย์** อย่างน้อย 7 ข้อ (เป้าหมายเฟส 1 คือ 10 ข้อ) ความยากอย่างน้อย 3 ระดับ ใช้ชนิดโจทย์อย่างน้อย 3 แบบ มีโจทย์สถานการณ์จริงอย่างน้อย 2 ข้อ

## เขียนโจทย์ให้ดี

- **คำใบ้** ไล่จากกว้างไปเฉพาะ: ข้อแรกชี้ว่าควรคิดเรื่องอะไร ข้อสุดท้ายบอกวิธี แต่ไม่บอกตัวเลขคำตอบ
- **misconception** ให้คิดว่านักเรียนจะผิดแบบไหน แล้วคำนวณ "คำตอบผิด" ที่ความผิดนั้นให้ออกมาจริง ๆ ใส่ไว้พร้อมคำอธิบายว่าผิดตรงไหน
- **ตัวเลือกหลอกใน mcq** ทุกตัวต้องมาจากความผิดที่เกิดขึ้นได้จริง และต้องมี `feedback`
- **หน่วย** ใส่ใน `answer.unit` และบอกในโจทย์ว่าต้องตอบเป็นหน่วยอะไร
- **ทศนิยม** ใส่ `tolerance` เสมอเมื่อคำตอบไม่ใช่จำนวนเต็ม
- **ตรวจคำตอบทุกข้อด้วยการคำนวณจริง** คำตอบผิดในแอปเรียนสร้างความเสียหายมากที่สุด

## สมการ

- ในบรรทัด: `$x^2 + 1$` แยกบรรทัด: `$$\frac{a}{b}$$`
- ใน YAML ที่ใช้เครื่องหมายคำพูดคู่ ต้องเขียน backslash สองตัว: `"$\\frac{1}{2}$"`
- หน่วยในสมการ: `$9.8\,\mathrm{m/s^2}$`

## สถานะและ AI

- เนื้อหาใหม่เริ่มที่ `status: draft` เมื่อพร้อมให้ตรวจเปลี่ยนเป็น `review` และเมื่อผู้ตรวจที่ไม่ใช่ผู้เขียนอนุมัติแล้ว ใส่ชื่อใน `reviewed_by` แล้วเปลี่ยนเป็น `published`
- ถ้าใช้ AI ช่วยร่าง ให้ตั้ง `ai_assisted: true` แอปจะแสดงให้ผู้เรียนเห็น และผู้ตรวจต้องตรวจทุกตัวเลข
- เนื้อหานำร่องทั้ง 10 หัวข้อในเฟส 0 ร่างโดย AI ทั้งหมด จึงยังเป็น `draft` และต้องผ่านผู้เชี่ยวชาญวิชาก่อนเผยแพร่
