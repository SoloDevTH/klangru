## สองเบาะแส สองตัวที่ไม่รู้

ที่ตลาดนัด นิดซื้อส้ม 2 กิโลกรัมกับมังคุด 1 กิโลกรัม จ่าย 140 บาท ส่วนต้นซื้อส้ม 1 กิโลกรัมกับมังคุด 3 กิโลกรัม จ่าย 220 บาท ส้มและมังคุดราคากิโลกรัมละเท่าไร

ถ้าให้ $x$ แทนราคาส้มต่อกิโลกรัม และ $y$ แทนราคามังคุดต่อกิโลกรัม (หน่วยเป็นบาท) ข้อมูลทั้งสองเขียนเป็นสมการได้

$$2x + y = 140$$

$$x + 3y = 220$$

สมการเดียวมีคำตอบได้หลายคู่ เช่น $2x + y = 140$ อาจเป็น $x = 50, y = 40$ หรือ $x = 40, y = 60$ ก็ได้ แต่เมื่อมีเบาะแสสองข้อ จะเหลือคู่เดียวที่เป็นจริงทั้งสองสมการพร้อมกัน สมการชุดนี้เรียกว่า **ระบบสมการเชิงเส้นสองตัวแปร** และคู่ $(x, y)$ ที่เป็นจริงทั้งสองสมการคือ **คำตอบของระบบ**

## ภาพในกราฟ

สมการเชิงเส้นสองตัวแปรแต่ละสมการเขียนกราฟได้เป็นเส้นตรง จุดบนเส้นคือคู่ $(x, y)$ ที่ทำให้สมการนั้นเป็นจริง คำตอบของระบบจึงเป็น **จุดตัด** ของเส้นตรงสองเส้น ซึ่งมีได้ 3 แบบ

- เส้นตัดกันที่จุดเดียว: มีคำตอบเดียว
- เส้นขนานกัน (ความชันเท่ากันแต่จุดตัดแกน $y$ ต่างกัน): ไม่มีคำตอบ
- เป็นเส้นเดียวกัน: มีคำตอบมากมายไม่จำกัด

การอ่านจากกราฟช่วยให้เห็นภาพ แต่ถ้าคำตอบไม่ใช่จำนวนเต็มจะอ่านได้ไม่แม่นยำ จึงต้องใช้วิธีทางพีชคณิต 2 วิธีต่อไปนี้

## วิธีแทนค่า

แนวคิดคือทำให้เหลือตัวแปรเดียว แล้วใช้วิธีแก้สมการเชิงเส้นที่เรารู้อยู่แล้ว

### ตัวอย่างที่ 1: ราคาส้มกับมังคุด

1. จัดสมการแรกให้ $y$ อยู่ข้างเดียว: $y = 140 - 2x$
2. แทน $y$ ลงในสมการที่สอง: $x + 3(140 - 2x) = 220$
3. กระจายและแก้สมการ: $x + 420 - 6x = 220$ → $-5x = -200$ → $x = 40$
4. แทน $x = 40$ กลับใน $y = 140 - 2x$: $y = 140 - 80 = 60$
5. ตรวจกับ **ทั้งสองสมการ**: $2(40) + 60 = 140$ ✓ และ $40 + 3(60) = 220$ ✓

ดังนั้นส้มกิโลกรัมละ 40 บาท มังคุดกิโลกรัมละ 60 บาท

## วิธีกำจัดตัวแปร

ถ้าสัมประสิทธิ์ของตัวแปรหนึ่งเป็นจำนวนตรงข้ามกัน การบวกสองสมการเข้าด้วยกันจะทำให้ตัวแปรนั้นหายไป ถ้าเท่ากันให้ลบแทน และถ้ายังไม่เท่าก็คูณสมการด้วยจำนวนที่เหมาะสมก่อน

### ตัวอย่างที่ 2: บวกสมการ

แก้ระบบ $3x + 2y = 16$ และ $5x - 2y = 0$

1. สัมประสิทธิ์ของ $y$ คือ $+2$ กับ $-2$ เป็นจำนวนตรงข้ามกัน จึงบวกสองสมการ: $8x = 16$
2. ได้ $x = 2$
3. แทนในสมการแรก: $3(2) + 2y = 16$ → $2y = 10$ → $y = 5$
4. ตรวจกับสมการที่สอง: $5(2) - 2(5) = 0$ ✓

### ตัวอย่างที่ 3: ต้องคูณก่อน

แก้ระบบ $2x + 3y = 12$ และ $x + y = 5$

1. คูณสมการที่สองด้วย 2: $2x + 2y = 10$
2. ลบออกจากสมการแรก: $(2x + 3y) - (2x + 2y) = 12 - 10$ ได้ $y = 2$
3. แทนใน $x + y = 5$: $x = 3$
4. ตรวจ: $2(3) + 3(2) = 12$ ✓

## เลือกวิธีอย่างไร

ใช้ **วิธีแทนค่า** เมื่อมีสมการที่ตัวแปรหนึ่งอยู่ข้างเดียวอยู่แล้ว เช่น $y = 3x - 2$ ใช้ **วิธีกำจัดตัวแปร** เมื่อสัมประสิทธิ์ของตัวแปรหนึ่งเท่ากันหรือตรงข้ามกัน ทั้งสองวิธีให้คำตอบเดียวกันเสมอ

## ข้อผิดพลาดที่พบบ่อย

- **ตรวจกับสมการเดียว** คำตอบต้องเป็นจริงกับทั้งสองสมการ ถ้าตรวจแค่สมการที่ใช้หา $y$ จะไม่เจอข้อผิดพลาดก่อนหน้า
- **เครื่องหมายผิดเมื่อลบสมการ** ต้องลบทุกพจน์ เช่น $(5x - 2y) - (3x + 2y) = 2x - 4y$ ไม่ใช่ $2x$
- **คูณสมการไม่ครบทุกพจน์** เมื่อคูณสมการด้วย 2 ต้องคูณข้างขวาด้วย
- **ตอบไม่ครบหรือตอบผิดตัว** หา $x$ ได้แล้วอย่าลืมหา $y$ และอ่านโจทย์ให้ดีว่าถามตัวแปรใด
- **ตั้งตัวแปรไม่ชัดเจน** เขียนให้ชัดตั้งแต่ต้นว่า $x$ และ $y$ แทนอะไรและมีหน่วยอะไร
