## ส่งรูปจากกรุงเทพฯ ถึงเชียงใหม่ในพริบตา

ฟ้าถ่ายรูปงานกีฬาสีแล้วส่งให้ยายที่เชียงใหม่ทางแอปแชต ไม่ถึงวินาทียายก็เห็นรูป ระหว่างทาง รูปนั้นผ่านอุปกรณ์หลายสิบเครื่องและสายยาวหลายร้อยกิโลเมตร บทนี้อธิบายว่าข้อมูลเดินทางอย่างไร

## เครือข่ายคืออะไร

**เครือข่ายคอมพิวเตอร์** คืออุปกรณ์ตั้งแต่สองเครื่องที่เชื่อมกันเพื่อส่งข้อมูลและใช้ทรัพยากรร่วมกัน เครือข่ายในบ้านหรือโรงเรียนเรียกว่า **LAN** เครือข่ายที่ครอบคลุมพื้นที่กว้างเรียกว่า **WAN** และ **อินเทอร์เน็ต** คือเครือข่ายของเครือข่ายทั่วโลกที่เชื่อมกัน อุปกรณ์สำคัญ ได้แก่

- **สวิตช์** เชื่อมเครื่องในเครือข่ายเดียวกัน ส่งข้อมูลให้ถึงเครื่องปลายทางในวงนั้น
- **เราเตอร์** เชื่อมเครือข่ายต่างกัน และเลือกเส้นทางส่งต่อข้อมูลไปยังเครือข่ายถัดไป
- **จุดเข้าใช้งานไร้สาย** ให้เครื่องเชื่อมด้วย Wi-Fi
- **เซิร์ฟเวอร์ (แม่ข่าย)** เครื่องที่ให้บริการ เช่น เก็บหน้าเว็บหรือส่งต่อข้อความแชต

## แพ็กเก็ต: แบ่งข้อมูลเป็นชิ้นเล็ก

รูปขนาดหลายเมกะไบต์ไม่ได้ถูกส่งเป็นก้อนเดียว แต่ถูกแบ่งเป็น **แพ็กเก็ต** ขนาดเล็ก (มักไม่เกินราว 1,500 ไบต์) แต่ละแพ็กเก็ตมี **ส่วนหัว** บอกที่อยู่ผู้ส่ง ที่อยู่ผู้รับ และลำดับที่ เราเตอร์แต่ละตัวอ่านที่อยู่ผู้รับแล้วส่งต่อไปทางที่เหมาะในขณะนั้น แพ็กเก็ตของรูปเดียวกันจึงอาจไปคนละเส้นทางและมาถึงไม่เรียงลำดับ ปลายทางใช้ลำดับที่เรียงกลับ และขอให้ส่งใหม่ถ้าชิ้นใดหาย (ดูภาพหลังบทอ่านนี้)

วิธีนี้เรียกว่า **การสลับแพ็กเก็ต (packet switching)** ต่างจากโทรศัพท์บ้านสมัยก่อนที่จองสายทั้งเส้นไว้ตลอดการคุย ข้อดีคือหลายคนใช้สายร่วมกันได้ และถ้าเส้นทางหนึ่งเสีย แพ็กเก็ตก็อ้อมไปทางอื่นได้

## ที่อยู่ IP และ DNS

ทุกอุปกรณ์บนอินเทอร์เน็ตต้องมี **ที่อยู่ IP** เหมือนบ้านเลขที่ **IPv4** เขียนเป็นตัวเลข 4 ชุด ชุดละ 0 ถึง 255 เช่น 192.168.1.20 (32 บิต จึงมีได้ $2^{32}$ ราว 4,300 ล้านที่อยู่ ซึ่งไม่พอสำหรับทุกอุปกรณ์ในโลก จึงมี **IPv6** ยาว 128 บิต)

คนจำตัวเลขยาก จึงใช้ชื่อโดเมน เช่น school.example **ระบบชื่อโดเมน (DNS)** ทำหน้าที่เหมือนสมุดโทรศัพท์ แปลชื่อโดเมนเป็นที่อยู่ IP ก่อนเบราว์เซอร์จะติดต่อเซิร์ฟเวอร์ได้

## โพรโทคอลและชั้นของเครือข่าย

**โพรโทคอล** คือกติกาที่ทุกเครื่องตกลงใช้ร่วมกัน เพื่อให้อุปกรณ์ต่างยี่ห้อคุยกันได้ งานส่งข้อมูลแบ่งเป็น **ชั้น** แต่ละชั้นทำงานของตัวเอง (ดูภาพแบบจำลอง TCP/IP)

1. **ชั้นแอปพลิเคชัน** เช่น HTTP สำหรับหน้าเว็บ DNS สำหรับแปลชื่อ
2. **ชั้นขนส่ง** **TCP** แบ่งข้อมูล ใส่ลำดับ ตรวจว่าครบ และขอส่งซ้ำ เหมาะกับหน้าเว็บและไฟล์ ส่วน **UDP** ส่งเร็วโดยไม่รอตรวจ เหมาะกับวิดีโอคอลและเกมที่ยอมเสียบางชิ้นได้
3. **ชั้นอินเทอร์เน็ต** **IP** ใส่ที่อยู่และพาแพ็กเก็ตข้ามเครือข่ายผ่านเราเตอร์
4. **ชั้นเชื่อมโยง** ส่งเป็นสัญญาณจริงผ่านสาย LAN ใยแก้ว หรือคลื่น Wi-Fi

ผู้ส่งห่อข้อมูลด้วยส่วนหัวทีละชั้นจากบนลงล่าง ผู้รับแกะออกจากล่างขึ้นบน แต่ละชั้นจึงเปลี่ยนเทคโนโลยีได้โดยไม่กระทบชั้นอื่น เช่น เปลี่ยนจากสาย LAN เป็น Wi-Fi โดยหน้าเว็บยังเหมือนเดิม

## ลูกข่าย-แม่ข่าย และ HTTP

เมื่อพิมพ์ที่อยู่เว็บ เบราว์เซอร์ (**ลูกข่าย**) ถาม DNS หา IP แล้วส่ง **คำขอ HTTP** ไปยัง **แม่ข่าย** แม่ข่ายตอบพร้อมรหัสสถานะ เช่น **200** สำเร็จ **404** ไม่พบหน้าที่ขอ แล้วเบราว์เซอร์แสดงหน้าเว็บ **HTTPS** คือ HTTP ที่เข้ารหัส คนกลางที่ดักข้อมูลอ่านไม่ออก เว็บที่ให้กรอกรหัสผ่านต้องเป็น HTTPS เสมอ อีกแบบคือ **เพียร์ทูเพียร์** ที่ทุกเครื่องเป็นทั้งผู้ขอและผู้ให้ เช่น การแชร์ไฟล์บางแบบ

## ลักษณะการเชื่อมต่อ ความทนทาน และการขยาย

**ลักษณะการเชื่อมต่อ (topology)** มีหลายแบบ (ดูภาพ) **แบบดาว** ใช้มากในโรงเรียน ทุกเครื่องต่อกับสวิตช์ เพิ่มเครื่องง่าย แต่ถ้าสวิตช์เสีย ทุกเครื่องในวงนั้นหลุด **แบบตาข่าย** มีหลายเส้นทาง จึงทนทานเมื่อสายบางเส้นขาด แต่ใช้สายมาก ตาข่ายเต็มรูปของ n เครื่องใช้สาย $n(n-1)/2$ เส้น อินเทอร์เน็ตจริงเป็นตาข่ายบางส่วนระหว่างเราเตอร์จำนวนมาก จึงยังทำงานได้แม้บางเส้นทางเสีย และ **ขยายได้** เพราะแบ่งเป็นเครือข่ายย่อยที่มีที่อยู่เป็นลำดับชั้น เราเตอร์ไม่ต้องรู้จักทุกเครื่อง แค่รู้ว่าจะส่งต่อไปทางใด

ข้อมูลบนเครือข่ายไร้สายลอยไปในอากาศ ใครอยู่ใกล้ก็รับสัญญาณได้ จึงต้องตั้งรหัส Wi-Fi แบบ WPA2 หรือ WPA3 และใช้ HTTPS โดยเฉพาะเมื่อใช้ Wi-Fi สาธารณะ

## ข้อผิดพลาดที่พบบ่อย

- **คิดว่าอินเทอร์เน็ตกับเว็บคือสิ่งเดียวกัน** เว็บเป็นบริการหนึ่งบนอินเทอร์เน็ต เช่นเดียวกับอีเมลและแชต
- **คิดว่าข้อมูลส่งเป็นก้อนเดียวทางเดียว** ที่จริงแบ่งเป็นแพ็กเก็ตและอาจไปคนละทาง
- **สับสนสวิตช์กับเราเตอร์** สวิตช์เชื่อมเครื่องในวงเดียวกัน เราเตอร์เชื่อมระหว่างเครือข่าย
- **ใส่ตัวเลขเกิน 255 ในที่อยู่ IPv4** แต่ละชุดมีแค่ 8 บิต
- **ลืมว่าเปิดเว็บต้องผ่าน DNS ก่อน** ถ้า DNS ใช้ไม่ได้ จะเปิดเว็บด้วยชื่อไม่ได้แม้เน็ตยังต่ออยู่
