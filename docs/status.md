## งานที่ต้องใช้คน เรียงตามลำดับ

1. หาครูผู้เชี่ยวชาญตรวจเนื้อหา (เริ่มจากคณิตและฟิสิกส์ซึ่งมีมากที่สุด) เปลี่ยนหัวข้อที่ผ่านเป็น `published` และใส่ `reviewed_by`
2. สร้างโปรเจกต์ Supabase, ตั้ง SMTP และอีเมลรหัส, deploy edge functions, ใส่คีย์ Anthropic
3. เขียนประกาศความเป็นส่วนตัวและให้ผู้รู้ PDPA ตรวจ (ADR 0007)
4. deploy เว็บ static (เช่น Cloudflare Pages หรือ GitHub Pages) และตั้ง `CONTENT_BASE_URL`
5. ทดสอบกับผู้เรียน 20 คน ปรับค่าตั้งต้นของระดับความชำนาญจากผล
6. สร้าง keystore, บัญชี Play Console, ส่ง internal testing
7. เมื่อมีผู้เรียนพอ: อ่านผล A/B และรัน calibrate
