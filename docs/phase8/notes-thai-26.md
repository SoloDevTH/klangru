# บันทึกชุดงาน thai-26 (เฟส 8)

หัวข้อภาษาไทย 7 หัวข้อจาก `docs/phase6/proposals-languages.yaml` ไม่มีแถว `extend:` ที่ผูกกับหัวข้อในชุดนี้ ภาพทุกภาพวาดเป็น SVG ด้วยสคริปต์ (scratchpad `phase8-thai-26/fig_*.py`) เรนเดอร์เป็น PNG ด้วย Chromium และเปิดตรวจทุกภาพแล้ว ไม่มีภาพจาก Commons ตัวอักษรในภาพคัดลายมือ (บ ป พ ฟ ด ต า) วาดเป็นเส้นกลางจากพิกัดที่กำหนดเอง (`letters.py`) แล้วซ้อนกับฟอนต์ Loma (TLWG ฟอนต์มีหัว) เพื่อตรวจรูปร่างและตำแหน่งหัว ไม่ได้ฝังโครงฟอนต์ลงในภาพ โจทย์สร้างด้วย `p_*.py` ผ่าน `build.py` ชุดเดียวกับ english-19 ตัวเลขทุกตัว (ราคา เงินทอน พ.ศ.–ค.ศ. เปอร์เซ็นต์ จำนวนรายการ วันในสัปดาห์) คำนวณด้วย python3 บทเรียนนับด้วย `Intl.Segmenter` ได้ 564–919 คำ ลิงก์อ้างอิงทุกลิงก์ตรวจแล้วได้ HTTP 200 และตรงเรื่อง (เปลี่ยน th:การฟัง ที่ redirect ไป การได้ยิน และ th:ประโยค ที่เป็นหน้าแก้ความกำกวม)

แหล่งความรู้ภาษาไทย: หลักภาษาไทยตามแบบเรียน สพฐ. และพจนานุกรมฉบับราชบัณฑิตยสถาน (เขียนจากความรู้ทั่วไปของหลักภาษา ไม่ได้คัดลอกจากหนังสือ) ผู้ตรวจที่เป็นครูภาษาไทยควรอ่านทุกหัวข้อ

- ข้อเสนอแก้แผน: prerequisite ในแผนว่าง แต่บทเรียนและโจทย์ใช้พยัญชนะตลอด ควรเพิ่ม `thai.writing.consonants` (ไม่ได้แก้เอง)
