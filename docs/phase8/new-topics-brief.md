# เฟส 8: เขียนหัวข้อใหม่ตามแผน (คู่มือผู้เขียนและ agent)

แต่ละชุดงานได้รายการรหัสหัวข้อจากแผนใน `docs/phase6/proposals-*.yaml` ให้เขียนเป็นหัวข้อจริงในคลัง ครบทั้งบทเรียน โจทย์ ตัวช่วยสอน และภาพประกอบ ในมาตรฐานเดียวกับหัวข้อที่เติมแล้วในเฟส 7

## อ่านก่อน

1. `docs/phase1/authoring-brief.md` ข้อกำหนดของบทเรียน topic.yaml ชนิดโจทย์ สื่อโต้ตอบ และการตรวจคำตอบ (ใช้ทั้งหมด ยกเว้นจำนวนโจทย์ ซึ่งใช้ตามไฟล์นี้)
2. `docs/phase7/enrichment-brief.md` ตัวอย่างแสดงวิธีทำ คำถามชวนคิด ภาพประกอบ และวิธีเรนเดอร์ภาพเพื่อตรวจ
3. `docs/authoring-guide.md` ส่วน "สื่อประกอบ" และ "ภาพประกอบ"
4. ตัวอย่างที่ทำครบแล้ว: `content/math/pythagoras/`, `content/health/nutrition/`, `content/management/qc-tools/` และหัวข้อในวิชาเดียวกับที่ได้รับมอบหมาย
5. แถวของหัวข้อในแผน: `grep -n "<รหัสหัวข้อ>" docs/phase6/proposals-*.yaml` ได้ทั้งแถว `topics:` (ชื่อ ความยาก prerequisite ตัวชี้วัด ขอบเขต) และแถว `extend:` ที่ผูกตัวชี้วัดเพิ่มจากหลักสูตรอื่น ข้อความของตัวชี้วัดดูได้ใน `curriculum/frameworks/<รหัสหลักสูตร>.yaml`

## ต่อหัวข้อ

- โฟลเดอร์ `content/<วิชา>/<ส่วนท้ายของรหัส>/` เช่น `biology.life.living-things` → `content/biology/living-things/` (ยกเว้นที่ระบุไว้ในงานมอบหมาย)
- `id`, `title`, `difficulty` ตามแผน `prerequisites` ตามแผน (ทุกตัวมีอยู่ในคลังแล้ว หรืออยู่ในชุดงานเดียวกัน) ถ้าคิดว่าควรต่างจากแผนให้เขียนไว้ในบันทึก ห้ามแก้เอง
- **ขอบเขตเนื้อหา = `scope` ในแผน + ข้อความของตัวชี้วัดทุกตัวที่ผูกกับหัวข้อ** (ทั้งแถว topics และ extend จากทุกไฟล์) บทเรียนและโจทย์ต้องสอนสิ่งที่ตัวชี้วัดเขียนไว้จริง ใช้ความรู้จากหลักสูตรต่างประเทศมาเสริมได้ตามที่เหมาะ
- รหัสโจทย์ใช้รหัสหัวข้อเต็มเป็น prefix: `biology.life.living-things.p001`, `.p002`, ...
- บทเรียน 500–1,000 คำ ภาษาไทยเป็นธรรมชาติ เหมาะกับระดับความยากของหัวข้อ (ความยาก 1–2 คือเด็กประถมต้นอ่านเข้าใจ ประโยคสั้น)
- โจทย์ **อย่างน้อย 15 ข้อ** ความยาก 1–5 ครบ ชนิดโจทย์อย่างน้อย 3 แบบ บริบทไทยอย่างน้อย 3 ข้อ คำใบ้ 2–3 ขั้น เฉลยเต็ม misconception จากความผิดพลาดจริง **คำนวณทุกตัวเลขด้วย python3**
- ตัวอย่างแสดงวิธีทำ (`worked-example`) 1–2 ตัวอย่าง คำถามชวนคิด (`check`) 1–2 ข้อ
- ภาพประกอบอย่างน้อย 1 ภาพต่อหัวข้อ เว้นแต่ภาพไม่ช่วยจริง (ให้เขียนเหตุผลในบันทึก) วาด SVG จากพิกัดที่คำนวณ แล้วเรนเดอร์เป็น PNG เปิดดูทุกภาพ ภาพในโจทย์ห้ามเฉลย
- แฟลชการ์ด 3–5 ใบ อภิธานศัพท์ และ `references` 2–4 ลิงก์ (วิกิพีเดียไทย/อังกฤษ OpenStax หรือแหล่งใน `curriculum/sources.yaml` ที่ `reuse: adapt` หรือ `link-only`) ตรวจว่าทุกลิงก์เปิดได้จริงและตรงเรื่อง
- `status: draft`, `ai_assisted: true`, `license: CC-BY-SA-4.0`, `authors: [ทีมคลังรู้]`

### เรื่องอ่อนไหว

สุขภาพ เพศศึกษา ยาเสพติด ความรุนแรง การปฐมพยาบาล: ให้ข้อมูลตรงตามหลักวิชาและแนวทางของกระทรวงสาธารณสุข เหมาะกับวัย ไม่ตีตรา และแนะนำให้ขอความช่วยเหลือจากผู้ใหญ่หรือบุคลากรทางการแพทย์ (สายด่วน 1669 เหตุฉุกเฉิน, 1323 สุขภาพจิต, 1300 ศูนย์ช่วยเหลือสังคม) ตัวเลขทางการแพทย์ต้องมีแหล่งที่ตรวจได้

## การจับคู่หลักสูตร `docs/phase8/mappings/<รหัสหัวข้อ>.yaml`

ทุกตัวชี้วัดที่แผนผูกกับหัวข้อต้องอยู่ในไฟล์นี้ ตัดสินตามสิ่งที่บทเรียนและโจทย์สอนจริง

```yaml
topic: biology.life.living-things
rows:
  - { framework: th-core-2560-science, indicators: ["ว 1.2 ป.1/1"], coverage: full }
  - { framework: au-ac9-science, indicators: ["AC9S1U01"], coverage: partial, note: "ยังไม่มี..." }
not_taught:
  - { ref: "uk-nc-science:UKNC-SC-Y1-2-WS-02", reason: "เป็นการทดลองจริงในห้องเรียน" }
```

**ห้ามแก้** `curriculum/`, `docs/phase6/`, `content/subjects.yaml` และโฟลเดอร์หัวข้อนอกชุดงาน ผู้ประสานงานจะนำไฟล์จับคู่ไปรวมและลบแถวออกจากแผนเอง
