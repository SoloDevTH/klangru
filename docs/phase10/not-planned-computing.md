# ตัวชี้วัดที่ไม่วางแผนหัวข้อ กลุ่ม computing (เฟส 10)

กลุ่มนี้มี university-foundations strand `programming` (OpenStax Introduction to Python Programming), `csta-k12-cs-2026` และ `acm-cs2023` ตัวชี้วัดที่หัวข้อเดิมสอนแล้ว (ส่วน ก) อยู่ใน `docs/phase10/existing-computing.yaml` และหัวข้อใหม่อยู่ใน `docs/phase6/proposals-phase10-computing.yaml`

ตัวชี้วัด PY และ acm-cs2023 ทุกข้อมีหัวข้อเดิมหรือหัวข้อใหม่รองรับ ไม่มีข้อที่ไม่วางแผน

## หมายเหตุสำหรับผู้เขียนหัวข้อ

- หัวข้อเสนอบางหัวข้อมีตัวชี้วัดที่ให้ผู้เรียน "สร้าง" "พัฒนา" หรือ "ถกเถียง" (เช่น S1-AIN-DD-03, S2-PHY-CI-04, HS-DAT-IM-28) บทเรียนสอนได้ด้วยโจทย์เขียนโค้ดที่จำลองระบบ หรือโจทย์ประเมินข้อโต้แย้ง แต่ถ้าเขียนแล้วยังไม่ครบตามที่มาตรฐานวัด ให้ผูกแบบ partial พร้อม note
- ตัวชี้วัดที่ต้องใช้ไลบรารีนอกไลบรารีมาตรฐาน (PY 15.2 NumPy, PY 15.3 Pandas, PY 15.5 การแสดงข้อมูล) สอนด้วยการอ่านและไล่โค้ดตัวอย่าง เพราะตัวรันในแอปไม่มีไลบรารีเหล่านี้ เมื่อเขียนแล้วอาจผูกได้เพียง partial
