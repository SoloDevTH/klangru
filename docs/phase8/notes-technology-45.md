## ความปลอดภัยในงานช่าง (materials-tools)

กฎในบทเรียนตรงกับแนวปฏิบัติทั่วไปของห้องปฏิบัติงานช่าง: แว่นตานิรภัยเมื่อเลื่อย เจาะ ตะไบ บัดกรี / มัดผม ไม่สวมเสื้อผ้าหลวมและเครื่องประดับ / **ไม่สวมถุงมือกับสว่านหรือเครื่องมือหมุน** / ยึดชิ้นงานด้วยปากกาจับหรือแคลมป์ / ตัดคัตเตอร์ออกจากตัวบนแผ่นรองตัดด้วยไม้บรรทัดเหล็ก / ถอดปลั๊กก่อนเปลี่ยนดอกสว่านหรือใบเลื่อย / หัวแร้งวางบนแท่น ระบายอากาศ ล้างมือ / ห้ามลัดวงจรแบตเตอรี่ลิเทียม / ไม่ต่อมอเตอร์เข้าขาไมโครคอนโทรลเลอร์โดยตรง ทุกงานอยู่ภายใต้การดูแลของครู ไม่ได้อ้างเอกสารมาตรฐานความปลอดภัยฉบับใด **ควรให้ครูการออกแบบและเทคโนโลยีตรวจ** ว่าตรงกับคู่มือห้องปฏิบัติการของ สสวท.
