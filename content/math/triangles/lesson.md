## ทำไมโครงหลังคาจึงเป็นสามเหลี่ยม

ลองเอาไม้ไอศกรีมสี่อันมาตอกหมุดที่มุมให้เป็นสี่เหลี่ยม แล้วกดที่มุมเบา ๆ กรอบจะบิดเป็นรูปเอียงได้ทันที แต่ถ้าใช้ไม้สามอันทำเป็นสามเหลี่ยม กดอย่างไรรูปร่างก็ไม่เปลี่ยน เพราะเมื่อกำหนดความยาวทั้งสามด้านแล้ว สามเหลี่ยมมีรูปร่างได้แบบเดียว นี่คือเหตุผลที่โครงหลังคาบ้าน โครงสะพานเหล็ก และเสาไฟฟ้าแรงสูง ใช้สามเหลี่ยมเป็นโครงสร้างหลัก

## ชนิดของรูปสามเหลี่ยม

**แบ่งตามด้าน**

- **สามเหลี่ยมด้านเท่า** ด้านยาวเท่ากันทั้งสามด้าน มุมทุกมุมเป็น $60^\circ$
- **สามเหลี่ยมหน้าจั่ว** ด้านยาวเท่ากันสองด้าน มุมที่ฐานสองมุมเท่ากัน
- **สามเหลี่ยมด้านไม่เท่า** ไม่มีด้านใดยาวเท่ากัน

**แบ่งตามมุม**

- **สามเหลี่ยมมุมแหลม** มุมทุกมุมเป็นมุมแหลม
- **สามเหลี่ยมมุมฉาก** มีมุมหนึ่งเป็น $90^\circ$
- **สามเหลี่ยมมุมป้าน** มีมุมหนึ่งเป็นมุมป้าน

## ผลบวกมุมภายในเท่ากับ 180 องศา

ลากเส้นผ่านจุดยอดบนสุดของสามเหลี่ยมให้ขนานกับฐาน มุมสองมุมที่ฐานจะเป็น **มุมแย้ง** กับมุมสองมุมบนเส้นใหม่ เมื่อรวมกับมุมยอดจะได้มุมบนเส้นตรงพอดี ดังนั้นสำหรับสามเหลี่ยมทุกรูป

$$\angle A + \angle B + \angle C = 180^\circ$$

ผลที่ตามมาคือ สามเหลี่ยมมีมุมฉากหรือมุมป้านได้ไม่เกินหนึ่งมุม

## มุมภายนอก

ถ้าต่อด้าน $BC$ ของสามเหลี่ยม $ABC$ ออกไปทางจุด $D$ จะเกิด **มุมภายนอก** $\angle ACD$ เพราะ $\angle ACB + \angle ACD = 180^\circ$ (มุมบนเส้นตรง) และ $\angle A + \angle B + \angle ACB = 180^\circ$ จึงได้

$$\angle ACD = \angle A + \angle B$$

มุมภายนอกเท่ากับผลบวกของมุมภายในสองมุมที่อยู่ไกลจากมัน (ไม่ใช่มุมที่อยู่ติดกัน)

### ตัวอย่างที่ 1: สามเหลี่ยมหน้าจั่ว

สามเหลี่ยมหน้าจั่วมีมุมที่ฐานมุมหนึ่งเป็น $50^\circ$ มุมยอดมีขนาดเท่าใด

1. มุมที่ฐานเท่ากัน จึงมีมุมที่ฐานสองมุม มุมละ $50^\circ$
2. มุมยอด $= 180^\circ - 50^\circ - 50^\circ = 80^\circ$

### ตัวอย่างที่ 2: มุมภายนอก

มุมภายนอกที่จุด $C$ มีขนาด $130^\circ$ และ $\angle A = 70^\circ$ จงหา $\angle B$

1. มุมภายนอกเท่ากับผลบวกของมุมภายในที่ไม่ใช่มุมประชิด: $130^\circ = 70^\circ + \angle B$
2. $\angle B = 60^\circ$
3. ตรวจ: $\angle ACB = 180^\circ - 130^\circ = 50^\circ$ และ $70^\circ + 60^\circ + 50^\circ = 180^\circ$ ✓

## ความเท่ากันทุกประการ

สามเหลี่ยมสองรูป **เท่ากันทุกประการ** ($\triangle ABC \cong \triangle DEF$) เมื่อยกรูปหนึ่งไปทับอีกรูปได้สนิท ไม่ต้องวัดครบทั้ง 6 ส่วน ใช้แค่ 3 ส่วนตามเงื่อนไขต่อไปนี้ก็พอ

| เงื่อนไข | สิ่งที่ต้องเท่ากัน |
|---|---|
| ด.ม.ด. | ด้านสองด้านและมุมที่อยู่ **ระหว่าง** ด้านทั้งสอง |
| ม.ด.ม. | มุมสองมุมและด้านที่อยู่ **ระหว่าง** มุมทั้งสอง |
| ด.ด.ด. | ด้านทั้งสามด้าน |
| ม.ม.ด. | มุมสองมุมและด้านที่ไม่ได้อยู่ระหว่างมุมทั้งสอง |
| ฉ.ด.ด. | สามเหลี่ยมมุมฉาก ด้านตรงข้ามมุมฉากและด้านอีกหนึ่งด้าน |

เงื่อนไขที่ **ใช้ไม่ได้** คือ ม.ม.ม. (สามเหลี่ยมอาจรูปร่างเหมือนกันแต่ขนาดต่างกัน) และ ด.ด.ม. ที่มุมไม่ได้อยู่ระหว่างด้าน (อาจวาดได้สองรูปที่ต่างกัน)

### ตัวอย่างที่ 3: เลือกเงื่อนไข

สามเหลี่ยม $ABC$ และ $PQR$ มี $AB = PQ$, $\angle A = \angle P$ และ $\angle B = \angle Q$ ด้าน $AB$ อยู่ระหว่างมุม $A$ กับมุม $B$ พอดี จึงเท่ากันทุกประการแบบ ม.ด.ม.

## ข้อผิดพลาดที่พบบ่อย

- **ใช้ $360^\circ$ แทน $180^\circ$** ผลบวกมุมภายในของสามเหลี่ยมคือ $180^\circ$ ส่วน $360^\circ$ เป็นของรูปสี่เหลี่ยม
- **ลืมว่ามุมที่ฐานของสามเหลี่ยมหน้าจั่วมีสองมุม** ต้องลบมุมยอดจาก $180^\circ$ แล้วหารสอง
- **สับสนมุมภายนอกกับมุมภายในที่อยู่ติดกัน** มุมภายนอกเท่ากับผลบวกของมุมภายในสองมุมที่อยู่ไกล ส่วนมุมภายในที่อยู่ติดกันรวมกับมุมภายนอกได้ $180^\circ$
- **ใช้ ม.ม.ม. หรือ ด.ด.ม. ยืนยันความเท่ากันทุกประการ** สองเงื่อนไขนี้ไม่เพียงพอ
