# เฟส 6: ขยายคลังให้ครอบคลุมหลักสูตร

กราฟความรู้ของคลังรู้รวมหลักสูตรไทยกับหลักสูตรต่างประเทศเข้าด้วยกัน ไม่ได้ยึดหลักสูตรฉบับใดฉบับหนึ่ง แผนนี้มาจากการเทียบคลังกับหลักสูตร 38 ฉบับใน `curriculum/` (5,570 ตัวชี้วัด) ทั้งหลักสูตรแกนกลางของไทย Australian Curriculum V9.0, England National Curriculum, Common Core, NGSS, CSTA, CEFR, HSK และองค์ความรู้ระดับมหาวิทยาลัย แล้วจัดตัวชี้วัดที่ยังไม่มีหัวข้อสอนเป็นหัวข้อในกราฟ หัวข้อหนึ่งจึงรับตัวชี้วัดจากหลายหลักสูตร และไม่ได้แบ่งตามชั้นเรียน (ADR 0002)

`extend:` ในไฟล์ใช้ผูกตัวชี้วัดเพิ่มให้หัวข้อที่เสนอไว้ในไฟล์อื่น เพื่อไม่ให้เกิดหัวข้อซ้ำ เช่น ชีววิทยาระดับมหาวิทยาลัยใช้หัวข้อเดียวกับรายวิชาเพิ่มเติม ม.ปลาย และตัวชี้วัดของออสเตรเลีย อังกฤษ และสหรัฐฯ ส่วนใหญ่ผูกกับหัวข้อที่มาจากหลักสูตรไทย (`proposals-international.yaml` มี extend 187 แถว และสร้างหัวข้อใหม่เพียง 40 หัวข้อสำหรับเนื้อหาที่ไม่มีที่อื่น เช่น การสุ่มตัวอย่าง ความน่าจะเป็นแบบมีเงื่อนไข ข้อมูลสองตัวแปร เครือข่าย การออกแบบการทดลอง และปัญญาประดิษฐ์) extend ผูกได้เฉพาะหัวข้อในแผน ตัวชี้วัดที่หัวข้อซึ่งเขียนแล้วในคลังสอนต้องเพิ่มใน `curriculum/mappings/`

แผนมีวิชาที่ยังไม่มีในคลัง 5 วิชา คือ `biology` `earthscience` `engineering` `technology` และ `science` (6 หัวข้อ ทักษะกระบวนการทางวิทยาศาสตร์ การออกแบบการทดลอง และธรรมชาติของวิทยาศาสตร์ ซึ่งใช้ร่วมกันทุกสาขา) เมื่อเขียนหัวข้อแรกของวิชาใดให้เพิ่มวิชานั้นใน `content/subjects.yaml` ก่อน

`engineering.computing.programming-basics` เดิมซ้อนกับวิชาคอมพิวเตอร์ จึงรวมเข้ากับ `computer.programming.functions` ด้วย extend ใน `proposals-advanced.yaml`

## ถ้าเขียนครบตามแผน

- หลักสูตรแกนกลางไทยทุกฉบับครอบคลุมครบ ยกเว้น เคมี 3 ม.6/4 (เข้าร่วมสัมมนาหรือนิทรรศการ ทำในแอปไม่ได้) สุขศึกษาและพลศึกษา 25 ตัวชี้วัด (ทักษะการเคลื่อนไหวที่ต้องปฏิบัติจริง) และการงานอาชีพ 35 ตัวชี้วัด
- Australian Curriculum Mathematics และ Digital Technologies, England National Curriculum mathematics และ computing, Common Core, NGSS และ CSTA ครอบคลุมครบ
- AC9 Science เหลือ 9 และ UK NC science เหลือ 8 ตัวชี้วัด ซึ่งเป็นการลงมือสังเกต วัด และใช้อุปกรณ์จริง (รายการอยู่ในหัวไฟล์ `proposals-international.yaml`)
- AC9 HPE และ AC9 Economics and Business ยังไม่ได้วางแผนให้ครอบคลุม (เหลือ 95 และ 20) เนื้อหาส่วนใหญ่ใกล้กับหัวข้อใน `proposals-health.yaml` และ `proposals-business.yaml` แต่ยังไม่ได้ผูกรหัส
- CEFR ครอบคลุม A1–B1, HSK ระดับ 1–3 (ระดับสูงกว่านั้นยังไม่วางแผน)
- องค์ความรู้สภาวิศวกรและวิชาพื้นฐานมหาวิทยาลัยครอบคลุมเฉพาะแกนที่ใช้ร่วมกันทุกสาขา วิชาเฉพาะสาขายังไม่วางแผน

## ใช้งาน

```bash
npm run plan                  # ตรวจแผน (รวมอยู่ใน npm run validate แล้ว) และดูความครอบคลุมหลังทำตามแผน
npm run plan -- --order       # ลำดับหัวข้อที่ควรเขียน เรียงตามกราฟรวมของคลังและแผน
npm run curriculum -- --missing   # ตัวชี้วัดที่คลังปัจจุบันยังไม่สอน
```

ตัวตรวจบังคับว่ารหัสหัวข้อไม่ซ้ำ prerequisite มีอยู่จริงในคลังหรือในแผน ไม่มีวงวน และรหัสตัวชี้วัดทุกตัวมีอยู่ในหลักสูตร

เมื่อเริ่มเขียนหัวข้อใด ให้ย้ายแถวนั้นออกจากไฟล์แผน สร้างโฟลเดอร์ตาม `docs/authoring-guide.md` แล้วเพิ่มแถวใน `curriculum/mappings/` ตามตัวชี้วัดที่บทเรียนและโจทย์สอนได้จริง

## ข้อควรระวัง

- ชื่อและขอบเขตของหัวข้อร่างโดย AI จากตัวชี้วัด ครูผู้เชี่ยวชาญควรตรวจการแบ่งหัวข้อและลำดับก่อนเริ่มเขียน
- รหัสตัวชี้วัดของรายวิชาเพิ่มเติม องค์ความรู้สภาวิศวกร และ England National Curriculum (UKNC-*) เป็นรหัสที่เราตั้ง เพราะต้นฉบับไม่มีรหัส (ข้อความยังตรงต้นฉบับ)
- ระดับความยาก (1–10) เทียบกับหัวข้อที่มีอยู่โดยประมาณ ปรับได้เมื่อเขียนจริง
