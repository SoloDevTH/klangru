## ไฟประดับกับปลั๊กไฟในบ้าน

ไฟประดับราคาถูกบางชุด ถ้าหลอดขาดเพียงดวงเดียว ทั้งสายจะดับหมด แต่ในบ้าน ถ้าหลอดไฟในห้องครัวขาด พัดลมและทีวียังทำงานได้ตามปกติ ความต่างนี้มาจากวิธี **ต่อ** อุปกรณ์ แบบแรกคือ **อนุกรม** แบบหลังคือ **ขนาน**

## การต่อแบบอนุกรม

อุปกรณ์ต่อเรียงกันเป็นทางเดียว ประจุต้องผ่านทุกตัวตามลำดับ

- **กระแสเท่ากันทุกตัว** $I = I_1 = I_2$
- **ความต่างศักย์แบ่งกัน** $V = V_1 + V_2$
- **ความต้านทานรวม** $R = R_1 + R_2 + \dots$ มากกว่าตัวที่มากที่สุดเสมอ

ตัวต้านทานที่มากกว่าได้ความต่างศักย์ส่วนที่มากกว่า เรียกว่า **การแบ่งแรงดัน**

$$V_1 = \frac{R_1}{R_1 + R_2}\,V$$

## การต่อแบบขนาน

อุปกรณ์แต่ละตัวต่อคร่อมจุดสองจุดเดียวกัน กระแสแยกไหลได้หลายทาง

- **ความต่างศักย์เท่ากันทุกตัว** $V = V_1 = V_2$
- **กระแสแยกกันแล้วรวมกัน** $I = I_1 + I_2$
- **ความต้านทานรวม** หาจาก

$$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \dots$$

ถ้ามีสองตัว ใช้สูตรลัดได้ $R = \dfrac{R_1 R_2}{R_1 + R_2}$ ความต้านทานรวมแบบขนาน **น้อยกว่าตัวที่น้อยที่สุด** เสมอ เพราะการเพิ่มทางเดินทำให้กระแสไหลได้ง่ายขึ้น

กระแสจะเลือกไหลผ่านทางที่ความต้านทานน้อยกว่ามากกว่า เรียกว่า **การแบ่งกระแส** สำหรับสองทาง

$$I_1 = \frac{R_2}{R_1 + R_2}\,I$$

สังเกตว่าตัวเศษเป็นความต้านทานของ **อีกทางหนึ่ง**

| | อนุกรม | ขนาน |
|---|---|---|
| ปริมาณที่เท่ากันทุกตัว | กระแส | ความต่างศักย์ |
| ปริมาณที่แบ่งกัน | ความต่างศักย์ | กระแส |
| ความต้านทานรวม | มากกว่าตัวที่มากที่สุด | น้อยกว่าตัวที่น้อยที่สุด |
| ถ้าตัวหนึ่งขาด | ทั้งวงจรหยุด | ทางอื่นยังทำงาน |

### ตัวอย่างที่ 1: วงจรอนุกรม

ตัวต้านทาน $3\ \Omega$ และ $9\ \Omega$ ต่ออนุกรมกับแบตเตอรี่ $6\ \mathrm{V}$

1. ความต้านทานรวม: $R = 3 + 9 = 12\ \Omega$
2. กระแส: $I = \dfrac{6\ \mathrm{V}}{12\ \Omega} = 0.5\ \mathrm{A}$ เท่ากันทั้งสองตัว
3. ความต่างศักย์: $V_1 = (0.5)(3) = 1.5\ \mathrm{V}$ และ $V_2 = (0.5)(9) = 4.5\ \mathrm{V}$
4. ตรวจ: $1.5 + 4.5 = 6\ \mathrm{V}$ ✓

### ตัวอย่างที่ 2: วงจรขนาน

ตัวต้านทาน $4\ \Omega$ และ $12\ \Omega$ ต่อขนานกับแบตเตอรี่ $12\ \mathrm{V}$

1. ทั้งสองตัวได้ $12\ \mathrm{V}$ เต็ม: $I_1 = \dfrac{12}{4} = 3\ \mathrm{A}$ และ $I_2 = \dfrac{12}{12} = 1\ \mathrm{A}$
2. กระแสรวม $I = 3 + 1 = 4\ \mathrm{A}$
3. ตรวจด้วยความต้านทานรวม: $R = \dfrac{4 \times 12}{4 + 12} = 3\ \Omega$ และ $\dfrac{12\ \mathrm{V}}{3\ \Omega} = 4\ \mathrm{A}$ ✓

## วงจรผสม

วงจรที่มีทั้งอนุกรมและขนาน ให้ยุบทีละส่วนจากข้างใน

1. หาความต้านทานรวมของกลุ่มที่ต่อขนาน
2. รวมกับตัวที่ต่ออนุกรม ได้ความต้านทานรวมทั้งวงจร
3. หากระแสรวมจาก $I = \dfrac{V}{R}$
4. ย้อนกลับหาความต่างศักย์และกระแสของแต่ละตัว

### ตัวอย่างที่ 3

ตัวต้านทาน $5\ \Omega$ ต่ออนุกรมกับกลุ่มขนานของ $4\ \Omega$ และ $12\ \Omega$ ทั้งหมดต่อกับ $16\ \mathrm{V}$

1. กลุ่มขนาน: $\dfrac{4 \times 12}{16} = 3\ \Omega$ รวมทั้งวงจร $5 + 3 = 8\ \Omega$
2. กระแสรวม: $I = \dfrac{16}{8} = 2\ \mathrm{A}$
3. ความต่างศักย์คร่อมกลุ่มขนาน: $(2\ \mathrm{A})(3\ \Omega) = 6\ \mathrm{V}$ (อีก $10\ \mathrm{V}$ ตกคร่อม $5\ \Omega$)
4. กระแสแยก: $\dfrac{6}{4} = 1.5\ \mathrm{A}$ และ $\dfrac{6}{12} = 0.5\ \mathrm{A}$ รวมได้ $2\ \mathrm{A}$ ✓

## แผนภาพวงจรและกฎสองข้อที่ใช้ได้ทุกวงจร

นักวิทยาศาสตร์และช่างไฟทั่วโลกเขียนวงจรด้วย **สัญลักษณ์มาตรฐาน** (ดูภาพสัญลักษณ์ในบทเรียน) เส้นตรงคือสายไฟ ซึ่งถือว่าไม่มีความต้านทาน แอมมิเตอร์ต่อ **อนุกรม** ในทางที่ต้องการวัดกระแส ส่วนโวลต์มิเตอร์ต่อ **คร่อม** (ขนานกับ) อุปกรณ์ที่ต้องการวัดความต่างศักย์

กฎสองข้อนี้เป็นที่มาของสูตรอนุกรมและขนานทั้งหมด

1. **กฎของจุดต่อ:** กระแสที่ไหลเข้าจุดต่อ = กระแสที่ไหลออก เพราะประจุไม่ได้หายไปหรือเกิดขึ้นใหม่ที่จุดต่อ
2. **กฎของวงปิด:** เดินรอบวงปิดหนึ่งรอบ ผลรวมความต่างศักย์ที่ตกคร่อมอุปกรณ์ทั้งหมด = ความต่างศักย์ของแบตเตอรี่ เพราะพลังงานที่ประจุได้จากแบตเตอรี่ถูกใช้ไปจนหมดเมื่อกลับมาถึงจุดเดิม

## ความสว่างของหลอดไฟและการลัดวงจร

หลอดไฟยิ่งมีกระแสผ่านมาก (หรือมีความต่างศักย์คร่อมมาก) ยิ่งสว่าง เวลาวงจรเปลี่ยน ให้คิดตามลำดับ: ความต้านทานรวมเปลี่ยนอย่างไร → กระแสรวมเปลี่ยนอย่างไร → ความต่างศักย์ของแต่ละส่วนเปลี่ยนอย่างไร

**การลัดวงจร** คือการมีลวดที่แทบไม่มีความต้านทานต่อคร่อมอุปกรณ์ กระแสเกือบทั้งหมดจะไหลผ่านลวดแทน อุปกรณ์ที่ถูกลัดจึงดับ ความต้านทานรวมลดลง และกระแสรวมพุ่งสูง ถ้าลัดคร่อมแบตเตอรี่โดยตรง สายไฟจะร้อนจัดจนเป็นอันตราย

## วงจรไฟฟ้าในบ้าน

ไฟบ้านในประเทศไทยมีความต่างศักย์ $220\ \mathrm{V}$ เต้ารับและเครื่องใช้ไฟฟ้าทุกเครื่องต่อ **ขนาน** กัน ทุกเครื่องจึงได้ $220\ \mathrm{V}$ เต็ม สวิตช์ของแต่ละเครื่องต่อ **อนุกรม** กับเครื่องนั้น ส่วนเบรกเกอร์หรือฟิวส์ต่ออนุกรมกับสายเมน ทุกครั้งที่เปิดเครื่องเพิ่ม ความต้านทานรวมลดลง กระแสรวมจึงเพิ่มขึ้น ถ้าเปิดพร้อมกันหลายเครื่องจนกระแสเกินพิกัด เบรกเกอร์จะตัดไฟเพื่อป้องกันสายไฟร้อนจนเกิดไฟไหม้

## ข้อผิดพลาดที่พบบ่อย

- **ลืมกลับเศษส่วน** หลังบวก $\tfrac{1}{R_1} + \tfrac{1}{R_2}$ ผลที่ได้คือ $\tfrac{1}{R}$ ยังต้องกลับเป็น $R$
- **บวกความต้านทานที่ต่อขนาน** เหมือนอนุกรม ความต้านทานขนานต้องน้อยลง ไม่ใช่มากขึ้น
- **คิดว่าความต่างศักย์แบ่งเท่ากันในวงจรอนุกรม** ตัวที่ความต้านทานมากกว่าได้ความต่างศักย์มากกว่า
- **แบ่งกระแสกลับด้าน** ทางที่ความต้านทานน้อยกว่าได้กระแสมากกว่า
- **ใช้ความต่างศักย์ของแบตเตอรี่ทั้งหมดกับตัวต้านทานในวงจรผสม** ต้องหาความต่างศักย์คร่อมส่วนนั้นจริง ๆ ก่อน
- **คิดว่ากระแส "ถูกใช้หมด" ระหว่างทาง** กระแสที่ไหลกลับเข้าแบตเตอรี่เท่ากับกระแสที่ไหลออกเสมอ สิ่งที่ถูกใช้คือพลังงาน ไม่ใช่ประจุ
